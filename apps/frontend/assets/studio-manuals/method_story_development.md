# 故事开发方法：单集定位与结构思考

供**原创、续作**的剧本生成使用：动笔前想清本集在全剧中的坐标、戏剧功能、情绪任务与钩子落点。本方法是**内部思考工具**——按它推演，但**不输出执行过程**（不在剧本中复述定位分析、节拍推演或决策记录），也**不是审批清单**——不新增制作阶段或确认关口。思考结论只体现为剧本头部三行与场次正文本身。

## 1. 结构总纲：单线推进，大小三角嵌套

- 主流结构为**单线型**：情节围绕单条主线推进，矛盾集中、节奏连贯；短剧多线并行易被弃剧。
- **大三角**：3 个核心角色/势力构成全剧主要矛盾，贯穿始终不可轻易改动。
- **小三角**：围绕主角的次要矛盾，解决一个再进下一个，避免同时铺多条。

## 2. 本集定位：三幕坐标与节奏阶段

按总集数 N 确定本集坐标，只做定位，不虚构其他集剧情：

- **所属幕**：约前 30% 为第一幕、中 40% 为第二幕、后 30% 为第三幕。
- **节奏阶段**：对照下方类型框架，判定本集所处阶段（如「误会拉扯升温期」）。

前 10 集黄金结构（本集集序落在其中时对照）：

| 集数 | 核心任务 |
|------|----------|
| 第1-2集 | 快速引入主角，直接抛强冲突（契约绑定、意外变故），一秒入坑 |
| 第3-4集 | 明确主角核心行动目标（复仇/追爱/逆袭），埋伏笔 |
| 第5-8集 | 引入多方配角施压，强化矛盾 |
| 第9-10集 | 假付费点（目标近在咫尺却落空）+ 正式卡点，推向小高潮 |

微短篇：卡点整体提前至第 6-7 集，第 1 集需承载常规短剧 3-4 集的信息量。

热门类型节奏框架（按总集数 N 的百分比，集数四舍五入）：

| 类型 | 节奏骨架 |
|------|----------|
| 甜宠 | 契约绑定（第1集）→误会拉扯→秘密曝光（≈10%）→情感破冰→危机爆发（≈30%）→撒糖打脸→新危机（≈60%）→确认心意→圆满 |
| 虐恋 | 前期误会伤害（1-20%）→男主悔悟（21-40%）→追妻受阻（41-70%）→悔改和解（71-100%） |
| 萌宝 | 带娃回归逆袭→男主发现孩子解心结→联手反击反派→家庭团圆 |
| 战神 | 隐藏身份受辱（1-30%）→身份曝光打脸（31-60%）→解决核心危机→登顶巅峰 |
| 重生 | 前世被害（第1集）→重生改命→信息差逆袭（31-70%）→复仇圆满 |

## 3. 本集戏剧功能与故事核

- **戏剧功能**（六选一）：建立 / 发展 / 高潮前积累 / 高潮+余波 / 新世界建立 / 新高潮+开放结局。
- **核心问题**：本集要让观众追问什么，一个问题说清。
- **故事核**：一句话 ≤50 字，本集对全剧核心吸引力的承载。
- **隐线推进**：本集如何推进主角人物弧——被 X 定义为 Y → 用 Y 的方式做成 Z → 发现 Y 本身是 W。
- **场景核心**：一句话——这集要给观众什么体验。

## 4. 付费卡点判定

按总集数 N 的比例判定本集是否命中卡点位（四舍五入取整；未命中的集**不硬造**付费点）：

| 位置 | 卡点 | 设计要求 |
|------|------|----------|
| ≈10% | 首次 | 核心矛盾升级（秘密将曝光、关系面临破裂） |
| ≈30% | 二次 | 生死危机、秘密将揭露或遭陷害，强情感冲击 |
| ≈50% | 中期 | 阶段目标达成时重大反转 |
| ≈70% | 后期 | 悬念伏笔展开，引入重大翻转 |
| ≈90% | 收尾 | 揭露阴谋、圆满结局（短剧必保爽剧收尾） |

- **付费点 5 标准**：选关键瞬间（强烈情绪冲击）；设根本性改变（性格/价值观/行为方式）；调好奇心（暗示、伏笔、悬念）；用高燃场景（高潮处戛然而止）；感情流围绕情感阶段转变（无感→好感→醒悟→确认→表白）。
- **核心特征**：场面宏大、事态紧急、围观者众（宴会、认亲、发布会、婚礼）。
- **假付费点**：可多次设置，让观众误以为目标将成实则受阻。
- **四类写法**：身份差（通用）；感情错位（女频）；人物命运巨变（被打压→机缘→反击）；环境剧变（末世）。
- **卡点集素材**：关系类（反目/复燃/断绝/宣布婚事/霸气护妻）；冲突类（陷害/产业被占/揭发）；真相变故类（亲子鉴定/假传死讯/被控入狱）；行动类（请君入瓮/忍辱负重/一夜成名）。

## 5. 全局情绪布局

按付费点比例划分阶段（以复仇类为例，可迁移其他题材）：

| 阶段 | 集数范围 | 核心情绪 | 作用 |
|------|----------|----------|------|
| 铺垫 | 1%-10% | 压抑+愤怒 | 拉仇恨，让观众期待反击 |
| 试探 | 11%-30% | 紧张+小爽 | 给小甜头，留住注意力 |
| 转折 | 31%-50% | 震惊+焦虑 | 制造大波澜，提升期待 |
| 爆发 | 51%-70% | 爽感+解气 | 情绪高潮，释放积压压抑 |
| 收尾 | 71%-100% | 温暖+圆满 | 收尾情绪，留正面印象 |

类型基调占比：甜宠=甜60+微虐30+惊喜10；复仇=压抑40+爽感50+解气10；重生逆袭=爽感50+期待30+温暖20；家庭伦理=共情40+委屈30+和解30。

## 6. 信息差设计

标定本集采用的信息差类型，操控观众情绪：

- **主角知+配角不知+观众知**：观众拥有先知爽感，期待配角被打脸。
- **主角不知+配角知+观众知**：观众为身处险境的主角焦急，代入感极强。
- **主角配角都不知+观众知**：观众想指导主角又好奇反派结局，期待感拉满。

## 7. 集末钩子

- 每集结尾必留钩子，勾住下一集情绪。
- 紧扣三者之一：主角的下一步行动 / 反派的反击 / 第三方的态度。
- 类型：智识钩子 / 悬念钩子 / 情感钩子 / 世界观钩子。
- 检验标准：观众有「想立刻知道后续」的冲动。
