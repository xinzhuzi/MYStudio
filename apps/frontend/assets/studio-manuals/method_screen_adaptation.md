# 剧本改编方法：小说转短剧的取舍思考

供**小说改编**的剧本生成使用：把本章原文转成短剧剧本前，想清保什么、删什么、人物与基调怎么处理。本方法是**内部思考工具**——按它做删减与改编决策，但**不输出执行过程**（决策直接体现在剧本正文与尾部改编追踪表，不复述分析），也**不是审批清单**——不新增制作阶段或确认关口。

## 1. 改编七要点（一切决策的基准）

1. **强画面感**：所有保留内容必须能转化为镜头语言，拍不出来就换表达方式。
2. **台词精简**：剔除冗余，每句台词服务于剧情推进或人物塑造；身份、过往、纠葛等背景信息优先用台词带出。
3. **节奏极致快**：每个画面都拉升情绪，可适当牺牲细微逻辑保证紧凑。
4. **只沿主线展开**：砍掉支线，仅保留核心人设与高光时刻。
5. **降低理解成本**：世界观不复杂，听台词就能掌握核心剧情，漏看部分不影响理解。
6. **情绪大于一切**：核心是饱满强烈的情绪体验；逻辑与情绪冲突时优先情绪张力。
7. **开篇给足期待感**：第 1 集即呈现激烈、高情绪张力场景，后续围绕开篇建立的期待展开。

## 2. 删减决策优先级

**优先删除**：节奏拖沓的铺垫（不推主线的环境描写、日常闲聊）；信息密度低的重复（同类冲突不可重复呈现）；载体不支持的内容（大段心理描写、复杂设定说明）；主线贡献弱的支线（不影响结局的人物关系与事件）。

**优先保留**：本集核心情绪点（爆点/虐点/爽点至少覆盖一个）；人物关系拉扯场景（关系越紧密虐感越强）；付费点前的情绪铺垫链（压抑→爆发的完整弧线）；身份反差与信息差场景（核心爽感来源：观众先知适合逆袭/战神/赘婿，观众焦急适合虐恋/悬疑，观众上帝适合寻亲/身份错位）；高光打脸时刻与反转节点。

**替代手段**：蒙太奇压缩（多场过渡戏并成快切）；台词带过（一句话交代整场戏的信息）；完全删除（无主线贡献且无情绪点）。

每项删减归入四类理由之一：节奏拖沓 / 信息密度低 / 载体不支持 / 主线贡献弱。

## 3. 人物弧光与塑造

- **弧光必有锚点**：初始状态 → 关键变故 → 性格转变 → 最终状态，转变须有事件支撑；主角与重要配角必须有弧光。
- **行动塑造**：不同性格角色面对同一困境反应须有差异，行动线与性格强绑定。
- **设定记忆点**：为重要角色保留专属细节（口音、下意识动作、特殊怪癖、独门技能）。
- **人物推动剧情**：是「人物引导剧情」而非「人物套进预设剧情」，人设差异本身是推进动力。

## 4. 类型基调锁定

| 类型 | 核心基调 | 占比参考 |
|------|----------|----------|
| 甜宠 | 甜＞微虐＞惊喜 | 甜60+微虐30+惊喜10 |
| 复仇 | 压抑＞爽感＞解气 | 压抑40+爽感50+解气10 |
| 重生逆袭 | 爽感＞期待＞温暖 | 爽感50+期待30+温暖20 |
| 家庭伦理 | 共情＞委屈＞和解 | 共情40+委屈30+和解30 |

**基调一旦确定不中途大幅更改**——甜宠剧突加「全家惨死」级虐心会令观众出戏弃剧。

## 5. 短剧语言规范

- 现代剧用「家主」代指家族掌权人，「执法局/执法人」代指公安/警察；禁用「市长」「县长」等实际称呼，改为「市首」「总督」。
- 财富表达可突破现实货币体系（「亿元」「百亿订单」等夸张表述）营造爽感。
- 台词一律口语化，禁用半文半白、文言文、生词冷词。
