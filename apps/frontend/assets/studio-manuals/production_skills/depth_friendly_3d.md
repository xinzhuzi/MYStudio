# 3D 纵深构图 · 通用生图技法（2.5D 渲染管线必需）

> **本手册是纵深友好提示词的唯一真相源**：代码不写死任何 token，分镜生图与 AI 首帧撰写均从本文件解析。
> 分镜帧图会进入「深度估计 → 2.5D 相机运镜」管线（35 种运镜）。图内的深度结构质量直接决定成片视差质量。

---

## 一、原理（为什么提示词要按 3D 写）

```
分镜帧图 → 深度估计模型逐像素推断远近 → 深度图 → 浮雕式 2.5D 网格 → 3D 相机运镜产生视差
```

深度估计模型靠图内**深度线索**工作。三层分离清晰的图 → 视差干净利落；平面海报式构图 → 运镜即"整张皮在晃"。

## Depth-Friendly Composition (2.5D 渲染必需)
生成的首帧/尾帧提示词必须内置以下纵深结构（这些图之后会做深度估计 + 3D 相机运镜）:
- **三层分离**: 构图描述中明确前景(遮挡元素)、中景(主体)、背景(环境)三个层次
- **近景遮挡**: 尽量为画面安排伸入画框的前景元素(树枝/门框/廊柱/人物肩背), 是视差感的最大放大器
- **透视引导**: 有条件时纳入道路/走廊/街道/河流等引导线与消失点
- **大气透视**: 远景淡化处理形成近实远虚的色彩分离（注意与画质禁用词协调：主体保持锐利，仅远景层淡化）
- **全画面清晰**: 描述中要求"全画面清晰/深景深"，绝不要求背景虚化 — 景深由渲染阶段按深度图施加，源图虚化会毁掉深度边缘
- **轮廓分离**: 主体与背景要有明确的明度/色彩/虚实边界，避免主体融入背景
- **禁止**: 正面平面化构图、海报式平涂背景、大面积无结构空墙
<!-- depth-guide:end -->

## 四、手写提示词速查

**加这些（按效果排序）**：

| 中文 | 作用 |
|---|---|
| 前景伸入画面的树枝/门框/廊柱/肩背 | 视差放大器，效果最猛 |
| 前景、中景、背景三层分明 | 视差的根本 |
| 道路/走廊延伸至消失点 | 透视引导线，深度估计最爱 |
| 远景淡化（大气透视） | 天然深度标注（主体保持锐利） |
| 全画面清晰、深景深 | 关键 — 景深由渲染阶段施加 |
| 主体轮廓与背景明暗分明 | 深度边缘干净 |

**避免这些**：

- 正面平面化构图（证件照式）、海报式平涂背景
- 源图要求"背景虚化/浅景深" — 毁掉深度边缘
- 大面积无结构区域（空墙、纯色平天空）
- 镜面、玻璃、半透明物体 — 深度估计错乱
- `hazy`/`foggy` 全图雾化 — 见通用禁用词表
