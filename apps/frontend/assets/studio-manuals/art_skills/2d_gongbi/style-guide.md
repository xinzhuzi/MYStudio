## 1. 工笔画是什么？
## 1. What Is Chinese Gongbi Painting?

**工笔｜Gongbi** 是中国传统绘画的重要表现方式之一，强调严谨、细致、精确的线描，以及层层设色形成的细腻视觉效果。

**核心不是“画得很细”，而是“精谨而有秩序”。**

> **Gongbi is not simply “highly detailed Chinese painting.”**  
> It is a coordinated visual system built around precise linework, layered pigments, elegant forms, decorative order, and controlled composition.

### 工笔的核心公式｜Core Formula

```text
工笔 = 精谨线描 × 层染设色 × 东方造型 × 装饰秩序 × 留白构图 × 传统材质
Gongbi = Precise Linework × Layered Pigments × Classical Chinese Form × Decorative Order × Negative Space × Traditional Materiality
```

# 3. 线描系统
# 3. Linework System

线描是工笔画最重要的视觉骨架。

### 核心特征｜Key Characteristics

- **细而不弱｜Fine but controlled**
- **稳而不僵｜Steady but fluid**
- **准确而有韵律｜Precise yet rhythmic**
- **轮廓清晰｜Clear contours**
- **局部强调结构｜Selective structural emphasis**

### 推荐术语｜Recommended Prompt Terms

```text
meticulous fine-line brushwork

```

### 传统线描语义｜Traditional Line-Drawing References

```text

```

> **注意｜Note:**  
> 线条不应该自动变成现代漫画式粗描边。

### 避免｜Avoid


# 4. 设色系统
# 4. Coloring and Pigment System

工笔的颜色通常不是一次完成，而是通过**分染、罩染、复勒、提染**等方式逐渐建立层次。

### 中文美术概念｜Chinese Art Concepts

**分染｜Layered tonal modeling**  
通过局部深浅变化建立体积和层次。

**罩染｜Transparent glazing / overlay wash**  
在已有颜色之上叠加薄而透明的色层。

**复勒｜Reinforcing contours**  
设色完成后重新整理、强调关键线条。

**提染｜Selective highlight and color lifting**  
加强局部亮部和视觉焦点。

### AI Prompt Vocabulary

```text
layered traditional pigments
layered mineral pigments
subtle color washes
transparent pigment layering
controlled color gradation
delicate tonal modeling
traditional Chinese pigments
refined mineral color
soft pigment transitions
```

### 混合风格原则｜Hybrid Rule

# 27. 负面 / 抑制词的使用原则
# 27. Negative / Suppression Terms

某些模型支持 negative prompt；若支持，可考虑：

```text
thick comic outlines
cartoon cel shading
photorealistic photography
3D render
plastic skin
neon colors
modern anime proportions
oversaturated colors
cluttered composition
excessive ornament
heavy Western oil-paint texture
```

但不要机械加入很长的负面词列表。

> **优先通过正向 Prompt 明确定义 Gongbi，而不是依赖 Negative Prompt 修正所有问题。**

# 28. Quality-Control Checklist
# 28. 质量检查清单

## Linework / 线描

- [ ] 线条是否细、稳、准？
- [ ] 轮廓是否清晰但不粗重？
- [ ] 衣纹、发丝、花瓣、羽毛是否有精细线条？
- [ ] 是否出现漫画式黑色粗边？

## Color / 色彩

- [ ] 是否具有层染感？
- [ ] 是否像传统颜料，而不是塑料质感数字上色？
- [ ] 饱和度是否受到控制？
- [ ] 强色是否局部使用？

## Figure / 人物

- [ ] 人物是否优雅而非夸张？
- [ ] 面部比例是否古典、精致？
- [ ] 手势是否自然？
- [ ] 服饰是否具有传统中国特征？

## Composition / 构图

- [ ] 是否有足够留白？
- [ ] 是否形成明确视觉焦点？
- [ ] 是否存在非对称平衡？
- [ ] 是否过度拥挤？

## Material / 材质

- [ ] 是否有微妙宣纸质感？
- [ ] 是否具有传统手绘表面？
- [ ] 颜料与纸张是否自然融合？
- [ ] 材质是否过度到像扫描件？

## Style Integrity / 风格完整性

- [ ] 第一眼能否识别为 Gongbi？
- [ ] 是否跑成普通“Chinese Fantasy”？
- [ ] 是否跑成 Anime？
- [ ] 是否跑成 Photorealism？
- [ ] 是否跑成现代 3D Concept Art？

# 30. 核心结论
# 30. Final Principle

**工笔画的本质不是“更多细节”，而是“更精确地控制细节”。**

> **The essence of Gongbi is not more detail, but more controlled detail.**

优秀的 AI Gongbi Prompt 应该同时说明：

```text
How it is drawn
如何画

How it is colored
如何设色

How the figure is designed
人物如何塑造

How the composition is organized
如何构图

How the traditional material feels
如何体现传统媒介
```

最终目标不是生成：

> **a very detailed Chinese painting**

而是生成：

> **a meticulously constructed Chinese Gongbi artwork with elegant linework, layered traditional pigments, classical forms, controlled ornament, balanced negative space, and a quiet poetic character.**
