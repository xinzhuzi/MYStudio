# 全局美学基础 · 3D块面

---
必须严格、完整遵循下方全部风格约束与全局规则，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

## 一、风格基因

| 维度 | 定义 |
|---|---|
| 一级风格 | 3D块面 |
| 媒介类型 | 3D 渲染 |
| 核心锚点 | low poly geometric 3D art |
| 视觉要点 | faceted shapes, angular silhouette, simple forms, clean environment |
| 情绪基调 | 低多边形块面风格，强调几何结构、简洁体块和清晰配色。 |
| 质感锚词 | flat shaded polygons, crisp edges, minimal texture |

## 二、全局色彩与光影

| 项目 | 约束 |
|---|---|
| 色彩基线 | fresh green, sky blue, sandstone orange |
| 主光方案 | clear daylight, simple ambient occlusion, readable shadow |
| 画面层次 | 主体清晰、前中后景可读、焦点明确 |
| 质量锚定 | 最佳质量、杰作、高细节；low-poly 几何3D美术；分面形体、棱角剪影、简洁造型、干净环境；清澈日光、简练环境光遮蔽、可读阴影；平面着色多边形、 干脆利落的边缘、 极简纹理、 锐利焦点、 细节丰富的背景、 精致构图。 |
| 反向规避 | 最差质量,低质量,劣质, 模糊, 糊化, 变形, 失焦, 畸形身体, 多余肢体, 水印, 签名, 文字, high-poly 写实, 有机圆润形体, 噪点纹理 |

## 三、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明“3D块面”和“low poly geometric 3D art”作为风格锚点 |
| R2 | 必须保持“3D 渲染”媒介边界，不混入错媒介词 |
| R3 | 必须包含“faceted shapes, angular silhouette, simple forms, clean environment”中至少 2 个视觉识别点 |
| R4 | 必须说明光源或光影方向：clear daylight, simple ambient occlusion, readable shadow |
| R5 | 必须把质量锚点与主体内容融合，不输出解释性说明 |

## 四、严禁项

| 编号 | 严禁内容 |
|---|---|
| X1 | 直接写入具体作品、作者、厂牌或版权角色名称 |
| X2 | high-poly realism, organic smooth shapes, noisy texture |
| X3 | 低质量、模糊、变形、裁切、文字、水印、签名 |
| X4 | 人物身份漂移、服装不一致、手部结构错误、场景空间混乱 |
