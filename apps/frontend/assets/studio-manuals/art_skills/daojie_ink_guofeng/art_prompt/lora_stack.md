# 三国望神州风格栈 · LoRA 组合手册(Krea 基模)

> 09-18 深调结论:Civitai Krea 2 基模下**没有**《三国望神州》的「大而全」单件——该风格=水墨×工笔×传统色×留白的组合审美,走风格栈;SD1.5/SDXL 系精品(墨心 MoXin 28.7万dl/工笔系列/国风插画1.8万dl)**不能跨基模使用**。

## 组合规则

1. **漆艺鎏金恒锚**:任何组合必含,权重不低于 0.8(主视觉身份)
2. **同层不叠**:D 层(水墨场景)候选件互斥试 A/B,不叠加(水墨语义会互相稀释)
3. **超集工作流跑**:用 `MY-K2_文生图_超集`(12带重平衡正好调淡彩浓度;KSampler er_sde/simple 与三国杀件推荐参数兼容)
4. **基准对拍**:按《三国望神州》§14 一句话定义写基准词,三件组合出图逐件 A/B 裁量,留下的固化进本表
