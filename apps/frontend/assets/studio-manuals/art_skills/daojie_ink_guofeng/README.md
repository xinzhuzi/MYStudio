## 历史画卷基准(09-18《三国望神州》美术 DNA 并入)

> 以下为参考基准的历史说明；道劫当前配色以 2026-10-16 用户裁定为准：以丰富多彩的传统设色为主，配色协调统一，主色统领、辅色呼应、点睛色突出，饱和度与对比度受控且层级分明。不将参考中的淡彩、低对比解释为现行全局要求。

本风格自 09-18 起并**《三国望神州》**美术基准(真源在 `docs/prompts/三国望神州.md`,AI Visual Bible v2.2,09-18 用户重下版;本手册 09-18 完成 v2.2 对齐修订,要点已全量并入 prefix、art_prompt 与 style_guide):水墨不是黑白水墨而是**淡墨+淡彩+细线+低对比+局部重点色**(源文档第4.1节);工笔是**现代角色设计的工笔线描化**而非馆藏复刻(源文档第2.1节/第3节);色彩走**中国传统色受控饱和体系**(传统色＋受控饱和度＋受控对比度＋角色识别色,颜色可以较鲜明,关键是视觉层级不失控,源文档第5.1节;石青/赭黄/淡朱/宣纸白…),「淡」非「旧」;**留白与疏朗构图是一级条件**——留白不是画面必须很空,而是控制视觉密度和信息优先级(Visual Density Control),留白量按资产分型取值(角色立绘中/剧情高/山水很高/战斗低中,源文档第6.1–6.2节);人物处在具体历史事件中(连环画=叙事气质参考,营销词不作硬约束;源文档第28节 C 亦定位「辅助 Style DNA」);历史真实感＞奇幻感、线条＞光效、构图＞堆料;**游戏实况=三维等距+青绿淡彩+水墨笔触混合体**(纯古画质感缺游戏完成度),战斗演出(猛火计类)为高饱和特效大作、豁免堆料黑名单(源文档第20.3节:动作强度增加,不等于视觉语法切换成仙侠 CG)。框架层级按源文档第0.1节/第0.2节:**新中式为上位总框架(内部工作分类)**,水墨/工笔/白描/传统色/古典山水均为其下可替换组件(v2.1 第0节 排除清单明列「不是纯水墨画」,该清单 v2.2 已移除,资产验收侧七项排除由本手册 `style_guide/00_总纲.md` 第一节.2 继承)——旧口径「以中国传统水墨画为基底」自本版废止(09-18)。

- 修仙题材的AI美术生成（角色、场景、法宝、分镜等）

## 严禁内容

- 完全写实摄影/3D写实渲染
- 机械均一勾边、失去结构的贴纸式色块、摄影式体积塑形
- 赛博朋克/科幻/过度现代元素
- 粗劣线条/模糊画质/低精度建模
- 色彩混乱/风格不统一/审美崩坏

## 风格体验

在本风格下，您将体验到：

- 角色造型以工笔白描勾勒，线条如铁线银钩，气韵生动
- 场景保留来源色相，以协调的传统设色组织主辅层次；空间与留白服从类型规则
- 法宝器物以工笔重彩描绘，材质质感古朴，灵光内蕴
- 分镜与渲染保持多彩协调、主次分明的传统绘画语言与修仙古韵
