# 道劫 · 水墨国风修仙风格说明

本风格专为《道劫》修仙题材打造。上位框架为**新中式修仙叙事游戏美术**——项目内部分析框架（沿源文档§0.2 免责口径：新中式为内部工作分类，非官方风格标签；深论见 `style_guide/00_总纲.md` §二与 `style_guide/06_新中式设计语言.md`）：

> 新中式修仙叙事游戏美术 ＝ 中国传统美术 DNA ＋ 现代角色设计 ＋ 现代构图/数字绘画 ＋ 修仙历史文化元素。（v2.1 工作公式，项目内部沿用；v2.2 §0.2 已移除该公式，改以结构树定位——新中式为内部工作分类、非官方标签）

传统绘画 DNA（水墨/工笔/白描/传统色/古典山水）是**可替换组件，不是基底**；所有美术提示词、规范和生成内容均严格限定于：

- **水墨国风动画**：水墨、工笔、白描等传统绘画 DNA 组件化承载的修仙动画风格，涵盖修仙、斗法、渡劫等题材
- **工笔写意融合**：工笔线描勾勒形体结构，写意泼墨渲染气韵意境，二者有机结合
- **传统水墨技法**：皴擦点染、浓淡干湿、留白飞白等传统国画技法的数字化表达
- **修仙古韵**：仙道意境、天人合一、道法自然的东方玄学美学表达
- **浅净平涂底质感**：底色为浅净哑光平涂色场（象牙白/米色），墨色渗透、水痕晕散以薄染表现；不追求扫描纸纹/纤维肌理
- **水墨成片质感**：构图讲究、水墨光影层次、动态张力、灵气氛围

## 历史画卷基准(09-18《三国望神州》美术 DNA 并入)

本风格自 09-18 起并**《三国望神州》**美术基准(真源在 `docs/prompts/三国望神州.md`,AI Visual Bible v2.2,09-18 用户重下版;本手册 09-18 完成 v2.2 对齐修订,要点已全量并入 prefix、art_prompt 与 style_guide):水墨不是黑白水墨而是**淡墨+淡彩+细线+低对比+局部重点色**(源文档§4.1);工笔是**现代角色设计的工笔线描化**而非馆藏复刻(源文档§2.1/§3);色彩走**中国传统色受控饱和体系**(传统色＋受控饱和度＋受控对比度＋角色识别色,颜色可以较鲜明,关键是视觉层级不失控,源文档§5.1;石青/赭黄/淡朱/宣纸白…),「淡」非「旧」;**留白与疏朗构图是一级条件**——留白不是画面必须很空,而是控制视觉密度和信息优先级(Visual Density Control),留白量按资产分型取值(角色立绘中/剧情高/山水很高/战斗低中,源文档§6.1–6.2);人物处在具体历史事件中(连环画=叙事气质参考,营销词不作硬约束;源文档§28 C 亦定位「辅助 Style DNA」);历史真实感＞奇幻感、线条＞光效、构图＞堆料;**游戏实况=三维等距+青绿淡彩+水墨笔触混合体**(纯古画质感缺游戏完成度),战斗演出(猛火计类)为高饱和特效大作、豁免堆料黑名单(源文档§20.3:动作强度增加,不等于视觉语法切换成仙侠 CG)。框架层级按源文档§0.1/§0.2:**新中式为上位总框架(内部工作分类)**,水墨/工笔/白描/传统色/古典山水均为其下可替换组件(v2.1 §0 排除清单明列「不是纯水墨画」,该清单 v2.2 已移除,资产验收侧七项排除由本手册 `style_guide/00_总纲.md` §一.2 继承)——旧口径「以中国传统水墨画为基底」自本版废止(09-18)。

## 适用范围

- 修仙题材的AI美术生成（角色、场景、法宝、分镜等）
- 需要水墨国风、工笔写意、修仙意境的视觉创作
- 修仙动画、仙侠游戏美术、概念设计、水墨插画创作

## 严禁内容

- 完全写实摄影/3D写实渲染
- 日式赛璐璐平涂/动漫渲染
- 赛博朋克/科幻/过度现代元素
- 粗劣线条/模糊画质/低精度建模
- 色彩混乱/风格不统一/审美崩坏

## 风格体验

在本风格下，您将体验到：

- 角色造型以工笔白描勾勒，线条如铁线银钩，气韵生动
- 场景充满水墨意境，山水云雾以写意泼墨呈现，留白深远
- 法宝器物以工笔重彩描绘，材质质感古朴，灵光内蕴
- 分镜与渲染均强调水墨成片质感、修仙古韵、传统国画技法
