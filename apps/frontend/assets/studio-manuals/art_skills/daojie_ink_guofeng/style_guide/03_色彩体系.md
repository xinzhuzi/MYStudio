## 一、总纲:传统色是一套配色方法,不是一枚滤镜

**传统色(traditional Chinese colors)是「按对象分配色彩的方法」,不是「一枚可以全屏套用的色彩滤镜」。**

- **官方实证**:《三国望神州》官方明确使用「中国传统色系」**根据人物气质设计立绘**(v2.1 §1 依据引文,v2.2 已移除;现行对应源文档§5.1「角色识别色」口径)——配色的决策单位是「这个人物 / 这场戏」,不是「这张图套什么色调」。
- **现代转译**:传统色 × 现代色彩管理 = **传统中国色体系＋受控饱和度＋受控对比度＋角色识别色**(源文档§5.1 原句;传统×现代结构见源§0.2 结构树,v2.1 §0.1.2 对照表已移除)——颜色可以存在、可以较鲜明,关键是不要让画面失去视觉层级;色彩层搜索组件 = traditional Chinese colors / muted Chinese colors(§25 第四优先级)+ controlled saturation / controlled contrast(§17 角色模板原词)。
- **优先级对仗**(prefix.md 风格基因行的色彩位):**传统色＞霓虹色**;同排位还有历史真实感＞奇幻感、线条＞光效、构图＞堆料、人物气质＞华丽装饰。

### 正确理解 / 错误理解

| 维度 | 正确理解 | 错误理解 |
|---|---|---|
| 色彩来源 | 中国传统色名体系,一物一色、按气质分配 | 一枚统一色调滤镜(全屏青 / 全屏灰褐) |
| 色彩数量 | 每图 2-3 种矿物色点缀(prefix 公式;受控而非压低,源§5.1) | 色相堆叠、满幅鲜艳 |
| 决策顺序 | 先读角色/场景设定事实,再查参考盘补空缺职责 | 先定「高级灰色调」再往里塞主体 |
| 统一性来源 | 同一套色名体系 + 同一套淡彩纪律 = 古雅统一 | 全图套同一枚滤镜 = 假统一 |

> **「少量高识别强调色」**(源文档§5.2 正确关系末项):指旧金、暗金、朱砂、血红这类一望可辨的小面积色,只作 accent 点睛(法印 / 旗纛 / 刃口 / 阵纹),永不做大面积主色——它就是「少量视觉锚点」的用色本体。

1. **「宣纸白」是色名,不是质感词**——它指暖白底色相(绢本感的白);「宣纸质感 / 纸纹 / 纤维 / 褶皱」仍按 prefix「纸面与成片质量」硬锁严禁。源文档§5.2 基底色列出「宣纸白 / 米白」,仅指**底色色相**,不连带解禁纸纹(prefix.md 浅净平涂底硬锁)。
2. **墨线颜色锁**:线条用浓墨或焦墨,禁彩色线条、禁纯黑死线(prefix.md 硬约束色表)。

## 三、色量关系:大面积稳定基底,强调色少而准

**正确关系(源文档§5.2 原句):大面积稳定基底 + 中等强度人物色 + 少量高识别强调色。**色彩核心不是「低饱和」,而是**传统中国色体系＋受控饱和度＋受控对比度＋角色识别色**(源§5.1 原句)——颜色可以存在、可以较鲜明,关键是不要让画面失去视觉层级;v2.1 §4.1 旧句「低饱和大面积基底＋中低饱和人物服饰＋少量视觉锚点」按此口径修正读法:「淡」=受控的淡,而非压暗的旧。

### 三层色量结构

| 层 | 面积 | 强度 | 内容 |
|---|---|---|---|
| 基底 | 大面积 | 稳定(受控) | 宣纸白/米白平涂底 + 淡墨层次 + 青绿远山(源§5.2 Base Palette:宣纸白/米白、墨黑/墨灰、土黄/赭色、青灰/石青、青绿、棕灰) |
| 服饰/主体 | 中面积 | 中等强度 | 人物衣袍主色(primary)+ 次层材质色(secondary),合计 2-3 种矿物色(源§5.2 Character Accent:朱红/绛红、暖黄/赭黄、青色、少量金属暖色) |
| 视觉锚点 | 小面积 | 高识别(可较鲜明,仍非荧光) | 朱砂法印、旧金阵纹、旗纛、刃口——即「少量高识别强调色」 |

### 错误关系(源文档§5.2 原列,五条全禁＋一条同向)

| 错误形态 | 病因 |
|---|---|
| 全屏青色滤镜 | 把「统一」理解成「滤镜」,一枚青色调色器 |
| 全屏灰褐滤镜 | 把「旧」当「淡」,压暗当受控 |
| 金蓝高对比 | 把「国风」理解成「金蓝对撞的东方幻想」(§5.2 错误关系原词;§26 高危方向同向) |
| 荧光红蓝 | 荧光色相冒充强调色,失去传统色来源 |
| 赛博紫 | 现代赛博色相混入传统色体系 |
| 高饱和国风 CG | 把「仙侠」理解成「特效堆料」(§26 风险清单:X6 堆料黑名单同源) |

### 判断依据(为什么这是红线)

- **评分表权重**:源文档§14 评分表「色彩系统」占 10%,判断标准 = 传统色＋受控饱和。
- **归级证据**:满屏金光/高饱和蓝紫/巨量粒子等 v2.1 一票否决信号,筛选语境按源§15 Production Gate 归级——命中即不入 S/A 主生产,按 R/X 归级;资产验收语境照打回,不进权重权衡。
- **候选快筛**:「它会不会出现金光、蓝紫、高饱和和仙侠特效?」(v2.1 §21 六问第 4 问,v2.2 已移除;现行对应源§14 指标＋§19.1 Fantasy Suppression)。
- **严禁项对接**:X2(高饱和动漫色)、X6(金色过多 / 高饱和青蓝;适用 = 静态资产与剧情图)。

## 四、淡而不脏:定义与四色换算表

> **「淡」是关键,而非「旧」**(prefix.md §二 历史画卷传统色扩补原句;v2.2 读法:「淡」＝受控的淡,而非压暗的旧——源文档§5.1)。
> 「淡」不等于:灰蒙蒙、发脏、低质量、旧照片、泛黄滤镜(v2.1 §4.2 原列,v2.2 已移除;现行对应源§5.2 错误关系「全屏灰褐滤镜」)。
> 目标(源文档§5.1 原句):**颜色可以存在,也可以较鲜明;关键是不要让画面失去视觉层级。**(v2.1 §4.2 旧句「颜色真实存在,但不抢主体」同义)

### 四色换算表(每个色相都往传统色名上落)

| 色相 | 正确落点(色名) | 错误落点 | 一句话判断 |
|---|---|---|---|
| 红 | 朱红→绛红、朱砂感 | 荧光红、鲜艳游戏红 | 红是矿物朱砂的沉,不是荧光的亮 |
| 黄 | 赭黄、土黄 | 黄金特效、金色光效 | 黄是土与赭的黄,不是金属光效的黄 |
| 青 | 石青、青灰 | 赛博蓝、灰绿泥色 | 青是青——有明确色相,不是灰绿泥色 |
| 白 | 宣纸白 / 绢本暖白底色相 | 纯数字冷白 | 白保留暖白底色相 |

### 色彩严禁表(红线收口于此,不散落段落)

| 严禁项 | 处置 |
|---|---|
| 做旧滤镜、泛黄滤镜、旧照片感 | 负面段:yellowed aged sheet、scanned-paper filter(prefix §五负面③原词) |
| 灰蒙蒙、发脏、低质量 | 负面段:AI muddy noise、dirty texture(prefix §五负面③原词) |
| 满幅灰褐化 | 人工审稿拒收(prefix §二扩补禁令) |
| 整图灰白化 / 黑白滤镜 / 单色素描 | prefix §二硬口径:彩色工笔默认成片,线描合格但灰白化仍算不合格 |
| 满幅鲜艳、霓虹与糖果饱和度 | 负面段:high saturation neon(prefix §五负面② + 底座「禁霓虹与糖果饱和度」) |

> 「旧」的合法出口只有一个:岁月、风霜、战痕**仅在来源事实要求时作克制的叙事线索,须次要、不抢戏**(prefix 成片质量锁)——它是叙事线索,不是色彩滤镜。

## 五、量化口径:审稿观察栏,不进提示词

> prefix.md §二「色量与色相口径」:本色盘是组织画面的**参考盘**,不是生成硬门——色相故事以角色/场景设定与题材事实(Source facts)优先,底座不锁默认色板。

### 观察项 / 提示词项分野

| 口径 | 数值/表述 | 用途 | 写进提示词? |
|---|---|---|---|
| 可辨彩色占比 | 30%-70% | 人工审稿观察与报告 | 否 |
| 色相偏移容差 | ±6° | 理解容差,非验收门 | 否 |
| 饱和度偏移容差 | ±8% | 同上 | 否 |
| 明度偏移容差 | ±10% | 同上 | 否 |
| 整体色温 | 偏冷中性 | 组织画面理解 | 否——用「清冷墨色基调」表达 |
| 饱和度语言 | 低饱和淡彩(prefix 原词;v2.2 读法＝受控饱和,源§5.1) | — | 是——「低饱和淡彩、矿物色薄染」 |

### 三条硬口径(prefix §二原口径)

1. **禁整图灰白化 / 黑白滤镜 / 单色素描**——彩色工笔默认成片;人物服装、纹样、玉石、金属、山水、云气之间必须有可辨色相层次。
2. **禁满幅鲜艳**。
3. **默认公式:水墨为主、2-3 种低饱和矿物色点缀、古雅统一。**——该公式为 prefix 生成契约原文,v2.2 侧读法:「2-3 种矿物色」＝受控饱和度＋受控对比度下的传统色组织(源§5.1),「点缀」＝大面积稳定基底＋中等强度人物色＋少量高识别强调色(源§5.2),颜色可以较鲜明,层级不失控。

### 色温/对比/饱和的提示词表达(描述口径 → 画面语言)

| 参数 | 画面口径 | 提示词表达 |
|---|---|---|
| 整体色温 | 偏冷中性,水墨清冷基调 | 清冷墨色基调、冷中性宣纸底 |
| 对比度 | 中低对比,层次过渡柔和 | 墨色层次过渡柔和、淡墨渐变 |
| 饱和度 | 低饱和淡彩 | 低饱和淡彩、矿物色薄染 |

## 六、色盘组织:配色五职责

组织色彩时**按职责思考**,不按「色号好看」思考(prefix.md §二):

| 职责 | 含义 | 参考色例 |
|---|---|---|
| base | 画面底色(浅净平涂底) | 宣纸白、米色、浅象牙、米白 |
| ink | 墨线与墨色层次 | 浓墨、淡墨、焦墨、铁黑 |
| primary | 主体主色(跟随角色/场景设定) | 石青、靛蓝、朱红、赭石、赭黄 |
| secondary | 次层材质色 | 玉青、暗赭、栗褐、淡青、青灰、棕灰、土黄 |
| accent | 点睛色(小面积焦点) | 朱砂、旧金、暗金、血红(法印/伤痕/刃口)、淡朱 |

**组织纪律**:

1. **来源事实优先,配料只补空缺职责**——角色/场景设定已声明的主色直接采用;设定没写的职责,才从参考盘选色名补位。
2. **09-18 历史画卷扩补色名**(prefix §二):石青、灰青、米白、土黄、赭黄、淡朱、暗红、棕灰——均为色名用法,同上不抄色号。
3. **精选方案示例**(prefix §二,色名组合,非硬约束):
   - 人物淡雅 = 宣纸白 + 浓墨 + 石青 + 玉青 + 旧金
   - 人物魔道 = 冷灰底 + 铁黑 + 靛蓝 + 暗赭 + 血朱砂(仅法印)
   - 场景青绿 = 宣纸白 + 淡墨 + 石绿 + 石青 + 赭石
   - 道具旧金 = 宣纸白 + 浓墨 + 旧金 + 暗玉青
4. **冲突裁决**:以角色/场景设定事实为准。

## 七、情绪色盘:按气质配色的场景化

「按人物气质配色」(v2.1 §1 官方依据引文,v2.2 已移除;现行对应源§5.1「角色识别色」)在道劫落地为两层:

- **单角色层**:角色气质决定服饰 primary——清冷→石青/玉青;华贵→旧金/朱红;魔修→铁黑/靛蓝 + 血朱砂法印。
- **成批画面层**:情绪场景决定整幅主辅色与对比关系——查下表(prefix.md §二 情绪色盘,七场景;「光效与对比建议」列从略,详见原表):

| 情绪场景 | 主色 | 辅色 | 画面关键词 |
|---|---|---|---|
| 修炼悟道 | 宣纸白 + 青绿 | 旧金 + 淡墨 | 空灵、悟道、天人合一 |
| 宗门盛典 | 朱红 + 旧金 | 宣纸白 + 浓墨 | 庄严、华贵、法度森严 |
| 斗法对决 | 浓墨 + 靛蓝 | 朱红 + 血红 | 凌厉、肃杀、剑气纵横 |
| 日常修行 | 青绿 + 宣纸白 | 赭石 + 淡墨 | 清新、宁静、山间修行 |
| 渡劫突破 | 暗金 + 朱红 | 靛蓝 + 浓墨 | 壮烈、天威、劫雷轰鸣 |
| 冥界幽境 | 靛蓝 + 浓墨 | 血红 + 淡墨 | 幽冥、阴森、鬼气森森 |
| 战场水墨(09-18 三国基准) | 淡墨 + 宣纸白 | 赭石 + 朱红(旗/甲 focus) | 水墨战场、疏朗大气、墨韵层叠 |

**使用规则**:

1. 情绪色盘是**组织参考**,不是硬门——与角色/阵营设定冲突时,设定事实优先(与五职责同一裁决序)。
2. 每格主辅色仍须过「四、换算表」:宗门盛典的朱红是朱砂感的红,不是游戏红;渡劫突破的暗金可按 L3 例外拉亮(见「八」),但只限局部。
3. **战场水墨行 = 「少量视觉锚点」的成片示范**:淡墨浓淡分层铺战场、低对比远山雾气,赭石 + 朱红的旗甲作视觉锚——锚点是旗甲,不是满幅烟尘。

## 八、faction palette 衔接:既有阵营色与三层约束

### 既有资产

`art_prompt/art_faction_palette.md`(ma-faction-palette-v1,分镜帧【色彩】段注入源):12 阵营 × 三轨——person(服饰点缀)/ scene(全锁)/ prop(弱倾向:材质色优先 + 小纹样),每轨按五职责注入「底色 + 墨线 + 主色 + 辅色 + 点睛」。该文件头部已带 09-18 口径:**本表阵营色继续生效,新增扩补色名(石青/灰青/米白/土黄/赭黄/淡朱/暗红/棕灰)按 prefix「全局色彩盘·历史画卷传统色扩补」职责组织**。

### 三层约束强度(prefix.md §二)

| 层级 | 强度 | 内容 |
|---|---|---|
| L1 硬约束 | 高 | 水墨基底色、低饱和青绿淡彩、宣纸底色 |
| L2 软约束 | 中 | 灵气色、法宝色、境界色可按修仙体系微调 |
| L3 例外机制 | 低 | 渡劫/突破/大战等高光时刻可临时突破局部色彩 |

### 裁决序(冲突时从前往后)

**角色/场景设定事实(Source facts)＞ 阵营色(art_faction_palette)＞ 情绪色盘/参考盘默认**。

- 分镜【色彩】段:优先取阵营色三轨;空缺职责用扩补色名补位。
- 角色立绘/单资产:设定事实优先,阵营色作组织参考。
- L2 微调示例:同是金色系 accent,佛门古卷走旧金,金丹/元婴光华走暗金(境界事实决定);同是红系,人族灵气正朱,魔修压成绛红只作法印——按修仙体系事实微调,不换色系。

### 魔道暗色分支(prefix §二分支)

阵营为魔道/邪道/邪修时**仍用同一底座与本篇全部纪律**:深墨/铁黑/靛青为主,暗赭/栗褐承接材质,血朱砂/朱红只作法印、旗记、伤痕、眼神或刃口焦点;禁满幅黑红。暗色改变的是职责色与线条力度,**不是**「淡而不脏」标准。

### 战斗豁免(单一口径,勿扩大)

**提高动作强度,但不要改变基础画风**(prefix X6 译句;源文档§20.3 原句:「战斗画面可以更强烈,但——动作强度增加,不等于视觉语法切换成仙侠 CG」)。X6/L3 双口径同源:战斗/技能演出镜头视觉强度可临时拉满(官方「猛火计」演出实证 = 高饱和红金 + 光效大作),但**线条与传统色体系在镜头间隙保持恒定**;豁免只给演出镜头,不给静态资产与剧情图,不自创第二套豁免。

## 道劫应用要点

1. 配色先读设定事实(Source facts),再查参考盘补空缺职责;裁决序 = 设定事实 ＞ 阵营色 ＞ 情绪色盘/默认。
2. 默认公式:水墨为主 + 2-3 种低饱和矿物色点缀 + 古雅统一(prefix 原文;v2.2 读法＝受控饱和);正确关系 = 大面积稳定基底 + 中等强度人物色 + 少量高识别强调色(源§5.1/§5.2),颜色可以较鲜明,层级不失控;锚点只用少量高识别色(朱砂/旧金/旗纛/刃口)。
3. **淡是关键而非旧**:红落绛红朱砂感、黄落赭黄、青落石青青灰、白留宣纸暖白;禁做旧滤镜/泛黄/满幅灰褐化/整图灰白化。
4. 色名纪律:只写色名,不抄色号、不写色温数值/百分比/占比;色温用「清冷墨色基调」等画面语言表达。
5. 「宣纸白」是色名,「宣纸质感/纸纹/纤维」仍禁——两口径严格分开。
6. 情绪场景查七场景表定主辅色;战场水墨以旗甲为锚(淡墨大面积 + 锚点小面积)。
7. 分镜【色彩】段优先注入阵营色三轨(底色/墨线/主色/辅色/点睛),空缺职责用扩补色名补。
8. 渡劫/大战高光镜头可按 L3 临时突破局部色彩;镜头间隙回到传统色体系,静态资产不豁免。
9. 审稿三看:看脸与服饰(可辨色相层次)、看底色(暖白底色相在不在)、看锚点(少而准)。
10. 高饱和蓝紫/满屏金光/巨量粒子:筛选语境按源§15 Production Gate 归级(不入 S/A 主生产),资产验收语境即打回,均不进权重权衡。
