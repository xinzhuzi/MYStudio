## 二、新中式：上位框架速览

**免责口径（先立此存照）**：「新中式」是对现代设计方法的概括，**不是官方美术标签**（源文档§0.2 重要说明：新中式历史叙事游戏美术是**内部工作分类**，不作官方风格标签、不作模型筛选唯一标准）；道劫侧写作「新中式修仙叙事游戏美术」时，同样注明为项目内部分析框架。

### 1. 定义公式（v2.1 §0.1.1 原句保留；v2.2 已移除该公式，现行定位见 §0.2 结构树）

> 新中式历史叙事游戏美术 ＝ 中国传统美术 DNA ＋ 现代角色设计 ＋ 现代构图/数字绘画 ＋ 历史文化元素。

道劫侧：**新中式修仙叙事游戏美术**＝同一公式，历史文化元素按修仙世界的历史化考据组织——阶层、门派、服饰形制均取历史事实，不发明幻想形制。

### 2. 传统层 × 现代层（v2.1 §0.1.2 拆解表，右列道劫化；v2.2 现行对应 §0.2 结构树——传统/现代之外新增图形语言与历史内容两枝，速览见本篇 §三.4）

| 传统层 | 现代层 | 道劫最终表现 |
|---|---|---|
| 工笔 / 白描 | 游戏角色设计 | 修仙人物立绘（掌门至散修皆有可识别身份设计） |
| 连环画 | 分镜与叙事设计 | 论道 / 斗法 / 渡劫的单幅叙事场面 |
| 水墨 | 数字边缘与空气处理 | 背景虚实、远景淡化、云雾留白 |
| 传统色 | 现代色彩管理 | 受控饱和淡彩＋少量高识别强调色（朱砂感法印、旧金阵纹；源文档§5.1/§5.2） |
| 山水画 | 游戏场景构图 | 大留白、远近层次、山门与洞天布局 |
| 历史服饰 | 现代角色造型 | 修仙阶层门派服饰轴（形制考据，深论见 02 篇） |

核心句（v2.1 §0.1.2 原句保留；v2.2 同义口径见 §0.1）：

> **传统文化视觉 DNA 被现代游戏美术重新组织。**

因此新中式**不是让画面更潮、更时尚，也不是加入赛博或现代服装元素**（v2.1 §0.1.2 口径，v2.2 已移除该句；§0.2 现行同向提醒：模型筛选时不要让「新中式」本身成为唯一搜索标准）。

### 3. 风格母体：拆层组合，不找万能单体（源文档§10/§36）

风格由可独立控制的模块层组成，审稿与组词都按层思考：Style（中国人物画 / 连环画 / 现代中国游戏美术）· Line（工笔 / 白描）· Color（中国传统色 / 受控饱和）· Composition（留白 / 古典构图 / 卷轴画册关系）· Costume（道劫＝阶层门派轴）· Scene（山水 / 城池 / 战场 → 宗门 / 洞天 / 斗法场）。模块可替换、可重组；「一个万能风格单体」不存在。源文档的 S/A/B/R/X 生产准入分级（§15）、评分表（§14）与 A/B 测试协议（§13）作为**方法论**迁移使用，具体 LoRA 模型与链接不进本指导主体。

### 4. 新中式 ≠ 东方幻想（一行带过）

历史（修仙世界史实感）为主体、留白、传统色、淡雅、线描、克制——对照堆满视觉信息、高饱和金蓝紫、强光影、CG 体积渲染、金光粒子（v2.1 §0.1.4 对照表；v2.2 现行对应 §26 规避方向与风险清单）；`fantasy` 不作核心关键词。深论与全表见 **06 篇**。

### 5. 游戏化语言承载点（速览级）

- **现代游戏完成度**：干净可读、工艺清晰、资产统一——README 定调「游戏实况＝三维等距＋青绿淡彩＋水墨笔触混合体」，纯古画质感缺游戏完成度（README.md:18）。
- 落点是**游戏资产**而非单幅画作：角色立绘、资产统一性、AI 漫剧镜头栈整体保留这套语言。
- 新中式作为游戏美术框架的完整展开 → **06 篇**。

## 三、视觉 DNA 双轴与 v2.2 新增层

v2.2 将核心视觉 DNA 扩为**八维**（源文档§1：Character / Line / Ink / Color / Spatial / Graphic / Historical / Material）；本篇仍以水墨/工笔双轴为主轴行文，其余独立新层速览见 §三.4。

双轴分工总句（prefix.md 提示词装配顺序·媒介层级的统一口径，prefix.md:117）：

> **工笔负责结构，水墨负责气韵。**

### 1. 水墨＝空气与边缘语言，不是黑白滤镜（源文档§4.1）

| 优先理解 | 避免理解 |
|---|---|
| 墨色浓淡 | 全画面黑白 |
| 虚实边缘 | 大量泼墨 |
| 空气透视（atmospheric perspective） | 狂草飞溅 |
| 远景淡化 | 强烈水墨纹理覆盖人物 |
| 山水层次 | 黑白高反差 |
| 局部笔触、局部晕染 | 把水墨当滤镜铺满全图 |

AI 口径（英文为源文档§4.1 原词表）：优先 **subtle / controlled / soft**——`subtle ink atmosphere`、`light ink wash`、`controlled brush texture`、`soft ink transitions`、`faded distant background`、`soft edges`；避免 `heavy ink splash / black-and-white filter / extreme splash ink / chaotic brush texture`。

衔接道劫基线：水墨是**淡墨＋淡彩＋细线＋低对比＋局部重点色**（README 历史画卷基准）；彩色工笔默认成片，灰白化 / 黑白滤镜 / 单色素描直接不合格（prefix.md 硬约束，prefix.md:106）。

### 2. 工笔＝人物线条逻辑，不是古画临摹（源文档§3）

| 优先 | 避免 |
|---|---|
| 细线、清晰轮廓、线条有轻重 | 动漫粗描边、赛璐璐勾边 |
| 五官结构明确 | 模糊五官、平涂脸 |
| 衣褶清楚但不碎、甲胄结构清楚 | 密集褶网、无结构乱褶 |
| 发冠、配饰、武器具有设计感 | 炫技式装备堆料 |
| 颜色克制（薄透矿物罩染） | 高饱和上色 |
| 线条像画出来 | 均一黑轮廓、贴纸式勾边、矢量感轮廓（§3.2 负面新词，全表见 06 篇 §5.6） |

定性（源文档§2.1，原句保留）：

> **现代历史游戏角色 × 中国人物画线描逻辑 × 历史身份设计。**

不等于「画面必须像博物馆里的宋代工笔画」。AI 关键词（源文档§3.2 原词表）：`fine Chinese linework`、`fine ink contour`、`delicate brush line`、`controlled contour weight`、`expressive ink line`、`traditional figure outline`。脸部 / 比例 / 线稿深论 → **01 篇**。

### 3. 双轴合用示例（正向表述，只作风格语言参考）

> 画中人临风而立于山门之前：工笔细线勾勒眉眼、发丝与衣缘，衣褶两三长笔结构分明；远山以淡墨层层淡化，云雾处大片留白（negative space），石青道袍在宣纸白底上薄透罩染，旧金只作剑穗一点。

### 4. v2.2 新增层速览（源文档§1 八维 DNA 中的独立新层，每层一句话）

| 新层 | 一句话口径 | v2.2 节号 |
|---|---|---|
| Graphic / Presentation Language | 「像」不止怎么画，还包括怎么组织画面与呈现故事——画卷 / 画册 / 连环画分镜 / 书法字体 / 装饰纹样 / UI 古典视觉框架 | §8 |
| Material Language | 材质差异清晰（布 / 木 / 石 / 金属 / 皮革 / 纸 / 水）而绘画语言统一——非各材质独立 3D 写实渲染 | §21 |
| Era Lock（时代锁） | 历史约束按 Era＋Identity＋Status＋Costume Set 组织，防跨时代污染（宋服＋汉甲＋明冠＋唐饰不为合格） | §9.2 |
| Master Reference | 九类母图组成 Visual Anchor Set（标准男 / 女角色、近景头像、全身立绘、安静剧情、战斗、山水远景、城池建筑、连环画叙事镜头），新 LoRA 统一与它对拍 | §23 |
| 模型元数据 | 每个模型记录 Model Name / Role / Test Result 等全字段，**Last Verified** 特别重要——模型页 / 版本 / 触发词会变，生产前必须重新核对 | §24 |

## 四、道劫定调：优先级与基准衔接

### 1. 四优先级（原句保留，审稿排序用）

> **历史真实感＞奇幻感、绘画审美＞特效审美、构图＞堆料、线条＞光效。**

补齐 prefix.md 风格基因行全序：传统色＞霓虹色、**留白＞满构图**、人物气质＞华丽装饰（prefix.md:11）。源文档同义表述合并进此序，不另立新序。

### 2. 「淡」、受控饱和与留白

- **「淡」是关键而非「旧」**（原句保留）：淡墨淡彩细线低对比——青是青非灰绿泥色，红是朱红 / 绛红非鲜艳游戏红，黄偏赭黄非金色特效，白保留宣纸白 / 绢白的暖白底色相（prefix.md:48 历史画卷扩补）；禁做旧滤镜、禁满幅灰褐化。
- **受控饱和（v2.2 修订，源文档§5.1）**：色彩核心不是「低饱和」，而是**传统中国色体系＋受控饱和度＋受控对比度＋角色识别色**——颜色可以存在、可以较鲜明，关键是画面不失去视觉层级；「淡」据此读作「受控的淡」，而非「压暗的旧」。
- **留白是一级条件**（原句保留）＋**分型密度口径（v2.2，源文档§6.1/§6.2）**：留白不是「画面必须很空」，而是**控制视觉密度和信息优先级**（Visual Density Control）；大面积天空 / 水面 / 雪地 / 远山 / 浅雾承担视觉呼吸，清疏构图优先于堆料，但留白量按资产分型取值——

| 场景 | 留白 | 视觉密度 | 动态 |
|---|---|---|---|
| 角色立绘 | 中 | 中高 | 低 |
| 剧情场景 | 高 | 低中 | 低 |
| 山水远景 | 很高 | 低 | 低 |
| 战斗画面 | 低中 | 中高 | 高 |
| Key Art | 中 | 中高 | 高 |
| 连环画叙事 | 按镜头变化 | 中 | 中高 |

  prefix.md 生成契约不动，手册侧以本口径审稿（冲突裁定见「六」）。速览见此，深论 → **04 篇**。
- 传统色组织法（速览，源文档§5.2）：**大面积稳定基底＋中等强度人物色＋少量高识别强调色**（prefix.md:48 生成侧行文仍其旧文，解释以源文档口径为准）；「按人物气质配中国传统色」（v2.2 §5.1 角色识别色口径）→ 道劫按阶层门派气质配传统色，深论 → **03 篇**。

### 3. 连环画定位（降格口径）

连环画＝**叙事气质参考**：人物处在具体事件中（v2.1 §7 列举的对峙 / 交谈 / 战斗 / 送别 → 道劫对应论道 / 斗法 / 渡劫 / 入宗 / 谒见 / 送别；v2.2 现行对应 §28 C：人物叙事 / 单幅故事场景 / 动作瞬间 / 人物关系 / 历史事件视觉化），不摆拍。**「连环画」「剪纸画」系官方营销词，视觉占比有限（多在过场/UI），不作硬约束**（README 09-18 官方截图实证，README.md:18）；v2.1 §7「极其重要的一层」的强度口径不沿用——v2.2 §28 C 自身亦定位「辅助 Style DNA」，与 README 降格同向。

### 4. 战斗豁免（单一口径，X6）

> **提高动作强度但不改变基础画风。**

战斗 / 技能演出镜头的视觉强度可临时拉满（官方「猛火计」类演出实证＝高饱和特效大作，README.md:18），但线条与传统色体系在镜头间隙保持恒定；豁免只及演出镜头，**静态资产与剧情图不适用**（prefix.md:158 X6）。不自创第二套豁免、不扩大范围。深论 → **05 篇**。

## 五、最终视觉目标：三眼判断与终审第四句（源文档§33；前三句 v2.1 译文保留，第四句 v2.2 新增）

> **第一眼：这是一个现代游戏。**
> **第二眼：这是一个非常有中国传统绘画底蕴的游戏。**
> **第三眼：人物像游戏角色，但线条、服饰、色彩、留白和构图又明显来自中国人物画与连环画。**
> **最终：即使改变时代、角色和场景，视觉系统仍然保持统一。**
> 而不是第一眼就看到「AI 国风」「仙侠」「东方幻想」。

道劫读法：把「现代游戏」读作「新中式修仙叙事游戏」。

最终公式（源文档§33 原句，v2.2 七项乘法；括注为道劫轴替换）：

> **现代游戏完成度 × 中国人物画 DNA × 连环画叙事 × 历史系统（道劫＝修仙阶层门派服饰轴，形制仍取历史事实） × 传统色 × 受控空间密度 × 图形呈现语言。**

v2.2 相对 v2.1 公式新增**受控空间密度**（留白口径升格，§6.1）与**图形呈现语言**（§8）两项；旧「留白」一项并入「受控空间密度」。

审稿四问（可执行版）：

| 眼 | 问题 | 不过的典型样子 |
|---|---|---|
| 第一眼 | 像一款现代游戏的资产吗？ | 像古画截图、像孤立单幅插画，无完成度与资产统一性 |
| 第二眼 | 有传统绘画底蕴吗？ | 线条 / 设色 / 构图无人物画来源，只剩「古风」标签 |
| 第三眼 | 线条、服饰、色彩、留白、构图经得起看吗？ | 动漫描边、仙侠铠甲、满构图零留白、高饱和堆料 |

### 3. 写作纪律（读各篇时同步执行）

- **色名纪律**：给提示词的建议只用色名（宣纸白 / 米白 / 朱红 / 绛红 / 石青 / 青灰 / 赭黄 / 朱砂感…），不抄色号、不写色温数值 / 百分比 / 可辨彩占比——数值口径只留在指导正文的审稿观察栏。
- **两口径严格分开**：「宣纸白」是可用色名；「宣纸质感 / 纸纹 / 纤维」是禁用质感词（prefix.md 浅净平涂底硬锁，prefix.md:102）。源文档出现「宣纸白」不连带解禁纸纹。
- **英文词口径**：关键风格词括注英文只取源文档 v2.2 现行原词表——§25（搜索策略）/ §3.2（线条）/ §4.1（水墨）/ §5（色彩）（如 `negative space`、`fine Chinese linework`、`subtle ink atmosphere`），不自造英文词；提示词正文仍按 prefix.md 装配顺序以中文题材正文为主。
- **示例句正向表述**：写作与提示词示例不出现「不要 / 禁止」句式，否定项一律归入避免词表或 Negative Prompt 段（对齐 prefix.md 装配顺序，prefix.md:112-114）。

## 八、道劫应用要点

1. **先背一句话定义与七项排除**——审稿第一动作是对「它不是」表，命中任一排除项即打回，先于一切细节评判。
2. **双轴分工句随身**：工笔负责结构（五官 / 手部 / 衣缘 / 甲胄走细线勾勒），水墨负责气韵（背景 / 远景 / 云雾走淡墨虚实）。
3. **优先级即裁决序**：历史真实感＞奇幻感、绘画审美＞特效审美、构图＞堆料、线条＞光效；同级争议按此排序。
4. **「淡」非「旧」、受控饱和、留白一级条件＋分型密度是色调与构图的默认态**，偏离需显式理由（如战斗演出豁免）；留白量按资产分型取值（立绘中 / 剧情高 / 山水很高 / 战斗低中）。
5. **三眼判断作终审**：第一眼现代游戏 → 第二眼传统底蕴 → 第三眼线条服饰色彩留白构图来源可辨 → 终审第四句「改变时代、角色和场景，视觉系统仍然保持统一」（v2.2 §33）。
6. **自动层零接触**：不抄写、不追加「四、工笔硬锁」；负面项一律进 Negative Prompt 段，正向正文保持正向表述。
7. **色名纪律两口径**：只写色名不写数值；宣纸白（色名）与纸纹纤维（禁用质感词）严格分开。
8. **战斗豁免只走 X6 单一口径**：演出镜头可临时拉满强度，线条与传统色体系在镜头间隙恒定；静态资产永不适用。
9. **连环画只作叙事气质参考**：营销词不作硬约束；叙事场面按道劫事件（论道 / 斗法 / 渡劫 / 入宗 / 送别）组织。
10. **按层组词、不找万能单体**：Style / Line / Color / Composition / Costume / Scene 分层思考，模块可替换可重组。
11. **冲突以 prefix.md 为准**——本指导是人读参考，不拥有生成行为。
