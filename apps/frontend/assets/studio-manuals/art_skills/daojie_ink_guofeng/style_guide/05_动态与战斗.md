## 一、总纲:两类画面,一个画风

**核心原则(源文档§20.3 原句):「战斗画面可以更强烈,但:动作强度增加,不等于视觉语法切换成仙侠 CG。」**(prefix.md X6 译句「提高动作强度,但不改变基础画风」同向沿用;v2.1 §8 原句已由 §20.3 承接)

静态画面与战斗画面不需要完全一样,但分化只发生在**强度层**(动势/姿态/墨色冲击/分镜张力),不发生在**画风层**(线条/传统色/留白语法/媒介)。战斗画面加的是动作与墨的浓度,不是另一套渲染语法。v2.2 将画面分型为三种视觉密度(源§20:剧情 §20.1/角色 §20.2/战斗 §20.3),本章按静态剧情与战斗两极组织,角色立绘密度见源§20.2 与 `04_留白与构图.md` §2.2 分型表。

| 维度 | 静态/剧情画面 | 战斗/技能画面 | 画风层归属 |
|---|---|---|---|
| 构图 | 清疏留白、低信息密度 | 动势构图仍守三层分明,主体明确 | 画风层(两者相同) |
| 视觉密度 | 低~中(源§20.1: Density Low~Medium) | 中~高(源§20.3: Density Medium~High) | 强度层(浮动) |
| 线条 | 工笔细线勾勒(fine linework) | 同一套细线,动势中仍可辨 | 画风层(恒定) |
| 色彩 | 淡彩 2-3 种低饱和矿物色点缀 | 同一传统色体系,允许局部点睛色加锐 | 画风层(恒定) |
| 墨色 | 淡墨层叠、墨分五色 | 浓墨重笔、泼墨飞白可局部加强 | 强度层(浮动) |
| 姿态 | 克制站姿/坐姿,中性微表情 | 动作方向明确、重心真实、强调姿态 | 强度层(浮动) |
| 特效 | 灵气以水墨晕染表现 | 演出镜头可拉满视觉强度(X6 战斗侧) | 强度层(仅限镜头级) |

**强度分层模型(贯穿全章)**:

- **恒定层** — 工笔线描、传统色体系、浅净平涂底、留白语法、衣物完整锁、身份一致性:任何画面强度下都回到同一套 DNA。对应历史画卷基因行:**线条＞光效、构图＞堆料、绘画审美＞特效审美**(prefix.md 风格基因节)。
- **浮动层** — 动势、姿态张力、墨色浓淡对比、镜头强度:按剧情需要在七字诀基线与演出拉满之间滑动,滑动范围由 X6 战斗侧豁免单一口径界定(见本章四)。

## 二、静态/剧情画面:七字诀

静态剧情画面(修炼悟道/日常修行/师徒对话/宗门日常/悟道顿悟)按七字诀执行(七字诀系 v2.1 §8 原表,v2.2 已移除;现行对应源§20.1 剧情密度参数: Density Low~Medium / Motion Low / **Negative Space: High / Line: High / Atmosphere: High**——七字诀与之逐项同向,道劫侧沿用七字诀执行):

| 字诀 | 释义 | 道劫提示词落点(色名/画面词) |
|---|---|---|
| **淡** | 墨淡彩淡,**「淡是关键而非旧」**——颜色真实存在但不抢主体(v2.2 读作受控饱和,§5.1) | 淡墨层叠、薄透矿物罩染、低饱和淡彩(controlled saturation) |
| **静** | 姿态与情绪克制,中性微表情,画面无骚动 | 静坐悟道、屏息对谈、清静无扰 |
| **疏** | 疏朗布景、低信息密度,次要元素围绕主体 | 疏朗布景、受控视觉密度(controlled visual density)、次要元素简省 |
| **雅** | 宋式典雅秩序,矿物色古雅统一 | 青绿雅正、宣纸白底、古雅统一 |
| **留白** | **留白是一级构图条件**——天空/水面/雪地/雾气承担视觉呼吸 | 大面积留白(negative space)、远景淡墨轻压、允许画面「空」 |
| **线条** | 工笔细线承载结构,线条优先于渲染 | 细线勾勒(fine linework)、铁线描轮廓、发丝衣纹清楚 |
| **气韵** | 写意晕染给空气与远景,气韵生动 | 水墨晕染、空气透视(atmospheric perspective)、灵气如雾 |

### 优先/避免词表(静态剧情)

| 优先 | 避免 |
|---|---|
| 淡墨、薄染、清疏、安静背景(soft background,§17)、大块留白(negative space,§25)、开式构图(open composition,§7/§18) | 满构图、超高细节背景、堆满视觉信息 |
| 中性微表情、克制神态 | 夸张表情、戏剧化姿势 |
| 灵气如雾、远山淡墨(faded distant background,§4.1 原词) | 强光影、高对比黑白、狂草飞溅 |

静态悟道/日常修行配色直接引用 `prefix.md` 情绪色盘对应行(修炼悟道=宣纸白+青绿/旧金+淡墨,柔光留白;日常修行=青绿+宣纸白/赭石+淡墨,清新雅致),色名照抄,数值与色号口径留在审稿观察栏。

## 三、战斗/技能画面:强度走动态层

### 3.1 可增加项与道劫侧译

v2.1 §8 战斗可增加项(动势、姿态、墨色冲击、旗帜运动、战马、烟尘、速度感)v2.2 已移除,现行对应源§20.3 战斗密度参数: Density Medium~High / Motion High / **Ink Impact: Medium~High** / Negative Space: Medium / **Special Effects: Controlled**——「墨色冲击」与「特效受控」自此为源文档原词。道劫侧以**墨色与姿态**承载同等职能:

| 可增加项(v2.1 §8) | 职能 | 道劫侧承载(提示词落点) |
|---|---|---|
| 动势 | 画面有运动方向 | 动作方向明确、重心真实、劈斩/掌击/闪身择一(成片模板 21 要点) |
| 姿态 | 强调姿态传达人物张力 | 持剑回身、踏罡步斗、袖拢诀印;眼神情绪写明(锐利/冷峻择一) |
| 墨色冲击 | 视觉冲击由墨承担 | 浓墨重笔、泼墨飞白沿动作轨迹、气势凌厉(情绪色盘·斗法对决行) |
| 旗帜运动 | 大面积运动元素 | 宗门旗幡翻卷、幡幢当风、剑穗与袍袖翻飞 |
| 战马 | 骑乘动态 | 御剑破空、遁光拖墨痕、灵鹤俯冲、异兽坐骑践尘 |
| 烟尘 | 环境反馈 | 罡风卷尘、碎石纷飞、劫云翻涌、低对比远山雾气 |
| 速度感 | 速度的可视化 | 剑光以银白线条+墨色残影表现(视频约束 V3)、墨色运动残迹 |

### 3.2 动态四通道(怎么把强度画进去)

1. **姿态通道** — 动作写到动词精度(持何物、劈向谁、重心落哪脚);动作方向保持一致(视频约束 V1:左→右前进、右→左对抗),动作有起承转合(V5)。
2. **墨色通道** — 灵力冲击=水墨晕染+对应颜色淡彩(V2),剑光=银白线条+墨色残影(V3);泼墨飞白只落在动作轨迹上,脸、手、武器轮廓保持线描可读(成片模板 21)。
3. **毛发衣袖通道** — 动感由发束、袍袖下摆整体翻卷的轮廓线、剑穗与松散配件承载;衣褶仍守 2-4 条长结构褶(prefix 衣褶裙摆锁),衣物完整可穿(prefix 衣物完整锁)——战损以点睛色(刃口/伤痕/血朱砂)交代,衣袍本身保持闭合完整。
4. **点睛色通道** — 朱红或旧金只作击中焦点(成片模板 21),法印/刃口/旗记用血红小面积提锐;金色只作烫金/旧金点缀,不作视觉主角(X6 静态侧原文)。

### 3.3 优先/避免词表(战斗/技能)

| 优先 | 避免 |
|---|---|
| 浓墨重笔、泼墨飞白、剑气纵横、罡风、劫云压顶 | 仙侠法阵、金光爆炸、满屏粒子 |
| 动作轨迹墨痕、银白剑光线条、遁光 | 巨型神兽、霓虹光效、体积光泛滥 |
| 三层构图、背景简化、旗甲视觉锚 | 电影海报式堆满(人物巨大+特效齐上) |
| 灵气如墨晕开、淡彩沿轨迹 | 高饱和蓝紫、荧光色、赛博感 |

### 3.4 战斗红线(严禁表)

| 编号 | 严禁内容 | 判定依据 |
|---|---|---|
| B1 | 仙侠法阵/金光爆炸/满屏粒子/巨型神兽/霓虹光效 | v2.1 §8「不能因此变成」原单(v2.2 已移除);现行对应源§19.1(magic circle / giant dragon / phoenix / excessive particles / neon fantasy lighting)+§26 风险清单;筛选语境按源§15 Gate 归级,资产验收语境照打回 |
| B2 | 战斗画面变成另一套渲染语法(CG 体积渲染/赛璐璐/厚涂特效) | 「提高动作强度,但不改变基础画风」;X1/X2 全局严禁继续适用 |
| B3 | 背景自动塞满、堆料式战斗海报 | 源§14「空间/视觉密度控制」指标+§15 Gate 归级(v2.1 一票否决已替代);构图＞堆料 |
| B4 | 衣袍撕裂/碎边/褴褛承载「战损」 | prefix 衣物完整锁(全员):战痕走点睛色与岁月感,衣物完整可穿 |

Negative Prompt 追加词(并入唯一末尾负面段;源文档§19 原词=§19.1 xianxia/oriental fantasy/eastern fantasy/magic circle/giant dragon/phoenix/excessive particles/neon fantasy lighting+§19.4 overcrowded/maximalist composition,prefix 负面基线原词=golden glow/volumetric light/dramatic god rays/high saturation,不自造):`xianxia, oriental fantasy, eastern fantasy, golden glow, volumetric light, dramatic god rays, neon fantasy lighting, magic circle, giant dragon, phoenix, excessive particles, high saturation, overcrowded, maximalist composition`。

## 四、视觉强度豁免(X6 战斗侧):单一口径

**精确引用(prefix.md X6 原文)**:「**战斗/技能演出镜头不适用本条**(官方『猛火计』演出实证=高饱和红金+光效大作):此类按 art_storyboard_video『连环画叙事层』双层口径——**视觉强度可临时拉满,但线条与传统色体系在镜头间隙保持恒定**。」(猛火计为三国侧官方演出实证,引自 README 09-18 历史画卷基准;v2.1 源文档§1 依据引文 v2.2 已移除,仅作豁免强度证据。)

**装配顺序第 3 条(prefix.md)同步引用**:「动作镜头可临时提高视觉强度但线条与传统色体系不变。」

### 适用范围

| 画面类型 | X6 堆料黑名单 | 视觉强度 |
|---|---|---|
| 战斗/技能**演出镜头**(分镜帧/视频高潮) | 豁免 | 可临时拉满(高饱和特效大作级) |
| 渡劫/突破高潮演出镜头 | 豁免(叠加 L3 例外:高光时刻可临时突破局部色彩) | 可临时拉满 |
| 斗法/大战的**静态剧情图、章节插图** | **全部适用** | 按静态画面强度,走墨色与姿态承载 |
| 角色设定板/立绘/资产图 | **全部适用** | 七字诀基线 |

### 豁免三条件(同时满足才可拉满)

1. **镜头级** — 豁免只落在单个演出镜头/单帧高潮,「临时」即用毕即收;镜头间隙(前一帧/后一帧的剧情帧)回到传统色与工笔线常态。
2. **演出类** — 只有战斗/技能/渡劫突破演出可用;悟道、日常、对话、场景空镜按静态画面处理。
3. **线色恒定** — 拉满的只有强度(饱和度/特效/冲击),工笔线描与传统色体系在画面内仍可辨;线条断裂、色体系整体漂移即豁免滥用。

### 两条不自创红线

- **不自创第二套豁免** — 除 X6 战斗侧外,不再为「燃」「爆」「帅」等任何理由新增豁免名目;L3 例外只管局部色彩突破,不覆盖堆料黑名单。
- **不扩大豁免范围** — 豁免止于演出镜头,静态资产/剧情图/设定板一律按 X6 原文执行;「这个角色很重要」不是拉满理由。

## 五、连环画叙事分镜语言

### 5.1 定位口径(README 09-18 降格)

「连环画」「剪纸画」系官方营销词,09-18 官方截图实证其视觉占比有限(多在过场/UI)——**当叙事气质参考,不作硬约束**;不按 v2.1 §7「极其重要的一层」强度引用(v2.2 已移除该定级,现行源§28 C 自身亦定位「辅助 Style DNA」)。落到生产:连环画语言用于组织**叙事画面感**(人物处在具体事件中),用于提示词时是气质词(如「连环画叙事感」),不是需要逐项验证的硬指标。

### 5.2 七项叙事价值(源§28 C 五项原词+侧补两项 → 道劫侧译)

| 叙事价值 | 道劫侧译 |
|---|---|
| 人物叙事 | 人物带着身份与目的出现在画面(修士在做事,非摆拍) |
| 单幅故事场景 | 一格说清一个道劫事件瞬间 |
| 清楚的主次关系 | 主体明确、次要元素围绕、背景交代后让位 |
| 历史事件视觉化 | 道劫事件视觉化(悟道/斗法/渡劫/宗门事务/魔道入侵择一) |
| 动作瞬间 | 抓「正在发生」的一刻(出剑半式/诀成刹那/劫雷将落) |
| 人物关系 | 双人/多人的站位、视线、手势说明关系张力 |
| 场景交代 | 背景用具体物件说明地点(石阶/灯盏/残符/丹炉/山门) |

> 其中人物叙事、单幅故事场景、历史事件视觉化、动作瞬间、人物关系为源§28 C 原词;「清楚的主次关系」「场景交代」为道劫侧补(v2.1 §7 原列)。

### 5.3 理解链与「纯国画 LoRA 不够」的原因

```text
传统人物画 → 连环画叙事 → 现代游戏角色设计 → 镜头化/分镜化
```

单一「国画 LoRA」通常只覆盖链首(怎么画),缺叙事组织(画什么瞬间)、现代角色完成度与镜头语言——这是源文档§28 C 给出的方法论结论(连环画=「辅助 Style DNA」;图形层镜头语言锁定见源§8.2:Shot Language / Panel Layout / Narrative Framing / Visual Hierarchy。其具体模型与链接不入本指导,只作筛选方法论佐证;分级/评分/六问迁移见 5.5)。道劫侧同理:纯古画质感缺游戏完成度(README 09-18 官方截图实证),分镜生产须同时带叙事语言与游戏资产完成度。

### 5.4 单幅叙事五要素(写分镜/剧情图时逐项过)

1. **事件定性** — 本格讲什么事件(对峙/交谈/行军/骑乘/战斗/谋划/入城/送别择一,prefix 装配顺序第 3 条叙事事件单;道劫侧扩补悟道/渡劫/宗门事务),人物处在具体事件中,摆拍即返工。
2. **动作瞬间** — 表现冲突/发现/转折的一瞬间(回头/伸手/压住伤口/递出卷轴,成片模板 03 要点)。
3. **主次关系** — 主体占视觉重心,次要元素围绕分布,背景用具体物件说明地点后降细节。
4. **三层构图** — 前景遮挡+中景人物+远景环境(成片模板 03;R6 纵深条款见 art_storyboard_video「3D 纵深构图」)。
5. **双人关系格** — 谈判/师徒/对峙用双人构图:只有角色 A 与 B,前后或左右关系明确,眼神方向与手部动作说明张力(成片模板 26)。

### 5.5 审稿六问(v2.1 §21 六问 → 动态叙事迁移;v2.2 已移除原表,现行对应源§14 评分+§15 Gate+§32 验收八问)

1. 这张图在用**水墨语言**承载动作与事件,还是只在堆特效?
2. 动势之中是否保住现代游戏角色设计完成度(比例/结构/装备可信)?

## 七、AI 漫剧镜头栈与「同一部作品」

### 7.1 镜头栈(源文档§11.3 原序,道劫侧沿用;图形构图层为 v2.2 新增位)

```text
Style Reference(风格底座/风格参考)
      ↓
角色身份锁定(面容/体型/发型,身份一致性锁)
      ↓
服饰/时代锁定(阶层门派服制+形制时代,锁定服饰结构)
      ↓
镜头 / Pose(景别/机位/动作方向)
      ↓
场景(三层构图+留白用途)
      ↓

      ↓

      ↓

```

游戏化美术语言(现代游戏完成度/资产统一性/角色立绘/镜头栈)整体保留自源文档的方法论,题材事件换成修仙叙事(悟道/斗法/渡劫/宗门/魔道)。生成顺序按源§30 组织:**身份→服饰→姿态→场景→镜头**,一致性底线=「同一个人连续出现 20 张时仍然像同一个人」;镜头语言的锁定项另见源§8.2(Shot Language/Panel Layout/Narrative Framing/Visual Hierarchy)。

### 7.2 资产统一性:恒定量与变量

**核心(源文档§8.2/§36 原句):「这样连续 100 张图才有机会被识别为:同一部作品」「建立一套能够持续生成 100 张、1000 张仍然属于同一视觉世界的生产系统」**,不是每张独立追求最漂亮(源§13.1:「不要通过单张『最好看的图』决定模型」)。

| 类别 | 内容 | 跨镜行为 |
|---|---|---|
| 恒定量 | 工笔线描、传统色体系、浅净平涂底、身份(脸/发/体型)、服制结构、光照语法(均匀平光/柔和侧光) | 全片一致,镜头间漂移即不合格 |
| 变量 | 景别/机位/姿态/动作方向/场景/情绪色盘行/视觉强度 | 按分镜需要变化,单镜单变化轴 |

(恒定量清单与源§30 一致性控制同源:Face Reference / Character LoRA / Costume Lock / Color Accent / Silhouette / Hair·Headwear / Weapon。)

强度轴同样服从统一性:演出镜头拉满后,相邻剧情帧回常态,观众看到的仍是同一部作品的两级强度,而非两部作品。

### 7.3 最终目标(源文档§33 三眼判断+终审第四句,道劫侧表述)

- 第一眼:这是一个现代游戏(修仙叙事游戏美术;「新中式」为项目内部分析框架概括,非官方标签,源§0.2)。
- 第二眼:非常有中国传统绘画底蕴(水墨工笔、传统色、留白)。
- 第三眼:人物像游戏角色,但线条、服饰、色彩、留白与构图明显来自中国人物画与连环画。
- 终审:即使改变时代、角色和场景,视觉系统仍然保持统一(v2.2 新增第四句)。
- 而非第一眼看到「AI 国风」「仙侠」「东方幻想」。

## 八、道劫应用要点

1. 先分型再动笔:本画面是静态剧情(七字诀)还是战斗/技能演出(动态层),决定强度基线。
2. **「提高动作强度,但不要改变基础画风」**——强度只走姿态/墨色/镜头,线条、传统色、留白语法恒定。
3. 战斗动态四通道:姿态(动词精度+方向一致)、墨色(晕染/飞白沿轨迹)、毛发衣袖(衣褶守 2-4 条、衣物完整)、点睛色(朱红/旧金只作击中焦点)。
4. 战斗红线五项不碰:仙侠法阵、金光爆炸、满屏粒子、巨型神兽、霓虹光效;负面词并入唯一末尾负面段。
5. 豁免只有 X6 战斗侧一套:镜头级、演出类、线色恒定三条件同时满足;静态资产/剧情图/设定板永不豁免,渡劫/突破/大战等高光演出镜头可叠 L3+X6(双豁免典型)。
6. 连环画=叙事气质参考,不作硬约束;单幅叙事五要素(事件定性/动作瞬间/主次/三层/双人关系格)逐项过,人物处在具体事件中,摆拍返工。
7. 理解链四段(传统人物画→连环画叙事→现代游戏角色设计→镜头化)同时满足;纯古画质感判缺游戏完成度。
8. 场景映射对号入座:斗法(浓墨重笔+泼墨飞白)/渡劫(灵气爆发天地异象,双豁免)/战场水墨(淡墨分层+旗甲视觉锚)/悟道日常(七字诀);色名照抄情绪色盘行,色号与占比只留审稿观察栏。
9. 镜头栈按源§11.3 原序装配(风格→身份→服饰/时代→镜头→场景→图形构图→色彩→序列/视频);**连续 100 张仍像同一部作品(源§8.2/§36)**优先于任何单张的「最漂亮」。
10. 审稿用六问收口:水墨承载否/完成度在否/背景塞满否/金光蓝紫否/线条可辨否/同一部作品否——任一项不过即返工。
