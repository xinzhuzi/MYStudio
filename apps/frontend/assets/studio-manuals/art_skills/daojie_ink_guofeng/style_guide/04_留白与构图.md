## 一、核心口径:留白是一级条件与 Visual Density Control

1. **留白是一级条件** — v2.1 §5 曾以「留白:必须升级为一级条件」立规(该节 v2.2 已移除);v2.2 现行口径(源文档§6.1 原句):**「留白不是『画面必须很空』,而是『控制视觉密度和信息优先级』」**,并明言「以后不用『必须大留白』作为单一规则,而使用 **Visual Density Control**」。道劫侧承接:一级条件表述保留(prefix.md 历史画卷基因行:「留白＞满构图、构图＞堆料、线条＞光效」),执行口径自 v2.2 起按分型密度取值(见 2.2)。一级条件的含义:留白与线条、传统色、人物气质平级,是画面组织的先决项,不是「画完主体后剩下的区域」。
2. **这是与东方幻想 AI 拉开差距的第一变量** — v2.1 §5 首句「这是本项目与大量『东方幻想 AI』最重要的差异之一」与 §0.1.4 对照表均已随旧节移除;现行对应源文档§26 规避方向与风险清单(金光/蓝紫高饱和/法阵/神兽/粒子/体积光/云海/幻想甲胄/过度装饰/超高信息密度)+§19.4 构图抑制模块。对照仍成立:新中式一列是留白/克制/山水与叙事空间;东方幻想一列是堆满视觉信息/金光粒子光晕/云海龙雷法阵。满构图不是小审美偏差,而是东方幻想模板的固定成分。
3. **构图＞堆料、线条＞光效** — 优先级对仗沿用 README/prefix 历史画卷基因行:构图的收益(呼吸、层次、主体)优先于细节堆料的收益,线条的收益优先于光效。写构图段时先问「空放在哪」,再问「还要加什么」。
4. **留白≠空白** — 留白是有用途的空(用途约束见第五节);纯白背景、无场景、空无一物属于画面缺陷,属于留白的反面(对齐 art_scene.md 严禁项「背景纯白/无场景」口径)。

## 二、留白不是「少生成东西」:六项职责、分型密度与测试双看

### 2.1 六项职责(源§6.1 全量)

留白不是删元素的副产物,它本身承担六项职责(源文档§6.1「留白主要承担」原列;v2.1 §5.1 旧表的「空间层次/古典画面感」两条已并入其余各项):

| 职责(源§6.1 原词) | 释义 | 道劫画面落点 |
|---|---|---|
| 主体突出 | 空衬托实,主角成为唯一视线锚点 | 立绘旁整片呼吸区,人物轮廓线因此可读 |
| 空间呼吸 | 画面有可歇眼的空间,观感疏朗不逼仄 | 大面积天空/浅雾/水面承担呼吸(prefix 装配第 3 条) |
| 情绪表达 | 空的方向与体量决定静/寂/远 | 悟道图的静、送别图的远、渡劫前的蓄势 |
| 前中后景关系 | 空白参与三层关系的构建,三层各自可辨 | 分镜三层分明(近景入框/中景主体/远景淡墨)的构图根源 |
| 远近虚实 | 远淡近清,空白承过渡 | 远山与近景之间的过渡空带、山脚隐雾 |
| 视觉引导 | 空区接住并引导视线落向主体 | 云梯石阶/灵溪自前景蜿蜒入画,视线由空处落向主角 |

古典画面感的「计白当黑」观看习惯仍在,但自 v2.2 起由图形呈现语言承载(源§8:画卷/画册/连环画分镜),不再单列为留白职责。

### 2.2 分型密度表(源§6.2 全量,本篇执行口径)

留白量按资产分型取值——「必须大留白」自 v2.2 起废止为单一规则,统一按 Visual Density Control 分型:

| 场景 | 留白 | 视觉密度 | 动态 |
|---|---|---|---|
| 角色立绘 | 中 | 中高 | 低 |
| 剧情场景 | 高 | 低中 | 低 |
| 山水远景 | 很高 | 低 | 低 |
| 战斗画面 | 低中 | 中高 | 高 |
| Key Art | 中 | 中高 | 高 |
| 连环画叙事 | 按镜头变化 | 中 | 中高 |

道劫侧读法:立绘=中(主体呼吸区在、背景安静即合格,勿强求空);剧情图=高(源§20.1:Negative Space: High);山水远景=很高;战斗=低中(源§20.3:Negative Space: Medium,动势优先);分镜帧按所属镜头类型对号。

### 2.3 测试双看

> **评审任何模型/LoRA/成片,不能只看「人物画得好不好」,必须同时看「它会不会给画面留空间」**(v2.1 §5.1 原句;v2.2 现行落点=源§14 评分指标「**空间/视觉密度控制**(10%)」:能否控制留白与背景密度;角色侧另见源§20.2「Background Detail: Low」)。

操作口径:同 seed 对拍时,除人物质量外固定加看一项——主体区域之外的面积是否承担呼吸/层次/引导,还是被模型自动填满。背景行为与人物质量分开记录、互不遮掩:人物高分+背景塞满,筛选语境按源§15 Production Gate 归级(不入 S/A 主生产),资产验收语境照第七节红线打回。

## 四、古典山水 = 构图规则,不是贴一张国画背景

### 4.1 场景要素清单(源§7 场景目标 → 道劫落点)

| 要素(源§7 原词) | 构图含义 | 道劫场景落点 |
|---|---|---|
| layered mountains(山体有层次) | 山体层层推进,而非一堵墙 | 灵峰三重,淡墨递远 |
| atmospheric perspective(空气透视) | 雾承担留白与层次过渡 | 灵雾横断中远景,山脚隐入雾中 |
| quiet architecture(建筑安静) | 建筑是节奏点,不是密度 | 宗门殿宇疏落三五处,沿山势布列 |
| sparse vegetation(植被稀疏) | 树石点景,铺满即失职 | 灵松三五株成节奏,不成林填底 |
| clear foreground/midground/background(前中后景明确) | 三层各自可辨 | 对齐分镜三层分明条款 |
| visual breathing space(视觉呼吸空间) | 「空」本身是画面成分 | 雪原渡劫、灵湖如镜、天际一线劫云 |

侧补两条(道劫侧沿用,现行锚点):远山简化→soft distant background(源§18)/faded distant background(源§4.1 原词);道路/河流提供视觉引导→源§6.1「视觉引导」职责(见 2.1 表)。

### 4.2 场景目标对句

> **古典山水构图规则 × 修仙游戏空间**,而不是「国画贴图 × 修仙角色」。(依据:源文档§7 原句「**古典山水构图规则 × 现代游戏空间**」,并告诫「不要把它理解成『直接贴一张古画背景』」,按道劫叙事转译)

- 前者:用山水章法组织**可通行、可进入、层次可辨**的游戏空间——山径能走、殿宇能进、远景能望;构图规则长在空间结构上。
- 后者:把一张国画垫在角色背后当背景板;贴图感、空间假、留白沦为「没画到的地方」。
- 落点:art_scene.md 场景美学原则第 2 条已并入此口径(「古典山水是结构不是贴图」)。

### 4.3 场景栈与构图控制(源§11.2、§29、§12)

- 场景生产栈(源§11.2):Base Model → 中国历史/叙事风格层 → 山水/建筑模块 → **参考构图** → 深度/结构控制 → 色彩一致性。v2.1 §15 四层场景栈已移除,现行栈里留白/构图由「参考构图+深度/结构控制」两步承担,仍是**独立控制位**,不是山水层的副产品。
- 构图控制口径(源§29 原句):「**构图首先是控制问题,其次才是风格问题。**」推荐手段=Reference Image / IP-Adapter / ControlNet / Pose / Depth / Lineart / Canny / Layout;「LoRA 可以影响构图倾向,但不应承担精确构图控制」。
- 权重口径(源§12):v2.2 不把固定数值写成规范,只给实验区间(Color/Auxiliary 0.10/0.20/0.30);构图精确控制不靠 LoRA 权重(源§29),轻量辅助件的具体权重以同 seed A/B 对拍确定(源§13),作者页推荐值只作起点。

## 五、与 prefix.md 装配顺序第 3 条的衔接

### 5.1 三条构图约束(项目/约束/提示词)

| 项目 | 约束 | 提示词落词 |
|---|---|---|
| 呼吸载体 | 大面积天空/雪地/水面/远山/浅雾承担视觉呼吸 | 大面积留白的天空、远山淡墨、浅雾横断 |
| 优先次序 | 清疏构图/疏朗布景/低信息密度/空气透视/远景简化**优先于堆料** | 疏朗构图、清疏布景、低信息密度、空气透视 |
| 主体关系 | 主体明确、次要元素围绕分布、背景不抢角色、允许画面「空」 | 主体居中景,背景安静,画面留有大片空区 |

### 5.2 留白用途约束(prefix.md 口径,五用途)

> 留白必须服务**视线、天道感、雾、水面或卷轴区域**,不是无意义空白(prefix.md 装配顺序第 3 条原口径)。

| 用途 | 含义 | 道劫正向示例 |
|---|---|---|
| 视线 | 空区接住并引导观者视线落向主体 | 立绘人物居右下,左上整片浅雾,视线由空处落向主角 |
| 天道感 | 空是「天/道」的在场方式 | 渡劫图上方大片天空,仅一线劫云横过 |
| 雾 | 雾是留白的柔化形态,兼作层次 | 灵雾横断中远景,山脚隐入雾中 |
| 水面 | 以空写景,倒影轻扫 | 灵湖如镜,近岸工笔、远岸留白 |
| 卷轴区域 | 长卷的蓄势段、册页的天地头 | 渡劫长卷自右向左展开,右段大量留白蓄势 |

### 5.3 构图段正向示例(示例只写正向;禁止事项一律进 Negative Prompt)

- 人物(内门弟子立绘):内门弟子立于画面右下,持剑按腰,左上大面积浅雾远山承担视觉呼吸,背景安静,开放构图。
- 场景(宗门山门):宗门山门居于中景,石阶自前景蜿蜒入画作视觉引导,天空大面积留白,远山淡墨简化,灵松三五株作节奏点。
- 长卷(渡劫):渡劫长卷自右向左展开,右段留白蓄势,中段劫云压顶,左段人物渡劫,卷轴构图。

口径提醒:留白区底色用色名写法(如「宣纸白」「米白」);纸纹/纤维类质感词与色名两口径严格分开,前者仍按 prefix 浅净平涂底硬锁禁用。

## 六、分型密度与镜头强度:留白口径的分界(§6.2 分型表+X6 单一口径)

- 静态/剧情场景留白=高、密度=低中(2.2 分型表;源§20.1 剧情密度:Density Low~Medium / Motion Low / **Negative Space: High** / Line: High / Atmosphere: High):淡、静、疏、雅、留白、线条、气韵全额适用;悟道、日常修行、送别、入定等静场是留白的主力场景。山水远景留白=很高、密度=低。
- 战斗/斗法演出镜头留白=低中、密度=中高(源§6.2 战斗行;源§20.3: Density Medium~High / Motion High / Ink Impact Medium~High / **Negative Space: Medium** / Special Effects: Controlled):视觉强度可临时拉满,线条与传统色体系在镜头间隙保持恒定(prefix.md X6 唯一口径);**提高动作强度,但不改变基础画风**(源§20.3 原句:动作强度增加,不等于视觉语法切换成仙侠 CG)。斗法镜头中留白可收窄,动势、墨色冲击、尘烟可增强。
- 战斗豁免只覆盖演出镜头本身;静态资产与剧情图不得援引该豁免减免留白(本篇不自创第二套豁免、不扩大豁免范围)。

## 七、筛选判据:10% 权重指标 + Production Gate 归级 + §13.1 观察

1. **权重项**:v2.2 评分表(源§14)设「**空间/视觉密度控制**」指标,权重 **10%**(v2.1「留白能力 15%」已改),判断标准=「能否控制留白与背景密度」。
2. **归级项**:v2.1 §14 一票否决「背景自动塞满」已被源§15 **Production Gate**(S/A/B/R/X)替代——命中即不入 S/A 主生产,按 R(DNA 研究)或 X(淘汰)归级。「权重+归级」双保险不变:10% 权重保证它被看见,Gate 保证满构图模型进不了主生产。
3. **候选快筛**:任何候选模型先问「**它会不会自动把背景塞满?**」——v2.1 §21 六问第 3 问(六问 v2.2 已移除)的现行对应=源§14 指标+§13.1 观察四项(平均稳定性/风格一致性/可控性/与其他模块兼容性);源§13.1 原句:「不要通过单张『最好看的图』决定模型」。
4. 操作口径:每个候选固定两条对拍——①人物图带留白指令(negative space / soft background),②场景构图模板(源§18)。任一条背景自动填满即记归级证据;两条均留白合格后,再看人物/线条/色彩各项。

## 九、道劫应用要点

1. 写任何画面先定留白:空放在哪、承担五用途(视线/天道感/雾/水面/卷轴区域)中的哪一项,再安排元素——**留白是一级条件**,与线条、传统色平级;留白量按分型取值(立绘中/剧情高/山水很高/战斗低中,2.2 表)。
2. 构图段落词按第五节三列口径:呼吸载体 + 优先词(疏朗构图/清疏布景/低信息密度/空气透视/远景简化)+ 主体关系(背景不抢角色、允许画面「空」)。
3. 英文构图词只取第三节词表原词(源§7/§25/§17/§18/§16.1 现行词),不自造英文词。
4. 高风险六词永不入正向;overcrowded/maximalist 收进 Negative Prompt,与其余负面合并为唯一末尾负面段。
5. 场景一律按第四节要素清单组织:山体层次/远山简化/云雾空气感/建筑稀疏有秩序/道路河流引导线/植被节奏点/前中后景明确/天空水面雪地大面积留白——**古典山水是构图规则,不是贴一张国画背景**。
6. 场景目标记对句:**古典山水构图 × 修仙游戏空间**,而不是国画贴图 × 修仙角色。
7. 评审与筛选执行双看:人物质量与背景留白行为分开记录;留白能力按源§14「空间/视觉密度控制」10% 权重打分,「背景自动塞满」按源§15 Production Gate 归级(不入 S/A 主生产)。
8. 静态与剧情图留白全额适用;斗法演出镜头按 X6 单一口径临时拉满视觉强度,镜头间隙线条与传统色恒定;静态资产不得援引豁免。
9. 留白区底色只用色名(宣纸白/米白),纸纹纤维质感词保持禁用,色名与质感两口径不混写。
10. 构图精确控制走 Reference/ControlNet/Layout(源§29),LoRA 只影响构图倾向;轻量辅助件权重按源§12 实验区间、同 seed A/B 对拍确定。
