## 一、本项目的新中式定义

### 1.1 定义式（v2.1 §0.1.1 原句保留；v2.2 已移除该公式，现行定位见源文档§0.2）

> **新中式历史叙事游戏美术 = 中国传统美术 DNA + 现代角色设计 + 现代构图 / 数字绘画 + 历史文化元素。**

道劫语境的转译（叙事轴换仙道，克制品味不变）：

| 项 | 源口径 | 道劫口径 |
|---|---|---|
| 名称 | 新中式**历史叙事**游戏美术 | 新中式**修仙叙事**游戏美术（项目内部分析框架） |
| 叙事内容 | 历史事件、历史人物处境 | 悟道、斗法、渡劫、宗门、魔道 |
| 视觉基因 | 工笔、白描、水墨、连环画、传统色、古典山水 | 原样继承（prefix.md 风格基因表 09-18 历史画卷基因行） |
| 品味 | 留白、克制、雅致、叙事 | 原样继承 |

结构树（源文档§0.2 原树，道劫侧叙事内容换修仙；v2.2 在传统 / 现代两枝外新增图形语言与历史内容两枝）：

```text
《道劫》目标视觉系统（沿源文档§0.2 结构树）
│
├── Traditional Art DNA —— 中国人物画 / 工笔 / 白描 / 水墨 / 连环画 / 古典山水
│
├── Modern Game Translation —— 现代角色设计 / 商业插画完成度 / 数字绘画 / 清晰视觉焦点 / 可控材质与光影
│
├── Graphic / Presentation Language —— 画卷 / 画册 / 连环画分镜 / 书法字体 / 装饰性视觉元素
│
└── Historical Content —— 时代 / 身份 / 服饰 / 甲胄 / 兵器 / 建筑场景（道劫侧按修仙世界的历史化考据组织）
```

### 1.2 一句话工作口径

> **把中国传统绘画的视觉规则重新组织为现代历史题材游戏美术。**（源文档§0.1 原句；道劫侧同义旧译「把审美规则翻译成现代游戏美术，而不是把古画直接搬进游戏」继续作口头版）

对应到提示词写作就是 prefix.md 装配顺序的既有分工：工笔负责结构（细线勾勒、墨线、衣褶），水墨负责气韵（淡墨晕染、留白、空气透视），游戏设计负责完成度（清晰视觉焦点、可读主体、资产统一）。

## 二、为什么成立：传统层 × 现代层

### 2.1 六行对照表（v2.1 §0.1.2 拆解保留；v2.2 现行对应源文档§0.2 结构树——新增图形语言与历史内容两枝，速览见 00 篇 §三.4）

它不是把「传统」原样复制，而是在传统语言上加入现代游戏视觉设计：

| 传统层 | 现代层 | 最终表现 | 道劫侧用法 |
|---|---|---|---|
| 工笔 / 白描 | 游戏角色设计 | 历史人物立绘 | 角色/掌门/长老立绘走工笔线描 + 现代造型 |
| 连环画 | 分镜与叙事设计 | 小人书式场景叙事 | 人物处在具体事件（对峙/斗法/渡劫/送别），叙事气质参考（README 09-18 降格口径，营销词不作硬约束） |
| 水墨 | 数字边缘与空气处理 | 背景虚实、远景淡化 | 远山淡墨、雾气晕散、soft edges |
| 传统色 | 现代色彩管理 | 受控饱和、少量高识别强调色（源文档§5.1/§5.2） | prefix.md 配色五职责：base 宣纸白 + ink 墨 + 少量 primary/accent |
| 山水画 | 游戏场景构图 | 大留白、远近层次 | 三层分镜纵深（近景入框/中景主体/远景淡墨） |
| 历史服饰 | 现代角色造型 | 可识别的身份设计 | 道劫按修仙阶层与门派气质重组（见 §5.2 服饰层） |

依据示例：《三国望神州》官方介绍明确将美术定位为「中国传统水墨工笔美术」，并**按人物气质配中国传统色**设计立绘（v2.1 §1 依据引文，v2.2 已移除；现行对应源文档§5.1「角色识别色」口径）；「淡」的方向、留白一级条件、线条优先三项在同一基准中被本包 prefix.md 全量吸收（prefix.md 历史画卷传统色扩补、装配顺序第 3 条、风格基因表）。

### 2.2 否定式定义（它不是什么）

源文档「它不是」清单（v2.1 §0 口径；该清单 v2.2 已移除，资产验收侧由 00 篇 §一.2 七项排除继承），道劫全量继承为**严禁表**（与 prefix.md X1–X6 同向）：

| 编号 | 它不是 | 对应严禁项 |
|---|---|---|
| N1 | 纯宋画复刻 / 纯工笔古画 | 传统国画复制感过强——Gate 语境归 R 级 DNA Reference、不作主生产（源文档§15）；资产验收语境仍为排除信号 |
| N2 | 纯水墨画（黑白滤镜/满幅泼墨） | prefix.md「灰白化拒收」：彩色工笔默认成片 |
| N3 | 东方幻想 CG / 仙侠 CG | X6 禁幻想堆料拉满 |
| N4 | 国风二次元 | X2 高饱和动漫色/赛璐璐平涂 |
| N5 | 满屏金光、云海、粒子和特效的「国风 AI」 | §3 九行对照 + 油腻东方幻想 AI 味定义 |

**新中式的「新」不指向潮流**：它**不是让画面更潮、更时尚，也不是加入赛博或现代服装元素**（v2.1 §0.1.2 口径，v2.2 已移除该句；同向现行提醒见源文档§0.2「模型筛选时不要让新中式本身成为唯一搜索标准」；与 prefix.md X3「西方奇幻/赛博朋克/过度现代元素」同源）。它强调的是——

> **传统文化视觉 DNA 被现代游戏美术重新组织。**（v2.1 §0.1.2 核心口径；v2.2 同义原句见 §0.1「把中国传统绘画的视觉规则重新组织为现代历史题材游戏美术」）

## 三、新中式 ≠ 东方幻想（九行对照全量）

这是本风格必须严格区分的一条线（v2.1 §0.1.4 对照表全量保留；v2.2 现行对应源文档§26 规避方向与风险清单）：

| # | 新中式修仙叙事游戏美术 | 东方幻想 / 仙侠 CG |
|---|---|---|
| 1 | 历史文化为主体 | 幻想世界为主体 |
| 2 | 留白（negative space） | 堆满视觉信息 |
| 3 | 传统色 | 高饱和金蓝紫 |
| 4 | 淡雅 | 强光影 |
| 5 | 线描 / 工笔 | CG 体积渲染 |
| 6 | 人物身份与服饰 | 炫技式装备 |
| 7 | 山水与叙事空间 | 云海、龙、雷电、法阵 |
| 8 | 克制 | 金光、粒子、光晕 |
| 9 | 现代游戏设计 | 欧美/日韩式幻想视觉语法 |

**搜索方向结论**：**「Chinese Fantasy / Oriental Fantasy」不能作为本项目的核心搜索方向**（源文档§26 裁定：这类词**经常把生成器引向另一套视觉语法**）。

### 3.1 油腻东方幻想 AI 味（源文档§26 风险清单）

高风险搜索词召回的结果池，风险特征固定为（§26 原词）：

> 金光 / 蓝紫高饱和 / 法阵 / 神兽 / 粒子 / 体积光 / 云海 / 幻想甲胄 / 过度装饰 / 超高信息密度。

**道劫的题材-画法分离**：道劫题材本身是修仙，但画法不走仙侠 CG。叙事内容用中文事实词表达（悟道/斗法/渡劫/宗门/魔道/符箓/丹炉），画法走新中式语言；「xianxia fantasy」类英文词只会在模型侧召回特效堆料池，进负面而不进正向。

### 3.2 与 X6 战斗豁免的关系（单一口径，不扩大）

渡劫、斗法等高光时刻的**演出镜头**可临时拉满视觉强度（prefix.md L3 例外机制、情绪色盘「渡劫突破」行、X6 豁免条款），但豁免只覆盖镜头瞬间，且沿用源口径：

> **提高动作强度，但不改变基础画风。**（v2.2 §20.3 原句：「动作强度增加，不等于视觉语法切换成仙侠 CG」；README / prefix X6 同向口径）

线条、传统色体系在镜头间隙恒定；豁免不延伸到静态资产（立绘/场景/道具恒守克制）。静态资产侧的对应红线即 X6 本体：金色只作烫金/旧金点缀，不作视觉主角。

### 4.2 道劫中文侧写法（与 prefix.md 同源，不自造第二套）

| 审美维度 | 优先词（中文） | 避免词（中文） |
|---|---|---|
| 线条 | 细线勾勒、墨线、铁线描、线宽连续有节奏 | 粗动漫描边、赛璐璐勾边、AI 自动勾边感 |
| 设色 | 宣纸白、米白、石青、青灰、赭黄、绛红、朱砂感、薄透矿物罩染 | 荧光红、赛博蓝、金色特效、高饱和金蓝紫 |
| 墨韵 | 淡墨、淡彩、低对比、局部晕染、远景淡化 | 黑白滤镜、满幅泼墨、狂草飞溅 |
| 构图 | 留白、疏朗、清疏、低信息密度、空气透视 | 堆满、epic、ultra detailed background、maximalist |
| 气质 | 克制、雅致、叙事、人物气质＞华丽装饰 | 炫技、华丽装饰、网红脸、偶像海报 |

**色名纪律**：给提示词的建议只用色名（「宣纸白」「朱红」「石青」），不抄色号、不写色温数值或百分比；可辨彩色占比等数值口径只留在人工审稿观察栏（prefix.md 色量与色相口径同款约定）。
**「淡」是关键而非「旧」**（prefix.md 传统色扩补原句）：青是石青/青灰，红是绛红/朱砂感，黄偏赭黄，白保留宣纸白的暖白底色相而非纯数字冷白；禁做旧滤镜、禁满幅灰褐化。「淡」在 v2.2 的准确口径是**受控饱和**（源文档§5.1：核心不是低饱和——**传统中国色体系＋受控饱和度＋受控对比度＋角色识别色**，颜色可以存在、可以较鲜明，关键是画面不失去视觉层级；§5.2 正确关系：**大面积稳定基底＋中等强度人物色＋少量高识别强调色**）；灰蒙蒙 / 发脏 / 旧照片 / 泛黄滤镜属「旧」，对应 §5.2 错误关系（全屏青色滤镜 / 全屏灰褐滤镜 / 金蓝高对比 / 荧光红蓝 / 赛博紫），归负面。
**「宣纸白」两口径**：「宣纸白」是可用**色名**（暖白底色相）；「宣纸质感/纸纹/纤维」是**禁用质感词**（prefix.md 浅净平涂底硬锁——底色永远是浅净哑光平涂色场，源文档出现「宣纸白」不连带解禁纸纹）。

## 五、对 AI 与 LoRA 筛选的直接意义

### 5.1 总框架 / 参考 / 组件（v2.1 §0.1.3 结论；v2.2 同口径见 §36 与 §10）

> **「新中式」是总框架；目标审美（历史画卷基准）是参考；具体的工笔、连环画、服饰、留白、传统色 LoRA 是构成组件。**

即：不存在也不必寻找「一个新中式 LoRA」；把新中式拆成可独立控制的层，逐层筛选、逐层组合（v2.2 §10「不是每一个视觉维度都需要使用 LoRA」、§36「不要再寻找一个万能 LoRA」同口径，具体模型与链接属筛选佐证，不进本指导主体）。

### 5.2 五层拆解（Style / Design / Costume / Composition / Color；分层口径对应源文档§10 LoRA 架构与 §0.2 结构树）

| 层 | 内容 | 道劫侧组织方式 |
|---|---|---|
| Style / 风格层 | 中国人物画、连环画、工笔白描、淡设色 | 原样继承；连环画作叙事气质参考（README 09-18 降格） |
| Design / 现代设计层 | 游戏角色设计、中国游戏插画、叙事插画、商业插画 | 原样继承——「第一眼现代游戏」由这层保证 |
| Costume / 服饰层 | 源文档按 Era＋Identity＋Status＋Costume Set 组织（§9.2 Era Lock） | **改为修仙阶层门派轴**：掌门/长老（庄重深色大袖，石青/旧金）、内门/外门（素袍青灰/米白）、散修（朴素布袍，赭黄/棕灰）、魔修（铁黑/暗赭+血朱砂点睛，prefix.md 魔道分支）；形制词仍取历史事实（道袍/大袖衫/法衣/直裰/圆领袍/短褐），不发明幻想形制 |
| Composition / 构图层 | 留白（negative space）、画册式（album painting）、卷轴式（scroll composition）、叙事构图 | **留白是一级条件**：大面积天空/水面/远山/浅雾承担视觉呼吸，背景不抢角色；留白量按分型密度取值（§6.1–6.2：立绘中/剧情高/山水很高/战斗低中） |
| Color / 色彩层 | 传统色、受控饱和度＋受控对比度＋角色识别色（§5.1） | prefix.md 配色五职责 + 传统色扩补（石青/灰青/米白/土黄/赭黄/淡朱/暗红/棕灰） |

### 5.3 六问筛选原则（任何候选 LoRA 先过六问）

1. **它是在教模型「中国怎么画」，还是只是在教模型「古装长什么样」？**（前者要，后者只是服饰层素材）
2. 它能不能保留现代游戏角色设计？
3. 它会不会自动把背景塞满？
4. 它会不会出现金光、蓝紫、高饱和和仙侠特效？
5. 人物线条是不是中国人物画式的细线，而不是动漫粗描边？
6. 它能否和独立的服饰 LoRA 共存？

前 5 项至少大部分通过，才值得进入主风格测试。

口径注记：六问为 v2.1 §21 原表（v2.2 已移除该清单）；v2.2 现行对应 **§14 评分体系（八指标）＋§15 Production Gate（S/A/B/R/X）**，观察四项见 §13.1（平均稳定性＋风格一致性＋可控性＋与其他模块兼容性），不要通过单张「最好看的图」决定模型。

### 5.4 评分表与 Production Gate（源文档§14 × §15，两语境分界）

v2.2 评分表（10 分制，八指标，原表抄录）：

| 指标 | 权重 | 判断 |

## 六、边界两侧案例与三眼判断

中线只有一条：**现代游戏完成度 × 传统审美**。两侧偏离方式相反。

| 侧 | 案例 | 偏离症状 |
|---|---|---|
| 传统侧（画感过强） | Modern Chinese Ink Painting 类模型（v2.1 §19 淘汰案；v2.2 §15 对应口径：传统 DNA 极高＋现代完成度低 → 归 **R 级 DNA Reference**，不作主生产） | 传统画感过强 / 容易变成「完整中国画」 / 现代游戏角色设计不足 / 把人物和场景一起拖回纯绘画表达 |
| 幻想侧（特效过强） | 高风险搜索词结果池（§3.1） | 金光/蓝紫高饱和/法阵/神兽/粒子/体积光/云海/幻想甲胄/过度装饰/超高信息密度；第一眼看到的是「AI 国风/仙侠/东方幻想」 |

两侧都是「不合格中线」：传统侧缺游戏完成度（Gate 语境归 R 级；资产验收语境为排除信号），幻想侧缺传统审美（Gate 语境归 X 级；资产验收语境命中 X6 即打回）。README 09-18 官方截图实证同理：游戏实况主视图是**三维等距 + 青绿淡彩 + 水墨笔触混合体**——纯古画质感缺游戏完成度，正是传统侧案例的镜像佐证。

### 6.1 三眼判断（源文档§33，验收与筛选通用；前三句 v2.1 译文保留，第四句 v2.2 新增）

> **第一眼：这是一个现代游戏。**
> **第二眼：这是一个非常有中国传统绘画底蕴的游戏。**
> **第三眼：人物像游戏角色，但线条、服饰、色彩、留白和构图又明显来自中国人物画与连环画。**
> **最终：即使改变时代、角色和场景，视觉系统仍然保持统一。**
> 而不是第一眼就看到「AI 国风」「仙侠」「东方幻想」。

### 6.2 最终目标公式（源文档§33 原句，v2.2 七项乘法；道劫修订注）

> **现代游戏完成度 × 中国人物画 DNA × 连环画叙事 × 历史系统 × 传统色 × 受控空间密度 × 图形呈现语言**

v2.2 相对 v2.1 公式新增**受控空间密度**（留白口径升格，§6.1）与**图形呈现语言**（§8）两项。道劫侧两处修订：连环画一项按 README 09-18 降格为**叙事气质参考**（官方营销词，视觉占比有限，不作硬约束）；历史系统一项按 §5.2 换轨为**修仙阶层门派轴**（形制词仍取历史事实，Era Lock 口径见源文档§9.2）。优先级对仗沿用 prefix.md 历史画卷基因行：**历史真实感＞奇幻感、绘画审美＞特效审美、构图＞堆料、线条＞光效、传统色＞霓虹色、留白＞满构图、人物气质＞华丽装饰**——其中**「线条＞光效、构图＞堆料」**是判断任何一张成图归侧的第一把尺。

## 七、道劫应用要点

1. 写任何风格定位文案或筛选结论时，「新中式」必带免责口径（非官方标签，是对现代设计方法的概括；「新中式修仙叙事游戏美术」是项目内部分析框架）。
2. 拆风格先过五层（Style/Design/Costume/Composition/Color）；服饰层按掌门/长老/内门/外门/散修/魔修组织，形制词只用历史事实词。
3. 检索与提示词以 §4.1 十五词为主词；`fantasy` 与 oriental/Eastern/Chinese fantasy CG 系英文词只进负面，正向正文用中文事实词（悟道/斗法/渡劫/宗门/魔道）。
4. 中文术语沿用 prefix.md 色盘与扩补口径（宣纸白/米白/石青/青灰/赭黄/绛红/朱砂感/薄透矿物罩染）；色名进提示词，色号与数值口径留审稿观察栏；「宣纸白」是色名，纸纹/纤维质感词恒禁。
5. 判任何图先用九行对照（§3）归侧，再用三眼判断（§6.1）定合格；两侧淘汰案（Modern Chinese Ink Painting / 东方幻想结果池）作对照样本。
6. 筛 LoRA 先过六问（§5.3）再打评分表（§5.4），**Production Gate（S/A/B/R/X）裁定用途**——命中否决信号不入 S/A 主生产，按 R（DNA 研究）或 X（淘汰）归级；资产验收语境七项排除照旧即打回。
7. 渡劫/斗法演出镜头可拉满视觉强度，但**提高动作强度，不改变基础画风**；豁免只限镜头，静态资产恒守 X6。
8. 组合思路恒为「总框架—参考—组件」：一个主导风格件 + 两三个轻量辅助件（线描/服饰/色彩构图），权重用同种子 A/B 定，不写死数值、不抄作者页推荐值（源文档§12/§13）。
9. 任何候选先问中线一句：**现代游戏完成度 × 传统审美**，缺任何一半即归入两侧淘汰案处理。
10. 负面词按 §5.6 模块化口径人读选配——**根据场景选择模块，不要全部永久叠加**；九型基座负面按场景选配、不整体叠加、不再扩词。
