## 一、总定位:写实人物 + 中国画线条审美 + 游戏角色美术

道劫人物轨与人物手册§一保持同一句话定位:

> **写实人物 + 中国画线条审美 + 游戏角色美术。**

目标区间即源文档§2.1 定式（v2.1 §3.1 旧句「历史人物写实感＋游戏角色设计感」的现行对应）：**现代历史游戏角色 × 中国人物画线描逻辑 × 历史身份设计**——偏写实而走绘画线描，既非纯影视真人，也非二次元（§2.1：「不依赖典型二次元美型模板」，目标不是「古画人物」也不是「欧美游戏角色」）。

优先级对仗沿用 prefix.md 历史画卷基因行(源文档同义表述已合并进来,不另立新序):**历史真实感＞奇幻感、绘画审美＞特效审美、构图＞堆料、线条＞光效、人物气质＞华丽装饰**。人物侧落点:

| 对仗 | 人物侧落点 |
|---|---|
| 历史真实感＞奇幻感 | 身份与气质可信,修为靠气韵表达而非金光堆料 |
| 绘画审美＞特效审美 | 笔意与墨韵优先于粒子光效 |
| 构图＞堆料 | 人物四周留白服务主体,背景让位 |
| 线条＞光效 | 面部/手部/衣褶先由线描保持可读,再谈渲染 |
| 人物气质＞华丽装饰 | 气质关键词优先于发冠配饰数量 |

最终视觉判断沿用源文档§33「三眼」标准（v2.1 §20 已换轨；v2.2 新增终审第四句）:

| 眼 | 判断 | 人物侧读法 |
|---|---|---|
| 第一眼 | 这是一个现代游戏 | 人物立绘有资产完成度,可直接进角色库 |
| 第二眼 | 有中国传统绘画底蕴 | 细线勾勒(fine linework)、薄透矿物罩染、传统色 |
| 第三眼 | 像游戏角色,但线条/服饰/色彩/留白来自中国人物画与连环画 | 线描承结构、气质承身份 |
| 终审 | 即使改变时代、角色和场景,视觉系统仍然保持统一 | 同源角色批量图仍属同一视觉世界(§36) |

反例信号:第一眼看到「AI 国风」「仙侠」「东方幻想」即不合格(源文档§33;高风险方向清单见§26)。

「新中式」口径：本篇如用「新中式修仙叙事游戏美术」表述，系项目内部分析框架（沿源文档§0.2 免责口径——新中式历史叙事游戏美术是**内部工作分类**，不作官方风格标签、不作模型筛选唯一标准）；定义边界、传统层×现代层对照与三眼判断的集中论述见 `06_新中式设计语言.md` §一/§二/§六。

## 二、角色比例:成年结构与写实区间

核心口径(源文档§2.1 定式,v2.1 §3.1 旧句的现行对应):

> **现代历史游戏角色 × 中国人物画线描逻辑 × 历史身份设计。**

| 项目 | 约束 | 提示词落点 |
|---|---|---|
| 骨骼 | 成年人结构、有真实骨骼关系;肩宽、腰位、四肢长度符合解剖 | 成年体格、真实骨骼比例 |
| 头身比 | 六至七头身,水墨古典比例(人物手册§四) | 六至七头身水墨古典比例、6-7 heads tall proportion |
| 身高 | 由角色设定指定;女性默认 160-170cm、男性默认 175-185cm(人物手册§四) | {身高}cm tall |
| 体态 | 仙风道骨:男挺拔端正、女轻盈飘逸(人物手册§四) | 体态清逸、身姿挺拔 |

优先/避免对照:

| 优先 | 避免(入负面清单) |
|---|---|
| 成年人写实结构 + 游戏角色设计感 | 幼态大头、childlike face(源文档§2.2) |
| 六至七头身水墨古典比例 | 二次元美少女比例、generic anime beauty(源文档§2.2/§19.3) |
| 历史画卷式庄重体格 | 欧美超级英雄比例(§2.1「目标不是欧美游戏角色」同向) |
| 绘画性写实——线描承结构 | 摄影级真人、photorealistic / 3d render look(源文档§19.2) |

> 四项排除对应源文档§2.1/§2.2 现行口径(「不依赖典型二次元美型模板」/childlike face/「目标不是古画人物,也不是欧美游戏角色」/photographic beauty retouching);幼态/二次元脸在 LoRA 筛选语境同时是 §15 Production Gate 归级证据(见本篇§八)。

## 三、脸部审美:年龄感、身份感与表情克制

核心口径(源文档§2.2 原则句,v2.1 §3.2 旧句「人物要有身份、气质和时代感,而非『人人都漂亮』」的现行对应):

> **人物应该「有身份」,而不是「统一地漂亮」。**

道劫侧读法(派生):「时代感」转写为修仙世界的古意与门派传承感——同一画面的人物像活在同一个世界与年代,而非现代人穿戏服。

| 维度 | 优先 | 避免(入负面清单) |
|---|---|---|
| 年龄感 | 面容承载岁月:眼角、法令、体态有年龄梯度;驻颜设定以眼神与姿态表达实际年龄 | 幼态脸、childlike face |
| 身份感 | 掌门/长老/内门/外门/散修/魔修身份可从冠带、袍色、佩剑直接读出 | 身份靠炫技式装备与堆料 |
| 五官 | 五官不过度精致;脸型由角色描述自然推导,人物间外观差异化(人物手册§二) | 统一「网红脸」、idol face / uniform handsome face(源文档§2.2) |
| 表情 | 表情克制:中性微表情,符合角色气质与修为境界(人物手册§二) | 夸张表情(人物手册 X5) |
| 男性专项 | 男性有骨相、风霜与年龄感 | 韩式/日式美型脸模板(K-beauty face,源文档§2.2)、generic anime beauty(§19.3) |

气质关键词驱动(人物手册§二,沿用到本篇§五谱系):五官不预设参数,由「性别/年龄/性格/气质/境界」描述自然推导;提示词必须写入整体气质关键词——清冷出尘/剑意凌厉/温润如玉/妖媚惑人。

## 四、线稿逻辑:线条画出来而非勾边(源文档§3.1,标题即「这是核心 DNA 之一」)

核心口径(源文档§3.1 原句,保留加粗):

> **线条像画出来,而不是像 AI 自动勾边。**

线条品质三要素:

1. **细线** — 细线勾勒(fine linework)为人物轨默认;线宽连续且有节奏(prefix.md 工笔硬锁)
2. **线条轻重** — 线条有轻重(源文档§3.1「细、稳、有轻重、有起伏」):转折、衔接与起收笔干净,轻重随结构走
3. **结构优先** — 脸部、手部、发丝、衣边、缝线先于上色从连续纪律性线描保持可读(prefix.md 工笔结构锁);发丝逐层细线勾勒,衣褶清楚但不碎,甲胄有结构不过度刻画(人物手册§一.3)

优先/避免词对照(源文档§3.2 原词表):

| 优先词 | 避免词(入 Negative Prompt) |
|---|---|
| fine Chinese linework | thick anime outline |
| fine ink contour | uniform black outline |
| expressive ink line | bold cel-shading outline |
| traditional figure outline | western comic inking |
| controlled contour weight | sticker-like contour / vector-like outline |

可叠加的人物侧关键词(源文档§3.2 原词表):fine facial linework、structured garment linework、delicate brush line、expressive ink line、controlled contour weight。

### 工笔人物口径(源文档§2.1;v2.1 §2.2 旧式「现代游戏角色设计 × 中国人物画线描」的现行对应)

> **现代历史游戏角色 × 中国人物画线描逻辑 × 历史身份设计。**

- 工笔在人物轨的含义是「人物线条逻辑」,而非博物馆宋代工笔画临摹(源文档§2.1「目标不是古画人物」原判)
- 落点:细线、清晰轮廓、线条有轻重、五官结构明确、衣褶与甲胄结构可读(源文档§3.1);**发冠、佩饰、武器具有设计感**;颜色克制走受控饱和口径(源文档§5.1,深论见 03 篇)
- 颜色克制执行**「淡」是关键而非「旧」**(prefix.md 核心口径):青是石青/青灰而非灰绿泥色,红是绛红/朱砂感而非荧光红,黄偏赭黄而非金色特效,白保留宣纸白的暖白底色相
- 色名纪律:提示词只写色名(如「宣纸白」「朱红」),色号、色温数值与百分比留在审稿观察栏,不入提示词
- 可用色名全表与四色换算(青→石青/青灰、红→绛红/朱砂感、黄→赭黄、白→宣纸白)见 `03_色彩体系.md` §二「道劫色名清单」与§四「淡而不脏:四色换算表」;量化口径分野见其§五

## 五、道劫修仙人物谱系(派生映射)

> 本节为派生：将源文档「按人物气质配中国传统色」的方法论（v2.1 §1 依据引文，v2.2 已移除；现行对应源文档§5.1「角色识别色」口径）与「服饰按 Era＋Identity＋Status＋Costume Set 组织」（源文档§9.2 历史约束结构；v2.2 §22 Character Bible 同款结构）转写为道劫修仙谱系。境界色按 prefix.md 色彩层级 L2 软约束（境界色可按修仙体系微调），非硬门；与角色设定事实冲突时，事实源优先。

### 5.1 双轴组织

- **阶层门派轴**(翻译规则:朝代服饰轴→道劫阶层门派轴):掌门/长老/内门/外门/散修/魔修;形制词仍取历史事实(交领右衽、深衣、束发、革带、道袍大袖等),不得发明幻想形制——词表以 `02_服饰系统.md` §二「历史服饰库(朝代模块)」为准(较人物手册§一.4 更全),阶层侧形制梯度见同篇§三「阶层与门派(身份轴)」
- **境界轴**:气质与年龄感梯度;与阶层相关而相互独立(外门老修士、少年元婴老怪均成立),两轴在提示词中分别声明

阶层门派轴速查(提示词落点为正向示例):

| 阶层 | 身份感落点(正向示例) | 服饰气质参考 |
|---|---|---|
| 掌门 | 法度森严、宗门气象、沉静威严 | 宣纸白主袍,旧金/暗金点缀 |
| 长老 | 沉静有威,执法/传道各有其度 | 石青/青灰深袍、革带 |
| 内门 | 整肃利落、锋芒初露 | 玉青/淡青 |
| 外门 | 质朴清朗、杂役风霜 | 米白/青灰、素布 |
| 散修 | 风尘江湖气、自辟蹊径 | 赭黄/棕灰 |
| 魔修 | 走 prefix.md 魔道暗色题材分支(见 5.3) | 深墨/铁黑/靛青,血朱砂仅点睛 |

### 5.2 境界气质分层(派生)

| 境界 | 年龄感梯度(视年龄) | 气质基调 | 境界色参考(L2 软约束) | 表情梯度 |
|---|---|---|---|---|
| 炼气 | 少年/青年居多 | 清朗质朴、心气外露 | 淡青/青灰,境界色弱 | 微表情尚存少年气 |
| 筑基 | 青年 | 沉稳渐生、进退有度 | 玉青/石青 | 表情趋内敛 |
| 金丹 | 中年视感 | 沉静有威、法度内蕴 | 暗金点缀(金丹光华,prefix 色盘 C9) | 眼神沉静 |
| 元婴 | 中老年视感或驻颜 | 清冷出尘、仙风道骨 | 旧金+宣纸白 | 表情克制至极,气韵承载情绪 |
| 化神及以上 | 驻颜与沧桑并存 | 天人气象、古井无波 | 暗金/旧金;突破时刻按情绪色盘 | 眉宇即语言 |

派生细则:

- **驻颜规则(派生)**:视年龄与实际年龄解耦时,沧桑必须落在眼神、姿态与手部,面容可以年轻——「年轻的脸+苍老的眼睛」是高境界角色的标准配置
- **情绪色盘挂接**(prefix.md 情绪色盘):修炼悟道=宣纸白+青绿,辅旧金+淡墨;渡劫突破=暗金+朱红,辅靛蓝+浓墨——悟道/突破题材人物图的主辅色按此组织;情绪色盘全表与按气质配色的场景化见 `03_色彩体系.md` §七,既有阵营色衔接见其§八
- 境界只改气质与点缀色;底座(浅净平涂底/细线勾勒/均匀平光)恒定

### 5.3 正魔分支(prefix.md「魔道/邪道暗色题材分支」)

启用条件:角色设定明确阵营为魔道、邪道、邪修或魔宗(Source facts 显式启用;仅凭黑色、夜景、冷峻不启用)。

## 六、连环画叙事气质(人物侧 · README 09-18 降格口径)

连环画在人物侧的价值(源文档§28 C 原词:人物叙事、单幅故事场景、动作瞬间、人物关系、历史事件视觉化;清楚的主次关系与场景交代为道劫侧补)。

**人物事件律(派生转写)**:叙事人物图让人物处在具体事件中——对峙/交谈(论道)/行军(云游赶路)/骑马(骑乘)/战斗(斗法)/谋划(密谋)择一(括号内为修仙语境转写;事件单以 prefix.md 提示词装配顺序第 3 条为准,v2.1 §7 事件列举已随旧节移除、现行价值清单见源§28 C);姿态与视线朝向事件对手或目标,而非镜头摆拍。单幅叙事五要素与审稿六问的展开见 `05_动态与战斗.md` §5.4/§5.5。

**降格口径**(README 09-18 官方截图实证):「连环画」「剪纸画」系官方营销词,视觉占比有限(多在过场/UI)——连环画**作叙事气质参考,营销词不作硬约束**,不按 v2.1 §7「极其重要的一层」强度引用(v2.2 已移除该定级;现行源§28 C 自身亦定位「辅助 Style DNA」,与 README 降格同向)。

动态与豁免:

- **提高动作强度但不改变基础画风**(prefix.md X6 译句;源文档§20.3 原句「战斗画面可以更强烈,但:动作强度增加,不等于视觉语法切换成仙侠 CG」):斗法、赶路可加动势、墨色冲击、烟尘与速度感,线条与传统色体系恒定
- 战斗豁免沿用 prefix.md X6 单一口径:战斗/技能演出镜头视觉强度可临时拉满,线条与传统色体系在镜头间隙恒定;静态人物资产不适用本豁免——豁免适用范围与三条件详见 `05_动态与战斗.md` §四
- **留白是一级条件**(README:「留白与疏朗构图是一级条件」;v2.2 起留白量按分型取值,角色立绘=中,源文档§6.2):人物图同样承担留白——soft background、restrained background detail(源文档§16.1/§17 原词)、negative space(§25),主体明确、背景让位;留白六项职责、分型密度表、优先构图词表与高风险词见 `04_留白与构图.md` §二/§三

## 七、游戏角色完成度与资产语言

- **现代游戏完成度**(源文档§14 评分指标,权重 20%)= 可直接作为角色资产:清晰视觉焦点、现代构图、数字绘画完成度(源文档§0.2 结构树 Modern Game Translation 枝:v2.1 §0.1.2 现代设计层的现行形态)
- 与人物手册四视图设定板对齐:面容/体型/发型/基础服装跨视图高度一致,是资产统一性的最小实现
- 批量一致性目标(源文档§8.2/§36 原句):「连续 100 张图才有机会被识别为:同一部作品」「持续生成 100 张、1000 张仍然属于同一视觉世界」——道劫人物库按宗门/阶层/境界组织时,同源角色批量图保持同一部作品感
- 画风层与服饰层分离(源文档§9.1 方法论):「怎么画」由本篇约束,「修士穿什么」由阶层门派轴+设定事实决定;二者不绑定,人物库才可扩展(v2.2 §9.1 在同一原则上新增 **Era Lock/时代锁**,§9.2/§9.3 深论见 02 篇)——分离原则的完整论证见 `02_服饰系统.md` §一

## 十、道劫应用要点

1. 定位一句话:**写实人物 + 中国画线条审美 + 游戏角色美术**;比例目标=历史人物写实感+游戏角色设计感,六至七头身水墨古典比例
2. 脸部三问:有年龄感吗?有身份感吗?表情克制吗?——「人人都漂亮」不是目标,「人物要有身份、气质和时代感」才是
3. 每张人物图必带气质关键词(清冷出尘/剑意凌厉/温润如玉/妖媚惑人择一或按角色组合);五官由角色描述自然推导,人物间外观差异化
4. 线稿自检:线条像画出来的吗?有轻重吗?细线勾勒承结构;thick anime outline / western comic inking 一类入 Negative Prompt
5. 工笔=现代历史游戏角色 × 中国人物画线描逻辑 × 历史身份设计;发冠佩饰武器有设计感、颜色克制(受控饱和,§5.1),「淡」是关键而非「旧」
6. 谱系双轴分别声明:阶层门派轴(掌门/长老/内门/外门/散修/魔修)+ 境界轴(炼气→元婴及以上);境界色按 L2 软约束,事实源优先
7. 驻颜设定走「年轻的脸+苍老的眼睛」:沧桑落在眼神、姿态与手部
8. 魔修走 prefix.md 魔道暗色分支:深墨/铁黑/靛青为主,血朱砂只点睛,铁线描更硬朗;显式设定才启用
9. 叙事人物图让人物处在具体事件中(对峙/论道交谈/云游赶路/骑乘/斗法/密谋择一)——连环画仅作叙事气质参考,营销词不作硬约束
10. 动作强度可提,基础画风恒定;战斗豁免只限演出镜头,静态资产不适用
11. LoRA 人物向四指标:中国人物画 DNA 20%/现代游戏完成度 20%/线条质量 15%/AI 模板感 10%;角色脸强二次元按源§15 Production Gate 归级,不入 S/A 主生产
12. 完成度终检:这张图能直接作为角色资产吗?同一角色批量图放在一起,仍像同一部作品吗?
