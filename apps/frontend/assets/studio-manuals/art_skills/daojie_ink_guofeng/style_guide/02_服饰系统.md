## 一、服饰与画风彻底分离原则

**核心原则（源文档§9.1）：画风层解决「怎么画」，服饰层解决「人物穿什么」，二者不绑定。**

```text
                 道劫人物（水墨国风修仙）
                         │
              ┌──────────┴──────────┐
              │                     │
            画风层                 服饰层
              │                     │
      水墨国风视觉 DNA           历史时代模块
              │               ┌─────┼─────┐
      ┌───────┼───────┐      汉    唐    宋    明…
      │       │       │
    线条    设色    构图
      │       │       │
    白描    淡彩    留白
```

（结构图沿用 v2.1 §9.1 双层图，v2.2 已移除该图；现行 §9.1 原则句保留并新增 Era Lock 时代锁，顶层换为道劫主体）

| 层 | 回答的问题 | 关键词（与 prefix.md 同源） | 归谁管 |
|---|---|---|---|
| 画风层 | 怎么画 | 细线勾勒（fine linework）、白描、墨线、薄透矿物罩染、淡彩、留白（negative space）——**留白是一级条件**、**线条＞光效、构图＞堆料** | prefix.md 风格基因 + 工笔硬锁 + 画风 LoRA |
| 服饰层 | 穿什么 | 朝代形制词（交领右衽／圆领袍／褙子／道袍…）、阶层门派映射、材质纹样、服饰色名 | 本篇词表 + 角色/场景设定事实 + 服饰 LoRA |

分离的三个操作含义：

1. **换朝代不换画风** — 汉甲角色与明道袍角色用同一套 prefix 底座渲染（工笔线描、浅净平涂底、矿物淡彩），变的只是题材正文里的服饰事实。
2. **换阶层不换画法** — 掌门鹤氅与外门短褐的差别写在形制、材质、色名，而非改线条、改构图、改光影。
3. **人物库才可扩展** — v2.1 §9.1 原话「这样才能让以后的人物库真正可扩展」（v2.2 已移除该句，解耦原则本身保留）。服饰按模块追加，画风层恒定，百图同源（资产统一性）；v2.2 在同一原则上加 **Era Lock／时代锁**（源§9.1 新增约束）：服饰按 **Era＋Identity＋Status＋Costume Set** 组织（§9.2 历史约束结构，源§9.2 并告诫「不要只写 Chinese ancient clothing」），跨时代混堆即污染（§9.3 原例：「宋代服饰＋汉代甲胄＋明代发冠＋唐代配饰」不能仅因「都是中国元素」判定合格——正对本篇 F3 红线）。

画风层各要素的分篇展开：人物线条逻辑（线条画出来而非勾边）见 `01_人物美术.md` §四；色彩方法与四色换算见 `03_色彩体系.md` §一/§四；留白职责与构图词表见 `04_留白与构图.md` §一/§二。本篇以下只管服饰层。

### 服饰可控三轴（v2.1 §9.2 S 级判据「可控朝代／身份／类型」，v2.2 已移除该表；现行对应源§9.2 历史约束结构 Era／Identity／Status／Costume Set）

| 轴 | 含义 | 词表所在 |
|---|---|---|
| 朝代轴 | 历史时代模块 | 本篇第二节 |

## 二、历史服饰库（朝代模块）

**服饰目标是「中国历史服饰库」，不锁定单一朝代（v2.1 §9 表述；v2.2 §9 历史系统按 Era／Region／Status 组织同一约束——§9.2「不要只写 Chinese ancient clothing，要尽量明确 Era＋Identity＋Status＋Costume Set」，§9.3 管单画面跨时代混堆而非全项目锁死单朝代）。** 允许范围：

汉／三国魏晋／南北朝／隋唐／五代十国／宋／辽金／元／明／其他有明确中国历史服饰特征的时代。

### 朝代形制词表（形制词取历史事实）

| 朝代 | 形制词（优先） | 甲胄 | 使用注意 |
|---|---|---|---|
| 汉 | 冠帽、交领右衽、深衣（曲裾／直裾）、宽袖、带具丝带 | 汉代札甲 | 交领右衽是历代汉制基线 |
| 三国魏晋 | 褒衣博带、大袖衫、幅巾束发、襦裙 | 札甲沿汉制 | 名士气＝大袖＋幅巾 |
| 南北朝 | 裤褶、缚裤、交领窄袖袍（胡风）、襦裙 | 裲裆甲 | 裤褶缚裤利落，适合武事 |
| 隋唐 | 圆领袍（缺胯袍）、幞头、半臂、披帛、革带 | 明光铠 | 披帛为女服配件 |
| 五代十国 | 沿唐制：圆领袍、幞头，渐趋宽博 | 沿唐制 | 过渡期，词表沿用唐 |
| 宋 | 褙子、直领对襟、直裰、革带、鹤氅（文人氅衣） | 山文甲（典籍列名）、步人甲 | 文人鹤氅的直系源头 |
| 辽金 | 左衽圆领窄袖袍、蹀躞带、皮毛缘边 | 皮甲、铁札甲 | 左衽是辽金标识，与汉制右衽严格区分 |
| 元 | 辫线袍（腰线袍）、质孙服、交领窄袖袍 | 布面甲渐起 | 束腰密褶是辫线袍特征 |
| 明 | 道袍、曳撒、贴里、直身／直裰、圆领袍、乌纱帽、襕衫；女服袄裙、马面裙、比甲 | 布面甲；山文甲形象见绘画传统 | 道劫道袍／鹤氅的直系母本 |

词表用法：

- **按角色设定选定朝代**，取该行形制词 2-4 个写入题材正文的服饰段，配材质与色名（见第五节）。
- 形制词是历史名词，直接用词本身（「圆领袍」「褙子」），不加幻想前缀修饰。
- 女服形制（襦裙、披帛、袄裙、马面裙、比甲）按角色性别取用，鞋履另受鞋靴性别锁约束（第八节）。

### 同画面朝代统一

`art_prompt/art_character.md` §一.4 口径：按角色设定选定朝代并在同一画面保持统一——显著降低「清代装束＋仙侠长袍混搭＋幻想铠甲＋跨朝代元素堆叠」漂移。两态启用：

- **修仙题材（道劫主体）**：沿用手册原约束，主轴是道袍／鹤氅／劲装／甲胄梯度（第三节），默认倾向宋明文人服制语汇。
- **历史向题材**：启用朝代锚，整幕人物共用同一朝代行词表。

两态共同要求：同一画面、同一人物群，朝代语汇一致；跨幕跨卷可换朝代模块，画风层不动。

## 三、阶层与门派（身份轴 · 道劫派生组织轴）

> **标注：本节组织轴是道劫侧派生**——源文档按汉唐宋明朝代组织服饰库，道劫按修仙阶层（掌门／长老／内门／外门／散修／魔修）与门派气质重组；**形制词仍取历史事实，不发明幻想形制**。

### 阶层形制梯度表

| 阶层 | 类型（历史形制） | 材质 | 色名示例（与 prefix 色盘同源） |
|---|---|---|---|
| 掌门／宗主 | 鹤氅或大氅罩道袍、玉冠木簪、大典时道门法服（道教法服，唐制有阶） | 纱氅＋素绢内袍、玉带 | 宣纸白＋浓墨＋石青＋玉青＋旧金 |
| 长老 | 道袍／氅衣、革带 | 素绢为主、缘边云锦薄染 | 米白／青灰＋赭黄缘边 |
| 内门弟子 | 道袍／直裰、束腰带具 | 素布或细绢 | 淡青／米白＋栗褐革带 |
| 外门弟子／杂役 | 短褐素袍、布束腰 | 粗布 | 米白／土黄＋栗褐 |
| 散修 | 短打劲装（束袖短衣、袄子、缚裤）、行缠 | 耐磨布 | 青灰／棕灰＋赭石 |
| 魔修 | 深色道袍或铁黑甲胄件 | 深色布＋铁件、旧铜带扣 | 深墨／铁黑／靛蓝为主，血朱砂只作法印焦点（prefix 魔道分支口径） |

梯度逻辑：阶层越高，外披层（鹤氅／大氅）与玉质配件越显；阶层越低，短打化、材质朴素化。**人物气质＞华丽装饰**（prefix 历史画卷基因行）——身份识别靠形制轮廓与一处点睛，不靠堆料。

门派气质可再细分（如剑修偏劲装利落、丹修偏宽袖道袍），但每条映射仍须落到上表历史形制词；阵营用色不在本篇发明，查 `art_prompt/art_faction_palette.md`（形制轴＝本篇，色彩轴＝阵营表，两轴正交），阵营色与道劫色名清单的衔接规则见 `03_色彩体系.md` §八；境界气质分层（人物侧）见 `01_人物美术.md` §5.2，与阶层形制梯度配合使用。

## 四、类型轴：道袍／鹤氅／劲装／甲胄

| 类型 | 历史锚 | 提示词写法（正向，只写事实） | 优先／避免 |
|---|---|---|---|
| 道袍 | 明代男子主流便服：交领、大袖、侧有摆、白护领 | 「身着交领道袍，宽袖束带，素绢色淡青」 | 优先：宽幅平静布面、整下摆；避免：收腰奇幻裁剪 |
| 鹤氅 | 源自晋代鹤氅裘，宋明文人氅衣外披 | 「外披鹤氅，纱面轻薄，缘边赭黄一线」 | 优先：外披一层、随风轻动；避免：多层巨披叠加 |
| 劲装（短打） | 武侠惯用词，锚定历史短打：短褐、袄子、缚裤 | 「束袖短衣，腰束革带，下着缚裤，利落短打」 | 优先：束袖束腰的动词化描述；避免：自造「XX 战衣」类名词 |
| 甲胄 | 按朝代取：汉札甲／唐明光铠／宋山文甲·步人甲／明布面甲 | 「身披札甲，甲片结构以铁线描勾勒，旧铜扣带」 | 优先：甲片有结构、有重量感；避免：西式板甲、夸张肩甲 |
| 道门法服 | 道教法服，唐制有品阶 | 大典礼服场合启用，配玉冠 | 只用于掌门大典等设定明确场合 |

甲胄梯度单独说一句：门派护山武备按朝代风统一（全宗同用宋风山文甲，不混汉札甲与明布面甲于同一队伍），跨朝代混堆是漂移源（第二节「同画面朝代统一」）。

## 五、材质与纹样

### 材质微观质感（对齐 prefix.md §四.4 色彩材质口径）

prefix 口径：说明材质差异（矿物颜料、布、玉、旧铜、木、瓷），并写微观质感。服饰层落法：

| 材质 | 微观质感写法（正向） | 色名职责（prefix 配色五职责） |
|---|---|---|
| 素布／粗布 | 哑光平净织面，织纹细密安静 | base／secondary（米白、土黄、栗褐） |
| 绢／纱 | 轻薄通透，矿物色薄染成半透层次 | primary（淡青、石青） |
| 锦（云锦薄染） | 暗纹提花隐现，光泽内蕴 | primary＋accent（旧金缘边） |
| 玉（冠、带钩、佩） | 温润内蕴微光，匀净如瓷 | accent（玉青、旧金） |
| 旧铜（甲件、带扣） | 哑光沉色，转折处以点睛色提亮一线 | accent（暗金、赭黄） |
| 木（簪、珠） | 木质温朴，细线勾勒木纹 | secondary（栗褐、赭石） |
| 铁（甲片、魔修配件） | 铁线描勾甲片结构，深色块克制 | ink／primary（铁黑＋靛蓝） |

### 色名纪律（沿 prefix 全局规则）

- 提示词只用色名：宣纸白、米白、青灰、石青、玉青、赭黄、绛红、朱砂感等，沿用 prefix 色盘与历史画卷扩补口径；不抄色号，不写色温数值、百分比、可辨彩占比——数值口径只留在审稿观察栏。可用色名全表见 `03_色彩体系.md` §二，四色换算表（青→石青/青灰、红→绛红/朱砂感、黄→赭黄、白→宣纸白）见其 §四，量化口径分野见其 §五。
- **「宣纸白」是可用色名；「宣纸质感／纸纹／纤维」是禁用质感词**，两口径严格分开——本篇出现「宣纸白」不连带解禁纸纹（prefix 浅净平涂底硬锁）。
- **「淡」是关键而非「旧」**（prefix 扩补原句）：青是石青不是灰绿泥色，红是绛红／朱砂感非鲜艳游戏红，黄偏赭黄非金色特效。

### 纹样克制

| 优先 | 避免 |
|---|---|
| 素色大面＋深色缘边（领缘／袖缘／衣缘） | 满幅繁复印花 |
| 暗纹提花隐现（锦面） | 金线满绣 |
| 纹样只落一处（袖缘或下摆一角） | 图腾堆叠、多纹样并置 |
| 纹样题材：云纹、回纹、缠枝纹（小面积） | 亮片、珠串、大面积文字纹样 |
| 一枚玉佩或一条革带作身份锚 | 装饰抢过身份识别（**人物气质＞华丽装饰**） |

## 六、服饰 LoRA 筛选（S/A/B/C 四级标准）

### 四级标准（迁移自 v2.1 §9.2 原表；v2.2 已移除该表，现行对应：分级语境走源§15 Production Gate S/A/B/R/X，候选定位见源§27，可控判据见源§9.2，幻想服饰规避见源§26）

| 级 | 定义 | 判据 | 道劫栈中的位置 |
|---|---|---|---|
| **S** | 历史游戏服饰／游戏角色服装 | 本身来自游戏角色设计；有明确历史服装元素；Illustrious 或 SDXL；不依赖真人摄影；可控朝代／身份／类型 | 服饰层首选，权重主力 |
| **A** | 历史服饰 LoRA | 汉服、唐制、宋制、明制、古代铠甲等考据向 | 服饰层主力；可控粒度不足时降权或缩窄触发词 |
| **B** | 摄影／COS／真人汉服 | —— | 只作辅助。v2.1 §9.2 原因：它们容易把人物拉向真人摄影、古装写真，而不是游戏角色（v2.2 同向压制见源§19.2：photorealistic／plastic skin）。用时必须画风格栈主导对冲＋prefix 负面五类压写实渗漏 |
| **C** | 东方幻想服饰 | —— | v2.1 §9.2：原则上不作为核心服饰库（易出仙侠长袍、巨大披帛、夸张肩甲、奇幻铠甲、非历史配饰；v2.2 同向见源§26「幻想甲胄／过度装饰」）。**道劫侧升格为红线**：题材天然往仙侠漂，直接进严禁表（见下） |

### 游戏化服饰语言（本篇游戏话题承载点）

- S 级第一判据「**本身来自游戏角色设计**」（v2.1 §9.2 判据，v2.2 已移除；现行游戏化服饰定位见源§27 候选表「重点测试」行）一次带来三样东西：服饰可控性（朝代／身份／类型可触发词化）、现代游戏完成度（资产统一性，百图同源）、无真人摄影依赖。这正是 prefix「工笔＝现代角色设计的工笔线描化」在服饰层的对应物——形制是历史的，完成度是游戏的。

## 七、画风 LoRA 与服饰 LoRA 的组合与权重

### 组合栈（迁移源§10 LoRA 架构，道劫版；v2.1 §13 组合图已换轨）

基模（Illustrious／SDXL／Krea2，按现役画风栈）

      ├── Style：水墨国风／工笔线描／连环画叙事（画风层）

      ├── Color／Composition：传统色／淡设色／留白

现役画风栈（Krea2 基模、六层 DNA→件）见 `art_prompt/lora_stack.md`；本篇只管 Costume／Armor 两枝的选件与权重。

### 权重思想（源§12 实验区间；v2.2 原则：不把固定数值写成规范）

| LoRA | 实验区间（源§12 原值，历史起点） |
|---|---|
| Style | 0.20 ～ 0.60 |
| Line | 0.10 ～ 0.40 |
| Costume／Armor | 0.20 ～ 0.50 |
| Color／Auxiliary | 0.10 ～ 0.30 |

- **一个主导 LOra＋两三个轻量辅助 LoRA**（组合思想沿 06 篇「总框架—参考—组件」口径；v2.1 §13 原句已移除）——主导给画风层，服饰件按 Costume／Armor 区间作辅助；同层不叠（lora_stack 组合规则）。

## 道劫应用要点

1. 动笔先分层：问「这句是画风还是服饰」——画风句归 prefix 底座（自动层），服饰句才进题材正文。
2. 服饰描述三轴至少指名两轴（朝代／身份／类型），全不可控的不进生产。
3. 同一画面、同一人物群朝代语汇统一；跨幕可换朝代模块，画风层不动。
4. 形制词只用本篇历史词表（汉札甲、唐圆领袍、宋褙子、明道袍…），不自造、不加幻想前缀；「劲装」锚定历史短打写法。
5. 阶层梯度用形制轮廓与一处点睛识别（掌门鹤氅玉带／外门短褐束腰），**人物气质＞华丽装饰**。
6. 色名只用色名（宣纸白、石青、赭黄、绛红、朱砂感），不抄色号；「宣纸质感／纸纹／纤维」恒禁用。
7. 材质写微观质感（布哑光平净、玉温润内蕴、旧铜转折提亮一线），纹样只落一处。
8. 服饰 LoRA 先分级再进栈：S／A 作主力，B 只辅助并压写实渗漏，C 是红线。
9. 画风 LoRA 与服饰 LoRA 分开评估；「历史适配／可混搭」是服饰件主判据；权重同 Seed A/B 定，Costume／Armor 按源§12 实验区间 0.20-0.50 起步。
10. 衣物完整锁、衣褶 2-4 条、鞋靴性别由自动层携带；正文只写正向事实，战斗镜头按 X6 只提视觉强度。
11. 跨篇问题按互索引跳转：人物线条与境界气质→`01_人物美术.md`；色名与换算→`03_色彩体系.md`；留白与构图→`04_留白与构图.md`；动态强度与 X6 豁免→`05_动态与战斗.md`；新中式边界→`06_新中式设计语言.md`；总览路由→`00_总纲.md` §七。
