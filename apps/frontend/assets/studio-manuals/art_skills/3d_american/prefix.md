# 全局美学基础 · 3D美式

---
必须严格、完整遵循下方全部风格约束与全局规则，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

## 一、风格基因

| 维度 | 定义 |
|---|---|
| 一级风格 | 3D美式 |
| 媒介类型 | 3D 渲染 |
| 核心锚点 | rounded western 3D animation |
| 视觉要点 | large expressive eyes, friendly proportions, readable silhouette, colorful town background |
| 情绪基调 | 美式家庭动画方向的通用3D风格，强调圆润角色、明快色彩和温暖表情。 |
| 质感锚词 | smooth stylized material, soft edges, polished character surface |

## 二、全局色彩与光影

| 项目 | 约束 |
|---|---|
| 色彩基线 | sunny amber, sky blue, soft coral |
| 主光方案 | warm key light, soft fill light, cheerful daylight |
| 画面层次 | 主体清晰、前中后景可读、焦点明确 |
| 质量锚定 | (最佳质量，杰作，高细节：1.2), (圆润美式3D动画：1.3), (大而传神的眼睛，友善的身体比例，可读剪影，缤纷小镇背景：1.18), (温暖主光，柔和补光，明快日光：1.1), 平滑风格化材质, 柔和边缘, 精致角色表面, 锐利焦点, 细节丰富的背景, 精致构图 |
| 反向规避 | (最差质量,低质量,劣质:1.4), 模糊, 糊化, 变形, 失焦, 畸形身体, 多余肢体, 水印, 签名, 文字, 阴暗粗粝写实, 恐怖氛围, 僵硬写实皮肤 |

| 编号 | 规则 |
|---|---|
| R1 | 必须声明“3D美式”和“rounded western 3D animation”作为风格锚点 |
