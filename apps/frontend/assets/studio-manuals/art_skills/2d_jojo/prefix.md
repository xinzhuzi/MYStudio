# 全局美学基础 · 2D高对比姿态漫画

---
必须严格、完整遵循下方全部风格约束与全局规则，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

## 一、风格基因

| 维度 | 定义 |
|---|---|
| 一级风格 | 2D高对比姿态漫画 |
| 媒介类型 | 2D 动画 / 插画 |
| 核心锚点 | high-contrast pose-driven manga |
| 视觉要点 | dramatic pose, angular face, muscular silhouette, ornate costume |
| 情绪基调 | 高对比姿态漫画风格，强调夸张造型、硬朗阴影和舞台化动作。 |
| 质感锚词 | heavy hatching, bold contour, sculptural linework |

## 二、全局色彩与光影

| 项目 | 约束 |
|---|---|
| 色彩基线 | purple, black, gold accent |
| 主光方案 | harsh side light, deep shadow, theatrical contrast |
| 画面层次 | 主体清晰、前中后景可读、焦点明确 |
| 质量锚定 | (最佳质量,杰作,高细节:1.2), (高对比姿态驱动漫画:1.3), (戏剧化姿势,棱角面容,肌肉感剪影,华丽服装:1.18), (硬朗侧光,深重阴影,舞台化对比:1.1), 重排线,粗犷轮廓线,雕塑感线描,干净构图,可读剪影,高细节,完成度高的插画 |
| 反向规避 | (最差质量,低质量:1.4), 模糊, 凌乱线稿, 解剖错误, 3D渲染, 照片写实, CGI, 水印, 签名, 文字, 柔和可爱 moe 风, 极简扁平风格, 无力姿势 |

## 三、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明“2D高对比姿态漫画”和“high-contrast pose-driven manga”作为风格锚点 |
| R2 | 必须保持“2D 动画 / 插画”媒介边界，不混入错媒介词 |
| R3 | 必须包含“dramatic pose, angular face, muscular silhouette, ornate costume”中至少 2 个视觉识别点 |
| R4 | 必须说明光源或光影方向：harsh side light, deep shadow, theatrical contrast |
| R5 | 必须把质量锚点与主体内容融合，不输出解释性说明 |
