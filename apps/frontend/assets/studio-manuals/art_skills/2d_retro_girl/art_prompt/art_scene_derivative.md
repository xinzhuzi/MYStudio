# 场景衍生生成 · 2D复古少女

## 一、基础原则

- 保持原场景地标、空间结构、材质年代感和风格边界。
- 只改变时段、天候、景别、镜头角度或局部氛围。

pastel glow, soft highlight, gentle vignette，thin elegant line, screentone texture, soft color wash，rose pink, lavender, pearl white，
前中后景层次保留，单画面构图，画面中无任何人物，
