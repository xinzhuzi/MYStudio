# 道劫导演语法 · 影史众长融合九式

> **本文立场**：道劫的导演语法不是某一个大师的翻版，而是把世界影史被验证过的成熟手法**逐式翻译进水墨 DNA** 后的融合体。本文就是这九式融合技法的定义与用法；引用影片仅为溯源，不依赖任何外部资料在位，本文自足。
> **关系**：叙事手法细节真源＝`director_planning_narrative.md`（本文是其上的「镜头语法层」，手法解释不重复）；画法与色盘权威＝美术风格手册（`daojie_ink_guofeng`）的 C1-C10 与光影方案 A-G，本文**永不覆盖**。
> **适用门**：九式仅选择当前场景已具备事实的拍法；三色指三族/明确三股，不覆盖晏燎整体融合进度。早期灰黑反应、龙气暗金点缀不等于整体阶段跃迁。万道归真是超越九境的终极状态，不是第十修炼境界；个体不复存在，不新增肉身余生。留白与声音仅为可选修辞，不强制纯白、三音和声或拉远，不借九式补事件。

## 一、九式签名技法（道劫独有，逐式可执行）

### 第一式 · 静中微澜
**溯源**：侯孝贤（《刺客聂隐娘》《悲情城市》）的静观长镜——时间在画面里自己流淌。
**道劫化**：把「时间的流淌」换成「灵气的呼吸」。七成长镜静观，但静止画面不超五秒必有**墨色晕开、灵气丝缕、光影推移、衣袂微动**四者其一；人物极静，画面活着。悟道、闭关、独处场景的默认语法。

### 第二式 · 卷轴展卷
**溯源**：沟口健二（《雨月物语》）的一卷一场与卷轴画构图——镜头如手卷横向展开。
**道劫化**：缓摇＝横卷徐展，天地自右向左入画，速度以「观众来得及品味每一寸水墨」为上限；赶路、宗门全景、山水过渡段用整幅长卷交代空间。境界递进段用「卷轴段落感」——一境一段，段间水墨晕染转场。

### 第三式 · 三色分章
**溯源**：张艺谋（《英雄》）的色彩即叙事——不同段落用不同主色，观众不读台词也知道身处哪段故事。
**道劫化**：不按情绪换色，按**种族与阵营**换色——人族戏暖朱红当家、妖族戏青绿当家、鬼族戏靛蓝当家、愿力戏金色点睛、魔道戏血红加浓墨。整集的主色相就是「这是谁的场」的声明；转阵营时主色随之整段更替，形成道劫独有的分章感。

### 第四式 · 墨阶为时
**溯源**：塔可夫斯基（《潜行者》《镜子》）的时间雕刻——用画面质感的缓慢变化标记时间与心境。
**道劫化**：时间流逝不靠钟表，靠**墨色浓淡推移**。回忆＝淡墨残卷（细节模糊、只剩轮廓、血迹独清晰）；当下＝中墨；天道注视＝留白变沉。悟道长镜里灵气由淡墨轻染渐至浓墨重彩，可作原文已有精进的视觉修辞，不据此推定境界；当章确已抵达万道归真时，可选浓墨归留白表达「真白」，也可不用，不将留白等同实体变化。

### 第五式 · 剑意一镜
**溯源**：道劫战斗宪法的自有语法（大开大合的完整镜头，反快切），与书法化的五系道途同构。
**道劫化**：每剑一完整镜头，起手—出剑—收势不切镜；剑光即一笔书法——剑主正楷端正（斩魂夺魄）、剑衍冥影行书（三影同刺、虚化穿梭）、剑星星轨金粉（心眼感知视界）、剑魔浓墨叠影（魔影同框连斩）、剑狂狂草血煞（燃血渐浓）。一镜之内只允许一种主导笔意；「快」由剑光书写速度表达，不由剪辑频率表达；「变」由鬼影分身同框表达，不由切镜表达。

### 第六式 · 一臂之距
**溯源**：王家卫（《花样年华》）的距离美学——欲触未触，距离即关系。
**道劫化**：距离美学在道劫有**两处落点**——①柳念漪线的**理念决裂**：曾是并肩战友，道不同后同框越来越难，一臂之距渐宽成一片留白，那片空白就是各自坚持的道（偶尔灵气在留白处隐约交汇如墨迹互渗——都记得旧日并肩）；②晏燎自身的**自持**：「只有红颜，没有伴侣」——心知肚明、永不挑明，守护、成全、目送，唯独不说破。与兄弟线的泼墨交融（拍肩、碰拳、背靠背）形成显式对照。

### 第七式 · 一人两影
**溯源**：今敏（《未麻的部屋》《红辣椒》）的心理空间视觉化——内在冲突外化为可看的画面结构。
**道劫化**：晏燎与**苏无忌残识**（道基融合的鬼修意识）的相伴不用闪回，用**当帧内**的语言——影子靛蓝而本体常色、阴阳构图半暖半冷中间一道流动墨线、两个晏燎面对面对切（一个朱红灵气一个靛蓝灵气）；其终局是**身份溶解**——对切渐融、靛蓝一侧越来越淡、两个影子轮廓重合，直到意识消散只余一影。玄清子×血魔尊是**共生侵蚀**而非一人双面：宿主本名殷无垢、道号玄清子是身份皮，体内另寄上古血魔尊残念——残念如墨渗纸，端正线描被扭曲墨迹一寸寸吞没，渐变至主元神消散；本名被唤起时可拍半寸拂尘之颤式的身份裂缝。心魔幻境可叠加汤浅政明（《心灵游戏》）式的流动变形质感——仅此窄用，变形不得外溢到非心魔场景。

### 第八式 · 器物传情
**溯源**：小津安二郎（《东京物语》）的日常物件叙事——一只壶、一列火车承载全部情感。
**道劫化**：道劫的情感落点尽量交给器物（方向级锚点，细节以原著圣经为准）：断剑归元（师承托付）、木剑刻字信物（独孤遗赠；刻字原文两说，以事件轴为准）、灰布条（对亲人的选择）、草鞋（凡人之道）。大事之后的第一个镜头永远给物件特写，不给脸；尾段新纪元的众生烟火戏以此式为主语法——鞋墙、种子入缝、木架上的备用草鞋。

### 第九式 · 中心渡劫
**溯源**：张艺谋（《大红灯笼高高挂》）的对称仪式感，与道劫「天命所归/独立天地间」的中心构图传统。
**道劫化**：完全对称的**中心仪式构图**专属仪式性场景——渡劫一人居中天雷正劈、大典宗主居中、原文已有的众生同火可用晏燎居中、各族墨流汇聚（不限定三色，不预设抵达终态）；对称越工整，天道压迫越重。日常戏用微偏构图保留人间气。战斗中剑主的正面机位对称是正统剑路语法（见分镜表手册五系道途战斗分镜表），不属此式禁列。

## 六、禁用词翻译表（外来模板词→道劫合法写法）

道劫只用中文三段式＋装配链。常见冲突词处理如下（左列词禁直贴，本行为规则语境）：

| 禁直贴 | 道劫写法 |
|---|---|
| film still / 35mm / grain / cinematic | 删；成片质感由底座「彩色工笔成片质感」承担 |
| natural light / 自然光（摄影语义） | 改写：光色服从场景与时段，以分染罩染的平整色面表达 |
| high contrast / 高对比 | 改写：受控对比、层级分明（主色辅色点睛各就各位） |
| neon / 霓虹 / 雨夜霓虹 | 禁（色域违禁词）；冷调场景改用靛蓝＋浓墨表达 |
| 体积光/景深虚化/镜头光晕类摄影术语 | 禁；纵深感用前中后景墨色层次＋空气透视（远山如黛） |
| `--ar` `--style` `--v` 等工具参数 | 删；画幅参数取美术侧类型配置，正文不写像素 |

> 本表禁词与美术侧运行时 sanitize 词表（cinematic 族/胶片颗粒族/景深虚化族）同源对齐；出图侧由装配链与 sanitize 兜底，本文管规划与分镜层的源头纪律。

## 七、使用流程

1. **导演规划阶段（⑥段输出）**：按场别选式（悟道＝静中微澜＋墨阶为时；大典＝中心渡劫＋三色分章…），把式名写进①主题立意/②视觉风格/③叙事节奏；手法细节引 `director_planning_narrative.md` 对应章。
2. **分镜表阶段**：式名决定镜头节奏倾向；景别与时长纪律仍走 `director_storyboard_table_narrative.md`（每镜8~15秒、长镜制、静止画面必须有微动）。
3. **出图阶段**：画风槽只允许§二白名单词条＋底座画法；色槽遵循 C1-C10，灵气对象与阶段取当前原文允许的色态，不将晏燎整体限制为三色；外来词先过§六。
4. **九式组合律**：单集主用二至三式，忌全上；三色分章是整集级决策，静中微澜是默认底盘，其余按场别点缀。
5. **视频阶段**：按场别选式后，依§八 H3 骨架撰写视频提示词（风格锚→核心创意→分段过程→声音→结束状态）。

## 八、H3 视频模板

> **消费路声明**：视频生成工作流读的是美术侧 art_storyboard_video 模块，本节供导演规划与 agent 会话引用——工作流不会自动读本节。
> **风格适配门**：本节内容已过道劫风格适配门（G1-G6，六门＝色槽/画法/节奏/题材/声效/sanitize）——写入前逐项核验，不适配即淘汰。

### H3 法定骨架

每个 H3 视频提示词按此结构写（四锚＋时间戳分段）：

```text
【核心创意】一句话创意＋［主体］在［场景］。
【分段过程描述】
[0–4s] 开场：场景定调＋主体初始动作（写幅度和速度）。
[4–8s] 中段：动作承接上一拍，写惯性衔接。
[8–12s] 收尾：主体停住，画面定格在［色调］。
【声音】
overall_soundscape：环境声＋物理声＋有无对白。
non_diegetic_music：配乐；不想要就写「无配乐」。
【结束状态】画面收在［想要的那一帧］。
```

> **时长拆段通则**：总时长 N 秒 → 按 ⌈N/4⌉ 段拆，每段 3-5 秒。12s=3段、8s=2段、15s=4段（末段可至3s）；骨架示例的三段是 12s 基准，其他时长按此通则增减段数。

### 道劫风格锚模板

每个 H3 提示词开头的完整段落（替代色卡的原导演风格锚）：

```text
配色：主色 [C1-C10 按场景选一] 占 20%，辅色 [C1-C10] 占 18%、[C1-C10] 占 16%……让主色占主导，其余按比例递减。
光线：[从光影方案 A-G 选一]——[该方案的道劫色词表达]。
运镜与构图：[从九式选一或组合]——[该式的核心词条]。
氛围与情绪：[三色灵气/留白/墨阶/剑光书法等道劫语汇]。
```

> **C1-C10 速查**：C1=宣纸白 C2=青绿 C3=朱红 C4=靛蓝 C5=旧金 C6=浓墨 C7=淡墨 C8=赭石 C9=暗金 C10=血红（详表见美术侧 style_guide/03_色彩体系.md）

### 关键规则

- 时长 4-15 秒（整数秒），不硬写超限
- **H3 时长与分镜的对应关系（时长冲突修）**：一个 H3 生成可覆盖一个完整分镜（8-15s）或一个镜内节拍（4-8s）；写成完整镜时取 8-15s 上段，写成节拍时取 4-8s 下段并在【核心创意】标注『本段为镜内节拍，与前后段合并为完整镜』
- 一镜一种主导运镜；动作拆 2-3 节拍写清因果；三段须为同一镜头内的连续节拍——禁跨段切换机位或景别
- 参考素材就地声明角色（哪张图当什么用）
- 负面词尽量正向表达（不写现代交通工具，场景全为山门/古道/灵舟）
- 声音必须单独成段且必含 `overall_soundscape`
- 声音域限传统五件（洞箫/古琴/大鼓/埙/编钟）＋环境音（松涛/灵泉/剑鸣等）——**禁电子合成器/现代乐器**（G5）
- **分层说明（声乐层修）**：剧本层（script_narrative §五）禁写乐器名；本节属视频提示词层，可按 planning §九 乐器体系写配乐方向——两禁令不冲突，各管各层
- 上限约 7000 字符——糊成一段不分层才是问题，写长不是
- **冲突裁决**：光影方案（A-G）管画面氛围倾向（辅色、光感），种族分章（第三式）管主色归属——两处冲突时种族分章优先，光影方案的色在辅色位适配

### 九式定制表

| 式 | H3 模板定制要点 | 建议时长 | 主奏乐器 | 适配门核验 |
|---|---|---|---|---|
| 静中微澜 | 全程静止或极缓运镜；[0-4s] 建立空镜定调；节拍内必有墨色晕开/灵气丝缕/光影推移/衣袂微动四者其一 | 10-15s（呼吸需要时间） | 古琴 | G3 过（静止在长镜制内）；G5 过（环境声+古琴一音） |
| 卷轴展卷 | 缓摇＝手卷徐展；[0-4s] 天地自右向左入画；速度以「品味每一寸水墨」为上限 | 12-15s（展卷需从容） | 洞箫 | G3 过（缓摇）；G1 过（色调写法走 C1-C10） |
| 三色分章 | 按种族取主色（人族暖朱红/妖族青绿/鬼族靛蓝/愿力金/魔道血红+浓墨）；[0-4s] 确立主色相即「谁的场」 | 8-12s（确立→展开→定调三拍） | 编钟 | G1 过（三色灵气是道劫自有体系）；G4 过（无现代词） |
| 墨阶为时 | 回忆段用淡墨残卷滤镜；时间推移用墨色浓淡变化表达；色调从淡到浓或从浓到留白 | 10-15s（浓淡渐变需时间感知） | 古琴+埙 | G2 过（水墨技法＝底座组件）；G1 过 |
| 剑意一镜 | 一招一镜不切；起手→出剑→收势在同一时间戳段内完成；剑光即书法笔画，按当场五系笔意与已有色态取用 | 8-12s（完整战斗镜，不以快切压缩） | 大鼓 | G3 过（完整镜头非碎片）；G2 过（不将五系恒画成银白墨线） |
| 一臂之距 | 仅用于柳念漪理念决裂或晏燎自持的既有关系场景；距离随原文可渐宽，不恒定所有双人距离，也不覆盖兄弟拍肩、碰拳、背靠背 | 8-12s（距离变化承接当场关系） | 埙 | G2 过（构图语法）；G4 过（不补关系或动作） |
| 一人两影 | 残识浮现用当帧语言（影子变色/阴阳构图/对切）；不用闪回 | 8-12s（浮现→对峙→消散或共存） | 洞箫+古琴 | G2 过（当帧语言）；G5 过（三色灵气音效） |
| 器物传情 | 当场已有物件承接事件后果；[结束状态] 收在器物；短段在【核心创意】标注镜内节拍，并入8-15s完整镜 | 4-8s（镜内节拍，非完整镜） | 古琴 | G2 过（特写画质走底座）；G3 过（不以短段冒充完整镜） |
| 中心渡劫 | 完全对称中心构图；天雷从正上方劈下；对称越工整天道压迫越重 | 12-15s（仪式感需要铺垫+高潮+余韵） | 大鼓+编钟 | G2 过（对称构图）；G5 过（大鼓+编钟） |

### 写法纪律

- **外来 HEX 一律过 §六 翻译表**：色卡的 `#5F7D6B` 必须写成「青绿山水，约道劫青绿 C2」；`#CD853F` 写成「琥珀棕≈旧金 C5 点睛」；违者＝违规
- **色槽恒为道劫 C1-C10＋三色灵气**，外卡只借结构不借色值
- **不写 `--ar` `--style` `--v` 等工具参数**——H3 在界面里选画幅
- 契约注意：新增文本不可触发 sanitize 词表（禁 `cinematic`/`film grain`/`35mm` 等实拍词——引用它们仅在「禁直贴」语境行）

> 正文只写画面事实——纪律语句（禁XX/勿XX/不含XX）是对写手的规则，不得写进提示词正文

### 完整拼装示例

以「晏燎在道口镇废墟独坐悟道」（12s，静中微澜＋散光清透 A）为例——风格锚在前、骨架四锚在后，声音与结束状态收尾，全格式如下：

```text
【风格锚】
配色：主色宣纸白（C1）占 20%，辅色青绿（C2）占 18%、赭石（C8）占 16%、浓墨（C6）占 10%，主色宣纸白占主导，其余按比例递减。
光线：散光清透（A 方案）——宣纸白底上青绿微暖，废墟残垣投下淡赭石过渡层。
运镜与构图：静中微澜——七成长镜静观，固定机位微仰，晏燎居中偏左，右侧大面积留白。
氛围与情绪：留白中灵气如呼吸起伏，墨色晕开极缓，人物极静而画面活着。
【核心创意】废墟里的一次不动之悟——晏燎在道口镇废墟独坐悟道。
【分段过程描述】
[0–4s] 开场：道口镇废墟全景定调，断墙残瓦间薄雾未散，晏燎盘坐碎石中央，衣袂被风极缓掀起一角。
[4–8s] 中段：承接开场气息，晏燎周身灵气丝缕自淡墨中浮现，如呼吸般三起三伏，身后残墙苔痕青绿缓缓晕开一分。
[8–12s] 收尾：灵气丝缕渐归于静，晏燎双目未睁，头顶薄雾向两侧徐徐分开，画面定格在宣纸白留白基调。
【声音】
overall_soundscape：废墟风声、碎石间草叶摩擦、远处灵泉滴落；无对白。
non_diegetic_music：古琴单音三声，与灵气起伏同拍，末段渐弱至无。
【结束状态】画面收在晏燎静坐侧影与大面积宣纸白留白同框、灵气丝缕将尽未尽的一帧。
```

### Seedance 模板（火山方舟/即梦，候用）

> 视频生成工作流读的是美术侧 art_storyboard_video 模块，本节供导演规划与 agent 会话引用。Seedance 与 H3 的核心差异：Seedance **支持多镜头长叙事（单次最长 30 秒）**、支持**参考视频/白模/绿幕/局部编辑**、参考素材上限**30图+10视频+10音频**。以下骨架从色卡提取、已道劫化。

#### Seedance 2.5 官方五段结构（缺一段就不完整）

```text
【总控】一句话创意＋总时长（4-30s）＋画风声明（水墨国风修仙）。
【参考素材职责】每个素材写唯一职责——如「图1=场景定调」「图2=人物身份锚」「视频1=运镜参考」；无素材可省略此段。
【首帧完整状态】画面第一秒的全部可见内容——场景、人物位置、光源方向、色调。
【连续时间轴】[0-Ns] 按上文「时长拆段通则」逐段写动作与变化；时间戳连续不重叠；每镜一种主导运镜。
【场景限定】本段只写场景特定限制（如有）；不堆通用负面词。
```

#### Seedance 2.0 四段镜头模板（一镜一事）

```text
【运镜】只写一种主导运镜，写清速度（缓/中/快）。
【主体动作与表情】肢体部位＋幅度＋速度；抽象情绪转为可观察的面部/呼吸/重心变化。
【位置或空间变化】空间参考＋主体与前后景关系一句。
【风格与画质】贴道劫风格锚（同 H3 模板的风格锚）。
【约束】 Seedance 2.0 的负面词**必给**——但道劫只写场景特定限制（如「不写现代建筑」），禁堆通用负面词。
```

#### Seedance 与 H3 的选择依据

| | H3（海螺） | Seedance 2.5 |
|---|---|---|
| 适用 | 4-15s 单镜/短叙事 | 4-30s 多镜长叙事 |
| 参考素材 | 就地声明角色 | 50个素材逐个写职责 |
| 声音 | 原生立体声，必含 overall_soundscape | 总控里声明 |
| 负面词 | 尽量正向表达 | 只写场景特定限制 |
| 续写 | 不支持 | 可续写延长 |
| 特殊能力 | — | 参考视频/白模/绿幕/局部编辑 |

九式定制表与风格锚模板对 Seedance 同样适用——式决定内容要点与乐器，锚决定色盘与光线。
