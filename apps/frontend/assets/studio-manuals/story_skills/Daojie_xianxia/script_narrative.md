# 道劫·剧本级规则

> 剧本编写阶段的题材级规则，由系统注入剧本 prompt 的【题材剧本规则】节，只约束剧本文字。导演/分镜规则在 `driector_skills/`；世界观以【项目信息】与原著圣经为准，此处不复述。

## 一、开场放宽声明

通用手册开场条款「前两个镜头内出冲突动作或威胁台词」在道劫放宽为：允许第 1 个镜头为一个 ≤8 秒的水墨氛围 beat（空镜或环境晕染，如「墨色云气漫过山门」；按意境空镜处理，beat 内必须有墨色/灵气/光影微动），自第 2 个镜头起必须出冲突动作或威胁台词。放宽仅此一处：氛围 beat 至多 1 个、至长 8 秒，不得连用。

## 二、称谓体系

- 修士互称「道友」；尊长辈或高境界者为「前辈」；宗门内序辈称师父/师兄/师姐/师弟/师妹
- 宗门职务优先「宗主」「长老」；万劫圣宗中后期元老院职位（圣主、剑裁决、血锋大将等）按原文照用，不另造官职名
- 境界名（炼气/筑基/金丹/元婴/化神/炼虚/合体/渡劫/大乘）仅作身份层引用，单集至多出现两处，不堆设定；万道归真是超越九境的终极状态，不是第十修炼境界，不作身份境界引用。个体不复存在，不新增肉身余生；归凡意象不得改写成肉身复活
- 禁用一切现代现实称谓（市长/局长/警察/总裁等）；原文已用的称谓照用原文

## 三、灵气语汇与阶段边界

镜头描述按当前场景、种族与已知融合进度取色；不写「发光/特效/粒子」等游戏感词：

- 人族＝朱红（温暖厚重，如朱砂入水）
- 妖族＝青绿（灵动野性，如翠墨泼洒）
- 鬼族＝靛蓝（阴冷幽深，如靛青渗透）
- 晏燎整体灵气：三色驳杂→灰黑凝聚→暗金蜕变→暗金主色，依当章原文、原著圣经及已知融合进度；不硬编码卷次，不按颜色反推融合进度。五系道途不等于三股灵气，不把融合拍成五系觉醒
- 后期明确特指人、妖、鬼三股时仍可分别用朱红、青绿、靛蓝；不得拿三股特指概括后期整体力量。早期灰黑边界反应与龙气暗金丝缕合法，不表示整体已进入灰黑或暗金主色期
- 初期三股排异可用三色「翻涌/撕扯」；后续排异依当场已有色态，不机械套三色。愿力＝金色；魔道＝血红＋浓墨

灵气动词用水墨系：晕染、翻涌、渗透、交融。

- 种族三色≠五行配色：青绿非木、朱红非火、靛蓝非水——前者是种族灵气视觉，后者是灵气根骨分类，同色不同义

## 四、旁白腔与内心独白

- V.S.（旁白）：水墨写意短句，一句只状一景，克制留白；旁白不得替场景做事——动作与冲突交给镜头描述
- OS（内心独白）：内心独白是水墨修仙的类型语言——有秘密、有难言之隐时用 OS 直陈本心；禁用 OS 灌世界观设定
- 晏燎与苏无忌残识（道基融合的鬼修意识）的内在对话是本剧核心内心戏：对峙时刻写 OS 对切，不借旁白代言
- 诗化台词只留给关键情绪点；日常对话保持口语说人话（通用手册台词规范仍然适用）

## 五、禁令

- 剧本层只写入点音效（SFX，写声源与时机）；禁写配乐/BGM 与一切乐器名（古琴、洞箫等）——成片配乐归音乐产线，不在剧本层发生
