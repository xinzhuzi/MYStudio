# 道劫·剧本级规则

> 剧本编写阶段的题材级规则，由系统注入剧本 prompt 的【题材剧本规则】节，只约束剧本文字。导演/分镜规则在 `driector_skills/`；世界观以【项目信息】与原著圣经为准，此处不复述。

原文事实与台词优先于开场节奏、类型语言和集末钩子。只适配所给当章片段，不为满足拍法补写动作、人物关系、未来后果或对白／OS／V.S.；待确认内容不得先写入正式剧本。设定说明与比喻不能自动变成当场发生的动作；缺少可视载体时保留未定，不编造外在反应。

动作的施事、对象、数量、初始状态与先后顺序都属于原文事实，不是可自由填补的表演细节；命令不等于已经执行，静态结果不改写成当场变化，心理感知不外化成风雷或环境异动。原文对白逐字保留，不省略限定词，不将叙述、判断或比喻转成新发声。短片段按现有事实安排时长，宁可缩短或保持已有动作，不靠补动作、反复挣扎、旁白或续写凑满目标分钟数。

## 一、开场放宽声明

通用手册开场条款「前两个镜头内出冲突动作或威胁台词」在道劫放宽为：当章已有相应环境时，允许第 1 个镜头为一个 ≤8 秒的水墨氛围 beat（空镜或环境晕染，如原文已有的云气；beat 内只呈现已给墨色/灵气/光影微动），其后优先呈现原文已有的矛盾或压力。氛围 beat 至多 1 个、至长 8 秒，不得连用；静观、悟道或理念争执段没有冲突动作／威胁台词时，不为开场要求补造。

## 二、称谓体系

- 修士互称「道友」；尊长辈或高境界者为「前辈」；宗门内序辈称师父/师兄/师姐/师弟/师妹
- 宗门职务优先「宗主」「长老」；万劫圣宗中后期元老院职位（圣主、剑裁决、血锋大将等）按原文照用，不另造官职名
- 境界名（炼气/筑基/金丹/元婴/化神/炼虚/合体/渡劫/大乘）仅作身份层引用，单集至多出现两处，不堆设定；万道归真是超越九境的终极状态，不是第十修炼境界，不作身份境界引用。个体不复存在，不新增肉身余生；归凡意象不得改写成肉身复活
- 禁用一切现代现实称谓（市长/局长/警察/总裁等）；原文已用的称谓照用原文

## 三、灵气语汇与阶段边界

镜头描述按当前场景、种族与已知融合进度取色；不写「发光/特效/粒子」等游戏感词：

- 人族＝朱红（温暖厚重，如朱砂入水）
- 妖族＝青绿（灵动野性，如翠墨泼洒）
- 鬼族＝靛蓝（阴冷幽深，如靛青渗透）
- 晏燎整体灵气：三色驳杂→灰黑凝聚→暗金蜕变→暗金主色，依当章原文、原著圣经及已知融合进度；不硬编码卷次，不按颜色反推融合进度。五系道途不等于三股灵气，不把融合拍成五系觉醒
- 后期明确特指人、妖、鬼三股时仍可分别用朱红、青绿、靛蓝；不得拿三股特指概括后期整体力量。早期灰黑边界反应与龙气暗金丝缕合法，不表示整体已进入灰黑或暗金主色期
- 初期三股排异可用三色「翻涌/撕扯」；后续排异依当场已有色态，不机械套三色。愿力＝金色；魔道＝血红＋浓墨

灵气动词用水墨系：晕染、翻涌、渗透、交融。

- 种族三色≠五行配色：青绿非木、朱红非火、靛蓝非水——前者是种族灵气视觉，后者是灵气根骨分类，同色不同义

## 四、旁白腔与内心独白

- V.S.（旁白）：只沿用当章已有的旁白内容，水墨写意短句、一句只状一景；不得新增点题、未来后果或评价。原文叙述性心理不能改成新旁白；动作与冲突交给已有事实（原文叙述层的受控转译见四·附；本条仅约束非转译内容）
- OS（内心独白）：只沿用当章已有的内心独白内容；有秘密或难言之隐不等于授权编造心声，叙述性比喻不改成角色新台词；禁用 OS 灌世界观设定
- 晏燎与苏无忌残识（道基融合的鬼修意识）的内在对话只在当章已有相应对话时使用 OS 对切，保留原有内容；不因对峙、共生设定或题材核心地位新增发言，不借旁白代言
- 诗化台词只留给关键情绪点；日常对话保持口语说人话（通用手册台词规范仍然适用）

### 四·附：叙述层转译通道（原文叙述层 → 声音层）

小说第三人称叙述层明写的动机、代价、来历与世道设定（如追杀缘由、功法代价、断剑来历、矿奴世道），是原文事实的一部分，不得因「无当场发声者」而被排除出剧本。此类内容按下述通道进入旁白：

- 转译来源：仅限当章原文明文（叙述句、回忆段、设定句）。原文没写的，仍不得补。
- 转译三重约束（任一违反即违规）：
  1. 近逐字取原文——以原文句为底本，只允许剪（删句、删词、按镜切分、句序随画面顺序排列），禁止改写措辞、调换语义结构；跨句拼接不得增删或移接连接词（可/但/而/便等虚词不得跨句挪用，两原文句只可并列或切分）；
  2. 不加评价、不改语义——不得添原文没有的形容、判断、点题或情绪定性；
  3. 不补原文没有的信息——来历、数字、名号、设定一律照原文，缺则不写。
- 通道边界：本通道是「原文叙述性心理不能改成新旁白」「禁用 OS 灌世界观设定」的受控例外——例外对象仅限原文明文，且只走旁白，不得借道 OS；「不得新增点题、未来后果或评价」在通道内同样生效。通道内旁白不受「一句只状一景」约束，以三重约束为准（原文说理句/设定句原样入旁白不违规）。
- 压缩裁定门：凡剧本（含剧本压缩表 scriptDraft、分镜表）要删、压、后置原文明写的动机、来历、设定类信息，必须先列清单（原文句｜拟处置｜理由）报用户裁定，未裁定不得落稿。默认处置＝按本通道转译保留，而非删除。
- 下游口径：本通道转译的旁白不受「OS/旁白占比 ≤40%」「连续不超过 2 段」「旁白不得替场景做事」限制；承载镜语速判定线 4.6 字/秒（镜级与场级同用），纯对白与非转译旁白仍守 4 字/秒；既有成品不追溯重配，但不因此合法化。

## 五、禁令

- 剧本层只写入点音效（SFX，写声源与时机）；禁写配乐/BGM 与一切乐器名（古琴、洞箫等）——成片配乐归音乐产线，不在剧本层发生
