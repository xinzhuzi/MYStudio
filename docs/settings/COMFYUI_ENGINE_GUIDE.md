# ComfyUI 引擎指南

本文说明 `设置 → 本地配置 → ComfyUI 引擎` 区块的安装、更新、模型管理与存储配置。本地生成产线（K2 图像 / H3 视频 / 音乐）全部跑在这个自管引擎上，前端工作区见 [本地模型页](../panels/LOCAL_MODELS_GUIDE.md)。

## 引擎安装

首次使用时区块显示 `安装引擎` 按钮（一键安装，体积 GB 级，点击前有提示，绝不自动下载）。安装进度条按阶段显示大白话进展（下载源码 / 装依赖 / 同步自研节点包等），失败可重新点击从断点续装。

引擎安装位置（引擎「家」）在用户数据目录 `<userData>/comfyui/`：默认包括 `ComfyUI/` 源码、独立 `venv/`、`models/` 模型、manifest 与实例锁。用户工作流默认在 `<源码目录>/user/default/workflows/`；源码、venv、工作流等目录可在存储页迁移，实际位置以该页为准。安装包本身不携带引擎与模型，全部按需下载。

## 五个页签

区块展开后按页签组织（照 ComfyUI Desktop 设置布局，「模型」为默认页）：

| 页签 | 用途 |
|---|---|
| 模型 | 本地模型统一家 `comfyui/models` 的活清单 |
| 更新 | 引擎本体与生态插件的版本检查和更新 |
| 启动参数 | 自由命令行与环境变量 |
| 快照 | 引擎快照管理 |
| 存储 | 引擎家各目录的位置与迁移 |

## 模型页签

展示 `comfyui/models/` 的真实内容，按域折叠分组：`图片` / `视频` / `声音`。每个模型件显示名称、体积与可用性口径（部分家族有格式门槛，例如 MLX 格式仅 Apple Silicon 可用）；下载、更新等操作按件进行。本地 TTS、音效、视觉审核的模型也住在这个统一家里，与 ComfyUI 产线共用一套权重。

## 更新页签

- 版本策略=跟随最新 release；`检查更新` 显式点击才查（展开卡片不会自动查）。
- 有新版本时点 `更新到最新`；更新链强制拉取是幂等的，中断后重新点击会从断点续装。
- 更新链不做快照、无「一键回滚」；失败重试即自愈。生态插件的更新在同一页的插件台账里逐个进行（已装列表 + 可安装策展 + Registry 合并搜索），点对应插件行的「更新」。

## 启动参数页签

- 自由命令行整串是唯一真源（照 ComfyUI Desktop）；语法错误红字拒存。
- 大众端口（8000/8188/3000 等）黄字警告、`0.0.0.0` 红字警告，放行但提示风险。
- 环境变量表：添加行防抖落账，值默认遮蔽显示。

## 存储页签

目录行为平文本展示，共六行：

| 行 | 说明 |
|---|---|
| 模型目录 | 纯指针，指向模型统一家 |
| 源码目录 | ComfyUI 源码仓库与 custom_nodes 插件（改路径=整体搬移） |
| 引擎虚拟环境 | ComfyUI 专用 venv，与「Python 运行环境」无关；迁移时在新位置重建 |
| 工作流目录 | 可写用户工作流库；默认 `<源码目录>/user/default/workflows/`。内置模板从应用自带仓库库只读合并，不随这一目录迁移 |
| 输入目录 | 参考图与上传图片（可迁出源码目录；现有文件自动搬移） |
| 输出目录 | 生成产物（可迁出源码目录；现有文件自动搬移） |

源码 / venv / 工作流三行修改后走迁移 job（带进度）；输入 / 输出目录经官方 `--input-directory` / `--output-directory` 注入，改完重启引擎生效。

## 常见问题

- **引擎卡一直转 / 起不来**：见 [常见故障排查 · ComfyUI 引擎问题](../engineering/TROUBLESHOOTING.md)（端口占用、孤儿进程、插件 import 失败等配方）。
- **报「更新失败」**：先核引擎实际版本——更新本体常已成功，重按 `更新到最新` 会从断点续装。
- **改了启动参数没生效**：重启引擎；端口以引擎状态显示的为准。
