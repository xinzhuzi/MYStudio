## 3. 教材结构法(现行 v10 骨架,改前必读)


## 4. 冲突防免十律(每律带判例编号,判例见第 10 节)

1. **裁决序立宪**:条款冲突必须有总法庭,否则 AI 就近取权(哪条离输出近听哪条)。〔判例 C1〕
2. **豁免授权要窄**:"本节优先于XX条款"式宽授权会被照单全收——透明豁免曾写"优先于锚点保留/色词保持",9B 直接把月白腰带/白玉剑格删了。授权必须点名豁免什么、**不豁免什么**。〔C2〕
3. **别用可抄措辞写规则**:规则原文里的句子会被模型逐字抄进终稿("光照仅写落在主体身上的效果"整句照抄案)。规则措辞要"去回声化"。〔C3〕
4. **词级禁令优于句级**:"不得照抄本指令"难执行,"终稿不出现「背景」「仅写」「已移除」「透明模式」"可执行——黑名单是 token 级。〔C3〕
5. **模式词汇域隔离**:透明措辞(透明底立绘素材)不得泄进关模式;关模式的原文环境词(云海/山门石阶)不得被透明规则误删——两边都要写明。〔C4〕
6. **补丁轮叠完必须整文重审**:每次加注都可能和旧条款造新撞——规则5 扩场景元素(山门/灯笼/匾额"透明开同样生效")和透明豁免删除清单(山门石阶=第一例)正面对撞,是 v4 自己埋的。〔C5〕
7. **规则复杂度≠数据长度**:数据(色库表)涨 1000 字不炸思考链,规则多一层分派思考量超线性暴涨(3162→7k,3870→21k 草稿)。加规则前先想清楚能不能用一条窄禁令替代。〔C6〕
8. **同域词的从属关系要点名**:风格底座的背景句归透明豁免管(润炼模式"底座逐字不丢"不保护背景句)——裁决序有序但没点名的角落,模型会自己选。〔C7〕
9. **过期条款随架构同步清理**:负面清单"不超过用户清单范围"是只有用户负面的旧时代遗物,节点已是三源合并——文字必须跟着现实走。〔C8〕
10. **账实相符**:标题说 42 就必须真 42;说 10 个★在用就得 10 个在场(canon 外的在用词列入"在用补充")。〔C9〕

## 5. 措辞工程(透明/色词/锚点三族的细则)

- **环境词删除的边界**:删场景定位(山门石阶/云海/远山/天空/远处/远景/云雾/背景),保主体动作(右手按剑柄)与光照方向(左侧斜照)。
- **删环境≠删部件**:部件与环境同句时("立于山门石阶前,系月白腰带")删环境定语、留部件本体——这是防丢锚的核心句式,必须写进教材。
- **色词三源保护**:color_lexicon 在用词 + canon 42 名 + 模式提取(X色/X+色字),只保主体句中实际出现的;原文色词逐字禁换(青玉色≠青绿色)。
- **境界词**:炼气/筑基/金丹/元婴/化神/炼虚/合体/大乘/渡劫 + 初/中/后期/圆满——身份锚点里唯一可模式化的家族,丢了=身份漂移。
- **开头句公式**:透明开时不写"背景基调"四字,直接写"透明底立绘素材"(否则模型会写出"背景基调为透明底立绘素材"这种半遵循体)。

## 6. 模型适配纪律(LM Studio aggressive 系)

| 特性 | 实测结论 | 纪律 |
|------|---------|------|
| 思考焊死 | `/no_think`、`enable_thinking:false` 全被无视;`max_tokens=5` 的"回好"字,5 token 全进思考 | 思考控制只认顶层 `reasoning_effort`(节点 `thinking_effort` 档位) |
| 装载窗口 | JIT 装载默认 ctx=8192,输入~4k+草稿装不下=**饿死**(正文 0 字透传) | Windows 侧必须 `lmstudio-win-remote.sh load`(固化 -c 32768);闲置 1h TTL 卸载,用前重装 |
| 预算 | 草稿可 4.6k~21k 字浮动 | max_tokens 12000 默认;首轮空正文自动加预算重试一次(节点内置) |
| 速度 | 思考开 129~576s/发;思考关 25~76s/发 | 日常迭代用"关闭";终稿出图切"思考(xhigh)"(9/10 vs 7/10 质量) |
| 方差 | 温度 0.7 下逐发掷骰:同型上轮过下轮丢单点(一个锚/一个负向词/一个环境词) | 接受方差+机检自愈;结构失败(透传/格式破/锚点屠杀)从未发生,出现即报警 |
| 快档懒病 | 思考关偶发主体句原样照抄不改写 | 混句机检治不了;敏感透明型出稿必看,红则重发或切思考档 |

## 7. 机检自愈层(节点内置,教材改不到的部分)

> 1010 补(用户令「按照你的建议都做」):机检/解析的内容层失败现在**也换下一模型**——旧路只在网络层失败换目标,内容层失败(Win 拒收/解析失败)同模型补发一次后直接回退装配,其余目标从未被问到(分镜案:Mac 27B 活着载着零调用)。现行=拒收/解析失败→逐余位一发(零违例才收)→全败才回退装配(实弹:表情发 Win 两稿拒→Mac 27B 救回 526 字零违例采用)。同批:色词模式提取假红停用集(的了多全发夜景物彩图与温调相边字;C12 家族)与信封解析末路二阶(前导空白+缺{+值内裸引号+无尾引号四形态,治 5436 字全稿被扔案)。

**六检(确定性,零猜测;v10=负向解耦终裁重构)**:
1. 透明开黑名单(_META_TOKENS 指令词 + _ENV_TOKENS 环境词)
2. 关模式环境保留(对称检:主体句里的云海被删=违例)——透明开有删、关模式有保,两边都机检
3. 色词逐字(跨度贪心去重叠:词典源>模式源、长词优先、非色字数 tie-break——"阶下青灰"取青灰弃下青,"缠灰银丝"取灰银弃缠灰)
4. 境界词(域名词表)
5. 部件名词表(_PART_TOKENS 20 词:剑鞘/剑格/剑穗/腰带/发簪/山门/灯笼/匾额等)
6. **正负撞词**(1008 用户令):模型正向稿含负向语料 token=违例拒收——负向由三源程序构造后,这是正负冲突唯一残余面;豁免表 `_CLASH_EXEMPT` 语义分组声明(唯一在案=「大气透视」教材合法氛围词≠负向「透视」机位/形变缺陷义;干跑 A/B/C 三轮十型装配文+教材指令词+实弹样例零假红),空白归一双侧同规(C14 配方延撞词检)

「负向三源在场」检已退役(1008 解耦):其对象=模型负向稿,输出侧已不采信;终稿负向恒由三源源词程序构造=结构性不缺词。

**补发协议(零违例接收门,1008 终裁)**:任一检违例=不合格稿,同模型点着缺项重发一次(缺什么点名什么);**重试稿零违例才收**;重试仍有违例(违例变少不算过)/重试解析失败/补发请求失败=**拒收模型稿,回退已装配 direct 正稿+确定性负向**(拒收可见性=节点 print 日志+引擎 history,零新画布口;恒有输出不卡产线)。终稿负向在首稿/重试/拒收/透传全路径同值=`_sanitize_negative(三源源词合并)`。

**程序滤(透明开,出稿后自动)**:
- 纯环境句删除:含黑名单词且无主体锚(色/境/部件)的**整句**删;误删保护=删后 <max(40字,25%) 回退原文
- 括号剥离:含黑名单词的全/半角括号段整段删(治"(虽背景透明,但原立于山门石阶…)"式补注藏匿)

**不可机检(画布人眼+重发兜底)**:普通名词锚(匾额/乌木剑鞘整词)、构图措辞(正脸特写≈正面机位)、快速模式整句照抄。

## 8. 修改 SOP(改教材/色卡/规则必走,八步)

1. **脚本手术**:改 json 用 splice 脚本(`apps/build/scripts/qi21_sysprompt_*.py` 型),锚断言(旧串 count==1)+语义自检(关键标记在场/离场)——禁手改 json。
2. **整文重审**:改动落盘后全文逐句过一遍(第 4 节十律),重点查新加注与旧条款的对撞。〔C5 教训〕
3. **展示框双刷**:工作流 json + **蓝图 subgraphs json 两处** `[4030]` widgets_values 都要刷——`qi21_blueprint_sync_1001.py` 方向=蓝图→工作流("整体以蓝图为准"),只刷工作流就跑同步=被蓝图旧版吃回(实害:3870 展示框两轮被改回 3162,测试照样绿因为两边一致地旧)。
4. **蓝图同步**:双刷后跑 sync(应报"一致,零写入"幂等)。
5. **七路部署**:真源 json→装机 Resources/引擎 daojie-data;工作流→装机/引擎缓存;蓝图→装机/引擎家;节点 .py(若改)→三路。
6. **全套测试**:`pytest tests/test_qwen21_workflow_contract.py my_nodes/tests/` 全绿(装机固位对拍会抓漏拷)。
7. **实弹验收**:直调节点模块(无需引擎),`runs/campaigns/qi21-sysprompt-livefire/` 有测具;透传判定=捕节点 print 标记,**勿按长度猜**。
8. **落账**:记忆+本篇判例集追加;教材长度演化账(第 11 节)更新。

**测试断言语义(测具工程,血泪结晶)**:
- 同义词=ANY-of("正脸特写"≈"正面"+"机位"任一组全在即过),拆写=ALL-of("朱红灯笼"="朱红"且"灯笼"都在)——**两种语义必须分组声明**,混用=假红满天飞
- 断言标准必须与节点机检对齐(山风掀衣=主体动态非场景,两边同判)
- 探针改完先干跑验断言本身(连写锚点没给别名的假红曾污染三轮测试)

## 9. 验收标准

- **十型全量实弹**:九型+自由各一发,透明开型必埋环境词、透明关型必查环境保留
- **过关线(思考档)**:9/10 全绿;快速档:7/10 且红项均为单点(结构失败=0 透传、0 格式破、0 锚点屠杀、0 负向空转)
- **单发耗时**:思考档 129~576s、快档 25~76s 为健康带;超出=查窗口/队列/服务器
- 每次教材改动至少:人物(全锚)+透明型(环境删除)+场景(环境保留)三发抽验
