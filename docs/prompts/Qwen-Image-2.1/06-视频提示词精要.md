## 一、两支视频是谁、讲了什么

### 视频 A · PE 增强怎么做(research/10)

| 项 | 值 |
|---|---|
| 标题 / UP | 《QwenImage2.1官方提示词扩写-更好！更快！更准！》· 绘世玩家 · 2026-09-22 · 7:16 |
| 链接 | https://www.bilibili.com/video/BV1TshJ62ExX/ |
| 一句话 | 演示 **ComfyUI 官方原生节点路线**的提示词增强(零自定义 PE 插件) |

它讲的 PE 完整做法(要点,出处 research/10 §2):

1. **路线**:`Prompt(短中文句)→ StringOps 拼接 → 原生 TextGenerate(use_default_template=true,自动套 PE 宪法)→ 从JSON提取字符串(key=rewritten_prompt)→ rgthree Any Switch 与直写二选一 → TextEncodeQwenImage21`。
2. **模型**:PE 检查点用 Comfy-Org 官方 int8 件(T2I/I2I 各一件);生成三件套与我们同款(bf16 UNET + qwen3vl_8b CLIP + vae)。
3. **参数**(5 帧一致读数):temp 0.7 / topK 64 / topP 0.95 / presence **0.00** / max_length **4096**(唯一特调值,字幕专门讲它)。
4. **效果**:短中文句进 → 单行 JSON 出(rewritten_prompt 约 400-500 词英文长文 + wh_ratio 建议画幅);PE 生成 0.085-0.7s,4090 出图 9.76-15.87s/张。
5. **I2I 增量**:`Getimg1..9 → Image Batch Multi(kjnodes)→ TextGenerate.image` 多图进模型;短中文指令 → **中文**改写长文,身份锁「保持<image1>中人物的外观完全不变」句式。
6. **坑演示**:模板没生效时 TextGenerate 输出聊天体中文长文(带 /think 残迹)不是 JSON——非 PE 检查点/不套宪法就不可靠出 JSON。

### 视频 B · 提示词怎么排布(research/11)

| 项 | 值 |
|---|---|
| 标题 / UP | 《【干货汇总】Qwen-Image-2.1官方示例提示词拆解》· 龙猫M4K0 · 2026-09-21 · 10:14 |
| 链接 | https://www.bilibili.com/video/BV1nWhe6CE2D/ |
| 一句话 | 48 页幻灯片逐例展示 **37 个官方示例提示词全文**——不是 UP 自创方法论,是官方范式的证据库(片头主旨句:「把提示词写明白,画面自己就出来了」) |

它的「排布法」五要素(research/11 §四.3 原文):**成句不堆词/长度随任务走/编辑先锁不变量/方位词+逐格枚举锚定/一致性显式成句**。逐条展开(出处 §二):

1. **自然语言成句,零权重语法**:37 例无一处 `(word:1.2)` 式加权;强调靠措辞——「全部外观完全不变」「严格保持」「Strictly preserve」。
2. **长度随任务走**:162 → 4425 字全谱(旅行规划 UI 4425 字 ↔ AI 时间轴 162 字);「版面/多区域/多参考图任务→上千字长文;单场景摄影/简单卡片→一二百字短句」。Q2.1 长上下文是预算,该用满就用满。
3. **两种式样按任务选**:版面/多格任务用【方括号标题】分节(【版面与文字位置】【角色】…);单场景照片级任务用单段连续长文、分号隔语义块。
4. **顺序范式**:任务动词开头(「生成一张真人电影质感的单角色三视图设定参考图。干净灰色背景。」)→ 编辑类不变量先行(「保持<image1>中粉底液瓶的全部外观完全不变」)→ 方位词密集锚定(左侧/中央/从上到下)→ 一致性写成显式整句(「每一格里都是同一个人——面容、发型、服饰、身材比例保持一致」)。
5. **负向内嵌正文**:「不要」句直接写正文里,尾缀「无文字、无Logo,无水印」;37 例无一用独立负向栏;官方展示时**智能改写(PE)一律标「关」**。
6. **文字/颜色逐字逐值**:画面内文字引号逐字给定;配色 hex 色卡(#FFFFFF/#F2ECE9…)或具名色行列举。

## 四、对道劫线的使用建议(三句)

1. **直写是默认路,PE 只是可选增益**:四层装配整段直写 = 官方 37 例「智能改写:关」的同款工作方式,道劫量产一律走这条路([141] 默认 false 不动);PE 开关留给短句起步/要英文长文的场合,开了也别当依赖——参数要不要调,等 §三·待办1 的 A/B 结果,别照抄视频值。
2. **要透明图,只认官方头尾句**:等 §三·必改落地后,开 RGBA 开关即自动走「官方头句+四层装配全文+官方尾句」逐字版;在那之前别手改 [143] 句式、别自造透明句。画幅仍按九型档,wh_ratio 联动未排期前不用管。
3. **写句按 05 库纪律走,分歧已裁定别被视频带偏**:①层全肯定、零权重语法、质量词与比例词不入正文;②③层可在易错防漂点有限使用显式禁句与「无文字」式收尾(待办2 落库后生效);不搬计数断言、不改【】节标题、不学 @meeyo.com 拼接。
