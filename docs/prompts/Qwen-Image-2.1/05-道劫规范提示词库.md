## 一、用法(四层装配·一处换句)

**装配顺序**(照甲案;③④原文照抄,②=本库美化版):

```text
[①主体句·题材正文](七段公式简写,短——本库 ⟨①:…⟩ 槽,唯一手写位)
+ [②型底座·美化版纯画法锁质](本库该型节②层成文;型名/画幅档对齐 daojie_bases.json)
+ [③通用锁层](prefix.md §四.1 风格底座锁 + §四.2 结构锁 + §四.8 成片质量锁 三段提取后经 Q2.1 摘噪后处理(0925 军令,删否定禁令三句/正向句全保留)+四令底色句多彩化(0925 四令:§四.1 底色句单色场→多色相基底;均生成器侧 fork,手册原文不动);
                人物系六型再并 §四.4 衣褶 + §四.5 衣物完整 + §四.6 头发 + §四.7 鞋靴 四把全员锁,全文照抄零摘句)
+ [④配色职责行](0925 四令多彩轮:宣纸白领头的淡雅/青绿/旧金行退役,多彩行由生成器侧映射;手册原文不动=Q2.1侧偏差)
```

**三步用库**:

1. **挑型**:按型录九选一(画幅档/留白档随型,见各型节首),整段复制该型「装配全文」代码块。
2. **换槽**:把首行 ⟨①:…⟩ 整段角括号(**连括号**)换成你的主体句(参考该型主体句规范与 2 条示例);不换也成立,槽内已预置例一。换完跑重叠预检(见下「主体句纪律」第 5 条)。
3. **贴画布**:`qi21-道劫-t2i.json`(唯一用法,09-23 午定谳——前代道劫直写件已随轮退役删除)把「九型底座+通用锁层+四层装配」收进 **[40] 装配子图**(双击进入=九型底座常量+八级选型级联+锁层恒挂+换行拼接+PE/RGBA 路由):换型=子图面板八级开关一处切换(不跨型拼装),主体句=[24] 外露槽,装配预览=[27];其底座/锁层常量逐字=本库(生成器 `apps/build/scripts/qi21_daojie_t2i_0923.py` 从本库现读,契约测试互锁)。

**长度口径**:手册长度契约 300-800 字符(prefix.md:230)约束的是 ma-gongbi-v1 编译器装配的 LLM 生成路;本库直写槽路无编译器长度门,按 round5-jia 实拍口径(装配全文 1475-2086 字符含换行)整段注入,Q2.1 直写槽不截断(实拍 /history 逐字核验)。美化版②层较 canon 略长(每型+40-80 字符),仍在同量级。

**主体句纪律**(五则,取用/新写主体句通用):

1. 主体句**只写主体与画面,不重复风格词**——线条/墨色/设色/完成度 DNA 由②③层自动携带,写风格词=与底座双写。
2. **场景/概念气氛不写人**(该两型人物交给负向纪律;Q2.1 cfg=1 负向不参与采样,由①层「不写人」约定承担,空镜句尾可明写「空镜无人」)。
3. **同画面朝代统一**(汉唐宋明历代均可);历史向服饰按朝代实名+身份+地位+成套点名。
4. **全角标点**。
5. **发放前强制预检**:`python3 apps/build/scripts/daojie_canon_lib.py --overlap`(判据=≥10 字公共子串,对照**美化版②层**;CLI `daojie_subject_overlap_0922.py --base 型名` 对照的是 K2 侧 canon positive,两账并行勿混)。
