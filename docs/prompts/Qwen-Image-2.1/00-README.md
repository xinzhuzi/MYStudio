## 与提示词大全的关系

- 上级目录 `docs/prompts/`(索引页 `docs/prompts/README.md`,即「提示词资料索引」/提示词大全)收集的是**提示词、风格参考与实验记录**,多为「外部摘录/素材」或「日期实验记录」性质。
- **本目录 = 提示词大全的 Qwen-Image-2.1 专章,且是该章的宪法源**:其余条目给「写什么」的素材,本目录给「怎么写才合规」的法条。凡本仓库其它文档与本目录 01 篇的官方原文冲突,以 01 篇为准;01 篇与官方仓库现行版冲突,以官方为准并回写对账。

## 怎么用这套宪法(给起草提示词的 AI 与用户)

1. **写 2.1 文生图长文** → 读 01 篇第 2 节(T2I 分段地图)+ 第 4 节(五件套)+ 第 6 节(20 条手法),按八步走,验收线:约 20 句 / 400–500 词 / 开头句恰好 1 句约 20 词 / 位置短语 8–14 个 / 光照显式 / 总结句恰好 1 句。
2. **写 2.1 编辑/多图指令** → 读 01 篇第 3 节(I2I 分段地图)+ 第 5 节(格式七规)+ 第 7 节(9 条手法);记住两个最易踩反的点:描述语言跟指令走(中→中)、编辑指令禁 hedge(与 T2I 相反)。
3. **在 ComfyUI 里接增强** → 读 02 篇:装社区插件或图外跑 vLLM,参数按第 3 节对照表,presence_penalty(T2I=1.5/Edit=0)不许动。
4. **找参考成品** → 02 篇第 5 节两条官方手写示范(逐字全文)+ 01 篇第 8 节官方输入实例;官方 PE 真实输出语料不存在(缺口声明在 01 篇 8.0),勿引用编造的「官方输出」。
5. **选用技能辅助** → 读 03 篇;已装两件的私货点(三段式输出 / 300–500 词放宽 / 缩编比例表)已列明,仲裁以 01 篇为准。
