# 道劫九型·主体句示例九条(09-19)

用法:**[80] 道劫底座选对应型(分辨率自动跟随)→ [50] 主体句贴对应条目全文 → 出图**。
风格 DNA(线条/墨色/设色/完成度)底座自动携带,主体句**只写主体与画面**,不重复风格词。
可选:分镜剧情图型可追加连环画句「中国连环画风格…连环画分镜式构图」(见 prefix 手册连环画段)。
纪律:场景/概念气氛不写人(其负向已禁 person);同画面朝代统一(汉唐宋明历代均可);全角标点。

## 1. 人物(3:4 竖幅)

```
一位筑基后期的年轻女修，青玉色道袍束月白腰带，长发半束只簪一支素银簪，眉目沉静中带一点锋芒；她立于山门石阶最上一级，右手轻按剑柄未拔，视线越过阶下云海望向远处，晨光自左侧斜照，衣袂被山风微微掀起。
```

## 2. 场景(16:9 空镜,无人物)

```
暮春时节的黄昏，废弃的上古祭坛深藏在群山环抱的谷底，九根断裂的石柱围成半圆，坛心一泓浅潭映出残阳；谷口白雾正缓缓漫入，远山三重叠影渐次淡去。
```

## 3. 道具(1:1 四宫格:正/侧/背/细节)

```
一柄传承千年的青铜剑，剑身暗金底色上盘绕细密云雷纹，剑格铸成兽首衔环，剑柄缠深红丝绳，穗尾垂一枚带裂纹的灵玉；细节特写一格聚焦剑身近格处的旧伤裂纹与缠绕其上的金色修补纹。
```

## 4. 美宣(16:9/21:9 叙事瞬间,可拉高视觉强度)

```
雷劫降临的至暗时刻，白衣剑修独立孤峰之巅，周身剑气化作淡金色光罩，九道紫雷自翻墨般的劫云中劈落，他在最后一瞬反身拔剑迎击，衣袍与剑穗在罡风中猎猎狂舞；远景群山在雷光明灭中沉浮。
```

## 5. 三视图(21:9 横幅:前/侧/背)

```
同一位玄色劲装的青年刀修全身三视图：正面按刀垂立，侧面抱刀而立，背面负刀远望；三个视角姿态自然舒展，服饰纹样、配饰与发型在视角间完全一致。
```

## 6. 高清人脸(3:4 竖幅特写)

```
一位驻颜有素的女修面容特写：眉如远山含黛，眼尾微挑，瞳色深棕近黑，鼻梁挺秀，唇色淡朱；神情是劫后余生的平静，几缕碎发贴在微汗的额角，柔和顶光勾勒出面部的立体轮廓。
```

## 7. 分镜剧情图(16:9 叙事)

```
山雨欲来的渡口，老船工收篙回望，身后的少年修士第一次背起行囊离乡；乌云压江，渡口一盏灯笼是画面唯一的暖色，两人的目光都投向江雾深处若隐若现的仙山轮廓。
```

## 8. 表情差分(21:9 多格)

```
同一位红衣女修的五格表情差分：平静垂目、含笑不语、怒目剑眉、痛楚闭眼、决然睁眼；各格头部角度与光源方向保持一致，只有神态与眉眼唇形变化。
```

## 9. 概念气氛图(16:9/21:9,重留白)

```
千年一次的灵潮涨落之夜，悬浮的碎裂古殿群沐浴在青蓝色灵光中，万千萤火状灵尘随气流缓缓升腾；画面九成留给静谧的夜与雾，只余殿群一角与一株横生孤松的剪影。
```
