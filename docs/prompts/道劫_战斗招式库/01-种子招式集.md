## 二、主角剑系(专属轴,六式)

### A0 剑道三母式(总纲条目)

**道途锚**:canon——设定集御剑道途文件明言撩、斩、刺为一切剑系起手之母(各剑系道途共用的基础起手式)。本条目为总注:五系剑道招式(A1-A5)的起手均从三母式之一变形而来,拆招也拆回这三线。

**三线执行要点**:

- **撩(由下向上)**:沉肘坐腕起手,剑尖自下位走弧线撩向对方手腕或肋下;发力根源在拧腰,不在手臂;撩完剑路不停,顺势可转斩。
- **斩(由上向下或横扫)**:举剑过肩蓄势,重心自后脚移向前脚,下斩与进步同一拍完成;斩的落点宁取对方兵器根部,震开防线优于直接取身。
- **刺(直线前出)**:剑身放平收于腰侧,进步与出剑同时,剑尖走最短直线取咽喉或肩井;刺出后即回,不留满把空档。

**六槽速写**:人=三线起手前各有固定预备姿势(撩沉肘/斩举肩/刺收腰);械=正握为常,撩刺可换反握变速;气=基础剑罡贴刃薄发,不外溢;步=撩斩随进步,刺随垫步;着=撩取腕肋/斩取兵器根/刺取咽喉肩井,对方或兵器脱手或重心失守;镜=教学与拆招场景用中景平视一镜到底,实战中三母式多作起手半拍,不单独给镜头。

**主角换算铁律(本系总则)**:晏燎是剑修、全系剑圣,刀是副兵;凡持刀演出,三母式照用,但械槽一律注明**以剑法使刀**——握法走剑握、发力走剑意、剑罡照催,刀形只是外在。对齐我方图像 canon:静图产线的第一章节主角身份段=青年刀修+短刀部件清单(黑鲨皮鞘、黄铜刀格、缠灰绳刀柄、肯定式收鞘);此为副兵隐藏期的图像面口径,与「以剑法使刀」的表演面口径不矛盾,静图给收鞘状态、动图演出给换算句,两层各自照真源执行。

### A1 流云缠腕(剑主·缠斗式)

**道途锚**:canon 词场——剑主系「剑招行云流水」「流云三折」(道途对照表编号 1);招名自创,取缠斗中腕随身转的意象。

| 槽 | 执行描述 |
|---|---|
| 人 | 侧身对敌,重心居中偏前,后脚掌虚点地面;肩背放松,目光压在对方持械手腕上 |
| 械 | 剑正握,手腕松活;剑尖始终咬住对方中线不远送。持刀演出时注明以剑法使刀,握法仍走剑握 |
| 气 | 剑主系的剑魂之力,外显为淡白剑罡薄薄贴刃一层,不炸不涌,随腕转在剑尖凝出细芒 |
| 步 | 小幅环形绕走,每换一步,腕上换一个攻防角度;步幅永远小过对方,保持贴身距离由我方掌控 |
| 着 | 不求一击重创:连续削腕、点肘、封喉三个落点轮转;对方每次格挡都被下一削带偏半寸,兵器越举越歪 |
| 镜 | 中景跟拍,45 度斜侧保纵深;镜头随环形绕走缓慢环绕半圈,让观众看清距离在一点点被吃掉 |

**攻击轨迹**:环形连续小连削,削腕→点肘→封喉三点轮转。
**适用场景**:对单缠斗、拉锯压制、试探对方深浅。
**视觉记忆点**:剑尖始终咬中线,对方兵器被一寸寸带歪。

### A2 冥川挑渡(剑衍·冥属性挑斩式)

**道途锚**:canon 词场——剑衍系「幽魂斩与冥空挑斩」「冥属性剑法」(道途对照表编号 2);招名自创,取冥河渡刃的下挑意象。

| 槽 | 执行描述 |
|---|---|
| 人 | 起手沉肘坐腕,上半身后坐蓄势,重心先压在后脚;对方重击压顶的瞬间,重心骤然前移 |
| 械 | 短剑反握(剑衍短剑/重锋双修的短剑侧),剑尖垂指地面藏锋;持刀演出时同注以剑法使刀 |
| 气 | 冥属性灵气,外显幽蓝冷雾自剑格缠向剑尖;挑斩出手时冷雾被剑风撕开一道口 |
| 步 | 前踏一步直线进身,从对方重击的落点内侧穿过 |
| 着 | 剑锋自下而上挑斩对方持械手腕,冥气顺刃渗入,对方手臂当即发麻、五指握力掉半档,下一拍兵器握不稳 |
| 镜 | 近景起手特写(反握藏锋)→中景跟挑斩全程;低角度仰拍,强化由下向上的势 |

**攻击轨迹**:低位藏锋,直线进身,上挑弧线取腕。
**适用场景**:防反——专破压顶型重击;奇袭换节拍。
**视觉记忆点**:冷雾被剑风撕开一口,一挑过腕。

### A3 天眼点隙(剑星·裂空点杀式)

**道途锚**:canon 词场——剑星系「天眼波动之力灌注剑锋」「裂空剑法与雷刺连环」「以心观物破虚妄」(道途对照表编号 3);招名自创,取天眼观隙、一点即中之义。

| 槽 | 执行描述 |
|---|---|
| 人 | 双足钉地,心神往内一敛,双目微阖一拍再睁开(天眼开阖的演出时刻);呼吸放慢,全身只在指尖用劲 |
| 械 | 单手前伸剑身放平,剑尖遥指目标;持刀演出时同注以剑法使刀,点杀线仍走剑意直线 |
| 气 | 天眼波动灌注剑锋,剑刃泛起银白细密电芒(雷刺连环的雷性),电芒收束成一粒将发未发的光点 |
| 步 | 零位移——点杀式以静制动,脚步纹丝不动,距离由剑芒跨过 |
| 着 | 剑芒脱手成一线,贯穿目标肩井(精确取非致命点的点杀示范);对方肩甲崩开一角,整条手臂垂沉,重心歪向中招一侧 |
| 镜 | 三点剪辑:特写眼部开阖→特写剑尖光点→全景放出一线;命中瞬间不切镜,让弹道横穿整个画面 |

**攻击轨迹**:原地不动,一线剑芒遥点,跨距十余丈。
**适用场景**:对单点杀、近缠远拆(我方近战缠住时远程拆点)。
**视觉记忆点**:阖眼睁眼之间,一道银白横贯全场。

### A4 影缝暗刺(剑魔·残影暗刺式)

**道途锚**:canon 词场——剑魔系「短锋真解暗刺流」「鬼影三连」「魔气弥漫的暗杀剑术」(道途对照表编号 4);招名自创,取从影子缝隙里递刃之义。

| 槽 | 执行描述 |
|---|---|
| 人 | 压低身形贴地潜近,肩背内收缩小轮廓;出招瞬间拧腰送肩,把全身劲力压进一次短促递送 |
| 械 | 短锋反握,藏于小臂后侧,剑光不外露;持刀演出时同注以剑法使刀,暗刺线仍是剑刺 |
| 气 | 魔气弥漫——灰黑气雾裹住身形轮廓,高速变向时在旧位置拖出淡影;残影是速度残像,不是实体分身 |
| 步 | 折线错身:先向对方左侧虚踏,再折向右侧,两段变向后自侧后切入;每段变向都快过对方转颈速度 |
| 着 | 短锋自对方肋下甲缝刺入半寸即收;对方回刀格挡时只格中一道正在消散的残影 |
| 镜 | 中近景快切,镜头故意跟残影不跟真身;末镜定在真身收刃直起身的那一帧,观众与对方同步被骗 |

**攻击轨迹**:折线潜进,侧后肋下短刺。
**适用场景**:暗袭、骗招、乱战中枢近高价值目标。
**视觉记忆点**:格挡落空的那道残影还在冒灰气。

### A5 血沸惊锋(剑狂·血气爆发式)

**道途锚**:canon 词场——剑狂系「血煞之力灌注剑锋」「血锋挑斩与惊雷刺」「血气爆发的狂暴剑术」(道途对照表编号 5);招名自创,取血气沸顶、锋出惊人一击之义。

| 槽 | 执行描述 |
|---|---|
| 人 | 发力前全身肌肉绷紧一拍,头顶热气蒸腾如揭开锅盖;随即骤然放松爆进,姿态大开大合不留退路 |
| 械 | 双手握剑(剑狂狂暴路数),剑身先在身侧拖行半步带起尘线;持刀演出时同注以剑法使刀,双手剑架照走剑法 |
| 气 | 血煞之力自皮肤纹理透出,暗红血气顺小臂缠上剑身,剑锋过处血气被甩成断续的红痕 |
| 步 | 直线突进,不闪不避,以攻代守 |
| 着 | 一记全力下劈砸在对方格挡的兵器根段:虎口崩裂、兵器脱手飞出,对方连退三步,脚跟犁出两道土痕 |
| 镜 | 中景起(蓄势)→全景收(劈落与脱手);斜侧 45 度,结尾定格在承受方踉跄与飞出兵器的落点 |

**攻击轨迹**:直线爆进,全力下劈砸兵器根段。
**适用场景**:对单强攻、破防、士气打击。
**视觉记忆点**:虎口崩裂那一瞬,兵器与血气红痕同框飞出。

## 三、天象雷系(震雷道途词汇场,二式)

**系气质**(道途对照表编号 11/34):雷属性灵弹的远程轰炸路数——快、亮、覆盖广;演出上先聚云后落雷,环境参与度高。

### B1 云隙垂雷(高空轰落型)

**道途锚**:canon 词场——震雷「雷属性灵弹远程轰炸」(道途对照表编号 11/34);招名自创。

| 槽 | 执行描述 |
|---|---|
| 人 | 施术者单臂高举过顶,另一手掐诀下压指向目标区域;下颌微抬,视线钉在目标脚边而非身上 |
| 械 | 不持械(灵气系天象招) |
| 气 | 雷属性灵气在头顶低垂聚成一小片雷云,云腹发亮,云隙间垂下一道前粗后细的雷柱 |
| 步 | 立于原地不动,以雷柱的落点覆盖代替自身位移 |
| 着 | 雷柱轰在目标区域中心:地面炸开焦黑放射纹,碎石跳起半人高;承受方护体灵光被压成凹陷再碎裂,单膝砸地,持械手抖得握不住 |
| 镜 | 全景先交代雷云与地面距离(高空招必须给尺度)→中景拍雷柱贯落→近景拍承受方跪地抖手;仰拍起、俯拍收 |

**攻击轨迹**:垂直雷柱,区域覆盖轰落。
**适用场景**:对群压制、终结铺垫、逼对方离开固守点。
**视觉记忆点**:云隙那一线亮,先于雷声落下。

### B2 逐隙跳雷(逐隙传导型)

**道途锚**:canon 词场——震雷连珠路数(道途对照表「连珠灵铳」);招名自创,取雷沿缝隙逐跳之义。

| 槽 | 执行描述 |
|---|---|
| 人 | 施术者双指并拢,依次点向各目标,每点一次手腕回弹半寸,保持弹射节奏 |
| 械 | 不持械 |
| 气 | 指尖弹出细雷线,命中首目标后不熄灭,顺着地面水洼、金属残件这类导电缝隙渡向下一名目标——雷不认人,只认导隙,谁贴着导隙站,雷就渡到谁身上 |
| 步 | 小幅横移调整弹射夹角,让每一跳的导隙都连得上 |
| 着 | 每渡一处留一道灼白焦痕;被渡中者肌肉僵直半拍、动作变形;雷线末端目标被麻痹定身,兵器垂落 |
| 镜 | 中景一镜内完成二至三跳,镜头沿雷线横摇,不切碎——空间连续感就是这招的爽点 |

**攻击轨迹**:折线多段跳射,一雷沿导隙渡多目标。
**适用场景**:对群逐隙传导、驱离站位(谁站导隙边谁挨劈,逼人让开水洼金属)。
**视觉记忆点**:雷线顺着导隙一路点过去的那条折线。

## 四、寒冰系与劫火系(各一式)

### C1 霜坠沉锋(冰魄道途·寒冰)

**道途锚**:canon 词场——冰魄「寒冰诀」「冰魄重铸」(道途对照表编号 39);招名自创,取霜凝于锋、坠其兵刃之义。

| 槽 | 执行描述 |
|---|---|
| 人 | 双掌虚拢于腹前,如捧一捧雪,下颌微收,呼吸放到最慢;起手无声,寒意先于动作抵达 |
| 械 | 不持械 |
| 气 | 寒冰诀催出白蓝寒气,不落地面、不凝实体,专往对方兵器与甲面上贴;铁上挂霜,一息便厚一层 |
| 步 | 立定,以寒气的延伸代替自身移动 |
| 着 | 对方兵刃连挥数下,霜层越积越厚,剑身如裹冰衣,分量一点点加码;挥到后来整条持械臂抬不过肩,只得拖刃后撤,门户自乱 |
| 镜 | 近景拍霜在剑脊上一寸寸增厚→中景拍对方挥臂一次比一次低;「沉」要全程看得见,不给快切 |

**攻击轨迹**:寒气贴兵,霜重坠锋,零接触。
**适用场景**:废对方持械臂、压进攻节奏、为队友创造出手窗口。
**视觉记忆点**:剑脊挂霜,一剑比一剑低。

### C2 掠影曳火(劫火道途·飞刃速攻)

**道途锚**:canon 词场——劫火「劫火翔击」「御物飞刃」(道途对照表编号 25);招名自创,取掠影而过、刃尾曳火之义。

| 槽 | 执行描述 |
|---|---|
| 人 | 起手五指一拢再撒开,暗火贴掌心不熄;随飞刃群同步低空前掠,身体前倾压低风阻 |
| 械 | 御物飞刃——数枚短刃悬浮身侧听役,刃锋各指一个方向 |
| 气 | 劫火暗红偏黑;飞刃过处,连影子边缘都烫出细火星(取裂影斩意象自写的演出,伤在影随) |
| 步 | 低空掠进,人身与刃群同速同向,像一群联飞的镖 |
| 着 | 刃群掠过目标,衣袍数道口子绽开,创口边缘冒烟未燃;对方下意识抱头防御,胸口与袖口已各中一创 |
| 镜 | 中景横移跟拍,人与刃群同框同速前进;收在对方低头看创口的近景,火星在他影子上明灭 |

**攻击轨迹**:低空掠进,多刃横切。
**适用场景**:对单多创速攻、乱战冲阵穿行。
**视觉记忆点**:刃群过境后,影子上还留着火星。

## 五、体术格斗(擒龙道途词汇场,一式)

### D1 贴身过背锁(擒摔投技)

**道途锚**:canon 词场——擒龙「上钩拳前踢」「掷投」「擒摔投技为主的近身格斗术」(道途对照表编号 9);招名自创。此式补徒手位——兵器脱手或副兵隐藏期的近身解法。

| 槽 | 执行描述 |
|---|---|
| 人 | 先以上钩拳逼对方抬臂护头,门户露出;顺势沉肩入怀,背部贴上对方胸前 |
| 械 | 无兵器,徒手 |
| 气 | 体修真气灌注双臂与腰胯,沉身时气息下沉,发力时自脚跟拧起 |
| 步 | 上步贴身→转身背对→弓步发力,三拍一气呵成 |

**攻击轨迹**:入怀贴身,过背摔投。

**视觉记忆点**:整个人被翻过头顶时,脚还在原地的残影感。

## 六、御剑飞剑(御剑道途词汇场,一式)

### E1 断咏换锋(中断换招身法)

**道途锚**:canon 机制——御剑真术,设定集原文义为「中断当前施展的术法,瞬间切换施放其他术法」,是御剑道途的核心身法(43.御剑女);招名自创,取断其咏、换其锋之义。

| 槽 | 执行描述 |
|---|---|
| 人 | 身体正处在半式之中(前一式只走了七成),骤然定住半拍再爆出;这半拍的「停」就是给对方看的假拍 |
| 械 | 剑随身换式:前一式未走完的剑路半途改向,直接滑进后一式的出剑线 |

**视觉记忆点**:空中那道灵气拐弯的夹角。

## 七、反同质化禁忌(自写版)

1. **禁全是巨大灵气斩**——本库十二式里大范围能量轰击只占 B1 一式;新扩招式若与既有式同轨迹同量级,先换结构再入库。
2. **禁只有名词没有动作**——任何新条目先过 00 件六槽无效判据;写不出「着」槽的承受方反应,这条式子就还没想清楚。
3. **高空招必须交代尺度**——凡离地/落顶类招式,镜头语言里必须有一镜交代高度与路径(参照 B1 的全景先给)。
4. **残影非分身**——残影一律写成速度残像;实体分身属幻术体系,非本库默认,需要时在条目锚里显式标注。
5. **强招须有代价外显**——主角侧高强度催动按小说 canon 须外显身体代价(三色灵气冲突、道伤作痛等,见 02 件引气段),不写无代价的满功率。
6. **相邻连排功能不得重复**——两招都是蓄力/都是纯位移/都是受击=重排;连排节奏断点纪律见 00 件第二节末。
7. **换色不换结构=驳回**——只把某式的灵气颜色改一改当新招,机检虽过,按本节第 1 条驳回。

连排纪律(节奏断点、相邻功能不重复)见 00 件第二节末;下面给三组已校过的组合,消费方直接取用或改配:

## 十、系列池示例(B 震雷系·配角反派侧)

按 00 件 §3.2 系列标准栏目,给震雷一系补齐池子(其余系扩库时照此补):

- **系气质**:快、亮、覆盖广;先聚云后落雷,环境参与度高。
- **细分方向**:高空轰落型(B1)/逐隙传导型(B2);后续可扩「雷附兵刃型」「雷遁位移型」。
- **招式池**:云隙垂雷、逐隙跳雷(现 2 式)。
- **起势动作池**:单臂高举过顶掐诀下压;双指并拢依次点目标;双手交叠于胸前再猛然左右撕开(雷云从撕开处灌下)。

- **释放路径池**:垂直柱状覆盖;贴地折线跳射;直线贯穿(粗单发)。
- **反馈与结局模板**:护体灵光凹陷→碎裂→跪地;肌肉僵直兵器垂落;地面焦黑放射纹收尾。
