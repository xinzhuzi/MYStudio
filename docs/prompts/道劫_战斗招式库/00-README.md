# 道劫战斗招式库·库宪法与总纲(00)

最后核账:2026-09-28

> **一句话定位**:本目录是道劫战斗演出的**执行级动作素材源**——每一条招式都写成「能直接落进画面」的人体动作+兵器轨迹+灵气外显,而不是一堆神通名词。凡为道劫战斗场面起草提示词或分镜动作,先读本库;新会话只读本件,就应能起草一条合规招式。

## 一、定位与读者

本库是道劫 IP 战斗演出的**演出层**:把小说设定里的道途、术法、灵气体系,翻译成画面上可执行的动作语言。它服务三个消费方:

1. **九型美宣/分镜剧情图主体句的战斗场面段**——`docs/prompts/道劫_九型主体句示例.md` 与 `docs/prompts/道劫_九型配方.md` 的产线需要战斗动作素材时,从本库取招式条目,按该产线的主体句纪律(身份段原样搬运、部件清单句、肯定式收鞘等)装配,本库不改变那套纪律。
2. **H3 单镜视频提示词的动作线**——MiniMax H3 产线(`.agents/skills/h3-prompt-writing/SKILL.md`,只读单向引用,本库不改该技能任何文件)写动作段时,本库条目的六槽描述可直接充当动作线素材;时长密度按 H3 纪律自核(训练区间 5-15 秒,见 `docs/comfyui-kb/参数速查.md` H3 段)。
3. **道劫小说/漫剧分镜创作的动作参考**——写作与分镜需要一场「打得有来有回」的戏时,本库提供起手、轨迹、命中、反馈的执行细节库存。

**两个不替代**:

- 本库**不替代九型配方**——LoRA 配方、画幅、后处理链是配方层的事,见 `道劫_九型配方.md`;本库只管「这一招在画面里怎么打」。
- 本库**不替代小说设定集**——道途命名、术法名录、境界体系、人物 lore 的真源在 Unity MA 设定集(见第三节路径);本库是演出层,两层不重复、不互写。

## 二、六槽执行级描述 schema(口诀:人·械·气·步·着·镜)

每一条招式条目,必须按六个槽写全执行细节。六字诀如下:

| 槽 | 管什么 | 必答问句 | 反例(写了=不合格) |
|---|---|---|---|
| **人** | 谁在动、起手姿势与重心 | 出招者此刻是什么姿势?重心在前脚/后脚/正中?发力前身体先做什么(沉肩/拧腰/顿步)? | 只写身份不写身体:「剑修晏燎出手」——没说他是站是纵、重心在哪 |
| **械** | 何兵器、何握法 | 用的是什么兵器?正握/反握/双手?若是主角持刀,须注明「以剑法使刀」换算(见下) | 只写兵器名不写握持:「一柄短刀」——没说正反手、单双手、刀锋朝向 |
| **气** | 何种灵气、颜色与外显形态 | 催动的是哪一脉灵气(可引小说 canon 词:人红/妖绿/鬼蓝三色基色、剑罡、血煞、冥气等)?外显成什么(缠刃/离体/罩身/入地)? | 只写能量不写形貌:「灵力暴涨」——没有颜色、没有外显形态、没有身体代价(主角强招按 canon 须外显代价,见 02 件引气段) |
| **步** | 位移轨迹 | 出招全程人怎么走位——直线突进/折线错身/环形绕打/垂直升降?位移与出招是同时还是先后? | 只写快不写线:「身形一闪而至」——没交代轨迹形状与起点终点 |
| **着** | 命中点与承受方反馈 | 打在对方什么部位?承受方有什么**可见**反应——受力后滑/护架变形/兵器脱手/地面裂纹/踉跄/被锁死?承受方不得零反应 | 只写威力不写挨打:「一击重伤」——没写命中点,承受方全程零反应 |
| **镜** | 本招的镜头目的 | 这一招给什么景别(特写/近景/中景/全景)?什么视角(平视/仰拍/斜侧/俯拍)?它在叙事上干什么(立威/转折/终结/喘息)? | 只写氛围不写镜头:「气势磅礴的名场面」——没有景别、视角与叙事功能的任何一项 |

**主角换算铁律**:晏燎是剑修、全系剑圣,刀是副兵(隐藏剑修身份期取用);凡持刀场面,「械」槽必须写明**以剑法使刀**——使的仍是剑招、催的仍是剑罡、走的仍是剑意,严禁写成刀客路数(小说武器铁律)。同时守我方图像 canon:`道劫_九型主体句示例.md` 的主角身份段=青年刀修+短刀部件清单句(黑鲨皮鞘、黄铜刀格、缠灰绳刀柄、肯定式收鞘)——两者不矛盾(副兵隐藏期),条目里注明对齐关系即可,不改那份文档。

**无效条目判据**:一条招式若只有神通名词(「施展了某大神通,威压惊人」式)而没有上述六槽的执行细节,即判无效——它没有回答「谁、拿什么、怎么动、打哪、对方怎么了、镜头为什么这么给」任何一问。

**六槽与三个消费方的用法速查**:

| 消费方 | 取哪些槽 | 说明 |
|---|---|---|
| 静图(九型美宣/分镜剧情图) | 人·械·气·着·镜为主,步取定格位 | 静图是单帧:取起手或命中那一瞬,「步」槽只取落定格的那个位移位;主体句纪律(身份段/部件清单/肯定式收鞘)由配方产线自带,本库不重复 |
| H3 单镜视频 | 全六槽 | 5-15 秒内按「起手→位移→命中→反馈」排时间线,一镜内招式数与时长对齐(见 02 件字数预算节) |
| 小说/漫剧分镜 | 人·械·气·步·着 | 「镜」槽换成叙事功能词(立威/转折/终结),供分镜决定给不给特写 |

**单招与连排的边界**:六槽是**单招**粒度;一场连续对打=多个单招条目连排,连排时须自设节奏断点(急停重击/破招/摔投/换位之类),不得连续数秒高速对打不给断点,相邻两招功能不得重复(两招都是蓄力、都是纯位移或都是受击=重排)。一式定胜负的杀招不走六槽连排,走 02 件五段链。

## 三、分系组织法

顶层分两轴:

### 3.1 主角剑系(专属轴)

只收晏燎能用的招式:剑道三母式(撩/斩/刺,一切剑系起手之母)+ 五系剑道(剑主/剑衍/剑星/剑魔/剑狂)风味各成一系,以及主角跨系融合演出(万灵体、三色灵气、道伤代价外显)。此轴条目默认绑定主角换算铁律。

### 3.2 道途系列(通用轴)

对齐小说 71 道途十类分类。十类框架如下(道途数取自设定集对照表统计,本库建立时已实读核验):

| 类 | 道途数 | 代表道途(编号取自对照表) | 演出气质一句话 |
|---|---|---|---|
| 剑道 | 10 | 剑主(1)/剑衍(2)/剑星(3)/剑魔(4)/剑狂(5)/御剑(43)/孤锋(47)等 | 兵器即主角,招式看剑路 |
| 格斗 | 8 | 武神(7/30)/擒龙(9)/伏虎(32)等 | 徒手近身,摔投锁技 |
| 射术 | 10 | 惊鸿(10/33)/震雷(11/34)/云游(67)等 | 灵弹/灵矢远程,走位腾挪 |
| 法术 | 13 | 元灵(15)/冰魄(39)/造化(66)等 | 类别最宽,元素外显为主 |
| 圣职 | 9 | 圣裁(21/52)/灵卫(20/53)等 | 光焰裁决,守护治愈 |
| 暗夜 | 5 | 劫火(25)/绝影(27)/冥术(28)等 | 飞刃暗杀,鬼魅缠影 |
| 守护 | 4 | 青御(48)/龙御(51)等 | 盾击御敌,剑盾合一 |
| 枪术 | 4 | 霸王(57)/天决(58)等 | 长枪外功,突扫回环 |
| 枪剑 | 5 | 隐锋(61)/剑客(65)等 | 双持混械,隐秘暗杀 |
| 妖荒幻 | 3 | 天妖(69)/荒神(70)/幻翎(71) | 妖气变身,蛮荒巨弩,幻术灵兽 |

每系标准栏目:

- **系气质**:这一系打起来是什么观感(一句话定调)
- **细分方向**:系内可选的打法流派(各一句)
- **招式池**:本库已收录条目名(链接到 01 件对应节)
- **起势动作池**:出招前身体/手势/兵器的预备动作清单
- **灵气异象池**:聚气阶段环境与灵气的外显清单
- **释放路径池**:攻击本体的方向/速度/尺度/轨迹清单
- **反馈与结局模板**:承受方反应与收招余波的常用组合

**两层真源关系**:道途的命名与 lore 真源=Unity MA 小说设定集 `《道劫》/1.设定集/7.道途境界/2.道途/`(含 `道途对照表.md` 的 71 道途十类总览,本库建立时已实读核验其分类框架与剑道五系、流云三折等 canon 词);本库是演出层,只做「设定→画面」的翻译,不在本库内重抄设定,发现设定冲突以设定集为准并回本库订正。

## 四、招式命名纪律与禁用名清单

### 4.1 命名四原则

1. 招名一律**自创**,或取自道劫小说设定集词汇场;直接沿用小说既有术法名时,须与设定集原文核对描述一致(引 canon 不编 canon)。
2. 招名与来源素材的既有招名**不得同名**;本库建立时已对来源素材全目录逐名 grep 复核,后续新增招式同样处理。
3. 招名以 2-5 字为宜,能看出「打法或意象」其一,不堆大词。
4. 同系列招名避免共用同一尾字超过三个,防系列内同质。

### 4.2 机检规则

- 与任何来源文件**连续 50 字去空白重合**即驳回——描述文字必须自写,句式骨架刻意与来源拉开(来源惯用比喻链句式,我方用直陈句+因果句)。
- 结构层栏目名的借鉴如实记档:**逐条字段层**——「攻击轨迹/适用场景」与来源素材技法表头同名,「视觉记忆点」为来源「视觉价值」的近义改写;**系列栏目层**(本件 §3.2,与来源属性库结构同源度更高)——「系气质」为来源「核心气质」的近义改写,「细分方向」与来源属性库同名,「招式池」与来源章节「三、雷系招式池」同名(去系名前缀),「起势动作池」与来源同名,「灵气异象池」为来源「聚能异象池」的近义改写,「释放路径池」为来源「技能释放路径池」去前缀,「反馈与结局模板」为来源「被击反馈建议」与「结局模板」两节合并——均为泛用词汇层面的结构沿用,栏目内描述文字仍须全自写并过 50 字机检。
- 定稿前机检命令式(示例):对来源目录跑逐招名 `grep -rl "招名" 来源目录/`,零命中方可定稿。

### 4.3 名单核查步骤

新增招式时:①查下方禁用名清单;②对来源素材 combat 与 ultimate 两目录逐名 grep(见 4.2);③与 01 件既有招名查重;④三步全过才登记入池。

**四步走查实例**(以 01 件已定稿的「云隙垂雷」为样,新条目照此留痕):

1. 查禁用名清单——雷系禁用名有九霄雷罚/雷云天坠/万钧雷柱/玄霆裂空/黑雷审判/雷兽咆哮/苍穹雷狱/天穹震杀号等,「云隙垂雷」不同名,过;
2. 对来源两目录 `grep -rl "云隙垂雷" <来源目录>` 零命中,过;
3. 与 01 件既有招名(十二式)查重,无同名,过;
4. 登记:入 01 件 B 系招式池+总览表同步,锚注「自创名/震雷道途词汇场」。
