# 道劫战斗招式库·杀招五段链模板与分系扩展法(02)

最后核账:2026-09-28

> **一句话定位**:本件管「一式定胜负」的杀招/大神通释放怎么写——五段链(起手·引气·发劲·交锋·收劫)逐段必答问句、双范例、组合公式、生成前自检与分系扩展 SOP。单招与连排走 [01-种子招式集.md](01-种子招式集.md),schema 与禁用名纪律见 [00-README.md](00-README.md)。

## 一、适用边界

- 本模板管**杀招/大神通的单次核心释放**:小说语境里的道途神通、劫级对抗、一击定胜负的压轴演出。
- 本模板**不管**整场连续对打——那是六槽招式的连排(01 件第九节速配),杀招只做连排终点的「那一式」。
- **一场戏用一次为常态**:同一场戏里连放两次杀招,第二次的记忆点必然稀释;确需双重高潮时,两次的起手母题、灵气形态、交锋方式、余波类型四项至少换三项。
- 压轴级的判定不靠形容词堆砌(「恐怖」「毁天灭地」不计数),靠交锋段承受方的失守层级与收劫段的环境改变量。
- **与连排的接驳**:杀招作为连排终点时,前一招的尾状态(双方方位/距离/受力/控制点)就是杀招起手段的**既定起点**,起手段直接从该状态写起,不得重置站位;反之,杀招起手段里写的预备动作,就是前一段连排需要铺到的终点。

## 二、五段链模板(起手·引气·发劲·交锋·收劫)

### 2.1 起手

身体、手势、兵器如何**起动**。

必答问句:出招者第一处可见的预备动作是什么(哪只手/哪侧肩/哪条腿先动)?兵器(若有)从什么状态变到什么状态(收鞘→半出/垂指→平抬)?起动动作与下一段的引气是先后还是同拍?

常见废写:只写「他动了杀心,气场骤变」——零身体动作,起手段空转。

### 2.2 引气

灵气**从哪来、环境先如何被影响**。

必答问句:催的是哪一脉灵气(主角侧可挂三色灵气人红/妖绿/鬼蓝 canon 基色)?引气时周围环境先有什么可见变化(尘土/水汽/光色/风向/声音)?**强招的身体代价外显在哪**——小说 canon 的万灵体机制是:强催异质灵气必付代价(排异作痛、道伤裂缝剧痛、灰黑杂气外渗等;真源=Unity MA 设定集晏燎文件与灵气融合演进体系,核对日期 2026-09-28,引用取机制义自写演出)。**代价外显是本库差异化底牌**:无代价的满功率杀招在本库里不合格。

常见废写:「天地灵气疯狂涌来」——灵气没有来处、没有形态、没有代价,引气段三个必答全空。

### 2.3 发劲

攻击本体的**方向、速度、尺度、路径**。

必答问句:杀招本体朝哪个方向走?速度快到什么可见程度(残像/音爆云/地面被带起)?尺度多大——以画面里可参照物(人、树、屋脊)标定,不许只写「巨大」?路径是直线/弧线/垂直/多点封锁?

常见废写:「一道巨大的能量冲击」——方向尺度路径三无,发劲段只是个光效占位符。

### 2.4 交锋

承受方如何**挡/闪/卸/被锁或逐层失守**。

必答问句:承受方第一反应是什么(举械格挡/侧闪/结印反制)?失守分几层(护体先碎→兵器再脱→重心再倒)?每层失守的可见证据是什么?承受方**全程零反应=不合格**,此为硬线。

常见废写:「敌人瞬间被轰成渣」——承受方没有过程,交锋段被跳过,杀招打在了纸片上。

### 2.5 收劫

伤害结果、**环境改变与记忆点尾帧**。

必答问句:收招后画面里多了什么(地形改变/痕迹/漂浮物)?少了什么(声音/光/人)?最后一帧定在什么画面上——观众散场后还记得的那一格?

常见废写:「一切归于平静」——平静不是画面,尾帧没有着落。

### 2.6 字数预算与时长适配

五段成文合计适配 H3 单镜 5-15 秒的动作密度(时长口径:训练并测试 5-15 秒,见 `docs/comfyui-kb/参数速查.md` H3 段;本库建立时已实读核验)。预算表:

| 段 | 字数预算 | 占比义 |
|---|---|---|
| 起手 | 30-50 字 | 蓄势,给镜头一个起跳点 |
| 引气 | 50-80 字 | 环境先变,代价外显,占最重 |
| 发劲 | 40-60 字 | 一次写清方向/速度/尺度/路径 |
| 交锋 | 60-90 字 | 失守分层的每一层都要字 |
| 收劫 | 40-60 字 | 尾帧定格 |

合计约 220-340 字对 10-15 秒;短杀招(5-8 秒)按比例整体压缩,但五段一段不删、交锋段最后压。

### 2.7 从 01 件单招到杀招的积木装配法

杀招不是凭空写,是拿 01 件单招条目**放大改层**而来。装配对照:

| 杀招段 | 取 01 件哪个槽 | 放大什么 |
|---|---|---|
| 起手 | 「人」槽+「械」槽 | 预备动作放大成可给镜头的起跳点:半步/阖眼/收鞘半寸这类可拍细节 |
| 引气 | 「气」槽 | 外显升级(贴刃→改天象/改环境),并新增**代价外显**(单招可省,杀招必写) |
| 发劲 | 「步」槽+「着」槽的轨迹部分 | 尺度从人身级放大到场景级,须补参照物标定 |
| 交锋 | 「着」槽 | 承受方反应从一次性放大为**逐层失守**(护体→兵器→重心,至少两层) |
| 收劫 | 「镜」槽 | 叙事功能落成尾帧定格,并从 §四 余波清单取环境改变 |

装配规则:一条杀招至多取两式单招作积木(主杀伤+辅势,如范例一=点杀线+爆发架);取三式以上会互相稀释,记忆点立不住。

## 三、完整范例(两条)

### 范例一·主角终结杀(积木=01 件 A 系)

> 场景设定:主角持刀(副兵隐藏期)对强敌终局一击;积木取 A3 天眼点隙的点杀线与 A5 血沸惊锋的爆发架,**以剑法使刀**换算执行。

- **起手**(约 40 字):主角反手压刀柄,刀尖仍收在鞘口半寸;左脚后撤半步,重心沉到后腰,双目微阖。
- **引气**(约 70 字):再睁眼时天眼已开——刀身浮起银白细芒;同一拍,血煞自小臂纹理透出暗红,两系剑意合流。左前臂旧伤处法则裂缝剧痛,几缕灰黑杂气自袖口外渗——代价与威力同框。
- **发劲**(约 50 字):拔刀。刀光不走横斩,走剑刺的直线——鞘口炸开,一线银红交缠的芒跨过两人之间七步,快过对方眨眼。
- **交锋**(约 80 字):对方举械横挡,刀芒撞上械身,护体灵光先凹陷、再龟裂、第三拍整面碎开;兵器被撞得脱手飞旋,对方半边肩甲崩落,整个人向后滑出两步,脚跟犁开地面。
- **收劫**(约 50 字):刀回鞘,灰黑杂气散尽。焦线自对方脚尖烧到七步外的原位;他后仰格挡的姿势迟了半息,膝盖砸地。尾帧:鞘口银红芒熄灭。

### 范例二·反派天象杀(震雷道途词汇场)

> 场景设定:雷修反派广场级压轴;词汇场取震雷道途雷属性灵弹路数(真源=Unity MA 道途对照表,核对日期 2026-09-28)。

- **起手**(约 35 字):反派腾身悬停半空,单臂高举过顶,五指缓缓攥死;云层在他头顶开始打旋。
- **引气**(约 75 字):雷属性灵气自四面八方的高空汇来,头顶云腹压低、发亮,整片广场被照成惨白;地面碎金属先于人声跳动电花,空气里浮起焦味。广场守军的旗帜被静电竖起,猎猎作响。
- **发劲**(约 55 字):五指张开——云隙垂下两道前粗后细的雷柱,八字形斜罩向广场中心,覆盖半径以旗杆为参照约五杆之距;雷柱落下前,雨滴悬停了半拍。
- **交锋**(约 80 字):守军结阵撑起联合护罩:头一道雷柱砸上罩顶被滑开,只留白痕,持阵者虎口发麻;第二道不打罩,斜钉阵前石板,地面下沉半尺,阵脚自乱、护罩散口;余劲掀翻前排盾兵,幸存者抱头伏地不敢仰视。
- **收劫**(约 50 字):雷光敛去,广场中心只剩焦黑放射纹与半截熔弯旗杆;雨点落回灼纹,蒸起白汽。尾帧:反派悬停未动,缓缓收手,云旋散场。

## 四、环境余波与记忆点清单(六类)

杀招收劫段至少取一类落笔;两类以上更稳。

| 类 | 示例(各 2-3 例,自写) |
|---|---|
| 地面 | 焦黑放射纹自落点向外递减;地砖被掀成叠瓦;裂缝里渗出余温蒸气 |
| 植被 | 草叶齐齐倒伏向同一反向;树冠被削去一层断口整齐;花瓣被气浪卷成环 |
| 水位 | 水洼被整面掀成雨幕;溪流断流半息再合拢;水面余纹久久不散 |
| 天气 | 云旋散场慢于雷光半拍;雨滴悬停的违和感;风向往落点倒灌 |
| 空间感 | 声音迟来(先见光后闻响);光比骤变(惨白→复暗);距离感错位(七步焦线比目测长) |
| 旁观者反应 | 幸存者伏地不起只敢看焦纹;远处哨兵握旗的手在抖;孩童被大人按住头别过脸 |

## 五、反同质化组合公式

同系杀招防撞式的组合记法(槽位与示例皆本库自创):

```text
道途系 + 起手母题 + 灵气形态 + 交锋方式 + 余波类型
```

三个不同组合示例(均为槽位演示,非成品条目):

1. 冰魄系 + 悬停双掌下按 + 霜脉沿水线爬行 + 冻足后逐层冻结上肢 + 水位类(整面冰壳罩溪)
2. 劫火系 + 五指拢而复撒 + 暗红偏黑火贴刃环身 + 多创速攻逼抱头防御 + 植被类(草叶倒伏向反向)
3. 御剑系 + 半途骤停假拍 + 灵气轨迹空中拐弯 + 反切持械臂磕飞兵器 + 空间感类(旧轨迹余光未散)
4. 主角剑系(双系合流) + 收鞘半寸的极简预备 + 银红两色剑罡交缠 + 直线点杀三层破守 + 空间感类(焦线比目测长)——即范例一的公式化写法

主角侧与反派侧的组合差异:主角杀招的起手母题取**极简/收势**向(鞘口半寸、阖眼一拍),以小搏大;反派取**铺张/借天**向(悬停、聚云、环境预兆)。同一灵气形态,起手母题一换,正邪气质立分——这是组合公式里性价比最高的一槽。

## 六、生成前自检五问

1. **去色测试**:把这条杀招的灵气颜色全部去掉,它的结构(起手→交锋→尾帧)还认得出来吗?认不出=只剩特效。
2. **承受方的脸**:交锋段写完,承受方最后一张脸/最后一个体态是什么?答不出=零反应违规。
3. **代价在哪**:主角侧强催,引气段的身体代价外显写了吗?(反派侧可换成环境预兆,但不可两头皆无。)
4. **参照物**:发劲段的尺度有没有用画面内参照物(旗杆/屋脊/七步)标定?只有「巨大」不算数。
5. **尾帧定格**:收劫段的最后一帧,观众散场后还记得哪一格?说不清=记忆点未立。

五问过四可定稿;「去色测试」与「承受方的脸」两问不过,直接回炉。

### 6.1 五问快用演示(拿范例二走一遍)

1. 去色测试:去掉「惨白/焦黑」等色词,八字形双雷柱、罩顶滑开与地陷阵乱、旗杆熔弯仍在——结构成立,过。
2. 承受方的脸:持阵者虎口发麻、盾兵掀翻、幸存者抱头伏地——末态「伏地不敢仰视」有落点,过。
3. 代价在哪:反派侧以环境预兆替代身体代价(云腹压低/金属跳电花/旗帜静电竖起),过。
4. 参照物:覆盖半径「以旗杆为参照约五杆之距」——有标定,过。
5. 尾帧定格:云旋散场慢于雷光半拍、反派缓缓收手——定格在反派的「不动之动」,过。

### 6.2 交给 H3 单镜时的时间轴切分建议

五段链交给 H3 提示词动作线时(技能本体 `.agents/skills/h3-prompt-writing/SKILL.md` 只读引用,本库不改其格式):

- 起手+引气合占前 40% 时长(蓄势给足,H3 对「环境先变」的演出消化好);
- 发劲占 15%(一拍爆发,不拖);
- 交锋占 30%(逐层失守每一层都给秒点);
- 收劫占 15%(尾帧至少停一秒,记忆点要给观众看清的时间)。
- 5 秒短镜:起手与引气各砍半,交锋保两层失守,收劫保尾帧一秒——四保三舍一,舍发劲的慢镜部分。



## 七、分系扩展 SOP

四步:

1. **读设定集提词汇场**:读 Unity MA 对应道途文件(`《道劫》/1.设定集/7.道途境界/2.道途/`),摘术法名与核心特征作锚;设定冲突以设定集为准。
2. **按六槽起草**:单招条目照 01 件格式;杀招条目照本件五段链。
3. **过双检**:00 件 §4 四步走查(禁用名→来源目录逐名 grep→本库查重→登记)+50 字机检;新杀招名同规则。
4. **登记**:杀招入本件对应系范例区或 01 件系池(视量级),索引与总览表同步,核账日期更新。

**库规模纪律**:系列扩展**不拆新文件**——01 件内分节追加;杀招范例超出本件两条时,在本件内按系增设范例区,仍不拆件;全库招式超过 40 式再议拆卷(00 件 §6)。
