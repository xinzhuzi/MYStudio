## 先建立身份锚点

固定年龄表现、身体比例、脸型、发型轮廓、基础服装、材质、颜色、配饰和渲染方式。姿势、情绪和场景是可变项，不应混进永久身份描述。

```text
在中性浅色背景上生成专业角色设定图。
身份：[原创角色]、[比例]、[脸型]、[发型轮廓]、
[基础服装与准确颜色/材质]、[标志性配饰]。
布局：全身正面、侧面、背面；中性/开心/担忧三种表情；
一个代表性动作；配饰和材质细节图。
所有画格保持脸部结构、发型、服装结构、颜色和比例一致。
避免多余肢体、镜像错误、服装变化、裁脚、商标、水印和非必要文字。
```

## 一致性评分

分别给身份、比例、发型、服装结构、配色、配饰和画风打 0–2 分。低于 10/14 的画格应重新生成，并把失败项写成不可变化的约束。每次只改变一个变量，才能判断哪条要求真正有效。

### 三视图可以直接用于 3D 建模吗？

它适合概念参考，但不等于严格正交工程图。建模师仍需解决透视、隐藏结构和局部不一致。

图片模型可能生成看似合理但错误的标签，重要文字应在后期替换。本仓库是独立资源，不代表 OpenAI 官方背书。最后审核：**2026 年 7 月 16 日**。
