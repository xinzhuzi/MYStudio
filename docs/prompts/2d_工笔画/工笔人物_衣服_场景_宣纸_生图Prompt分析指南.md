# 中国传统工笔画生图 Prompt 分析指南

> 适用于你当前这类：**古典东方女性人物 + 汉服/襦裙 + 工笔画 + 宣纸 + 大面积留白 + 疏梅场景**。
>
> 核心目标不是单纯“生成一个古风美女”，而是把画面拆成 **人物、发型、服饰、姿态、线描、设色、场景、构图、纸张、氛围** 等模块分别控制，从而提高不同生图模型之间的可复现性。

---

## 一、整体画面风格分析

这张图的视觉核心可以概括成：

**传统中国工笔人物画 × 低饱和矿物色 × 精谨白描/线描 × 宣纸留白 × 非对称构图。**

画面不是“纯水墨画”，也不是“厚重国潮插画”。它更接近：

- 传统工笔人物画
- 细线勾勒人物轮廓、五官、衣纹、发丝
- 颜色薄而多层，强调分染、罩染、提染
- 背景弱化，不使用复杂环境抢夺人物主体
- 采用大面积空白形成静谧感
- 使用少量梅枝作为构图锚点

因此 Prompt 最重要的不是不断增加“古风”“仙气”“唯美”等形容词，而是控制**绘画媒介和视觉层级**。

# 二、人物分析

## 2.1 人物年龄与气质

建议不要简单写“美女”。

更准确的描述是：

```text
年轻东方女性
容色清丽
眉目如画
五官秀雅
面容柔和
神情含蓄宁静
气质古雅
```

### 推荐关键词

```text
清丽
秀雅
端庄
含蓄
宁静
古典东方女性
五官精致但不过度网红化
```

### 不推荐

```text
绝世美女
顶级美女
网红脸
浓妆
性感
夸张大眼
欧美立体五官
```

原因是这些词容易把人物拉向现代商业人像，而不是传统工笔人物。

---

## 2.2 脸部与五官

工笔人物的脸部通常不是靠强烈明暗塑造，而是靠**极细线条 + 极轻分染**。

建议重点控制：

```text
眉形细长
眉目清秀
眼型狭长柔和
鼻梁线条细
唇色淡雅
面部轮廓柔和
五官比例自然
```

### 推荐 Prompt

```text
精致清秀的东方女性五官，细长眉，清润眼眸，鼻梁秀雅，唇形小巧，面部线条柔和，神情含蓄宁静
```

### Negative Prompt

```text
浓妆
烟熏妆
夸张睫毛
欧美五官
过度立体鼻梁
网红脸
塑料皮肤
高光磨皮
```

# 三、发型分析

这是工笔人物非常重要的一层。

不要只写：

```text
黑长直
```

因为模型很容易生成现代长发少女。

应该明确告诉模型是：

**古典盘发 + 垂落长发 + 发饰。**

## 3.1 推荐结构

```text
乌黑长发
古典高髻/挽髻
细致盘发
少量鬓发自然垂落
部分长发沿背部垂下
传统金玉发簪
细小花卉发饰
流苏耳饰
```

## 3.2 推荐 Prompt

```text
乌黑浓密长发，古典挽髻，发髻精致端庄，少量鬓发自然垂落，长发沿背部垂下，点缀细致传统发簪与小型花饰，耳侧垂落细长流苏
```

## 3.3 发丝线描重点

如果你需要“工笔味”更强，可以加入：

```text
发丝以极细而稳定的墨线逐根勾勒
发束结构清晰
线条疏密有致
不使用块状黑色头发
```

这会明显减少“AI黑色头盔头发”的感觉。

---

# 四、身材与姿态分析

当前画面最重要的不是性感，而是：

**修长、端雅、克制。**

## 4.1 身姿

推荐：

```text
身姿修长
肩颈舒展
身体微微侧立
姿态端庄
重心稳定
手部自然收拢
动作含蓄
```

这是传统人物画非常典型的表达方式。

## 4.2 构图姿态

推荐：

```text
人物位于画面中央偏右
身体形成垂直向下的视觉轴
脸部朝向画面一侧
身体与衣带形成斜向流线
```

这样既不会太呆板，也不会变成现代时装站姿。

---

# 五、服装分析

这是当前画面第二个核心。

你原始要求：

> 石青襦裙配赭石披帛

这个方向很好，因为它天然形成：

**冷色主体 + 暖色辅助。**

---

## 5.1 内层服装：石青/青灰色襦裙

建议使用：

```text
石青
青灰
灰蓝
花青
低饱和蓝绿
```

不要写成：

```text
亮蓝
宝蓝
荧光青
高饱和蓝
```

否则很容易变成仙侠游戏服装。

### 推荐 Prompt

```text
石青色传统襦裙，青灰偏冷的低饱和色调，布料轻柔，衣面带有细密传统纹样，颜色温润克制
```

---

# 六、披帛分析

披帛是这张画非常重要的视觉元素，因为它负责制造“流动线”。

你的设定：

> 赭石披帛

非常适合。

## 6.1 披帛颜色

推荐：

```text
赭石
赭红
棕橙
淡朱砂
暖褐
```

并且强调：

```text
低饱和
半透明
柔软
自然垂落
```

## 6.2 披帛的主要作用

不是为了“增加衣服复杂度”，而是为了制造：

**长线条、曲线和动态节奏。**

例如：

```text
披帛从肩部自然垂落
沿身体形成连续长弧线
末端轻柔展开
```

这样人物会显得更修长。

---

# 七、衣纹分析

工笔画和普通 AI 古风插画最大的区别之一，就是：

**衣服不是靠大量褶皱堆细节，而是靠有节奏的线条。**

推荐描述：

```text
衣纹线条流畅
衣褶疏密有致
线条细而稳定
转折自然
长线与短线相结合
衣纹顺着身体结构展开
```

### 不推荐

```text
大量褶皱
复杂布料细节
超高细节织物
密集纹理
```

因为过多细节会破坏工笔画的“清雅”。

---

# 八、服装纹样分析

传统纹样应该是：

**有，但不能抢人物。**

推荐：

```text
细密传统花卉纹样
云纹
卷草纹
如意纹
小型暗纹
局部刺绣
```

推荐 Prompt：

```text
服饰带有精致而克制的传统花卉与卷草纹样，纹样疏密有序，仅在衣缘、袖口与裙摆局部出现
```

重点是：

> **局部出现。**

这样背景仍然安静，主体仍然突出。

这类画面非常适合使用“冷暖对比，但整体低饱和”的方案。

## 9.1 主色

```text
石青
石绿
青灰
花青
```

## 9.2 辅色

```text
赭石
朱砂
暖褐
浅金
```

## 9.3 肤色

```text
淡米白
暖白
极淡赭红分染
```

## 9.4 原则

推荐一句非常实用的 Prompt：

```text
整体低饱和雅致，仅以石青、石绿、赭石、朱砂作局部点缀，避免高饱和艳色
```

这样可以显著降低“游戏立绘感”。

# 十、工笔线描系统

这是整个画面的核心技术层。

不要只写：

```text
工笔画
```

建议拆开写：

```text
精谨线描
细腻墨线
线条细而稳
勾勒精确
线条有轻重变化
人物轮廓清晰
发丝逐层勾勒
衣纹流畅
五官线描细致
```

### 推荐组合

```text
(中国传统工笔画:1.35)
(精谨线描,细腻墨线,线条细而稳,勾勒精确有韵律:1.28)
```

对于支持权重的模型可以使用。

不支持权重的模型，则直接自然语言描述即可。

# 十一、设色方式分析

这张图不是“平涂上色”。

应该强调：

```text
层层设色
分染
罩染
提染
淡彩
色彩渐变自然
矿物颜料层染
```

### 推荐 Prompt

```text
传统工笔设色，层层分染与罩染，颜色由浅入深，局部提染，矿物颜料质感温润，色彩之间过渡细腻
```

这会比简单写“彩色工笔画”更加稳定。

---

# 十二、场景分析

当前画面其实是一个非常典型的：

**极简中国画背景。**

场景不是“完整庭院”。

也不是：

```text
亭台楼阁
山水湖泊
古建筑
大量花草
```

而是：

> **留白 + 一枝疏梅。**

---

# 十三、为什么只需要一枝疏梅？

梅枝在这里不是主要景物，而是：

### 1. 提供空间参照
让人物不会像悬浮在空白中。

### 2. 平衡人物轮廓
人物是一条主要垂直形体，梅枝提供横向/斜向线条。

### 3. 增加东方审美符号
观者无需大量环境，就可以立刻感受到传统东方绘画语境。

### 4. 保持留白
如果梅花太多，就会抢主体。

---

# 十四、梅枝 Prompt

推荐：

```text
画面边缘一枝疏梅淡影
枝干细长自然
零星梅花
花朵疏落
颜色极淡
边缘略带虚化
不喧宾夺主
```

还可以使用：

```text
一枝从画面边缘斜入的老梅枝
少量淡粉白梅
疏密有致
若隐若现
```

### Negative Prompt

```text
满树梅花
大片花海
繁密花枝
鲜艳花朵
背景花卉堆满
```

---

# 十五、场景留白分析

“大面积留白”不是让背景完全纯白。

真正重要的是：

**弱纹理 + 低对比 + 无明确物体。**

推荐：

```text
大面积安静留白
背景极简
环境元素稀少
主体周围保持纯净空间
背景对比度极低
```

这样既有“画”，又不会变成“白色 PPT 背景”。

---

# 十六、宣纸分析

推荐的不是“旧宣纸”，而是：

**干净、温润、低纹理宣纸。**

### 推荐

```text
细腻宣纸质感
温润米白纸面
极细微天然纸纤维
轻微纸张颗粒
干净均匀
手绘颜料附着于纸面的质感
```

### Negative Prompt

```text
脏污
污点
水渍
霉斑
严重泛黄
旧纸
做旧纸张
粗糙纤维
明显纸张纹理
灰尘
颗粒过重
脏背景
```

---

# 十七、构图分析

这是一个典型的：

**非对称平衡构图。**

## 推荐布局

```text
        疏梅枝
          ↘
           人物
           │
           │
           │
        大面积留白
```

更准确地说：

- 人物承担主要视觉重量
- 梅枝位于边缘
- 留白占据大量面积
- 人物不要完全顶满画幅
- 四周保持呼吸空间

---

# 十八、比例与画幅

推荐：

```text
纵向画幅
2:3
3:4
4:5
```

其中人物工笔画非常适合：

```text
2:3
```

因为长形画幅可以充分表现：

- 发丝
- 披帛
- 长裙
- 衣纹
- 留白

# 二十一、如果想更“工笔”，应该强化什么？

优先强化：

```text
精谨线描
细墨线
工整衣纹
发丝勾勒
传统设色
分染罩染
低饱和矿物颜料
宣纸
大面积留白
```

不要简单不断增加：

```text
8K
超详细
极致细节
超级写实
HDR
电影级
```

这些词容易把风格带向现代数字插画，而不是传统工笔。

---

# 二十二、如果想更“古画”，应该强化什么？

```text
古典东方人物造型
传统工笔人物画
宋画/明清人物画语境
含蓄神态
平静姿态
低饱和传统颜料
留白
疏梅

```

同时降低：

```text
现代审美
网红脸

```

# 二十三、如果想保持“干净”，最重要的 Prompt

可以单独记住这句话：

```text
背景极简，大面积纯净留白，温润米白宣纸，纸张纹理极轻，仅保留细微天然纤维感，背景低对比、低噪点、无污迹、无水渍、无做旧痕迹
```

这句话对很多模型都很有用。

# 二十四、Prompt 的正确分层方法

以后写类似画面，可以按照下面顺序构建：

```text
① 绘画类型
↓
② 人物
↓
③ 五官
↓
④ 发型
↓
⑤ 姿态
↓
⑥ 服装
↓
⑦ 服装纹样
↓
⑧ 线描
↓
⑨ 设色
↓
⑩ 场景
↓
⑪ 构图
↓
⑫ 宣纸
↓
⑬ 氛围
↓
⑭ Negative Prompt
```

这种结构比把几十个形容词全部堆在一起更容易控制。

---

# 二十五、最终记忆公式

这类工笔人物图，可以记成：

> **人物精致 + 衣服克制 + 线条精细 + 颜色低饱和 + 场景极简 + 宣纸干净 + 留白充足。**

真正决定画面高级感的，不是“元素越多越好”，而是：

> **细节集中在人物，环境主动退后。**


## 结论

对于这类中国传统工笔人物图，建议始终把画面分成四个层级：

### 第一层：人物
五官、发丝、姿态、神情，是最高优先级。

### 第二层：服饰
石青襦裙 + 赭石披帛形成冷暖平衡，纹样只作局部点缀。

### 第三层：场景
一枝疏梅 + 大面积留白，不建立复杂环境。

### 第四层：材质
宣纸只承担“纸感”，不要让纸张纹理成为主体。

这样生成出来的效果，才更接近：

**“一幅画在干净宣纸上的传统工笔画”**，而不是“带着脏纸纹理的古风 AI 插画”。

## 27.2 与 K2 实测结论的冲突项(采用本指南时须修正)
