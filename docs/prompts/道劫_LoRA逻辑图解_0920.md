# 道劫 LoRA 逻辑图解(09-20)

> 给美术的画布内说明书:这套 LoRA 栈怎么运转、每件是干嘛的、九型各自点亮谁。所有启停与权重均为 `daojie_lora_stack.json` 现值投影。

## 一、这套逻辑怎么运作

这套栈的运作就三步:①你在 [80] 底座选型器挑图型(人物/场景/道具…九型之一);②[90] LoRA 栈跟着型自动点亮该亮的件、按定谳权重挂上——配方不用你背;③按型配方(该亮谁、默认权重)只住在一个数据文件里(daojie_lora_stack.json),热改即时生效,本文只是它的投影;你在 [90] 手上的急停开关与权重微调则随画布保存。你只需写好主体句。turbo 加速件=你的操控杆:开=4步快出参考图,关=关本槽并在 [12] 手改 12步+cfg5 走质档;启停由你手动掌控,预设只是初始值。

> 用语:定谳/终审=测试后的拍板结论;对拍=A/B 对照实测;消融=逐件关闭验证贡献;判崩=实测否决;备选槽/纯库存=件在库但预设不点亮,启用须把 [90] preset 切「专家·全自定义」手拨(部分件还须补触发词,见各条);台账=docs/comfyui-kb/LoRA库存台账-0919.md;急停=[90] 槽开关,关=真关。

## 二、14 件逐件说明

### 功能件(全局挂载)

**加速·4步蒸馏(turbo)**

加速件,4步蒸馏把出图压到4步快跑。九型预设全开×1.0(仅初始值)。开关=你的操控杆:启停由你手动掌控、设置随画布保存;正式图质档做法=关本槽+[12] 手改 12步+cfg5(备查)。

**服从度·ProjectorScale(projector)**

服从度件,让画面更听话、更贴提示词。九型恒开×0.01;权重口径特殊——0.01 就是标准档,别按常规往大拉(09-19 A/B 定谳)。

### 人物三件(daojie_lora_stack.json 分组名;三件点亮范围各异,见各条)

**细节·细节滑杆(detail)**

细节滑杆,提发丝、织纹等细部清晰度。九型全开×1.0,是所有图型共享的细节底座,不随型变化。

**亚洲面孔·AsianMix(asianmix)**

面孔件,管脸的观感,不占画风名额。点亮:人物/美宣/三视图/高清人脸/分镜剧情图/表情差分/设定板×0.4;场景/概念气氛(空镜无面孔)与道具(静物)关。

**鎏金·水墨武侠漆艺(liujin)**

国风立绘质感主锚。点亮:人物/道具/美宣/三视图/高清人脸/分镜剧情图/表情差分/设定板×0.3;场景/概念气氛免鎏金(09-19 裁定)。注:人物型=鎏金与金雾同开叠加;场景型=鎏金关、只留金雾(所谓「互换」)。

### 质感

**光影·Afterlight(afterlight)**

电影化光影件。九型全关——消融裁定它正是画面变电影化的主因,默认旁路;要用须把 [90] preset 切「专家·全自定义」手开×0.8。

**质感·电影感(cinematic)**

电影镜头感画风件。九型全关(草案口径),美宣走叙事时可考虑。纪律(专家档手拨时):画风件同开≤1,鎏金算半件;金雾=气氛件不占画风名额,按矩阵双档点亮。

### 画风其他(备选槽)

**identity·编辑身份(identity)**

编辑身份件,图生图/编辑流里保住同一张脸。九型恒关——跑文生图曾出丑图,只供编辑系流程用。

**画风·暗笔刷(darkbrush)**

单色水墨重笔触风。九型全关、默认备选槽;启用须在主体句补触发词 monochrome ink wash style。台账列 kill 候选待勾选。

**画风·美学Masterpiece(masterpiece)**

通用美化提质量件。九型全关、默认备选槽,不入常设矩阵。台账列 kill 候选待勾选。

### 画风水墨

**画风·淡彩线描插画(tancai)**

连环画式淡彩线描增益件。九型全关=纯库存(分镜0.5 候选已撤,09-20 终审)。w1.0 描边化+紫灰污染判崩;启用须补触发词 watercolor ink illustration style。

**画风·墨洗SumiWash(sumiwash)**

四件水墨中墨味增益最大(洇散墨韵、纸上墨感)。九型全关=纯库存——场景与概念气氛 09-20 终审出局。w1.0 光斑粒子判崩。

**画风·水彩湿画(shihua)**

湿接水彩感,比水墨更松更通透。九型全关、场景向备选。硬顶0.8;人物/道具禁用(09-19 对拍)。

**画风·金雾仙侠(goldenmist)**

金纱仙气氛核心件,双档:×0.8(人物/高清人脸/分镜剧情图/设定板)、×0.6(场景/概念气氛图),其余型(美宣/三视图/表情差分/道具)关。注:人物型=与鎏金同开叠加;场景型=鎏金关、只留金雾。
