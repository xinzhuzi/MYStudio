# 《三国望神州》线描表现层 Prompt Guide

## Line Language / 线描表现层

> **版本：v1.0**
>
> **用途：** 用于《三国望神州》目标视觉的 AI 生图、LoRA 筛选、ComfyUI Prompt 组合，以及角色、甲胄、服饰、场景和 AI 漫剧镜头的线描控制。
>
> **核心定义：**
>
> **线描表现层不是简单要求“线画得细”，而是控制线条的粗细、轻重、结构、变化、笔性与造型作用。**
>
> 核心目标：
>
> **细、稳、变、有结构、有笔性。**

---

# 1. 什么是“线描表现层”

线描表现层（Line Language）负责控制：

```text
线描表现层
│
├── 线宽 / Line Width
├── 线重 / Line Weight
├── 线条变化 / Line Variation
├── 轮廓 / Contour
├── 结构线 / Structural Line
├── 五官线 / Facial Line
├── 衣褶线 / Garment Line
├── 发丝线 / Hair Line
├── 甲胄线 / Armor Line
└── 笔性 / Brush Character
```

真正的目标并不是：

> “让画面出现很多黑线。”

而是：

> **让线条参与形体塑造、结构说明、人物识别和视觉节奏。**

理想状态：

> **线条像画出来，而不是像 AI 自动勾边。**

---

# 2. 线描表现层的核心原则

## 2.1 Fine / 细

线条整体应偏细致，而不是粗黑漫画描边。

推荐：

```text
fine linework
fine ink lines
delicate linework
fine Chinese linework
delicate ink contour
fine brush lines
```

核心词：

```text
fine Chinese linework
delicate ink contour
```

---

## 2.2 Controlled / 稳定与受控

线条虽然细，但不能松散、混乱或机械。

推荐：

```text
controlled linework
controlled contour
controlled ink contour
precise linework
refined contour
```

核心思想：

> **线条必须服务于造型，而不是单纯制造纹理。**

---

## 2.3 Varied / 有变化

中国人物画式线描不应所有地方完全一样粗。

推荐：

```text
varied line weight
subtle line weight variation
controlled contour weight
delicate and varied contour lines
expressive contour weight
```

推荐核心组合：

```text
subtle line weight variation,
controlled contour weight
```

这里需要强调：

> “细”不等于“统一细”。

更准确的是：

> **整体细致 + 局部轻重变化。**

---

# 3. Structural Line / 结构线

这是从“漂亮水墨插画”进入“人物画”的关键。

线条应该帮助说明：

```text
人物结构
面部结构
衣服结构
甲胄结构
武器结构
```

推荐：

```text
structured linework
descriptive linework
structural contour
clear garment construction
defined facial structure
precise object construction
```

人物推荐：

```text
structured linework,
defined facial structure,
clear garment construction
```

核心思想：

> **线条不仅描边，还要解释形体。**

---

# 4. Chinese Figure Drawing / 中国人物画线描逻辑

这一层用于建立传统中国人物画 DNA。

推荐：

```text
Chinese figure drawing
traditional Chinese figure outline
Chinese figure painting linework
traditional figure linework
baimiao-inspired linework
gongbi-inspired linework
traditional brush contour
```

---

# 5. Gongbi 与 Baimiao 的使用区别

## 5.1 Gongbi-inspired

重点：

- 工整
- 精细
- 清晰
- 结构明确
- 线条控制稳定

推荐：

```text
gongbi-inspired fine linework
gongbi-inspired ink contour
refined gongbi linework
```

注意：

> 推荐使用 `gongbi-inspired`，而不是直接把整个 Prompt 核心建立在 `gongbi painting` 上。

原因是：

```text
gongbi painting
```

有可能把模型整体拉向“完整古画临摹”。

而：

```text
gongbi-inspired fine linework
```

更明确地限定：

> **只借鉴工笔的线描逻辑。**

---

## 5.2 Baimiao-inspired

重点：

- 白描
- 线条主体
- 轮廓与结构
- 极少依赖强烈色块

推荐：

```text
baimiao-inspired figure linework
baimiao-inspired ink contour
traditional baimiao line drawing
```

---

# 6. Brush Character / 笔性

AI 最容易出现的问题之一是：

> 线条虽然很细，但像 Vector Path。

因此需要加入“笔性”。

推荐：

```text
expressive brush line
subtle brush character
natural ink stroke variation
organic brush lines
controlled brush texture
hand-drawn ink contour
natural brush movement
```

最推荐：

```text
natural ink stroke variation
hand-drawn ink contour
```

目的：

> **避免机械、统一、矢量化的数字轮廓。**

# 8. Face Line / 面部线描

面部不能过度依赖粗轮廓。

重点是：

```text
眼睛
眉形
鼻梁
嘴唇
脸部轮廓
```

推荐：

```text
delicate facial linework
defined facial structure
precise eye and brow lines
subtle facial contours
refined facial outline
```

避免：

```text
thick facial outline
bold black face contour
anime facial line
heavy cel-shading line
```

目标：

> **五官清楚，但不是动漫式粗描边。**

---

# 9. Hair Line / 发丝线描

头发是非常容易暴露 AI 感的部分。

推荐：

```text
delicate hair strands
fine hair linework
natural flowing hair lines
individual fine strands
organic hair contour
controlled loose strands
```

不建议：

```text
thick hair outline
solid black hair contour
graphic hair shape
```

注意：

> 发丝线可以轻、细、丰富，但不要让每根头发都获得同等视觉权重。

---

# 10. Garment Line / 衣褶线描

衣服不能只是“有花纹”。

线条应该说明：

```text
衣物结构
层次
褶皱
重量
方向
穿着方式
```

推荐：

```text
structured garment folds
clear garment construction
fine clothing linework
defined fabric folds
controlled robe linework
traditional garment linework
```

核心：

> **先说明结构，再表现装饰。**

---

# 11. Armor Line / 甲胄线描

武将与普通人物的线描逻辑应该有所区别。

推荐：

```text
precise armor linework
structured armor construction
defined plate edges
controlled geometric contour
fine armor detailing
historical armor linework
fine weapon detailing
```

完整示例：

```text
fine Chinese linework,
controlled ink contour,
structured linework,
subtle line weight variation,
precise armor linework,
structured armor construction,
defined plate edges,
fine weapon detailing,
natural ink stroke variation
```

重点不是让甲胄“变得精细到爆炸”，而是：

> **结构明确、边缘可读、历史装备逻辑清楚。**

---

# 12. Weapon Line / 武器线描

武器应保持清晰的剪影和结构。

推荐：

```text
precise weapon outline
fine weapon detailing
clear weapon silhouette
structured weapon design
controlled metallic contour
```

尤其在角色立绘中：

> 武器既是物件，也是人物身份识别元素。

因此不能被过度水墨化到无法识别。

---

# 13. Scene Line / 场景线描

场景线描不能完全复制人物线描。

重点：

```text
空间层次
轮廓密度
远近虚实
建筑结构
山体结构
```

推荐：

```text
delicate landscape linework
fine architectural linework
controlled mountain contours
soft distant ink lines
sparse brush lines
varied contour density
faded distant outlines
```

其中非常关键：

```text
varied contour density
faded distant outlines
```

建议理解为：

```text
前景
→ 线条更明确

中景
→ 中等明确

远景
→ 淡化、弱化
```

这样才能与：

```text
atmospheric perspective
```

结合。

而是：

> **防止线条进入动漫粗描边、欧美漫画、矢量轮廓和机械 AI 勾边。**

## 19.1 Anime / 动漫粗描边


## 19.2 Vector / 矢量感


## 19.3 Western Comic / 欧美漫画

# 21. 不能混用的词

以下词容易产生冲突：

```text
fine linework
thick bold outline
delicate brush line
heavy black contour
soft subtle contour
strong comic inking
```

不要同时大量使用。

例如不建议：

```text
fine linework,
thick bold outline,
heavy black contour
```

这会给模型相互矛盾的线条指令。

# 23. 与其他视觉层的关系

线描表现层不能独立决定整张图。

推荐关系：

```text
Character
    ↓
决定“是谁”
    │
Historical
    ↓
决定“属于什么时代和身份”
    │
Line
    ↓
决定“怎么画”
    │
Color
    ↓
决定“怎么设色”
    │
Space
    ↓
决定“怎么组织空间”
    │
Narrative
    ↓
决定“发生什么”
    │
Graphic
    ↓
决定“怎么呈现”
```

因此：

> **Line 不负责解决 Character、Historical、Narrative。**

它主要负责：

> **形体如何被线条塑造。**

# 24. 与“水墨层”的区别

这是本项目必须保持的边界。

## Line

负责：

```text
结构
轮廓
人物
衣褶
甲胄
五官
物体
```

## Ink

负责：

```text
空气
远近
虚实
晕染
背景
墨色
空间气氛
```

因此理想组合是：

```text
Line = Structure
Ink  = Atmosphere
```

而不是：

```text
Ink = everything
```

# 25. 对“新中式水墨人物图”的修正方法

如果一张图已经拥有：

```text
水墨 ✅
留白 ✅
传统色 ✅
山水 ✅
```

但感觉更像：

```text
唯美古装人物插画
```

而不是：

```text
《三国望神州》历史游戏人物
```

优先增加：

```text
structured linework
clear facial structure
defined costume details
historical garment construction
subtle line weight variation
controlled contour weight
baimiao-inspired figure linework
```

而不是继续增加：

```text
ink wash
watercolor
mist
poetic
ethereal
dreamlike
```

因为后者只会进一步加强“唯美水墨插画”。

# 29. AI 漫剧中的线描一致性

连续镜头中不要每一张随意改变线描风格。

建议建立固定：

```text
LINE_CORE
```

所有镜头共享。

例如：

```text
LINE_CORE
+
Character Module
+
Costume Module
+
Shot Module
```

不要：

```text
Shot 01 → Gongbi
Shot 02 → Watercolor
Shot 03 → Ink Wash
Shot 04 → Anime Line
```

否则角色会失去统一的视觉身份。

---

# 30. Line LoRA 的筛选标准

测试一个 Line LoRA 时，不只看：

> “线够不够细。”

而应该看：

| 指标 | 问题 |
|---|---|
| 细致度 | 线条是否精细 |
| 稳定性 | 是否容易断裂 / 乱线 |
| 线重变化 | 是否具有自然轻重 |
| 结构作用 | 是否真正帮助塑造形体 |
| 人物适配 | 面部与衣褶是否自然 |
| 甲胄适配 | 武器和装备是否清楚 |
| 场景适配 | 建筑 / 山水是否自然 |
| 笔性 | 是否具有手绘感 |
| AI 感 | 是否出现机械勾边 |
| 兼容性 | 是否容易压坏其他 Style LoRA |

# 32. 最终判断标准

一套优秀的《三国望神州》线描语言，应该满足：

```text
✅ 线条细
✅ 线重有变化
✅ 轮廓受控
✅ 人物结构清楚
✅ 五官有中国人物画线描倾向
✅ 衣褶有结构
✅ 甲胄可读
✅ 发丝自然
✅ 远景线条弱化
✅ 具有笔性
✅ 不像 Vector
✅ 不像粗动漫描边
✅ 不抢色彩和空间的主导地位
```

最终目标：

> **让线条成为“造型语言”，而不是表面装饰。**

---

# 33. Final Definition / 最终定义

> ### Line Language / 线描表现层
>
> **通过细致、受控、具有轻重变化和笔性的人物线描，结合中国人物画、工笔与白描的结构逻辑，使线条承担轮廓、形体、人物身份和服饰结构的塑造作用。**
>
> 核心不是：
>
> **“更多线条”**
>
> 而是：
>
> **“更正确的线条”。**

---

# 34. One-Line Rule / 一句话规则

> **细而不弱，稳而不死，变而不乱，有结构而不机械，有笔性而不潦草。**
