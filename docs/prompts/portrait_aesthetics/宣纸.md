# 干净宣纸背景生图指南

> 适用于中国传统工笔画、古风人物、国画人物、AI 国画生图。
>
> 核心目标：**保留宣纸质感，但避免背景变脏、发黄、出现明显污点和过重纤维。**

---

## 一、核心概念：宣纸质感 ≠ 脏纸纹理

很多模型会把“宣纸”理解成：

- 泛黄
- 老旧
- 明显纸张纤维
- 污点、斑驳
- 水渍
- 霉斑
- 粗糙颗粒
- 扫描旧画的噪点

但高质量工笔画需要的是：

> **干净、温润、细腻、低纹理强度的宣纸材质。**

也就是说，目标不是生成一张“宣纸照片”，而是生成一幅“画在宣纸上的工笔画”。

---

## 二、为什么其他模型容易把宣纸生成得很脏？

模型训练数据中的“宣纸”经常与以下内容同时出现：

`古画 + 老纸 + 古籍 + 水墨画扫描件 + 做旧纸张 + 纸张纹理素材`

因此模型容易建立类似的关联：

```text
宣纸
→ 黄色纸张
→ 明显纤维
→ 旧纸
→ 污点
→ 水渍
→ 斑驳
```

所以只输入：

```text
宣纸
```

往往不够。

应该明确描述：

```text
宣纸材质
+ 温润米白
+ 极细微纤维
+ 低纹理
+ 干净纸面
+ 大面积留白
```

同时抑制：

```text
脏污、污点、水渍、霉斑、严重泛黄、旧化、粗糙纤维、过重颗粒
```

# 三、宣纸质感的三个等级

## A. 最干净型——推荐

适合工笔人物、古风少女、角色立绘、大面积留白。

### Prompt

```text
细腻宣纸质感，温润米白纸面，
纸张纤维极其细微，
背景干净纯净，纹理弱化，
大面积留白
```

### 视觉目标

像高质量国画作品经过专业扫描或印刷后的纸面。

优点：

- 最干净
- 不抢人物
- 不容易产生脏点
- 适合细线稿
- 适合工笔画

---

## B. 中等宣纸感

适合希望观众明显感觉到“纸”的存在，但又不希望背景太粗糙的情况。

### Prompt

```text
细腻宣纸纹理，
可见但柔和的天然纸纤维，
轻微纸面起伏，
温润米白色纸张
```

### 视觉目标

能够明显感觉到宣纸，但背景依旧干净。

---

## C. 强宣纸纹理

只在确实需要强化纸张材质时使用。

### Prompt

```text
明显天然宣纸纤维，
粗细交错的纸浆纹理，
明显纸面纤维，
轻微墨色渗化和纸张吸墨效果
```

### 注意

这一档最容易出现：

- 背景脏
- 颗粒过多
- 线稿被背景吞掉
- 人物细节下降

对于工笔人物画，一般不建议长期使用这一档。


# 五、Negative Prompt：专门抑制脏宣纸

直接复制：

```text
脏污，污点，水渍，霉斑，旧纸，严重泛黄，过度做旧，
粗糙纸纤维，明显纸张纹理，纸张噪点，颗粒过重，
脏背景，灰尘，污迹，破损纸张，斑驳，发黑纸面，
过度纹理，杂乱纤维，粗糙背景
```

---

# 六、最重要的 Prompt 逻辑

不要写成：

```text
一张宣纸，上面画着一个人物
```

更推荐：

```text
一幅中国传统工笔画，
人物是主要主体，
宣纸只是绘画载体，
背景大面积留白，
纸张纹理极轻微
```

模型需要理解的是：

```text
主体：工笔人物
↓
绘画风格：中国传统工笔画
↓
绘画载体：细腻宣纸
↓
背景：干净、大面积留白
```

而不是：

```text
主体：宣纸
↓
纸张纹理占据画面
↓
人物被放到纸上
```

后者非常容易产生脏背景。

---

# 七、为什么“大面积留白”也非常重要？

工笔人物画通常需要安静的背景。

如果背景加入大量：

- 纹理
- 纸纤维
- 墨迹
- 色块
- 水渍
- 颗粒

这些内容会和人物线稿竞争视觉注意力。

因此推荐：

```text
大面积留白
背景干净
低纹理
低对比度
纸张纤维极轻微
```

而人物部分保持：

```text
精谨线描
细腻墨线
线条细而稳
五官清秀
衣纹清晰
```

这样可以形成：

> **背景安静，主体精致。**

# 十二、不同模型的通用使用策略

## Flux / SDXL / ComfyUI

建议使用：

```text
宣纸材质 + 温润米白 + 极细微纤维 + 干净背景 + 大面积留白
```

并配合 Negative Prompt 抑制旧纸、污点、粗糙纹理。

如果使用 LoRA：

> 风格 LoRA 控制工笔画，Prompt 单独控制宣纸材质，避免让“宣纸 LoRA”把背景纹理推得过重。

---

## Midjourney 类模型

重点描述：

```text
clean refined Chinese rice paper
subtle paper texture
minimal paper fibers
clean warm ivory background
large negative space
```

避免连续堆叠：

```text
old paper
aged paper
rough fibers
vintage paper
weathered paper
```

否则容易偏向旧纸效果。

---

## 国产生图模型

中文描述通常更容易控制：

```text
温润米白宣纸
纸张纹理极轻微
纸面洁净
无污点
无水渍
无做旧
大面积留白
```

尤其推荐把：

> **“背景洁净、纹理弱化”**

明确写出来。

# 十三、一个非常实用的修改方法

如果第一次生成的背景还是很脏，不要直接把“宣纸”删掉。

而是逐级降低纸张纹理：

### 第一级

```text
极细微天然纸纤维
```

### 第二级

```text
纸张纹理极其弱化
```

### 第三级

```text
几乎不可见的宣纸纤维
```

### 第四级

```text
温润米白纸面，干净纯净背景
```

这样通常比直接删除“宣纸”更容易保留中国画媒介感。

# 十四、最终记忆公式

以后你想让 AI 生成：

**“有宣纸感觉，但一点都不脏”**

记住这一套：

```text
宣纸材质
+
温润米白
+
极细微纤维
+
低纹理
+
干净纸面
+
大面积留白
+
Negative Prompt 抑制污点/水渍/旧化/粗糙纹理
```

核心原则只有一句：

> **不要让 AI 生成“宣纸纹理”，而要让 AI 生成“画在干净宣纸上的作品”。**

本指南方法在本地 Krea2/Qwen 编码器上**实测成立**。同提示词同种子(速度档)三组对照:

| 空白底色区 | 裸「宣纸」 | 删掉「宣纸」 | **重定义(§四方法)** |
|---|---|---|---|
| 泛黄度 R−B | 53.2 | 50.8 | **36.4** |
| 脏斑方差 | 22.3 | 21.2 | **15.6** |

结论:**裸写「宣纸」确实脏(训练先验:旧画扫描件);但按本指南限定词重定义后,比彻底删掉更干净**,且保留中国画媒介感。K2 上推荐写法:

```text
底色是温润米白的细腻宣纸质感，纸张纤维极其细微，纹理弱化，纸面洁净素净
```
