## 五、正规测试流程(逐条照做)

1. 侧栏**重开**超集工作流(旧标签页是旧画布状态,必须重开)。
2. [50] 整段替换为 G2 → seed 20 + **fixed** → Queue,等出图,改名存 G2。
3. [50] 换成 G7 → **同一 seed 不动** → Queue,存 G7。
4. [50] 换成 G8 → 同 seed → Queue,存 G8。
5. 三张并排看**背景空白区**(左侧大块):黄不黄、脏斑多不多、织纹重不重;再看脸。
6. 想排除种子运气:换 seed=21/22 再各跑一轮,看结论是否稳定(脸对种子敏感,背景结论通常稳定)。
7. 出图文件位置:引擎家 `ComfyUI/output/`,画布历史里也能取。
