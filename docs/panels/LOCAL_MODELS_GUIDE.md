# 本地模型页（ComfyUI 工作区）

本文说明主导航 `本地模型` 页面（原「辅助」页，2026-09-10 起改为全屏 ComfyUI 工作区）。本地生图、生视频、音乐等产线都跑在这页托管的 ComfyUI 引擎上。引擎的安装与模型管理在 [ComfyUI 引擎指南](../settings/COMFYUI_ENGINE_GUIDE.md)。

## 页面入口

```text
主导航 -> 本地模型
```

进入后是沉浸式全屏布局：没有侧栏和头部，导航走全局悬浮球（点球展开「导航」分区可回概览或跳其他模块；在「本地模型」模块内，球菜单同时用于切换画布 / 配音室 / 漫影生图）。

## 三个工作区

| 工作区 | 用途 |
|---|---|
| ComfyUI 画布（默认） | 自管引擎的完整前端：节点画布、工作流库（仓库模板按 `0_分镜 / 1_图片 / 2_视频 / 3_声音` 分域；提示词参考资料在文档库）、生成队列与结果 |
| TTS 配音室 | 用本地声线克隆生成语音（选参考音频 + 文本 → `生成语音`；克隆走临时 profile，声音特征对齐后合成） |
| 漫影生图 | 快速文生图表单，见下节 |

## ComfyUI 画布

引擎状态由应用托管，画布会跟随引擎状态显示占位或界面：

- 引擎未安装 → 显示一键安装入口（体积 GB 级，手动点击才开始，绝不自动下载）。
- 已安装未运行 → 显示启动入口；启动后画布加载引擎完整前端。
- 运行中 → 直接进入画布。顶部信息栏可查看引擎状态与端口。

生成结果经媒体资产面板回流：`已导入` = 引擎 input 目录（参考图 / 上传图），`已生成` = 引擎 output 目录（生成产物）。画布左侧「工作流」可浏览和打开模板。`repo:` 项来自应用自带工作流库，为只读模板；改名、删除、新建文件夹等写操作作用于用户库。修改模板时另存用户副本。

「MY 工作流」的「分镜视频生成」「图像节点图」两个页签复用同一画布（章节环节链 + 分镜网格），业务分镜数据经桥接自动写入环节节点，详见 [基本工作流教程](../workflow/WORKFLOW_GUIDE.md)。

## 漫影生图

一句话流程：`选模型 · 写提示词 · 一键出图`（引擎没跑会自动启动）。

| 项 | 说明 |
|---|---|
| 出图模式 | `标准`：自由选主模型（取自 `diffusion_models` 目录），默认 8 步，输入范围 1–40 步。`加速 · 4 步`：Krea2 Turbo + 4 步蒸馏 LoRA 固定搭配，步数可选 4 / 6 两档；速度和画质依模型、输入及设备而变，UI 估算文案不是本轮性能测试结果。 |
| 主模型 | 从 `comfyui/models` 的 diffusion 权重中选择；加速档固定为 krea2_turbo（不可选）。 |
| 提示词 | 必填；为空时提示「先写提示词再生成」。 |
| 结果 | 成功后提示「图片已生成并存入媒体库」，可直接在媒体库 / 产物页使用。 |

## 常见问题

- **画布一直显示安装/启动占位**：先到 `设置 → 本地配置 → ComfyUI 引擎` 确认状态；排障见 [常见故障排查 · ComfyUI 引擎问题](../engineering/TROUBLESHOOTING.md)。
- **想改采样参数 / 工作流细节**：本地产线参数口径见 [ComfyUI 参数速查](../comfyui-kb/参数速查.md)（改参数前先查）。
- **生成的图在哪**：output 目录（媒体资产面板「已生成」）；漫影生图的结果额外自动存入媒体库。
