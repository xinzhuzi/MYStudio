## 一、全景:进程/端口/令牌

```
┌─ 应用(漫影工作室 Electron)──────────────────────────────┐
│ 渲染进程(React)                                          │
│   ├ ComfyCanvasStudio ──webview──→ 引擎前端(下面)        │
│   └ lib/assist/image-studio/* ──HTTP──→ sidecar          │
│ image_gen sidecar = http://127.0.0.1:17595               │
│   令牌:固定 Bearer/X-Manying-Image-Token = manying-local-image │
│   └ 引擎管理层(engines/comfyui/*)──→ ComfyUI 引擎进程    │
│       引擎 = http://127.0.0.1:<实际端口>(真源=manifest.json;  │
│       由 engine_manager spawn,勿手动起)                  │
└──────────────────────────────────────────────────────────┘
```

| 域 | 值 | 备注 |
|---|---|---|
| sidecar | `127.0.0.1:17595` | 开发侧车用 17597 勿抢 17595 |
| 引擎 | `127.0.0.1:<实际端口>` | 真源为 manifest 的 `engine.port` 与设置页实时状态；冲突时在 17000–17999 范围选择，不固定为 17001 |
| 桥令牌 | `manying-local-image` | `bridge_contract.BRIDGE_TOKEN` 与 sidecar LOCAL_TOKEN 断言一致;09-14 manying→my 改名**特意保留**(=前端持久化 provider apiKey,改了即断) |
| 家覆写 | 环境变量 `MYSTUDIO_COMFYUI_HOME` | 测试/定制用；装机默认 `<userData>/comfyui`，纯开发兜底 `~/.manying-dev/comfyui` |

**三条核心数据链路**(改动前先看懂自己动的是哪条):

- **链路 A·总览保鲜+图片带**(渲染层→引擎画布):`storyboard-overview-sync` 指纹守卫 → 逐镜缩略图(768px<1MB 铁律管线)经 `uploadBridgeReference`→sidecar `/comfy/bridge/reference`→引擎 `/upload/image?overwrite=true` 落 input 目录(`my-shot-<净化id>.jpg`;改名前旧文件名仍按值直读,不迁移) → 读取只读通用模板 `repo:0_分镜/分镜工作流.json`，克隆并注入当前章载荷后直接 `loadGraphData`；不导出工作流 JSON、不写用户库 → 引擎前端 `sidebar.js` 用 `/view?filename=…&type=input` 拉图、`onDrawBackground` 画进节点。
- **链路 B·成图回写**(引擎→渲染层):ComfyUI 里 `MyGenerated` 节点执行 → `my_nodes/bridge/writeback.py` POST sidecar `/comfy/bridge/writeback`(PNG b64+shotTarget)→ 收件箱 `bridge_inbox` → 渲染层 `consumeComfyBridgeWritebacks` 轮询消费(轮询住在 ComfyCanvasStudio)→ 写分镜库/媒体台账 → ack。
- **链路 C·侧栏数据**(渲染层→引擎前端):ComfyCanvasStudio 周期 `pushBridgeStoryboards`(镜 id/label 快照)→ sidecar `/comfy/bridge/storyboards` 存快照 → 引擎前端 `sidebar.js` 侧栏 GET 同端点拉取;点选=回填当前选中 MyGenerated 的 `shot_target` widget。

**webview 注入面**(ComfyCanvasStudio.attachWebview,dom-ready+did-finish-load 双事件):选中色 CSS(修 xterm 泄漏)、登录遮蔽第二层(`?raw` 导入 `my_login_cloak.js`)、`autoOpenOverview` 时注入 `buildOverviewOpenScript`(轮询 `window.app`→`loadGraphData`,一次性守卫)。

## 七、坑清单(实弹踩过,勿重蹈)

1. 侧栏 `icon` 参数=**完整 iconify 类名**(`icon-[lucide--list]`);裸名渲染空白只剩文字(SidebarIcon 把 icon 串直接当 class)。
2. 侧栏标签金锚点 `[data-testid="<tabId>-tab-button"]`;置顶=插到首个 `-tab-button` 前;title/aria 定位不可靠。
3. 自定义图标:DOM 置换槽 `i.side-bar-button-icon`;随主题单色=**CSS mask**(`background-color:currentColor`+logo alpha);图片内嵌 base64(源图先 `sips -z 64 64`)。
4. Vue 重渲染回滚:MutationObserver(rAF 节流)反复补正;标记属性防重复嵌套。
5. webview 注入:`window.app` 异步赋值须轮询;一次性守卫防覆盖手动切换;`insertCSS/executeJavaScript` 只能在 attach 后事件期调。
6. 旧默认库回种死循环(`merge_legacy_workflows_dir`);空夹 `.keep.json`。
7. 库 id=相对路径,深层嵌套全链路支持(后端 rglob/前端逐级建链);分镜绑定走应用内 ln,移动库文件不断链。
8. 节点新数据走 `properties`(如 myPreview),不走 widgets_values(序列化契约零影响)。
9. **双家双份**:源码改动必同步双家;装机侧定稿必打包(否则被 Resources 重同步冲掉)。
10. 登录遮蔽双层(引擎 my 模块第一层 + app `?raw` 第二层),真源 `my_login_cloak.js`;云端收编配置 `comfy-api-takeover.ts` 留空=零干预。
11. 改字符串进包验证:asar 里「没有」≠没构建——先确认引用链(死代码会被 tree-shake,如退役迁移器)。
12. `rg -r` 是 replace 不是递归;`rg -l` 才是列文件(zsh 里 `echo ===` 会炸,用 `echo "---"`)。
