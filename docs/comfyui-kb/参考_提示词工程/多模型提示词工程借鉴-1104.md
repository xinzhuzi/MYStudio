## 一、九模型 system prompt 适配模式(prompt_optimizer.py L1649-2028)

**模式**:每目标模型一套原生格式,不搞大一统——LTX2.5=七段式(scene/subject/action/camera/lighting/style/audio+时长填充+多镜 [Shot N] 扩展);Seedance=中文段标签(主体/动作/场景/镜头/光影/风格+【镜头N】扩展+**中文运镜词汇表:推、拉、摇、移、跟、升降、环绕**);Wan2.2=纯自然语言一段式 60-220 词;Kling=六段中文+运镜表;Hunyuan=五段或富段落;Veo3=电影感段落+声音一句收尾;Sora2=官方三部曲(Visual description:/Dialogue:/Soundtrack:,**可选段条件式存在——用户没给就不准输出空标题**);Z-Image=50-150 词单段。

**借鉴点**:①「每模型原生格式」适配原则(本地 H3/Krea2/qwen 三线同理);②可选段条件式存在禁令(Sora 的 Dialogue/Soundtrack 处理=道劫「画面文字段」同类问题的正解);③中文运镜词汇表(推拉摇移跟升降环绕)可入 director-storyboard。

## 二、Flux2 十一段职责边界写法(L1745-1887,图片线最值)

11 段标签结构(【主体】【表情】【动作】【衣服】【场景】【构图】【打光】【色调】【风格】【画面文字】【画质约束】),每段「写什么+**绝不写什么**」双句式:identity 只在 subject、clothing 只在 clothing、lighting 与 tone 分离、composition 不写光色;**禁 quality-tag 污水词**(8k/masterpiece/best quality/ultra detailed/award-winning 明令禁止);画面文字段=用户没提文字就整段省略禁空标题;标签双语系(中文模式【主体】英文模式 [Subject] 禁混);返回前六项自检。

**借鉴点**:与道劫三层分工同构但「每段 Never 句式」更极致——三源合并防重复(底座负面/型级/主体句负面)可参考其「同一信息只许住一段」原则。

## 三、输出后修复五件套(L2097-2400,「LLM 不守约时的机械修复网」)

1. `_ensure_supplied_dialogues`:用户台词逐字强制回填(丢了就机械补回)
2. `_ensure_fl2va_picture_labels`:FL2VA 裸标签(picture 1/2)缺失强制
3. `_repair_output_language`+`_is_mostly_wrong_language`:语言错→自动二次 LLM 重写
4. `_clean_nested_dialogue_tags`:嵌套/未闭合 `<d>` 状态机修复
5. `_normalize_subject_shorthand`:裸 S1-S20→(S1) 括号化;`_strip_filenames` 文件名剥离;`_format_prompt_sections` 标题强制独立行

**借鉴点**:与本地「逐字自检门」同族互补——本地门是「检出门」,这套是「修门」(机械可修的直接修,语义错的才回炉)。候需可工程化进 LLM 直投链。

## 四、对白抽取正则(L2133-2160)

中英双语说引语三模式:`说|说道|喊|问|回答|says?|shouts?|asks?|replies?`+中英引号包裹/无引号取到句末标点(**防把后续动作描述吞进对白**)+子串去重。

**借鉴点**:分镜产线 `splitDialogueLines` 的姊妹问题(自然文→台词逐字保真),候台词上游改造时参考。
