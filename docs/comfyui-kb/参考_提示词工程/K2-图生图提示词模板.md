# K2 图生图提示词规范模板

> 配套工作流:`Krea2-NSFW专业流-图生图.json`
> 写法核心:K2 是 Qwen3-VL 文本编码器,**吃完整描述句,不吃关键词堆**。
> 中文长句可用(现专业流同款),英文完整描述句服从度实测最佳,二选一即可,别混成标签堆。

---

## 一、五段式结构(按顺序填,段与段用逗号或句号衔接)

```
【1 参考图锚定】只描述"要保留的东西",这是图生图专属段
   · 主体:谁/什么,几个,什么姿态动作
   · 构图:景别(半身/全身/特写)、朝向、机位角度
   · 场景:在哪里,背景有什么
   · 光线色调:光的方向与性质,主色调,明暗

【2 重绘目标】想改什么就写什么,没提到的部分默认跟参考图走
   · 改动一件一件写清楚,动词具体(换成/添加/移除/改为)

【3 主体细节】人物的固定特征,跨图一致性靠这段
   · 五官/发型/肤色/身材/妆容/饰品

【4 风格与光线】你固定流里的风格段直接搬过来
   · 真实摄影,情绪写真,胶片颗粒质感……

【5 画质词】
   · 32K高清画质,细腻真人皮肤纹理,获奖作品……
```

## 二、denoise 档位 × 提示词写法(重点)

| denoise | 【参考图锚定】段 | 【重绘目标】段 |
|---|---|---|
| **0.30~0.40** 微调 | 可以省略(模型基本照抄原图) | 只写那一两处小改动 |
| **0.55~0.65** 均衡(默认 0.6) | **必写**,锚住主体/构图/色调三样 | 写清具体改哪,越具体越不跑 |
| **0.85+** 重画 | 无意义(几乎不看原图) | 当文生图全量写 |

一句话原则:**denoise 越低,提示词越少;denoise 越高,越接近文生图写法。**

## 四、避坑

- **别复述原图全部细节再要求全改**——锚定段和重绘目标打架时,denoise 低会听锚定、高会听重绘,结果不稳定。
- **改动件数 ≤3 效果最稳**,一次想换装+换场景+换发型 = 分两跑。
- NSFW 内容仅限成年角色;破限链(TE+LoRA+Rebalance)只负责"画得出来",提示词仍要写清楚"画什么"。
- 种子固定时,同提示词同参考图 = 可复现;调参数优先调 denoise,再动提示词。
