# 提示词工具生态观察(1103,候需求不施工)

> 真源:comfyit.cn「提示词大师」产品形态观察(article/487;1103 调研快照,底稿=记忆档 `comfyit-survey-absorbables-1103` 与任务档 `.trellis/tasks/11-03-h3-multisample-campaign/`)。**性质=候需求记档,不施工**——记的是别家怎么把提示词能力组织成产品;技术件本地皆已有,无技术增量。

## 背景

comfyit.cn(「ComfyUI搅拌站」,济南六乐信息科技)为商业工具站,三件套=ComfyUI管理大师(启动器)+提示词大师+LoRA训练大师。本档只取「提示词大师」的**产品形态**启示,不涉实物、不装机、不采购。

## 三条产品形态启示

1. **词库条目=标题+正负向+备注+封面+文件夹/标签双分类**:一条词库记录是五件套资产(标题、正向、负向、备注、封面图/视频),文件夹+标签双维度组织,封面可直接拖入 ComfyUI——提示词从「一段文本」升级为**可浏览、可管理、可直投的资产对象**。
2. **反推=批量×模型×输出风格正交**:图/视频批量反推,「模型×输出风格」两维正交组合成可选矩阵——反推不是单一功能位,是一组可组合的能力矩阵。
3. **「工程」=审美规则模板化复用**:可复用系统提示词+用户规则模板,把个人审美偏好沉淀为可挂载复用的规则包——卖点不在生成而在**复用**,「工程」二字落在模板化。

## 判定(候需求不施工)

产品层启示,技术件本地皆已有(1103 调研口径:提示词广场中文描述、Qwen PE 等均判无增量)。**候需求记档:日后用户若提提示词管理/反推产品化需求,以上三条为形态参照;不施工、不装机、不自建工具**(1103 任务档 prd.md R5,记档候令)。
