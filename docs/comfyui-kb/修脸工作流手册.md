# 修脸工作流手册(1119b 口径;供后续 AI/人接手)

> 适用域:`2_视频/H3视频/` 修脸链。两件并立:**正典修脸**(三采-单镜.json 内置四采臂)与**融合修脸件**(7_测试/三采-单镜-修脸.json,96 节点)。本手册含结构说明、错误史、发车口径、选型规则。
> 生成器:`apps/build/scripts/campaigns/h3_face_refine_fusion_1118.py`(幂等 --check/--apply,72 断言);对拍档案:`apps/output/h3-face-refine-survey-1118/fusion/`。

## 一、两件格局与选型规则

| | 正典四采修脸臂(在役) | 融合修脸件(7_测试,已验证备选) |
|---|---|---|
| 宿主 | 三采-单镜.json(5001-5023 段,#1065 开关) | 三采-单镜-修脸.json(=正典深拷贝+融合段 5101-5110 减差分) |
| 修脸机制 | YOLO 裁脸→InjectLatent→AudioLock→PerFrameDenoise(0.35 按脸缩放)→dn0.45 采样→贴回 | 同左底盘 + **SAM3.1 文本追踪遮罩双用**(潜空间噪声遮罩+贴回遮罩)+ **VOSR2 高频尾档** |
| 强项 | 成熟稳定;远景/特写均衡(1118 终审可交片) | 贴边/出画脸防错位(SAM mask);脸画布高频(VOSR2);陶艺对拍脸区清晰度 +113.6% |
| 弱项 | 磨皮偏重(实测脸区 Laplacian 反低于源);无贴边防护 | 时长 +69%(349→589s@243f);远景小脸受 PerFrameDenoise 低档限制(与正典同) |
| 选用 | 默认产线 | 需要贴边防护/高频增强时点名;写实素材增益最大 |

**选型一句话:默认正典;贴边出画、写实素材、要毛孔质感→融合件。**

## 二、融合件结构(96 节点,2026-11-19b 版)

## 三、错误史与修正(血泪碑,勿再犯)

1. **差分扩散在低降噪体制下反噬(1119 主案)**:作者件差分配 dn0.5~1.0(高重绘保背景);照搬进正典 dn0.45 体制+PerFrameDenoise 远景小脸低档 → 重绘被差分拽回原图,脸几乎不修甚至低于源(ch002 4K 实测远景四官糊化)。**修正=移除差分(1119b)。教训:嫁接外部组件必须核对其工作体制(降噪档位)与本件体制的兼容性,参数逐位保真≠体制兼容。**
2. **修脸条件空转**:独立发车裁四采子图时 prompt 被填成空串(沿用克隆件模板默认)→模型无重绘方向。**修正=发车必填正典 #25 身份句**(见 §四)。注:陶艺对拍两臂都空提示词 A 臂仍修得动(磨皮式)——空提示词是帮凶不是主犯,差分才是。
3. **对拍素材假信心(1119 教训)**:陶艺素材(写实+脸大+源脸只柔不糊)恰好全走融合件长板,判「B 全面胜」过快;ch002(动漫+远景小脸 45px+真糊团)才暴露体制冲突。**修正=对拍素材必须覆盖产线真实域(动漫/远景/小脸),至少两类题材。**
4. **SAM3.1 对国风动漫小脸:能检出**(远景 45px 白区 0.039%=脸区吻合;近景 2.07%)——曾被误疑失灵,探针(`fusion/sam3_probe.api.json`)证伪。SAM3 恒吃 5011 出口的 768 裁片,不碰 4K 底片,无压力。
5. **scp 直传引擎 input 会建同名流氓目录**(文件落不进目录里)→ GetVideoComponents Errno 2(LoadVideo 却能读=假绿)。**修正=恒走 /upload/image HTTP 且带 filename 参数**(curl -F "image=@file;filename=dst.mp4")。
6. **H3FaceTrackCrop 签名漂移**:引擎现版 `absent_frames`→`absent_shots`(off/by_identity),旧件 UI 存档的 widget 位校验会弹错;发车转换时补 `absent_shots:"off"`。
7. **无音轨源视频炸 AudioLock**(5014 `audio["waveform"]` None)——喂源前 ffprobe 验音轨,无则 ffmpeg 补静音 aac。
8. **e-p4 系终片与 ch002-4k-p3 不是同一生成**(e-p4/e-p4v2 互为字节副本;站位/妆造不同)——**跨生成视频禁止直接当对拍参照**,远景对比必须同源同生成同帧号。

## 四、发车口径(独立跑四采子图)

- **源视频**:ffprobe 验含音轨;经 /upload/image 上传(ASCII 名)。
- **参考图**:与视频角色同人的正脸(自源抽帧裁脸可行,如 `fusion/ref_ch002_face.png` 做法);写实/动漫风格尽量对齐源。
- **5012 prompt 必填**(正典 #25 默认句,可按角色改写,但保身份锚+清晰化指令):
  `The same person as in the video: sharp detailed facial features, clear bright eyes, well-defined facial contour, refined natural skin texture, clean hair edges; keep the exact facial identity, skin tone and lighting direction unchanged, no character redesign.`
- **seed**:固定值(禁 randomize;对拍两臂同值;引擎本底非确定→判恒统计口径,禁逐位)。
- **帧数**:LoadVideo 全帧自动,无需硬编码。
- **UI→API 转换**:参照 `fusion/build_ab_prompts_1119.py` / `convert_author_wf.py` 四坑(set/get 消解含 SetNode 输出旁路直连/VHS widgets=dict 按名取/seed 口 control 伪值跳位/动态组合组条目统一收;连线引用必须 ["id",slot] 字符串)。

## 五、验收方法

1. 抽帧:远景段+特写段各 ≥3 帧(注意 ffmpeg select 表达式 `eq(n\,60)` 转义);
2. 三态并排:源 vs 产物 vs 参照(同源!);脸区 4x 裁片逐官判读(眉/眼/鼻/唇);
3. 量化:脸区 Laplacian 方差(清晰度)+对源 RMSE(改动面)+背景区 RMSE(应=编码噪声级,验证只动脸);
4. 红线:远景四官不低于源;特写不抹细节;无贴回缝;身份零漂;表情/口型保持。
