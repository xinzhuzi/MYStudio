## 一、双档定义与选型规则

| | 远景修脸(默认) | 高清修脸 |
|---|---|---|
| 触发 | 5111=False(出厂默认) | 5111=True |
| 机制 | **正典链原样**:YOLO 裁脸→H3 重画→InjectLatent→AudioLock→PerFrameDenoise(0.35 按脸缩放)→dn0.45 采样→5022 **face_only 贴回**(masks 悬空=transform.face_rect 脸框+羽化,1118 正典现状行为) | **同链全跑**+出口复制对 **5024/5025**(5024 同为 face_only 贴回,widgets 逐位同 5022/5023)+**VOSR2 高频尾档 5110**(5021 解码 768 画布→5110→5024.refined_crops) |
| 强项 | 成熟稳定;远景小脸自动满档(45-75px→strength 0.93-1.0);口型/表情保持最佳 | 脸区锐度再抬一档并反超(f60 1.597×/f156 1.822× 源);特写毛孔质感 |
| 代价 | 锐度上限=重画本身 | 时长 +VOSR2 尾档;显存略增(VOSR2 只吃 768 画布,无 4K 全帧重采样) |
| 选用 | 默认产线 | 特写要质感/写实素材点名 |

**选型一句话:默认远景档;特写要毛孔质感、写实素材→拨 5111 高清档。**
远景档参数=**正典零调整定案**(5015 七参 `[1.0, 0.35, "absolute_px", 60.0, 200.0, 1, 9]`:脸越小越强、越大越轻;「远景要为小脸加力」假设不成立——方向反了,小脸本就满档端)。

## 三、错误史与修正(血泪碑,勿再犯)

1. **差分扩散在低降噪体制下反噬(1119 主案,已砍)**:作者件差分配 dn0.5~1.0(高重绘保背景);照搬进正典 dn0.45 体制+PerFrameDenoise 远景小脸低档 → 重绘被差分拽回原图,脸几乎不修甚至低于源(ch002 4K 实测远景四官糊化)。**修正=移除差分,禁回加(未来要高 dn 实验体制另行立项)。教训:嫁接外部组件必须核对其工作体制(降噪档位)与本件体制的兼容性,参数逐位保真≠体制兼容。**证据:fusion 役 ch002 4K 对拍(部分产物已丢失,验尸与结论存 `fusion/autopsy-1119.md`/`grill-report-1119.md`,以 PRD 与本手册为准)。
2. **SLNM 潜空间遮罩被 AudioLock 源码级覆写(已砍)**:`ComfyUI-H3-NativeAudioLock/__init__.py:50-54` `lock_audio` **无条件覆写** `locked["noise_mask"]`——上游 SetLatentNoiseMask(5107)带入的 mask 在 5014 恒被冲掉,该路在本引擎恒无效。探针实证:`fusion/probe-1119/`(p1z 真帧差 43.58dB;p1c/p1-t≡直通=Switch 洗清);陶艺对拍 B 臂增益实归 VOSR2+face_only 贴回,与潜空间遮罩无关。**修正=砍 5105/5106/5107 与中链 5112,5013→5014 直连复原正典原链。**
3. **SAM3 文检在 crop 画布零命中→全零 mask 静默直通(已砍)**:根因链(全源码行号)——SAM3_VideoTrack 文检"face"在 5011 的 768 crop 画布零命中(`comfy/ldm/sam3/tracker.py:1790-1791` packed_masks=None)→ SAM3_TrackToMask 静默返回全零 torch.zeros(`comfy_extras/nodes_sam3.py:498-500`)→ H3FaceStitch masks 分支 mm_≡0 直通(`ComfyUI-H3-FaceRefine/nodes.py:2342-2344`)。实弹证据:`dualmode/hd.mp4`(5024.masks=5104 旧接法)脸区对源 rmse 1.93/3.16=A2 直通级,VOSR2 增益整体缺席;`dualmode/maskprobe/`(crop 三帧 mask 实拍:f000/f060/f156 三态,"face"全零/"person"=98.5% 全画布人形非脸,**提示词修法不可行**;发起器 `dualmode/probe_mask_1119.py`);`dualmode/compare.md` 路由定谳段。注意:1118 融合役陶艺写实 crop 曾有微命中(白区 0.039%)——文检命中依画布域漂移,不可靠,且写实域增益从未被正向拆分实证。**修正=砍 5101-5104,5024.masks 恒悬空(face_only)。复活路径见 §七。**
4. **修脸条件空转**:发车时 #25 身份句被填空串(沿用模板默认)→模型无重绘方向。**修正=发车必填 #25 身份句**(见 §四)。
5. **对拍素材假信心**:陶艺素材(写实+脸大+源脸只柔不糊)恰好全走增益长板,曾判「B 全面胜」过快;ch002(动漫+远景小脸 45px+真糊团)才暴露体制冲突。**修正=对拍素材必须覆盖产线真实域(动漫/远景/小脸),至少两类题材;跨生成视频禁止直接当对拍参照(恒同源同生成同帧号)。**
6. **scp 直传引擎 input 会建同名流氓目录**(文件落不进目录里)→ GetVideoComponents Errno 2(LoadVideo 却能读=假绿)。**修正=恒走 /upload/image HTTP 且带 filename 参数**(curl -F "image=@file;filename=dst.mp4")。
7. **H3FaceTrackCrop 签名漂移**:引擎现版 `absent_frames`→`absent_shots`(off/by_identity),旧件 UI 存档的 widget 位校验会弹错;发车转换时补 `absent_shots:"off"`。
8. **无音轨源视频炸 AudioLock**(5014 `audio["waveform"]` None)——喂源前 ffprobe 验音轨,无则 ffmpeg 补静音 aac。
9. **A2 参照系陷阱(1119b)**:A2 正典臂对源 rmse 仅 3.14/1.93=**≈源直通**(编码噪声级)——真改脸的臂不可能≈A2;对拍锚须用「真源」或「另一同链渲染」,勿拿直通级参照写「同链应近同」红线(`dualmode/compare.md`/`a2-recheck.md` 定谳)。

**缓存逐出坑(1119 终版直发实证)**:双态连发之间若有他链任务插队执行,节点缓存被逐→第二发全量重跑(时长翻倍),且同 seed 两跑 p3 漂移 RMSE≈25(引擎本底非确定)→两态互差被漂移淹没。**对策:双态连发间守住队列;对比判据用「各自 vs 自己的 p3」环,不用两态互差。**

**引擎与环境口径(1119 彻查补)**:

## 六、验收方法

1. 抽帧:远景段+特写段各 ≥3 帧(ffmpeg select 表达式 `eq(n\,60)` 转义);
2. 多态并排:源 vs 产物 vs 参照(**同源同生成同帧号**);脸区 4x 裁片逐官判读(眉/眼/鼻/唇);
3. 量化:脸区 Laplacian 方差(锐度 lap_ratio)+对源 RMSE(改动面——**必须有真贴回量级,≈编码噪声级=直通嫌疑**)+背景区 RMSE(应=编码噪声级,验证只动脸);
4. 红线:远景四官不低于源;特写不抹细节;无贴回缝;身份零漂;表情/口型保持;高清档须「锐度反超+rmse 真贴回」双证(单看锐度会被直通侥幸骗过,f156 hd 7.2≥far 6.9 式假成立前科在案)。
