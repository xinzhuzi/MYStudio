# 跨镜连续性编译与质检规范(0928)

> 来源与性质:2026-09-28 外部课程方法论(逐镜独立生成视频场景下的跨镜连续性管理)学习消化,本文为**自研改写表述+漫影产线对照落点**,不复制原文,不涉来源方任何专名与包内文件/技能名。
> 一句话定位:**跨镜连续性 = 逐镜可机检的状态记录,不是祈祷**——每个镜头的入场状态必须由本镜数据显式交代,每条正式提示词必须自带完整物理事实,不依赖"上一镜"语境。

## 〇、适用范围与总则

**适用范围**:我方「分镜表 → 逐镜图像/单镜视频 → 章节组装」链条上的跨镜状态延续。单镜内部质量(构图/美术/音质)不在本规范内;工作流画布侧布局另见 [画布布局规范-0928.md](./画布布局规范-0928.md)。

**总则三条**:

1. **状态显式化**:凡影响下一镜观感的状态,必须在分镜表列、连续性状态或参考清单里各就各位;写「与前面一致」= 没写,审计判失败。
2. **产物自包含**:正式编译产物(最终提示词)必须能独立发给模型——模型既看不见规划对话,也看不见上一条视频;一切镜间关系须在编译时展开为完整物理事实。
3. **判定有据**:连续性判断(尤其轴线)落在场景地标+世界位置+前后镜图证上;证据不足标「待确认」,不武断、不自动改戏。

## 一、连续性状态字段清单(核心表)

八组字段,每组封一类跨镜断裂。列=字段组 / 它封什么断裂 / 我方现有承载(行内锚点) / 缺口与提案。

| # | 字段组 | 它封什么断裂 | 我方现有承载 | 缺口与提案 |
|---|---|---|---|---|
| ① | **世界位置**(人物相对场景地标) | 换机位后人物在场景里"瞬移",观众地理感崩塌 | 部分:场景资产版本携 `sceneViewpointId`/`spatialLayout` 且入内容指纹(apps/frontend/lib/studio/visual-continuity.ts:43-63);逐镜语义携 `sceneViewpointId`(apps/frontend/types/studio-storyboard-types.ts:40) | **缺逐镜"人物相对地标"的显式记载**——视点与布局挂在场景资产上,人物侧无世界坐标语义。提案:以「地标+相对关系」句式在分镜层落位(见 §二),字段方向见 P2 |

| ⑥ | **动作阶段**(动作完成到哪个可见节拍) | 上一镜手抬半空、下一镜已放下 | 已有:`actionIn`/`actionOut` 承接惯例(手册 storyboard_table_techniques.md:98-100);连续性状态镜级与人物级双载(apps/frontend/types/studio-storyboard-types.ts:16-17,:70-71);编译【动作承接】段(visual-continuity.ts:339) | 基本齐备;与①世界位置的联动记载(边做边走位)待 P2 |
| ⑦ | **台词进度**(分段编号/本镜完整文字/唇与呼吸状态) | 台词跨镜断句错位、口型对不上、字幕与语音漂移 | 部分:分镜项 `lines`/`speaker`/`speakerId`/`ttsSpokenText`(apps/frontend/types/studio-storyboard-types.ts:172-176);TTS 配音烘进每镜(.agents/skills/mystudio-workflow-integrity-testing/SKILL.md:209)与字幕 50 句级 cue(同件 :210) | **缺三件:分段编号+本镜完整文字+唇/呼吸状态**。提案见 §五与 P4 |
| ⑧ | **首尾帧参考在场性**(首/尾帧是否有实际可用图片) | 首帧无图靠模型脑补;尾帧与下一镜接不上;首尾同帧出"静止片" | 部分:`StoryboardKeyframe` I1-I4 不变式(apps/frontend/types/studio.ts:143-160);末帧交接惯例(docs/comfyui-kb/分镜H3视频产线.md:121);首尾同帧≈静止警示(同件 :105);旧镜回接 `origin: legacy-shot`(apps/frontend/types/studio.ts:157) | **缺"在场性"作为状态字段**(有图/待补/缺失三态)。提案见 P2 |

**读法**:

- 「我方现有承载」列为**已核验锚点**,后续核账按行内 file:line 直达;载体分三层——分镜表层(人写,手册管)、连续性状态层(`ShotContinuityState`,机器对账)、参考清单层(`orderedReferenceManifest`,图证职责)。
- 「缺口与提案」列只立方向;立项与补丁一律走 §七提案编号,不在本表内夹带。
- 八组字段是**审计对象全集**:任何一组只能写出「与前面相同」时,按总则 1 判失败、回到对应层补全后再编译。

**补充裁定(⑤光源,我方对包方法的本方化改造)**:

- 光源连续性**只走场景资产版本引用**:该镜引用哪个场景版本/视点,光影就由它携带;`scene-viewpoint` 主场景唯一性已由审计强制(apps/frontend/lib/studio/visual-continuity.ts:305-325)。
- **换光源=换场景衍生版**(夜景版/雨天版/火光版),不为光影在分镜表逐镜手写光源描述——与产品手册现行铁律同向(storyboard_table_techniques.md:73)。
- 本规范不做、也不提案做:在 `spatialRelation`/`description` 等分镜字段里补光影词表——那是开倒车。

## 二、双位置双写规则

**规则**:机位变 → 世界位置不变、画面位置可变。每个新镜头必须**同时落两写**:

1. **世界位置写**:人物相对场景地标的位置(地标名+相对关系句式);
2. **画面位置写**:新机位参数(机位方位/景别/焦段)+ 从该机位看到的人物画面落位(`spatialRelation` 3×3 网格取值)。

只写「人物还在原来的位置」这类含糊表述 = **审计失败**(总则 1:没写)。

**与既有载体的衔接**:

- 画面侧直接复用 `spatialRelation` 网格(apps/frontend/assets/studio-manuals/production_skills/storyboard_table_techniques.md:137-150)与 `orientation` 列(:103-107);
- 世界侧借「空间锚点链」写法——每场景固定「地标物+画面相对位置」逐镜继承(docs/comfyui-kb/参考_拼接衔接锁与一致性锚点.md:43);场景视点锚定复用 `sceneViewpointId`(apps/frontend/types/studio-storyboard-types.ts:40),世界位置记载不另造场景实体,只做逐镜人物侧的相对关系描述。

**自拟示例**(场景:书斋夜谈;空间锚=紫檀书案+西窗):

| 镜 | 世界位置写 | 机位写 | 画面位置写(spatialRelation) |
|---|---|---|---|
| SH07 | 沈砚立于紫檀书案南侧,背朝西窗 | 书案正面偏东,中景 | `沈砚(中中)` |
| SH08 | 沈砚仍在书案南侧,未移动 | 西窗内侧过肩俯拍 | `沈砚(左后)` |
| SH09 | 沈砚绕至书案北侧,与窗对望 | 书案正面偏东,中景 | `沈砚(中中)` |
| SH10(违规) | "沈砚还在原处" | 窗侧近景 | `沈砚(左中)` |

读法:SH07→SH08 换机位,世界位置两行一致、画面落位从中中变左后=合法双写;SH07→SH09 机位不变但世界位置变了,须在动作列给出绕行衔接动作(与朝向变化同规则,storyboard_table_techniques.md:107);SH10 判失败——世界位置无地标无相对关系,「还在原处」是典型含糊指代。

## 三、每镜双保险(参考图+完整文字,缺一不编译)

**正式视频镜默认同时需要两件**:

1. **本镜参考图**:能代表本镜构图的首帧/分镜图;
2. **完整文字状态**:人物、场景、动作、道具、对白的全量正向描述(编译产物级,非缩写)。

二者缺一,该镜停在「待补」,不得编译为正式提示词。

**分情形规则**:

| 情形 | 参考图 | 文字 |
|---|---|---|
| 同机位续动 | 可用前镜尾帧作首帧参考——对接我方 `keyframes` 的 `origin: legacy-shot` 回接(apps/frontend/types/studio.ts:157)与末帧交接惯例(docs/comfyui-kb/分镜H3视频产线.md:121);注意首尾同帧≈静止警示(同件 :105),两帧必须有真实差异 | **仍须全量重述**,不得因"接着上一镜"省略任何状态 |
| 换机位/景别/焦段 | **必须本镜新构图参考图**;身份参考图(角色定妆照/场景卡)不得冒充本镜构图——职责分离由 `referenceManifest.referenceRole` 承担(canonical/scene-viewpoint/prop-state/previous-approved-frame 等闭集,apps/frontend/types/studio.ts:186) | 同上,全量重述+按新机位改写画面位置段 |
| 参考图缺失/不可读 | 停「待补参考图」,不编译正式提示词 | — |

**最终提示词禁止指代词**(自拟等义中文禁用词表;清单本身为公共中文词汇的自述规则,规则=凡在编译产物中出现下列指代、须展开为完整正向描述后才放行):

> 上一镜 / 上一镜头 / 前一镜 / 刚才 / 此前 / 如前 / 接上文 / 见前文 / 同上 / 照旧 / 依旧 / 仍保持 / 保持原样 / 继续 / 接着 / 和前面一样 / 与前镜一致 / 沿袭上镜

**双层规则**:

- **缩写合法层**:计划文件/分镜表内部**可以**记「首帧源自 SH07 尾帧」——账要记得省,人和审账的工具都读得懂;
- **展开义务层**:编译产物**必须**展开为人物位置、姿势、道具、场景、对白的完整正向描述——模型只读产物,不读账。

**双轨测试稿**:允许「非正式测试稿」纯文字先行(对齐我方两档生成法的运动草稿经济学,docs/comfyui-kb/分镜H3视频产线.md §九),但不得登记为可生成正式版本。

【跨域边界】本节清单与 `.agents/skills/h3-prompt-writing/references/direct-zh.md` §二 的禁指代词条目同义但各治各产物:该件管单条 H3 提示词文本怎么写,本规范管分镜表→编译产物→审计链(含双层规则与 P3 机检提案);两文互链,不互抄解释段。

## 四、轴线三判据

我方既有 180° 视轴守恒铁律已立两态:同场景角色画面位置/朝向同侧锁定;变化须在动作列给出转身/转头衔接动作并同步更新朝向列(apps/frontend/assets/studio-manuals/production_skills/storyboard_table_techniques.md:54,:107;提示词侧同规则 storyboard_prompt_techniques.md:330,:362)。本规范在此之上补**第三态与判法**。

**判据优先级**:**场景地标+世界位置+前后镜图证 > 画面左右**。画面左右变化本身不等于越轴——换机位本就可能换左右(§二)。

**三态处置表**:

| 态 | 判定 | 处置 |
|---|---|---|
| ① 有动机换轴 | 镜内可见摄影机绕行 / 人物转身 / 运动穿轴 / 中性重建空间镜头(定场类)建立新轴 | 放行 |
| ② 无过渡硬切越轴 | 前镜固定在互动轴 A 侧、本镜固定 B 侧,且画面与镜头计划均无过渡证据 | **拦截该镜正式编译,交人工裁决**;不得静默改机位 |
| ③ 证据不足 | 图片或空间依据不够(缺本镜图/缺前镜图/缺世界位置记载) | 标「待确认」:不武断判越轴,不自动改机位,补证后重判 |

**判定步骤**(自上而下,首个成立即止):

1. 找前后镜的**稳定参照物**(视觉锚点):门、窗、楼梯、桌椅、地平线、主光方向等;
2. 依锚点判人物相对地标的**世界位置**与互动轴线两侧的机位归属;
3. 对照分镜表世界位置写(§二)与前后镜实际图片,确认有无 ① 态过渡证据;
4. 仅当 1-3 均无法落判时进 ③ 态。

## 五、长台词跨切与声音身份

**拆段与编号**:超长台词按标点、换气、语义转折拆段,给分段编号(格式建议:`S{镜号}-D{台词序}{段序}`,如 `S07-D2a`/`S07-D2b`;与 P4 衔接)。

**本镜完整文字**:每镜提示词写**本镜实际要说出的完整文字**——写的是"这一镜嘴上将出现的每个字",不是剧情梗概;禁止「把上一句说完」类指代(与 §三禁指代词清单同源同判)。

**自拟拆段示例**(一句长台词跨三镜):

| 段编号 | 所属镜 | 本镜要说出的完整文字 | 唇/呼吸状态 |
|---|---|---|---|
| S07-D1a | SH07 | 「你可知这十年,我把那封信读了几遍?」 | 说话者唇动;听者闭合 |
| S07-D1b | SH08 | 「每一遍,都当你在跟我说话。」 | 画外声——说话者不出画,听者反应镜唇闭 |
| S07-D1c | SH09 | 「如今信还在,人却回不来了。」 | 说话者重新入画,唇动;末字后换气收住 |

**声音身份锁定**:同一角色的音色/口音/基础语速**逐字锁定**,情绪只按表演节拍调。对接我方 TTS 绑定现状:分镜项 `speaker`/`speakerId`/`requiresFixedVoice`/`voiceProfileId`/`voiceMatch`(apps/frontend/types/studio-storyboard-types.ts:172-187)、TTS 配音烘进每镜(.agents/skills/mystudio-workflow-integrity-testing/SKILL.md:209)。

**切听者反应镜**:镜头切到听者时,说话者标**画外声**;显式写明唇属于谁、谁保持闭合——先例=旁白画外音时人物口型闭合标注(docs/comfyui-kb/参考_拼接衔接锁与一致性锚点.md:35)。

【跨域边界】本节只管跨切时的状态延续(分段编号/画外声/唇归属/声音身份);台词容量与时长预算的折算机制归 [docs/research/PIPELINE_METHODS_ABSORPTION_ANALYSIS_2026-09-28.md](../research/PIPELINE_METHODS_ABSORPTION_ANALYSIS_2026-09-28.md) 提案二,此处互链不展开。

## 六、受影响区间重算

**规则**:改一镜后,只重算「从该镜起、直到状态重新稳定」的连续区间,不重跑无关场次。

- **区间下界**=被改镜;
- **区间上界**=首个入场状态不再依赖被改镜的镜头(其后各镜的世界位置/道具/台词进度均可独立成立);
- **关键帧过期**:依赖旧首/尾帧的关键帧标**「过期-禁止使用」**,新帧另存版本;不得旧图配新镜清单。

**我方现状锚点(机械已有,语义待升格)**:

- 级联过期:`markContinuityDependentsStale` 把同组下游已审行标 stale 并打回待审(apps/frontend/lib/studio/visual-continuity.ts:567-599)——现语义=同组下游全区间(保守可靠),尚无"状态重新稳定即止"的上界;
- 单镜提升:提升计划支持 `selected_shot` 只动目标镜、其余镜零扰动(apps/build/chapter_video/tests/test_promote_chapter001_storyboard_continuity.py:213-235;store 夹具 :102-108)——机械上已能单镜收口;
- 修复链:只从既有工作流推导结构连续性元数据,不重生图不删资产(apps/build/chapter_video/repair_chapter001_visual_continuity.py:1-8)。

本节的升格方向见 P5:把「单镜机械能力」升为「区间语义规则」。

**自拟区间示例**:SH05(改:人物持灯入屋)→ SH06(同场接灯,依赖 SH05 尾帧作首帧)→ SH07(同场,灯已放上桌、台词进入新段)→ SH08(切新场)。区间=SH05~SH07:SH06 入场状态依赖旧尾帧(关键帧标「过期-禁止使用」),SH07 依赖 SH05 的灯位与 SH06 的台词进度,SH08 换场后入场状态独立成立=上界。SH08 起不重算、不重审。
