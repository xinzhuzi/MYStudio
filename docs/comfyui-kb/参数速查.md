## 前端缓存四层(改完东西界面不对,按序排查)

1. **画布内存态**(最常见):打开的 workflow 活在前端内存里,我改磁盘 JSON 不会同步进去。→ Workflows 侧边栏刷新,重新打开文件。
2. **侧边栏列表**:新写入的 json 不出现在列表。→ 同上,刷新按钮 / Cmd+R。
3. **前端重载**:界面显示异常、和实际状态不符。→ Cmd+R 整页重载;以下仅为独立 Comfy Desktop 的旧排障记录，不用于当前托管引擎：顽固时退出 Desktop,清 `~/Library/Application Support/Comfy Desktop/` 下的 `Cache` + `Code Cache`(2026-09-05 实测仅 9.9M,不是主因,但更新后偶发混入旧资源)。
4. **后端执行缓存**:改了参数输出没变(尤其 seed 相关)。→ 换 seed 再 queue;自定义节点不重跑 = IS_CHANGED 问题,bust 一个输入。

另:装新节点/新模型后必须重启 ComfyUI(节点注册只发生在启动时)。
