## 稳定核心口径(comfy_fire_core.py)

- **失败分类重掷**:空片/画幅/alpha 内容判废→换 seed+1000 重掷一次;确定性失败(门禁拒单/`_gongbi`/主体句/node_errors/**HTTP 4xx 拒单**/上传防线/模板断言/**输出缺失**)不重掷直报;超时/断连/HTTP 5xx→瞬时失败重掷前**先过队列清零闸**。
- **批次停线契约(入口层责任)**:批量入口(stage_fronts)遇瞬时类失败(含 queue-busy)**全线停线不再发下一件**——队列闸只管重掷这一发,批内「失败后继续发下一境」=并发在途通道,由入口层 break 承担。
- **deadline 可配**:env `MYSTUDIO_FIRE_DEADLINE_S` 或 CLI `--deadline`(缺省 900)。
- **空片门禁阈值不变**:<400KB / 非背景占比<8%;背景锚=边界环中位(env `MYSTUDIO_FIRE_ANCHOR=pixel` 回旧单像素口径);alpha/画幅门为入口①专挂(阈值见上表)。
- **上传三层防线/内存纪律入核心**:`upload_image`(overwrite=true+引擎返回名+md5 回拉)、`maybe_free_memory`(空闲<30% 先 /free,**失败吞错记日志**——止损动作不得变新故障点),两入口每次尝试(含重掷)同受检。
- **显式重做通道**:`--force --seed`(替代旧 `import fire_once` hack;幂等跳过仍为默认)。
- 两掷即止,无第三掷(死循环止损);真源防篡改=kv 脚本内冻结指纹锚(`FINGERPRINT_ANCHOR`,改真源须同步改锚)。
