# 参考：拼接衔接锁与一致性锚点协议

> 来源与性质：2026-09-15 竞品（TE MAN 插件技能库）方法论学习消化（其 license 允许学习阅读），本文为**自研改写表述+漫影产线对照落点**，不复制原文。排查背景见 [参考_TE-MAN可吸收排查.md](./参考_TE-MAN可吸收排查.md)。

## 一、多镜拼接五大衔接锁（逐镜生成 → 拼成一部片）

逐镜独立生成的视频直接首尾相接，观众会感到"不是一部片"。五把锁各自封一种断裂感：

| 锁 | 封什么 | 要点 |
|---|---|---|
| **口型锁** | 台词镜切换时的嘴型跳变 | 切点落在句间停顿或强鼓点上；**禁止在元音发声中途硬切** |
| **节奏锁** | 镜间节奏割裂 | 以 1/4 或 1/8 拍为网格对齐切点；需要时用变速（Speed Ramping）把动作压进节拍 |
| **色彩锁** | 跨批次生成的色温/风格漂移 | 全镜共用一条全局美学头部（风格描述）；后期统一加同款胶片颗粒/LUT 掩盖批次差 |
| **空间锁** | 空间跳跃感 | 上一镜**尾帧作下一镜首帧**（首尾帧链）；或同向运镜衔接；或 Match Cut（动作/构图匹配剪辑） |
| **文字动态锁** | 贴字/字幕的动态突兀 | 文字出现/消失跟随节拍点（如重音砸入、随低频破碎），前后镜动态语言一致 |

**Master Audio 母带独占**：分段生成严禁各自携带独立断裂音轨——BGM/音效一律对齐母带时间戳在成片层合成，单镜只出画面+台词声。

**漫影落点**：单镜视频生产（H3 单镜）→ 章节组装链。组装器已有两段式衔接，可对照此五锁逐项自检（尤其空间锁=尾帧→首帧链与 H3 FL2VA 形态天然匹配——若未来补首尾帧节点档位）；声音侧漫影走 Remotion 母带混音，天然符合 Master Audio 原则。

## 二、分镜质控机检硬门（生成前的表级质检）

分镜表写完 ≠ 能用。六项硬门全部可机检（LLM 可自查，代码可校验）：

1. **hook 密度**：镜头表必须有叙事钩子分布（受控词表：铺垫/视觉笑点/反转/揭示/回调/悬念/温情/追逐/表情节拍/高潮），不得整表平铺直叙。
2. **单镜时长 ≤15s**：AI 视频单镜上限，超限拆镜。
3. **单镜角色 ≤3 个**：超员拆镜或改群演远景。
4. **空间锚点继承**：每镜的空间锚点必须从上一镜继承（见第三节），凭空换场景=断链。
5. **每秒指令覆盖**：镜头描述按秒推进时，每一秒必须同时含五要素——动作/姿态/表情、镜头运动、空间位置、音频线索、与下一秒的交接。
6. **跨镜连续性链**：上一镜的退场状态 = 下一镜的入场状态（人物位置/朝向/手持物）。

配套字段参考（六列镜头表）：镜号&时长｜连续性衔接｜参考锚点｜hook 类型｜镜头描述（秒级指令）｜音频与对白轨（旁白镜须标注闭嘴：旁白画外音时人物口型闭合）。

**漫影落点**：导演规划链生成分镜表后加一道机检步骤（可做成纯提示词自查清单先落地，后续再代码化）；分镜表字段漫影更全（景别/运镜/时长/声音/关联资产），补的是"质控门"不是字段。

## 三、一致性锚点协议（跨镜不漂移的写法）

一致性问题本质是"锚点没有显式化"。三种锚点工具：

**1. 空间锚点链**：每个场景固定一个"地标物+画面相对位置"（如"断云崖石碑-画面左三分之一处"），逐镜继承；配光位基线（如"暮光从画面右侧来"）。观众与模型都靠它感知"还在同一个地方"。

**2. 身份锚点捐赠清单**（参考图怎么用才不污染风格）：参考图向生成**只捐赠**身份信息——脸部轮廓/发型/眼镜/五官比例；**不捐赠**摄影质感/皮肤纹理/现实光影。写法上显式声明："仅提取身份特征，忽略原图质感与光照"（防真人照片把写实质感带进风格化渲染）。

**3. 参考卡一卡一职**：人物参考卡/场景参考卡/文字参考卡严格分离，每张只负责一个窄域——一张卡既当人又当景，必然互相污染。

**漫影落点**：参考图体系（1+3 自动装配）可照此立规——装配提示词中显式写捐赠/不捐赠清单；角色参考图与场景参考图的提示词分工写死；空间锚点链可进导演规划链的场景卡字段。

## 四、⚠️ 宫格版式泄漏警示（重要失败教训）

**宫格图直接当视频/生成的参考图，模型会把"宫格版式本身"带进成片**——九宫格参考出来的画面常自带分格线或九联构图。正确用法：

- 宫格**只作中间产物**：一次生成多镜概念图 → **切割成独立单图后**，单图再作参考/关键帧（v1.0 竞品演示的正是这条管线）；
- 需要多张独立锚定参考图时，直接生成多张独立图，不要走宫格。

**漫影落点**：本教训直接约束 P2 宫格对拍实验设计（切割后才回灌）与未来正式流的说明卡；参考图规范收录此条。

## 五、流程治理三件 + 负向默认值

**1. 确认门 + 回退阶梯**：高成本动作（出图/出视频）前必有低成本确认物（分镜表/确认图/静帧）；失败不先烦用户——第一败强化锚点重试，第二败降载/缩时，第三败换法，三败才报告并给选项。默认推荐项置顶，"继续"=选推荐（确认词白名单：确认/继续/生成 即放行）。

**2. 最新资产纪律**：任何资产重做后，下游引用链全部指向新版本；禁止静默混用新旧版本（版本漂移是批量生产最常见的隐性烂片源）。

**3. 轻量旁路**：只要单图/单镜/只要分镜时走快捷路径，不强制跑全流程——小需求不背全流程债。

**负向默认值**：把"默认不做的事"写成硬规则（默认不加 BGM/旁白/字幕，除非明确要求）——治理的是 LLM/流程自作主张，不是模型能力。

**漫影落点**：AI 编排链（导演规划→分镜→批量生成）对照补缺：批量生成的失败重试阶梯（本任务 P3 落地）；生成版本引用走指纹体系（已有，天然满足最新资产纪律）；轻量旁路对应"只要单镜"场景的入口直开（已有单镜直开，符合）。
