## 三、上色指令配方(核心设计,动作锚方法论迁移)

**模式A·文字描述**(默认预填):
```
为这张画稿完整上色:{色彩段:她的头发呈__色,服装为__色,背景为__色调};
保留画稿的全部轮廓线条与细节,线条清晰不丢失;
她的人物身份、姿态与构图保持与原图完全一致。
```

**模式B·参考图取色**(接 image_b 时):
```
参考第二张参考图的配色,为这张画稿完整上色;
保留画稿的全部轮廓线条与细节,线条清晰不丢失;
她的人物身份、姿态与构图保持与原图完全一致。
```

**画稿类型适配段**(说明卡给三段可插拔):
- 素描稿附加:「参考原图的明暗关系上色,保留明暗体积感」
- 半成品色稿附加:「已上色区域保持原色不变,仅补全留白区域」
- 裸露画稿:色彩段正常写肤色/场景色(破限链已兜审查,无需特殊句式)

**配方铁律**(从褪衣线迁移):禁否定句(「不要改变线条」×→「保留线条」✓)/色彩段具体到色名/单目标(一次只上色不叠加其他编辑)。

## 六、备选路线全景(Plan B~F,主路线= krea2edit 失败时逐级启用)

**触发条件**:主路线冒烟验收不过(线稿结构崩,runbook A1 阶梯走完仍崩),按下列顺序启用。

### Plan B·图生图式(快速对拍,半天内)
线稿 VAEEncode→KSampler,denoise 矩阵对拍(0.85/0.90/0.95/1.0 四档,同 seed 同指令)。
K2 是 t2i 出身没有 img2img 专项训练,预期保线弱于 krea2edit,但矩阵扫一遍成本低(4×~2min),可能撞到可用档。破限链沿用。

### Plan C·线稿叠底两遍法(数学保线,最强兜底,推荐备选)
```
线稿 ──┬→ [主路线上色] → 彩色图 ─→ ImageBlend(multiply) ─→ 成品
       └────────────── 线稿 ────────┘
```
原理=传统数字上色:**彩色层 × 线稿层(正片叠底)**,线条区域数学级保留(乘法把白底变透明、黑线压暗成线),零 AI 不确定性。
- 实现零下载:core 节点 ImageBlend(mode=multiply)即可;线稿若为灰度扫描先去底噪(Threshold/Levels 类节点,LayerStyle 包在库)
- 与主路线组合形态:主路线 A1 崩到什么程度都能用——上色图哪怕线条糊了,叠上原线稿后线条立刻清晰;代价=线条覆盖处颜色略暗(可叠加一层 Screen/柔光补亮,调到自然)
- 这条路与「两步贴脸管线」(褪衣线余弹方案)同思想:AI 生成色彩 + 原像素保结构

### Plan D·等 lineart Control 权重(被动,零成本)
关注清单(每月查一次即可):[tori29umai/krea2-controlnet](https://huggingface.co/tori29umai/krea2-controlnet)(lineart=Planned)+ thedeoxen(已发 FLUX.2 版,K2 版可能跟进)+ facok 插件 README 权重表。发布后:装 facok 插件+下权重,主路线升级为 Control 管线,保线上限最高。

### Plan E·特批第二模型(最后手段,需用户特批)
Qwen-Image-Edit-2511+着色LoRA([现成方案](https://visionpaletteai.com/products/qwen-manga-colorization-comfyui-workflow))。违反单模型原则(历史两次否决),仅在 B/C/D 全灭且需求刚性时提请裁决。

### Plan F·自训 mini Control LoRA(远期)
tori29umai 配方公开(10.6万对+两阶段+rank64);缩小规模(几百对线稿/成品,可用本机 K2 自己造数据:成品图→lineart 预处理→配对)可训弱版。工程量大,仅当上色成为高频刚需再立项。

**路线决策树**:主路线崩→B 对拍(半天)→不行→C 叠底(当天可用,质量下限有保障)→C 的色彩质量不满→D 等权重(被动)+C 顶日常→需求刚性且等不及→E/F 特批。
