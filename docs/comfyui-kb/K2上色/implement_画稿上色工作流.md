## 实施清单(顺序)

1. **[核对]** object_info:`Krea2EditGroundedEncode.image_b` 与 `Krea2EditModelPatch.source_image_b/source_latent_b` 的类型与语义(双图接法);`LoadImage` 多实例无冲突确认
2. **[找图]** 检查 `input/` 有无线稿测试图;无→请用户提供(不代生成)
3. **[构建]** 复制稳定流 → 改造:改指令预填(模式A)+新增 [46]LoadImageB/[47]缩放B/[48]VAEEncodeB(模式B链,image_b 接通)+SaveImage 前缀改 `Krea2_上色_`+说明卡重写+ref_boost 1→4+节点标题重编号
4. **[静态自检]** JSON 连线一致性/悬空扫描(零连线死节点)/包围盒重叠/required 输入全覆盖(参照既有校验清单:零连线扫描+多源正向遍历)
5. **[冒烟]** API 提交(普通内容线稿,seed 固定),验收:无 execution_error+线稿结构可辨+色彩符合指令;**读完结果立即 POST /history 自清**
6. **[交付]** 报告+刷新提醒+防覆盖警告(旧标签页勿保存)

## 验收标准(从 PRD 继承)

- 同一张测试线稿:轮廓/五官/服装形态不崩、色彩符合指令描述
- 模式B(参考取色)单独验一次(可延后,用户令时)
- NSFW 画稿破限生效(R2 首跑观察项)
- 用户人眼终裁

## 回滚点

- 稳定流原文件不动(新建文件,零侵入)
- 新文件失败→删除即回滚,无模型/插件变更(零新依赖)

## 完成定义

冒烟图过用户验收 + 文件落位 `K2图像/上色/` + PRD 标记终态

## 支持需求清单(需要用户/外部提供什么)

| # | 项 | 说明 | 状态 |
|---|---|---|---|
| S1 | **一张测试线稿** | 普通内容(非NSFW)即可,常见比例(2:3/3:4),放 `input/`;不代生成(AI 造线稿会偏离真实画稿分布,验收失真) | 实施第2步检查,无则向用户要 |
| S2 | 实施批准 | 本计划已交,等用户点头 | **待批** |

| # | 项 | 说明 |
|---|---|---|
| S3 | 一张彩色参考图 | 模式B(取色)验收用;色调鲜明的成品图最佳;延后到用户令时 |
