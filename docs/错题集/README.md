## 二、共通错根（三册合并视图）

作图域八病（详表见 [作图错题集](作图错题集.md) 〇节）：①一手源在手边却绕开 ②把「过门禁/全绿」当「审过/验过」 ③拿自己的判断替代用户的决定 ④只验自己改的那一层 ⑤归因靠排除法不拉一手证据 ⑥工具建了不焊进流程 ⑦把 AI 读数当终审 ⑧没数完样本就说「全部」。

运维域六病（详表见 [Agent运维错题集](Agent运维错题集.md) 〇节）：①未验证就断言 ②并发账不算就发车 ③运行时黑盒机制不摸清就上 ④组合故障单层修 ⑤部署链不看消费面 ⑥拿探针/旁证当证据。

**跨册的三条总根**（凡报结论前自问）：

1. **未验证就断言**——「调了=生效」「部署了=生效」「取代了=安全」「测试绿=审过了」，同一类病横跨三册；一切系统行为结论必须实测读数/实物对账后才许出口。
2. **一手源绕开**——凭记忆、文件名、下拉框值、探针、侧信道拼结论，不开真源文件/日志/原包；判定权在用户，我的读数只当参考呈报。
3. **没数完样本就报「全部」**——以读过的子集当全集（42 角色 vs 201、「可做范围」vs 10 卷 4125 章、首版错题集自身漏 25 条）；带数字的逐个数，数完再说。
