## A. 画风与镜头方向的实证边界（zenstory，2026-11 A/B）

1. **文生模式天生偏真人实拍。** 正文写「国漫二次元、线稿、平涂」8 次中 5 次出真人；写「半写实三维国漫」6/6 全真人。
   **正解**：正文第一句先写媒介（`A 2D hand-drawn anime animation ... not live-action, not photographed,
   no real actors`），每个 `[Shot N]` 后重复一次媒介，人物与材质描述里删掉 `realistic / photorealistic`——
   二维形态 2/2 保持；**风格化三维这样写仍不够（4/4 真人）**，正解=开场挂一张同画风起始帧走首帧模式
   （2/2 三切全保持三维）。生成后逐段看画风，不以提示词写了形态为准。
2. **首帧模式下转身/出画方向基本不听**：写「转向画面左侧的门」6/6 全转右侧；换「转向她自己的右手边，
   也就是画面左侧的门」3/3 仍全右侧。**正解**：朝向焊进起始帧；或多出候选挑方向；或剪辑在转身前切走。
3. **VO 闭嘴约束三级写法**（H3 首帧，正脸近景各 4 次）：只标画外旁白→2 张嘴 1 微张 1 闭；+「嘴唇完全
   闭合」→1/2/1；+「旁白者不在画面、画中无人动嘴」→1/1/2。文字约束有一点用但**靠不住**，生成后必须核对口型。
4. **动作终点写接触物不写距离**：「约二十厘米后停住」4 次中 3 次仍碰到杯子；「指尖碰到杯沿后停住」4/4
   停在杯沿。写不出终点接触什么=这一拍还没想清楚。
5. **秒点欠排不是解药**：8s 单人镜三写法（秒段只到 5s / 补「定住到 8s」/ 只写相对顺序）都没有计划外动作、
   放杯都落在 6–7s——**把余量分配给已有阶段**，别写定格块；秒点是计划记账不是精确落点，精确对齐靠剪辑。

## B. 对白与表演的实证配方（zenstory）

1. **反应镜四步配方（H3 专用）**：触发 → 一个情绪词点名（「他立刻震惊」）→ **两处**当前景别读得到的
   泄露（目光停住、拇指悬住 / 笑容停住、手臂收紧）→ 落点并定住；反应在触发后 **1.5 秒内**落下。
   盲评清晰度 3.9/5、自然度 4.0/5 全拍第一；只写情绪词=演过头（强度 4.3 自然度 2.8）；逐段写满可见反应
   =太弱（1.9）；「不动声色的得意」最易被读错。⚠️ 此配方是 H3 实测，Seedance 2.5 同轮对照以完整链最好，
   **禁外推其它模型**。
2. **中文语速锚 ≈4.1 可发声字/秒**（同镜 20 次生成；字数不含标点）。台词过长先赶词、再无报错截断；
   延长镜长可救。对白可用窗口 = 镜长 − 开场/收尾拍 − **开口前等待** − 不可并行动作 − 他人发声 − 末尾反应落点。
   提示词阶段禁删词/改词/转 VO——超载走「简化动作→重叠→请求拆镜/改词」四级。
3. **开口普遍迟到**：正文写「约 0.2 秒开口」，实测多在 **1.3–2.4s** 才出声（13 镜首帧实测）。排镜长时把
   等待算进去；开头死等可剪。
4. **两字人名单独喊最不稳**：三条候选喊同一个名字，逐字转写出三个不同近音名。这类镜生成后逐字听，
   名字念错画面可用→后期换这一声。
5. **口型归属写法**：台词跟在说话人的可见动作句后、`<d>` 外先交代画内/画外与音色；台词期间画里另有正脸
   时，明写那人不说（`The messenger does not speak; his lips remain completely closed.`）——实测 2/3 口型
   错落 → 3/3 全对。**更优解是调度**：让不说话者出画或背身（骑手出画/背对时 12/12 全对）。
6. **跨镜音色锁不住文字描述**：音色逐字写死、无参考音频时，H3 每条重挑一次声音，同一角色换镜换嗓子
   （13 镜实测）。**角色在 ≥2 镜开口 ⇒ 绑参考音频**（`reference` 档：重演本镜台词，不携带原话）；
   无参考音频的说话镜生成前列缺口，不靠文字凑。
7. **`non_diegetic_music: N/A` 显式写**：省略该层小样本出现过额外配乐；无画外配乐时写 N/A 不留空。
   无对白镜的嘴部按实际表演写，不一律闭嘴。

## C. 托管 API 方言与接口契约（官方 MiniMax-AI/cli）

1. **首/尾帧输入与参考输入互斥**（frame mode 与 reference mode 不能混；参考音频必须至少配一张参考图
   或一段参考视频）。**连续段**要同时用上一段实际视频+实际尾帧时：视频走 `reference_video`（`<Video 1>`），
   尾帧走 `reference_image`（`<Picture 1>` 只锚开场姿态构图）。续接链三纪律（zenstory delivery-profile）：
   ①双输入**职责不同不可缺一**——视频承接动作速度/表演/运镜/声音空间，实际尾帧锚第一帧姿态双手持物光线
   构图，不得用计划尾帧或文字描述冒充实际尾帧；②**漂移不得前传**——实际尾帧与已接受起点冲突时先处理
   上一段结果，不把漂移写进下一段继续放大；③**重新起链条件**——两段间是换景别/换机位/正反打剪接（上一段
   尾帧本就不是下一段开场）、时间地点跳变、或明确选独立重生成时，各段从各自已接受起点重新生成。
2. **超长删减序**：正文超上限时**先删已被真实参考帧承载的重复描述**；连续性锁、逐字对白、已批准画内
   文字位置不得删（zenstory target-model-profile）。**运镜降级写法**：目标端不认具名运镜术语时，把运镜
   写成可见的画面关系变化（主体占画比、边缘进出、前后景遮挡关系），不是换一个术语。短于时长下限的镜头
   可与同场相邻镜装进一次生成（H3 多镜容器须每切关键帧，见 D-4）。
3. **duration 为必填整数，4–15 任意值**（不是只有 5/10/15 档）；写在提示词里的秒数不能替代生成设置。
   **MiniMax-H3-Max 是另一型号**：5–15s、480P/768P、仅文生+首/尾帧、**不支持 full-reference**——勿把 H3 的
   参考音频路径或 4s 下限套到 Max。
4. **媒体预检表**：首帧/尾帧各 ≤1 张 ≤30MB；参考图 ≤9（JPEG/PNG/WebP，边长 256–5760px，宽高比 0.4–2.5）；
   参考视频 ≤3（MP4/MOV，H.264/H.265，23.976–60fps，各 2–15s，合计 ≤15s）；参考音频 ≤3（MP3/WAV，各
   2–15s 合计 ≤15s）；混合参考总数 ≤12；本地媒体 base64 后请求体 ≤64MB。
5. **8 段构造序**（欠指定提示词的展开顺序）：输出目标(时长/画幅/用途/连续感) → 主体与资产 → 时间线(按时间
   序+清晰转场) → 场景 → 镜头(景别/角度/运动/焦点/切换) → 观感(风格/色彩/质感/节奏) → 声音(对白/环境/配乐
   /音效/与参考音频同步) → 约束(保什么/避什么：身份漂移、闪烁、文字、logo、硬切)。用户已给完整分镜则
   **原样保留**，只查长度/时间戳覆盖/引用编号/媒体兼容/自相矛盾。
6. **两极时间线 + locked end state 链**（多参考图顺序分镜时）：主时间线每镜一段（精确区间+时长+参考图
   号+初始状态+镜头+微时间线+**锁定终态**），镜内再分 3–5 微拍（establish/prepare/core/settle/hold）；
   **镜 N 锁定终态 = 镜 N+1 初始状态**，边界核对六项：人物位置姿态、视线、双手占用、道具归属/位置、
   物理连接、机位侧。时间区间连续无缝无叠、末点=总时长；默认 0.5s 精度；交接动作按因果序写
   （谁先稳住接触、原持有者何时释放）。官方结构化分镜模板段名：`[OUTPUT SPECIFICATION]` /
   `[OVERALL LOOK]` / `[CHARACTER AND SPATIAL CONTINUITY]` / `[PROP STATE CONTINUITY]` /
   `[TWO-LEVEL TIMELINE AND REFERENCE MAPPING]` / `[STRICT ACTION ORDER]` / `[NEGATIVE CONSTRAINTS]`。
7. 参考图顺序=CLI 重复旗标顺序（`reference image 1, 2, ...`），正文引用编号与挂载顺序一致（见 D-5）。

## D. Full-reference 编号与表演转移（zenstory + Square-Zero）

1. **编号按挂载顺序**：第 1 张图=`<Picture 1>`，视频音频各自从 1 起。正文编号与实际挂载顺序不一致时模型
   收到互相矛盾的素材说明而**接口不报错**——写正文前先列槽位清单（顺序→标签）。
2. **槽位分工纪律**：起始帧只锚构图与姿态；身份只锚长相体态；地理只锚空间关系；造型状态只锚服装损污。
   写进 `retention_analysis` 各自的保留范围，**不让角色板顺带决定构图、不让场景板顺带决定人物长相**。
   L2VA（只给尾帧）短剧产线建议不用：开场权威在分镜不在模型推断。
3. **面部识别板**：近景/特写/说话镜、无起始帧锚脸、身份槽只有一张全身板时→同角色加挂第二张同 Look
   面部板（`<Subject 1> is the woman in <Picture 1> and <Picture 2>...`）。盲评更接近原脸，但两种挂法都
   把脸拍老、痣曾 2 次画成并排两点——**面部板不替代生成后逐项比脸**。
4. **多镜容器**：相邻镜装进同一次 full-reference 生成的三条件——每镜都有已接受起始帧；时长和 4–15s；
   一份参考清单（各切关键帧按切序排前、共用图在后）。正文第一行写对齐句
   （`<Picture 1> aligns with the 0.00-second mark as the opening frame of [Shot 1]; ...`）。实测 9s 三切：
   逐切挂关键帧→切点 2.88–3.04/6.00–6.04s 且构图贴近逐镜生成；只挂第一切→切点漂到 2.92–3.88/5.88–6.21s、
   第 2/3 切构图偏离、出现过一次多余切。**无逐切关键帧不装容器**（文生/首帧模式本就用 [Shot N] 切镜，不适用此条）。
5. **表演转移（把参考视频当表演而非身份）**：源表演者映射为独立 `<Subject N>`（权威管时序/节奏/口型/
   眼动/微手势），**不继承**其身份/服装/画风；目标身份住自己的 `<Subject N>`。多人转移锁定
   `SOURCE PERFORMER A → <performance Subject A> → <target Subject A> (S1)` 映射且全程不变：A 说话只有
   目标 A 对口型、B 只复现听反应；源静音时禁目标出说话口型；显式禁交叉映射与串嗓。音频归属显式声明
   （`<Audio 1>` 独属 S1）；不从录音猜台词文本。**跨媒介风格锁**：目标画风定义为独立 Subject 并
   `fully_preserved`，声明参考视频只供表演、禁转移照片级皮肤/发丝/光照；转移后的面部运动须保持目标
   画风原生（插画脸用插画嘴型动画，不许渐变照片化）；风格块在 `[Shot 1]` 前重申一次即可，别全文重复。
   微表演属性点名清单：音素口型与协同发音、下颌开合、唇形压缩/圆展/长元音保持、视线与全/半眨眼、
   眉动与颊部张力、呼吸联动——别只写 "lip sync"。唱歌加：音符时值/乐句/换气点/长音口型/可见颤音。
6. **杂人禁声**：目标帧里有非表演者时，点名允许发声者，其余可见角色保持无声、不得继承主表演者口型轨。

## E. 官方体裁模板方法论（MiniMax-AI/MiniMax-H3 skills/ 八生成器）

固定**视频事件框架**（时间轴/UI 事件/人物位次/装备逻辑/文字结构不动）+ **动态风格填充**（按用户选的
{visual_style} 重写视觉处理/色板/角色渲染/灯光/UI 材质）+ **锁定身份**（每个角色一张参考图锚脸/发型/
比例，禁交换/融合/趋同）+ **色板联动系统**（≤5 色：主背景/UI 主色/文字/功能强调/危险红，全程菜单、面板、
HUD 沿用同一系统）+ **逐拍块**（每拍写：景别机位/画面内容/动作/声音）+ **负向清单**（逐项列禁：第三人/
分屏/硬切/身份漂移/UI 乱字/水印…）。八个体裁：3D 动画短片、品牌宣传、合作游戏开场、手绘实拍混合、
极简产品广告、MV 字幕、纸拼贴讲解、纸艺定格。模板原件在官方仓 `skills/*/`，本文只录方法论；
按体裁取用时去官方仓读对应 SKILL.md。
