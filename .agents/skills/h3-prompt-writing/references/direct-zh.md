# H3 中文直投模式参考(direct-zh):五要素顺序 · 指代词黑名单 · 对白容量复核 · 格式隔离

2026-09-28 立。本文只讲「中文直投」这一种手写提示词形态的写法与自查法;官方英文字段结构的真源是同目录 `base-en.txt`、`ref-en.txt` 与本技能 SKILL.md,两边互不替代、不得混写。

> 来源与性质:本文件的方法论骨架(五要素顺序、双形态交付要求、指代词黑名单种子词)学习消化自 2026-09-28 外部课程包的中文直投入门教学(该包无开源许可证);除上述思路对应外,数值口径(时长档/帧数网格/语速表)、锚点与容量算例皆我方自有,全文我方自写——不含来源方任何专名与包内文件/技能名,不复制其原文段落。

标注沿用我方文档三态惯例:【实测】=本机跑过、有日志;【文档】=官方或我方既有文档口径;【待实测】=方法成立、未做实机对比。

## 定位

「中文直投」= 把一个镜头的全部生成要求写成**一条自然中文段落**(允许按五要素分段换行,但不套任何英文字段壳),人工整段复制进网页或客户端输入框即可直接生成。

| 维度 | 口径 |
|---|---|
| 何时用 | 人工在网页/客户端手动生成;中文分镜管线出快速草稿,先看画面动起来;一切拿不到 API/节点入口的场所 |
| 何时禁用 | 我方产线与 API/节点路径——真源是官方英文字段结构,由组装器 `apps/frontend/lib/assist/image-studio/h3-shot-prompt.ts` 产出,不得拿直投段落顶替 |
| 混写禁令 | 两种形态不得出现在同一条提示词里:直投段落零英文字段名;官方结构不做中文字段壳 |

## §一 五要素固定顺序

一条合格的直投段落按以下顺序写全五要素,缺项即驳回自己重写:

| 序 | 要素 | 职责一句话 | 硬口径 |
|---|---|---|---|
| ① | 总时长与画幅 | 定死这一镜多长、多大 | 只写我方档位,禁写训练区外时长 |
| ② | 首帧物理描述 | 交代画面开头的物理事实 | 只写事实,禁氛围形容词 |
| ③ | 时序推进 | 逐秒说清发生了什么 | 先动作、后运镜、再对白;对白逐字 |
| ④ | 声音两层 | 定整镜声场 | 环境+动作合述;配乐单独一句 |
| ⑤ | 连续性限制 | 锁跨镜一致性 | 道具/轴线/口型/首尾帧四项逐一交代 |

### ① 总时长与画幅

只写我方口径:单镜标准单位 **5.167 秒 = 124 帧 @24fps**;画幅 **1344×768(16:9)**;训练区 **5–15 秒**,训练区外时长禁写(更长虽能跑,但属未训练区,直投稿一律不碰)。

帧数恒落在 17k+5 网格(`length mod 17 == 5`),名义秒数换帧数按向上吸附取档:

| 名义秒 | 帧数 | 实际时长(24fps) |
|---|---|---|
| 5 | 124 | 5.167s |
| 6 | 158 | 6.583s |
| 8 | 192 | 8.000s |
| 12 | 294 | 12.250s |
| 15 | 362(封顶) | 15.083s |

口径真源:`docs/comfyui-kb/参数速查.md` H3 段与 `docs/comfyui-kb/分镜H3视频产线.md` §二。

直投段落开头一句示例:「本镜 5.167 秒,画幅 1344×768(16:9)。」

### ② 首帧物理描述

写四样物理事实:**构图(景别与画面内容分布)、人物相对地标的站位、身体朝向、世界光源方向**。不写「孤独」「压抑」「氛围感」这类氛围形容词——氛围由光线事实、动作与声音层自己长出来,不由形容词说。

自造例句一(老居民楼走廊):

> 首帧:中景。老式筒子楼的公共走廊,穿军绿棉大衣的老人站在第三根廊柱东侧一步处,身体朝向走廊尽头的窗户;双手拢在袖筒里;光源是走廊顶灯,位于人物右前上方,窗玻璃上有反光。

自造例句二(家庭厨房):

> 首帧:近景。灶台前,扎马尾的年轻女性正对炒锅站立,身体朝向画右;左手扶锅柄,右手持木铲悬在锅口上方;光源为抽油烟机底灯,从人物正上方垂直照下。

### ③ 时序推进:按秒,先动作后运镜再对白

逐秒(或按 1–2 秒的节拍)推进,每一拍内部固定顺序:**动作 → 运镜 → 对白**。

- 动作:谁、做了什么、从哪到哪;
- 运镜:用下表的中文词写,一词对一官方词,禁自造「运镜丝滑」「电影感镜头」这类不可执行词;
- 对白:**逐字原文**,禁翻译、禁润色、禁压缩;本镜无人说话就明写「无对白,人物嘴唇闭合」。

运镜中文词 ↔ 官方受控词对照(官方词表是公共接口词汇,周边解释为本文自写):

| 直投中文写法 | 官方受控词 | 语义 |
|---|---|---|
| 变焦推近 / 变焦拉远 | Zoom In / Zoom Out | 焦距变化,机位不动 |
| 镜头推近 / 镜头拉开 | Push In / Pull Out | 机位整体前移 / 后移 |
| 左摇 / 右摇 | Pan Left / Pan Right | 机位固定,水平转头 |
| 左移 / 右移 | Truck Left / Truck Right | 机位水平平移 |
| 上仰 / 下俯 | Tilt Up / Tilt Down | 机位固定,纵向转头 |
| 上升 / 下降 | Pedestal Up / Pedestal Down | 机位垂直升降 |
| 环绕 | Arc Shot | 绕主体走弧线 |
| 跟拍 | Tracking Shot | 跟随主体运动 |

词表真源:本仓 `minimax-h3` 技能「Camera is a controlled vocabulary」节;中文→官方词在生产侧的映射实现见 `apps/frontend/lib/assist/image-studio/h3-shot-prompt.ts`,此处仅作背景,直投时人工按上表选词即可。

时序示例(自造,节选,接 §一② 例句一):

> 第 0–1 秒:老人从袖筒抽出右手,把搪瓷缸放上窗台;镜头推近(Push In)缓慢开始;无对白。
> 第 1–3 秒:他望向窗外说:「雪停了我就下去。」;镜头继续推近到近景。
> 第 3–5 秒:楼下传来扫雪声,老人嘴角动了一下没有开口;镜头停住不动。

### ④ 声音两层

- 第一层:环境声 + 动作声**合述成一句**(模型合并处理画内声);
- 第二层:观众可闻、角色听不见的配乐**单独一句**;
- 无配乐就明写「可闻配乐:无」,不留空让模型猜。

自造示例(接上例):

> 声音:走廊日光灯电流嗡声、楼下远处锅铲刮锅声、搪瓷缸落窗台的轻响,合为环境与动作声;可闻配乐:无。

### ⑤ 连续性限制

收尾一句交代四件事,把这一镜与前后镜焊住:

| 项 | 自查问题 |
|---|---|
| 道具状态 | 进镜时手里有什么、什么状态;出镜时变成什么状态 |
| 互动轴线 | 多人时谁的站位连线为轴、镜头在轴哪一侧,不越轴 |
| 口型开闭 | 无对白段明写嘴唇闭合;有对白段对白说完即闭 |
| 首尾帧交接 | 尾帧停在什么物理状态(手在哪、视线在哪、道具在哪),供下一镜首帧或剪辑对位 |

## §二 独立可读与指代词黑名单

铁律:**每条最终提示词必须脱离上下文独立可读**——只看这一段就能复现画面,不需要回翻上一镜或聊天记录。生成端没有上下文记忆,任何指代词到它那里都是空洞占位。

黑名单(不封顶,可扩充;判别标准:凡要靠回看别处才能解义的词,一律视同此类):

| 禁用词 | 病因 |
|---|---|
| 上一镜 / 上一镜头 / 前一镜 | 生成端无前文 |
| 继续 / 仍 / 仍然 / 依旧 | 未说明延续的是什么状态 |
| 同上 / 如上 | 无表格上下文可指 |
| 保持原样 / 和之前一样 / 如前所述 | 同上 |

替换法:**把被指代的物理状态展开成完整正向描述**,照 §一② 的物理口径重写一遍。展开自查清单:

| 展开项 | 要写到的颗粒度 |
|---|---|
| 站位 | 人物相对哪个地标、几步、哪个方向 |
| 身体朝向 | 面向 / 背向哪个具体目标 |
| 手脚动作 | 四肢各自在做什么 |
| 视线 | 看着哪个具体目标 |
| 表情与呼吸 | 可见面部状态、是否喘 |
| 手持道具 | 拿着什么、处于什么状态 |
| 伤势衣物 | 可见伤在哪、衣物破损到什么程度 |
| 光源方向 | 光从世界哪个方向来 |
| 屏幕方向 | 人物 / 运动在画面左还是右 |
| 台词进度 | 本镜开口前,整段台词已说到哪一句 |

一条自造的前后对照:

坏例(含指代词,驳回):

> 他保持上一镜的姿势继续靠在门框上,手里的茶仍然没喝,和之前一样看着院里的雨。

改好(展开为正向物理描述,通过):

> 首帧:中景。穿藏蓝工装的男人靠在木门框左侧,右肩抵住门框,双脚交叉站立;右手端白瓷茶杯,杯中茶水满至杯口下一指,液面平稳;视线落在院内雨幕;光源为屋檐下白炽灯,从人物右上方照下。

跨域边界(一句话):本节黑名单只治「单条 H3 提示词文本」(直投与官方结构两形态)的写法;分镜表→编译产物链路层的禁指代词双层规则与机检提案,归 `docs/comfyui-kb/跨镜连续性规范-0928.md`,两文各写各的、互不代述。

## §三 对白容量扣减复核

直投稿发出去之前,手工过一遍这把尺:

```
可用说话时间 = 镜头总时长 − 开场动作 − 呼吸停顿 − 听者反应 − 走位 − 收尾动作
对白字数上限 = ⌊可用说话时间 × 语速⌋(向下取整)
```

各扣减项按表演实况估;拿不准时宁可多扣——这把尺的目的是保证台词自然说得完,不是给台词腾地方。

语速用我方情绪口径:

| 情绪 | 语速(字/秒) |
|---|---|
| 怒、急、激动、嘶吼 | 4 |
| 平常叙述 | 3 |
| 悲、弱、低语、哽咽 | 2 |

口径真源:`docs/workflow/WORKFLOW_STORYBOARD_EDITING_OPERATIONS.md` 的时长回退表。方向注明:那条公式**从字数算时长**(分镜表缺时长时的回退估算),本节**从时长算字数上限**(写提示词前的手工复核),两者方向相反、互为补集,不是同一公式的两种写法。

自算换算例:

例一(5.167s / 平常语速):

- 扣减:开场动作 1.0s + 呼吸停顿 0.5s + 听者反应 0.7s + 收尾动作 0.4s = 2.6s,无走位;
- 可用说话时间 = 5.167 − 2.6 = 2.567s;上限 = ⌊2.567×3⌋ = 7 字;
- 台词「等雨停再走。」5 字,通过。

例二(8s / 怒速,含走位):

- 扣减:开场 1.5s + 走位 1.0s + 呼吸停顿 0.5s + 听者反应 0.5s + 收尾 0.5s = 4.0s;
- 可用说话时间 = 8 − 4 = 4.0s;上限 = ⌊4.0×4⌋ = 16 字;
- 台词 20 字 → 超容 4 字,进下方三处置。

例三(12s / 悲速):

- 扣减:开场 2.0s + 呼吸停顿 1.0s + 听者反应 1.5s + 收尾 1.0s = 5.5s,无走位;
- 可用说话时间 = 12 − 5.5 = 6.5s;上限 = ⌊6.5×2⌋ = 13 字。

超容三处置(按序执行,不得跳步):

1. **按语义拆段**:在标点、换气点、语义转折处把台词拆给相邻镜,不按字数机械截断;
2. **延长镜头**:把帧数升到更大网格档(如 124→158),并同步改 §一① 的时长表述;
3. **上报作者裁定**:时长预算与台词不可两全时交作者删改,写提示词的人不代改台词。

禁加速硬塞:「念快一点」「语速提上去」不是处置选项——对白逐字原文是 §一③ 的硬规则,容量与台词冲突时永远改结构,不改念法。

跨域边界(一句话):本节与 `docs/research/PIPELINE_METHODS_ABSORPTION_ANALYSIS_2026-09-28.md` 提案二同源同口径(4/3/2 情绪语速);本文只写写提示词的人的手工复核用法与换算例,产线自检门/lint 机制与超限处理阶梯归该提案,此处不重复展开。

## §四 与其它格式的隔离

- 直投段落**不得套用区块模板**——不管是「【画面】【声音】」式标签块,还是其它视频模型的分段壳——冒充别的格式;直投就是自然中文段落 + 五要素顺序,没有第二副骨架。
- 官方 API 字段名(`integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`、`subject_definitions`、`retention_analysis`、`detailed_description` 等)是公共接口词,但**只在官方结构模式里出现**;直投段落里出现任何一个英文字段名 = 形态混写,驳回重写。
- 同一镜需要双形态交付(直投快速稿 + 官方结构正式稿)时:分成两份各自成体——每份单独一块代码、单独落一个文件,互不嵌套、互不引用,谁也不是谁的注释。

## §五 生效边界与验证状态

- 直投模式**未经我方实机 A/B 对比,【待实测】**;实测完成前不得声称直投产出与官方结构产出等同。
- 可验法(建议):用 0.2 测试档(608×352、124 帧、4 步 turbo,单条全链约 334 秒,实测口径见 `docs/comfyui-kb/参数速查.md` H3 段)固定同一组三个镜头,分别以直投稿与官方结构稿并排出片,对比台词清晰度、运镜执行率与音画同步;结论回填本节。
- 本文只是写法参考,**不改动任何生产代码**;产线与 API/节点路径仍以官方英文字段结构为唯一真源。
