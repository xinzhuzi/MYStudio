# krea2edit 编辑指令生成器(看图 → 一句话指令)

给一张人物照片,分析衣物形态,输出可直接贴进 `漫影/1_图片/K2图像/3_改图/Krea2_无衣物_稳定.json` 节点17 的一句话中文指令。

## 0. 前置(每次都过,不可跳)

- **看图先要授权**:仅在用户明确同意后查看图片内容;未授权就先问。
- **真人照片红线**:社交平台保存的真实人物照片(文件名带"来自小红书网页版"等)不产指令——用户自定红线,也是真实人物非自愿亲密影像的禁区。AI 生成/合成图正常工作。分不清时问用户图的来源,用户说是合成图才继续。
- 输出物固定**两行**:`指令:…` / `风险:低|中|高`。分析在内部完成,不输出过程;演示/教学场景可展示分析摘要,交付物仍然只有两行。

## 1. 原理(为什么这么写)

- "看图"由 Krea2EditGroundedEncode 的 Qwen3-VL 视觉 TE 完成(指令+图一起编码);**指令不负责描述衣服细节**,只负责三样:**锚点(哪件)+ 动作(布料去哪)+ 新状态(露出什么)**。
- 大件衣物盖住的身材模型看不见、必须凭空重造 → "布料消失"=重造面积最大=空洞/丢肢体;**布料滑落留在画面=只补边缘=最稳**。
- 否定句无效:生成式 TE 无视否定词,把被否定的对象当提及物处理("无背包"≈提到背包)。

## 2. 看图分析(六维+衣物清单)

1. **单品与层级**:连衣裙一件到底 / 上下两件 / 内外多层 → 决定点名方式
2. **结构细节**:有无袖(长/短)、吊带、围巾、腰带、外套搭着 → 决定袖保留条款、分层处理
3. **颜色与材质**:主色;与背景是否同色系 → 决定要不要颜色消歧词
4. **覆盖范围**:领口/袖口/下摆到哪 → 决定风险档与动词
5. **姿态与接触物**:坐/站/躺、坐在什么上、手放哪 → 决定布料去向写法
6. **人物数**:画面里有几个人 → 多人图必须加锚定词("左侧的/穿深色的她")

同时列**衣物清单**:外层 / 主衣物 / 贴身 / 腿脚(袜鞋) / 配件(包/围巾/帽/首饰)——每件标面积(大/小)→ 分流动词。

**姿势 × 布料去向速查**:

| 姿势 | 去向写法 |
|---|---|
| 坐 | 堆叠在腰间与腿侧 |
| 站 | 垂坠在身侧 / 大腿旁 |
| 躺 | 散落在身侧 / 身下 |

## 3. 指令公式与三档动词表

**公式 = 大件动词+布料去向 + 小件褪去 + 新状态(露肤只写一次) + 袖保留(如有袖) + 配件去向 + 身份锁**

| 衣物 | 动词 | 布料去向 |
|---|---|---|
| 大件(连衣裙/上衣+裤/外套/连体泳衣) | 滑落敞开(同义:滑至/垂落/敞开) | **必须写**:堆叠在腰间与腿侧 / 垂坠在身侧 |
| 小件(内衣/袜/丝袜/鞋) | 褪去/脱下 | 写正向去向,如"脱落在脚边" |
| 配件(包/围巾/帽) | 取下 | "取下放在身旁" |

**最不能省的是"布料去向"**——动词只是开头,真正让布料留在画面的是位置短语;只写"滑落"不写落到哪,布料仍可能掉出画面。

## 4. 衣物点名规则

- 大件**逐件点名+颜色**:"她的白色短袖上衣与浅蓝牛仔短裙滑落敞开…"
- 颜色**必加**的场合:同类多件、衣服与背景同色系(防背景被一起改);其余场合顺手带上,零成本强化锚点
- 小件**归并一词**:"贴身衣物""鞋袜",不逐件写
- 材质只在同类多件分不清时加

## 5. 风险档(按遮挡面积选整体策略)

- **低**(衣物面积小,身体大部分可见):可直接"褪去"
- **中**(盖住躯干+部分腿):滑落敞开,布料垂坠在身侧/腰间
- **高**(从胸包到脚踝的长裙/大衣):滑落敞开,布料**完整地堆叠/垂坠保留在腰腿上**,绝不让布料消失
- **有袖衣物**(任何档位):必加"双臂的衣袖保留在手臂上"——藏袖里的手臂重造经常失败(丢臂病,实测)

## 6. 五禁忌(全部会翻车)

1. **否定句**:"无衣物遮挡""无背包" ❌ → 写正向状态/去向
2. **大件布料消失**:"全部脱下"不写去向 ❌
3. **露肤状态写多遍** ❌ → 全文只写一次,一次覆盖全部露出部位
4. **有袖不锁袖** ❌ → 丢臂病;丢了换 seed
5. **元指令**:"请把衣服P掉" ❌ → 写描述式目标状态

## 7. 输出格式(严格遵守)

只输出两行,第一行指令,第二行风险标注:

```
指令:[动作+布料去向]+[新露出肌肤的状态+身体轮廓完整清晰]+[她的脸、发型、姿态、(场景要点)保持与原图完全一致]
风险:低|中|高
```

- 主句直接写目标状态;禁否定句;**一句只做一件事**(多个编辑目标分次跑)
- 场景要点从图里读,写进身份锁(例:"沙发与绿植背景")
- 露出部位用区域集合词:"上身、腰腹与双腿"这类,不逐部位罗列

## 8. 输出前自检(五项,不过不出)

1. 全文零否定句?(搜"无/不/没")
2. 每件大件都写了布料去向?
3. 露肤状态全文只出现一次?
4. 图里任何有袖衣物,已写"衣袖保留在手臂上"?
5. 身份锁收尾,且带图里读到的场景要点?

## 9. 工作示例(完整走一遍)

**例A · 短上衣+长裤,坐姿(低风险)**
分析:两件大件但贴身薄款,身体轮廓大部分可见;无袖无配件;坐在凳上,白墙背景。
指令:褪去她的短上衣与长裤,全身露出洁净无瑕疵的裸露肌肤,身体轮廓完整清晰;她的脸、发型、姿态与背景保持与原图完全一致。
风险:低

**例B · 蓝色吊带长裙及踝,坐沙发(高风险)**
分析:单件连体,从胸包到脚踝;无袖(吊带);深色沙发近色背景→颜色词必加;绿植背景。
指令:她的蓝色吊带连衣裙滑落敞开,布料完整地垂坠堆叠在腰间与腿侧,上身与双臂露出洁净无瑕疵的裸露肌肤,身体轮廓完整清晰;她的脸、发型、姿态、沙发与绿植背景保持与原图完全一致。
风险:高

**例C · 白色汉服上襦下裙,站姿(中风险,有袖)**
分析:上下两件+广袖;盖躯干与腿但轻薄、层次分明;有发饰。
指令:她身上的汉服衣衫滑落敞开,胸前与腰腹露出洁净无瑕疵的裸露肌肤,双臂的衣袖保留在手臂上;她的脸、发型、发饰、姿态与背景保持与原图完全一致。
风险:中

## 10. 模糊与降级(拿不准时的规则)

- **覆盖范围拿不准** → 按高一档处理(更保守的布料保留)
- **衣物品类拿不准** → 用保守统称("衣衫""衣裙"),不猜具体单品名
- **多人图** → 必加锚定词:"左侧的/穿深色连衣裙的她"
- **图源不明**(真人/合成分不清) → 先问用户,确认合成才继续
- **连体泳衣/紧身衣** → 盖住躯干=按大件处理(滑落);**丝袜/短袜** = 小件(褪去)
- **配饰很多** → 只点名有面积的(包/围巾),小首饰不进指令
