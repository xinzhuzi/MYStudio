## 快查:九大机制(详法见真身·一)

| 症状 | 机制 | 一句话解法 |
|---|---|---|
| 不写就默认加料 | 误解机制 | 写不要什么+抽象词拆量化动作 |
| 主体发硬/死磕细节 | 扰动词 | 无义扰动词分流注意力 |
| 风格串味 | 风格泄漏 | 指定参考类型+分段写(主体/光线/色彩/风格) |
| 画面太"安全" | 鲁棒性破坏 | 构图/光线/风格换趋势词故意小失控 |
| 没空间感 | 伪透视词 | 方向词延伸/密度词分层/尺度词夸张 |
| 画面死板 | 时间词 | 过去式残留/现在式动态/将来时张力 |
| 情绪不集中 | 特征塌陷 | 压非主体/边缘柔化/强化局部对比 |
| 元素乱加 | 假因果词 | 状态因果+情绪当原因+先果后因 |
| 动作镜头割裂 | 反着写/身份三件套 | 镜头前置包裹动作;第一句永远是「这是一个什么场景」 |

## 铁律摘录(写作时恒查)

- 五块结构:情绪/主体/光线/镜头/细节;具体>简短;专业词出专业结果。
- 剪词:删情绪词、删重复词、删人类句式(写结构不写故事)。
- 视频:先身份(人物/环境/场景)→再镜头→最后动作;每镜只写「镜头从哪开始/谁是主角/它在做什么」;每镜锁结尾画面,下段从上一段结尾状态接。
- 参考图=减少自由度,一次只优化一个维度;图片提示词权重最高,改图先画框标注。
- 一致性:人物场景拆分/竖版四视图/先定动作再进场景;大场景用 3D 全景图,追求"看起来一致"而非"完全一致"。
- 活人感:人物+正在做的小事+下意识反应+情绪落点;皮肤当材质;只写哪里动/怎么动/为什么动。
- 过期词:8K/超高清/电影质感别再堆,重点已转向"怎么被拍出来的"。

## 适用边界

- 机制类技法跨模型通用(生图/生视频皆可);工具实测结论(Seedance/可灵/GPT-image-2 豆包等)带时间戳,以真身·七的实测日期为准,新版本需重验。
- super-i.cn 付费站内「提示词创作第 N 节」附件未采集(会员墙);本技能只含 B 站免费面公开的知识。
