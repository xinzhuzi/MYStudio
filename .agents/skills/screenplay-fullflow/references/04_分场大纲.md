# 分场大纲 · 第 4 道

> 上游：01 概念锚定 ＋ 02 角色圣经 ＋ 03 世界观（有就带）｜ 本道产出：**分场表 ＋ 一个已锁定版本**
> 内部对应：原 04 分场大纲。
> **核心纪律：只写发生了什么物理动作，绝不写对白。**

---

## 0. 输入从哪来

1. 用户贴了前置成果 → 用他贴的。
2. 同一个项目/对话里已有 → 读最新那份**已确认**版本。
3. 都没有 → 只问一句：「先把第 1 道的故事大纲给我。」然后停。

不要在这里重做概念，也不要顺手动人物。

---

## 1. 第一步：定场数（强制停止）

先读大纲里的**目标时长**，算出推荐场数，再问，然后停。

- 短片：约 **1 分钟 1.5–2.5 场**（10 分钟 ≈ 15–25 场）
- 长片：**1 页 ≈ 1 分钟**
- 剧集 / 短剧：按集排

```text
按你 XX 分钟的时长，我建议拆成 XX 个场景，你看合适吗？
你也可以直接告诉我你要的场景总数。
```

用户确认场数之后，才开始裂变场景。

---

## 2. 第二步：分场（按定位走对应节拍）

场景标题统一：`场号. 内景/外景. 地点 - 日/夜/晨/昏`

**每场必须带「预计场次时长」**，按本场动作量、信息量、对白密度、必要停顿估，**不许平均分配**。

### A｜三幕

- **第一幕 建置**：建置 → 建置 → **诱发事件**（全片 22%–25% 之前）
- **第二幕 对抗**：逐场升级，每场比上一场更难；中段一个 **中点**（大胜或大败，风险和代价翻倍）
- **第三幕 解决**：**危机**（两种价值只能选一个）→ **高潮**（回应这个选择）→ **结局**（1–2 场收尾）
- 片尾彩蛋可选

### B｜五节拍（艺术短片）

1. 意图与语境的奠基——隐喻性空镜或主角凝滞状态
2. 母题浮现——**强制外化角色圣经里的习惯手势或核心心结**
3. 隐喻交织——第二结构与物理现实发生交互
4. 意图的沉淀或决堤——没有动作高潮，用物理动作表现心理崩塌或无声妥协
5. 余音留白——意图闭环，留解读空间

### C｜五节拍（爆款网剧）

1. 黄金前 3 秒钩子（绝境点）
2. 复合底牌激活——**强制外化隐藏底牌的气场变化与视觉异象**
3. 预期落空与绝地反扑——必须给出逆鳞触发或标志性微表情
4. 极致爽感高潮——用群演的夸张肢体（瘫软/震惊）烘托
5. 致命悬念钩子——反杀刚停，立刻切进更大危机

### D｜自定义

按用户设定的规则裂变，但四问自检照样要做。

---

## 3. 第三步：逐场四问（每场都要过）

1. 这场能不能用「因为上一场发生了 X」开头？——不能 = 因果断了
2. 这场有没有价值变化（正→负 或 负→正）？——没有 = 空转
3. 这场服不服务于核心主旨？——不服 = 跑偏
4. **删掉这场，故事还成立吗？** ——成立 = 多余

任一条不过，用标签打在那一场前面，然后重写：

`⚠[因果性]` ｜ `⚠[价值]` ｜ `⚠[圣经]`（和角色/世界观冲突）｜ `⚠[节奏]` ｜ `⚠[信息倾倒]` ｜ `⚠[重复]`

---

## 4. 第四步：时长汇总

文件末尾汇总所有场次时长，并写清：

> 这是分场阶段的**节奏预算**，不是最终成片时长。写成完整剧本后要按真实台词重算一遍。

## 5. 输出格式

```
# 分场大纲
版本：v001
依据：01 概念锚定 v001 ｜ 02 角色圣经 v001 ｜ 03 世界观 v001（或「本片跳过」）
定位：A / B / C / D
总场数：___ 场 ｜ 总时长预算：___ 分钟
```

逐场写，每场格式：

```
场 1. 内景. 地点 - 日   （预计 90 秒）
[3–5 句，只写发生了什么物理动作。谁在场，什么价值进来，什么价值离开。不许写对白。]
```

**先落文件，再给卡片**：把正文连同下面这张版本卡，一次性写成项目文件夹里的 `04-分场大纲-vNNN.md`。
卡片是摘录，文件才是原件 —— 下一道读的是文件，不是聊天记录。

结尾附版本卡：

```
【版本卡 · 04 分场大纲 · v001】
状态：待确认
总场数：___ ｜ 总时长预算：___ 分钟
标注了问题的场次：___
第 5 道必读：场次锁定表全部字段 ＋ 每场核心事件与场尾结果
```

然后**停下等确认**。

---

## 6. 红线

1. 不许写对白。一句都不行。
2. 不许跳过「定场数」那次停止。
3. 不许平均分配时长。
4. 不许为了凑场数硬加「过场戏」——每一场都要能被四问通过。
5. 用户说「这场不要了」时，先问它承担的因果谁来接，再删。
