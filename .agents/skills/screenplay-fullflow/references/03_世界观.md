# 世界观 · 第 3 道（可跳过）

> 上游：01 概念锚定 ＋ 02 角色圣经 ｜ 本道产出：**世界观／设定集 ＋ 一个已锁定版本**
> 内部对应：原 03 世界观。

---

## 0. 什么时候该做，什么时候不该做

**该做**：科幻、奇幻、超能力、架空历史、有独特制度的现实（门派、公司帝国、江湖、法外之地）、有特殊空间规则的片子。

**不该做**：普通现实题材、家庭片、都市情感片。**世界规则不直接推动剧情时，直接跳过。**

判断标准一句话：**这条规则会不会改变人物的选择？** 不会，就不用写。

跳过的做法：只说一句「本片走现实规则，跳过世界观」，然后交给第 4 道。

## 1. 填什么（八块，缺哪块说明哪块不需要）

### 一、本世界的规则

- **和我们这个世界不同的地方**（3 条以内，只说真正影响剧情的）
- **完全一样的地方**（重力、生物、货币、国家…先钉死哪些不用解释）
- **技术 / 魔法水平**处在什么档位

### 二、体系（有金手指/超能力/法术才填）

> **没有硬规则的魔法等于作弊。** 这一节是世界观的核心。

- **它能做什么**
- **它不能做什么**（这一条最关键，没有限制就没有戏剧）
- **使用代价**（用一次要付出什么）
- **谁能用，谁不能用**

### 三、世界历史

- **与剧情相关的三件大事**：什么时候、发生了什么、留下什么后果
- **开场那一刻的世界状态**：政治上 / 社会上 / 自然或技术上

### 四、势力

每个势力写：目标 / 手段 / 谁说了算。至少写两个，并写清**它们冲突在哪**。

### 五、关键地点

只写真正承担剧情的 2–4 个。每个写：这是什么地方 / 谁在那生活或工作 / 这场戏为什么必须在这 / 有哪些场次发生在这。

### 六、道具与伏笔物件

| 物件 | 在哪出现（埋） | 在哪开火（收） | 它意味着什么 |
|---|---|---|---|

至少 3 件，必须和 01 的伏笔清单对得上。对不上就标出来问用户。

### 七、信息差（这一块最容易出好戏）

| 角色 | 知道什么 | 不知道什么 | 以为知道但其实错了 |
|---|---|---|---|

**冲突常常就长在这张表的第三列。**

### 八、设定怎么给观众（不许用对白倒）

- 禁止：「你也知道，我们的魔法是靠血来换的」
- 只允许：动作、画面里的物件、后果
- 好用的手法：**先让体系运行一次 → 主角把它当正常事反应 → 观众自己明白这在这世界里是常识**

## 2. 输出格式

```
# 世界观 / 设定集
适用性：本片需要世界观（理由：___）
版本：v001
依据：01 概念锚定 v001 ＋ 02 角色圣经 v001
```

正文按八块写，不需要的块写「本片不涉及」并说明为什么。

**先落文件，再给卡片**：把正文连同下面这张版本卡，一次性写成项目文件夹里的 `03-世界观-vNNN.md`。
卡片是摘录，文件才是原件 —— 下一道读的是文件，不是聊天记录。

结尾附版本卡：

```
【版本卡 · 03 世界观 · v001】
状态：待确认
影响的场次：___
信息差关键点：___（这是第 4 道拆场时要用的）
道具伏笔：___
```

## 3. 红线

1. **现实题材不许硬造世界观。** 造出来就是负担。
2. 不许写设定说明书式的长篇背景，每条都要能落到某一场。
3. 不许改 01 已经确认的主旨和结局方向。
4. 不许在这一步写分场或台词。
