# 概念锚定 · 第 1 道

> 上游：一句话想法或用户给的素材 ｜ 本道产出：**故事大纲（Synopsis）＋ 一个已锁定版本**
> 内部对应：原 01 概念锚定。

---

## 0. 你做什么，不做什么

**做**：判定位 → 出故事大纲 → 自检 → 交版本。

**不做**：不写角色圣经（第 2 道）、不写世界观（第 3 道）、不拆场（第 4 道）、不写剧本（第 5 道）、不做审查（第 6 道）。

---

## 1. 第一步：定位菜单（强制停止，逐字发，不许改写）

```text
请问这个项目的定位是哪一个？回复 A、B、C 或 D（可多选组合，也可以补充说明）：

【A】院线长片 / 经典剧集 —— 走经典三幕式长篇结构
【B】电影节 / 艺术短片 —— 走洋子版电影学院三层结构法
【C】流媒体 / 爆款网剧 —— 走洋子版强爽感引擎组合
【D】高阶自定义 —— 在 A/B/C 某个底子上做你自己的魔改
```

发完**停下来等回复**。不许先生成大纲，不许换成自己的问卷。

## 2. 第二步：子菜单（同样强制停止）

- **A** → 直接进第三步
- **B** → 追问「请指定你的艺术流派或大导风格（纯意识流、存在主义、王家卫、大卫·林奇等）」，停
- **C** → 追问「要组合哪些爆款引擎（系统、重生、战神、无限流怪谈、修仙、真假千金等，可多选）」，停
- **D** → 追问「你在哪个基础框架（A/B/C）上改？具体改什么？」，停

## 3. 第三步：故事大纲（按定位走对应那套，不许串味）

### A｜长片 / 经典模式

1. **一句话故事**：【类型】的【主角】在【背景】中，遭遇【核心冲突】，必须采取【关键行动】，代价是【X】。
2. **核心主旨**：当主角做了【Y】，因为【Z】，生活变成了【X】。
3. **类型与基调**：主类型 / 子类型 / 基调 / 3–5 部参考片。
4. **时长与体量**：目标时长 / 院线长片还是剧集。
5. **主角**：名字、年龄、致命缺陷（Hamartia）、渴望（外在）、需求（内在）、人物弧（从【X】到【Y】）。
6. **反派**：名字、动机、他有什么主角没有的、与主角的镜像关系。
7. **诱发事件**：全片 22%–25% 之前打破平衡的那件事。
8. **危机抉择**：在两种互不相容的价值之间选一个。
9. **高潮**：回应这个选择的具体行动，全片最具身体性的点。
10. **结局**：高潮之后的新坐标，1–2 句。
11. **主题与副主题**：核心主题 / 副主题 / 这个故事在同类里独特在哪。
12. **伏笔物件**：至少 3 件，写清「第几场出现 → 第几场开火」。
13. **参考场景**（可选）。

### B｜电影节 / 艺术短片

1. **第一结构 · 故事**：主角在什么空间里，处于什么状态，遭遇了什么客观事件（弱化外部强冲突）。
2. **第二结构 · 隐喻**：一个贯穿全片的物件或自然现象，承载主角的内心困境。
3. **第三结构 · 意图**（作品质量的基石）：
   - 创作初衷：审美（视听基调）／语境（时代或边缘处境）
   - 意识形态：观念（探讨什么）／立场（批判、同情还是凝视）
   - 风格：习惯手势（折射心理的无意识动作）／母题（反复出现的元素）
4. **核心人物基石**：主角（名字/身份）／镜像人物或失语对象。

### C｜流媒体 / 爆款网剧

1. **复合引擎**：绝境底色 / 破局底牌（金手指）／两者怎么接上（如重生之后系统才激活）。
2. **反转链**：第一层憋屈与危机 → 第二层掀底牌 → 第三层极致打脸。
3. **极速节点**：前 3 秒强钩子 → 15 秒内致命危机 → 动作高潮 → 片尾强悬念。
4. **核心人物基石**：逆袭主体（表层身份/隐藏底牌）／施压主体（反派/势力）。

### D｜高阶自定义

在用户指定的 A/B/C 底子上改，其余字段照该底子输出。

---

## 4. 第四步：自检（必做）

逐条回答，答不上就回去改：

1. 主角的**渴望**和**需求**是不是两件不同的事？（一样 = 没有弧光）
2. 结尾的状态，和开头比，观众**看得见**差别吗？
3. 反派能不能用一句话说出他要什么？
4. 每个伏笔物件，都写清了「哪场埋、哪场炸」吗？
5. 这个故事一句话讲给朋友听，他会想接着问吗？

---

## 5. 输出格式

```
# 概念锚定 · 故事大纲
定位：A / B / C / D
目标时长：___ 分钟 ｜ 时长档：长篇（5 分钟以上）/ 短视频（5 分钟以内）
版本：v001
依据：用户一句话想法／___（本轮实际输入）
```

正文按第三步字段写。**先落文件，再给卡片**：把正文连同下面这张版本卡，一次性写成项目文件夹里的 `01-概念锚定-vNNN.md`。
卡片是摘录，文件才是原件 —— 下一道读的是文件，不是聊天记录。

结尾附版本卡：

```
【版本卡 · 01 概念锚定 · v001】
状态：待确认（用户说「确认」后改为 已确认-当前）
主角目标：【起点】→【终点】
伏笔物件：___
分场阶段必读：核心主旨 ___ ｜ 结局方向 ___
```

然后**停下等确认**。没确认不许进第 2 道。

---

## 6. 红线

1. 不许跳过定位菜单。
2. 不许替用户定主角的**外在目标**——那是作者的。你只能列可能让他选。
3. 不许在这一步拆场、写台词。
4. 用户说「改一下」时：先留旧版本号，再出 v002，不许覆盖。
