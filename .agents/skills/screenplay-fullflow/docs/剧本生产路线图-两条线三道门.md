# 剧本生产路线图 · 两条线 × 五层质量 × 三道门

> 2026-10-29 探查定稿。回答「剧本应该怎么搞，搞的好一些」——第一问永远是「已有什么」：本仓剧本资产全量盘点 + 质量体系归拢 + 缺口接线。
> 触发本图的场景：任何剧本/台词/声音层工作开工前，先读此图对齐路线与门。

## 一、两条生产线

### A 线 · 道劫小说改编线（章集剧，成熟，App 生产链）

```
小说原文(《千年志：道劫》4125章)
  │  ← novel-writer 前置强制加载（Unity/MA 仓 .claude/skills/novel-writer/）
  │     · 番茄文稿=声音层耳感宪法（黄金3秒/强钩子/三有/心痒/冲突识别/禁空洞氛围句/禁烂梗）
  │     · A式契约（A-01 声口遮名测试 / A-02 现场POV禁解释句 / A-03 动作-结果-代价）
  │     · 角色卡 OOC 真源（Design/世界观小说/《道劫》/1.设定集/）
  ▼
剧本编写 Agent（手册=studio-manuals/script_execution_script.md）
  │  · 三大情绪要点（爆/虐/爽每集≥1）+ 爽点公式（装+打脸+震惊+收获）
  │  · 单集节奏骨架：0-2%冷开场 → 20-35%第一爆破 → 35-65%推进反转 → 65-85%第二爆破 → 85-95%卡点 → 末5-10%cliffhanger
  │  · 情绪点密度硬规：每60s≥3个；40%-80%区间禁连续40s无情绪点
  │  · 题材规则=story_skills/Daojie_xianxia/script_narrative.md（三禁令+转译通道+裁定门）
  ▼
scriptDraft → eventAnalysis → directorPlan → storyboardTable（App 链四件套）
  ▼
【门② script-doctor】两层八查（fresh-eyes 铁律）
  ▼
【门③ voice_preflight.py】配音前门（A1年龄冲突/A4特质对表/B1半句/B3现代词…FAIL拒跑）
  ▼
TTS 分段路由（说话人×emotion 档位）→ 出图（道劫 qi21 底座）→ remotion图动/H3 → 响度链 → 发布
```

**A 线铁的纪律（第一章血泪换来，1027-1029）：**
- **转译通道三重约束**：原文有据意义等价（可近逐字取用）/不加评价不改语义/不补原文没有的信息——**只剪不改写**；删减原文重要动机/因果/来历须列裁定清单过用户，未裁定不得进下游。
- **旁白只剩三类话**：画面给不了的（过去/内心/机理）+ 定性的（金句）+ 角色嘴里的（对白）；摄像机复述一句不留（「他低头看」「坐在那儿呼吸」全剥）。
- **半句话病**：压缩后每句单独听必须成立（有主语+完整谓意）；音效意图禁写在台词位。
- **说话人 POV 迁移**：心声归角色（独孤剑尘 004/008）、冷笑归监督者（赵四 002）、旁白出场即压最大悬念——比第三人称旁白更贴原文时，迁。
- **双口径语速**：镜时长口径抓「文本塞爆镜」、voice 实长口径抓「配音赶」，缺一不可；>5.2字/s=RED。
- **镜台词超编先查邻镜**是否已带同拍点，摘冗余优于压字。

### B 线 · 原创短剧线（新装，2026-10-29）

```
脑洞/一句话点子
  ▼
【screenplay-fullflow 六道】概念锚定 → 角色圣经 → 世界观(可跳) → 分场大纲 → 剧本深度融合 → 压力测试
  │  · ①破题=高概念+戏剧动作+主题锚点；②角色圣经=Want/Need/Lie/Flaw/Ghost（同时就是后续 OOC 检查底）
  │  · ④因果链检查（"因为"不是"然后"）+逐场四问；⑥洋子引擎=删除测试+A档五要素/B档留存五问+病灶定位回退
  ▼
【门② script-doctor】（同 A 线；原创章无原文时查7/8按导演计划判）
  ▼
分镜/出片：OnlyShot（ai-short-drama）180s×60grid 分集细则 + 分镜图8段模板 + 即梦出片
  或接入本仓产线（qi21 出图 + TTS 侧车 + remotion/H3）
```

**B 线手艺层（OnlyShot scripting-craft，红果口径）：** 每句台词≤15字；不要解释靠动作（"她生气了"→她把茶杯摔了）；每句话三选一目的（推进/揭性格/制冲突）；潜台词>表面意思；冲突对话≤3回合；每分钟≤60字对白；节奏标记（[钩子][爽点][反转][虐点][卡点][伏笔][兑现][母题]）；音效写具体配方不写"激烈音乐"。

## 二、五层质量体系（跨线共享，按层取用）

| 层 | 管什么 | 真源文件 |
|---|---|---|
| 1 结构层 | 目标弧/因果链/无废场/反转与价值转变/留存节拍 | screenplay-fullflow 六道（④四问+⑥删除测试/五要素/五问） |
| 2 耳感层 | 黄金3秒/强钩子/三有/心痒/悬念前置/节拍钉死/每镜尾钩/一集一金句 | novel-writer 番茄文稿 + ch1 耳感六法（本仓实战教训） |
| 3 台词手艺层 | ≤15字/潜台词/冲突≤3回合/润滑手法/半句话自检/声口遮名 | OnlyShot scripting-craft + A式契约 + ch1 九轮刀修 |
| 4 纪律层 | 转译三重约束/裁定门/旁白三类话/OOC 角色卡/称谓语汇 | script_narrative.md（A线）+ ②角色圣经（B线） |
| 5 可配性层 | 双口径语速/拗口连缀/TTS易错点/声线选角对表 | script-doctor 查3 + voice_preflight.py |

**核心认知：结构好≠耳感好≠可配好。** 第一章的教训就是四道技术门禁全绿但剧本被斥「狗屁不通」——六道压力测试审的是结构，观众划走是因为耳感；配音炸是因为语速。五层各有各的门，一层都不能替另一层兜底。

## 三、三道门（任何剧本进生产的硬顺序）

```
门① 结构门 = 六道⑥压力测试（病灶定位+回退修完）
门② 文字/叙事门 = script-doctor 两层八查（fresh-eyes 铁律：未参与写作的上下文执行）
门③ 配音门 = voice_preflight.py（FAIL=拒跑配音）
```

**不过检不出片。** 门②的 fresh-eyes 铁律与门①的「同一道连续退回3次停机」互为补充：作者自查无效，作者退回循环也要熔断。

## 四、本次探查发现的缺口与接线（2026-10-29 已做）

| # | 缺口 | 处置 |
|---|---|---|
| 1 | 六道⑤写台词无耳感/可配性约束（共同语法只有"可拍/拒小说化/无引号"） | SKILL.md 总控层加「⑤出口附加门」（耳感+语速帽+半句话+旁白三类话），不改参考件原文 |
| 2 | 六道⑥只审结构，不审文字与可配性 | SKILL.md ROUTING 补「⑥之后双门串联」：script-doctor → voice_preflight |
| 3 | ROUTING 不完整（缺 script-doctor/番茄文稿/voice_preflight 三个真源指针） | SKILL.md ROUTING 段重写，本图作为配套路线文档挂链 |
| 4 | B 线原创无 OOC 机制 | 不是缺口：六道②角色圣经即 OOC 底（②产物=角色卡真源），门②查 OOC 时以它为准 |

## 五、开工口令速查

- **改编（道劫章）**：「按 script_execution_script 写第X章剧本」→ 走 A 线全链（转译通道+裁定门）
- **原创短剧**：「从零跑一个剧本：我要做一部……」→ 六道 → 双门 → OnlyShot/本仓产线
- **只审剧本**：「审一下这个剧本」→ 门①（结构）或 script-doctor（文字/叙事）按需；完整链=①→②
- **改台词/耳感**：novel-writer 番茄文稿加载 → 逐镜改（报镜号+原文→改文，count验证+复读现值）
- **要快验效果**：16宫格分镜图 / TTS 侧车广播剧（38期视频两技巧的本仓等价物）
