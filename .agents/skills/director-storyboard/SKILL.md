# 导演计划与分镜表设计

## 总原则

**不是写「画面是什么」，而是设计「这场戏如何被拍出来」。**

每镜的判断八合一：导演叙事判断 + 摄影视觉设计 + 表演逻辑 + 剪辑节奏与切点 + 声音听觉叙事 + 连续性时空控制 + AI 视频模型可执行性。

决策优先级（冲突时前者胜）：**叙事清晰 > 人物表演 > 时空连续 > 情绪递进 > 剪辑节奏 > 视觉高级感 > 视觉炫技**。

导演自主判断域（不必问用户）：景别、焦段、机位、运镜、构图、表演、剪辑点、声音、节奏、光线。须问/须守的：用户给定的剧情、人物、时长、台词、首尾约束、产线规格。

## 一、导演判断层

### 每个镜头必须有戏剧功能

一镜至少服务一个目的（自查用清单）：建立空间/人物关系、引导注意力、提供信息、展示动作、强化表情、制造悬念、延迟或揭示信息、建立情绪、加速/放慢节奏、制造压迫/孤独/距离/反差、强调关键人物/道具/动作/台词、完成转折或转场。**禁止连续堆砌「漂亮但无叙事作用」的镜头**；一镜答不出功能=砍或并。

### 抽象情绪必须转成可拍行为

禁只写「人物很紧张/悲伤/惊讶」。必须写成：**眼神 + 面部变化 + 身体动作 + 停顿 + 呼吸 + 视线 + 动作节奏**。
例：听见意外消息后，动作短暂停顿、呼吸轻滞、视线转向声音来源，再回看对方，表情逐步从正常变为难以置信。

### 情绪必须形成曲线

默认：**建立 → 引入 → 发展 → 累积 → 转折 → 高潮 → 余韵**。可按剧情压缩变形，但禁无理由的情绪跳跃。导演计划里先写本章/本场曲线，再落镜。

## 二、摄影层

每镜自动决定：**景别 + 机位/高度 + 焦段感 + 构图 + 主体位置 + 前中后景关系 + 景深 + 对焦 + 光线 + 色调 + 纹理 + 氛围 + 镜头运动**。

- **景别语义**（禁全片同景别）：远景=建立空间与人物关系；中景=动作与关系；近景=强化情绪；特写=心理/关键信息；极特写=危险/决定性瞬间/关键细节；Insert=道具信息插入。
- **焦段心理**（禁每镜同焦段逻辑）：广角=空间/透视/压迫/夸张关系；标准=自然日常真实感；中长焦=空间压缩/偷窥感/孤独/心理压力；长焦特写=高强度情绪/眼神/嘴角/手部/关键道具。
- **运镜词汇表**(中文系):推、拉、摇、移、跟、升降、环绕、跟随(英文系 Static/Push-in/Pull-out/Dolly/Tracking/Pan/Tilt/Crane/Arc/Rack Focus);多镜扩展记号=【镜头N】(中文系)或 [Shot N](英文系)。
- **运镜必有叙事原因**：平静→稳定克制；紧张→轻微推进/手持/焦点变化；失控→明显手持或快速跟拍；意识到关键信息→推进/变焦点；受冲击→突然停止、切特写、改变运动方向或节奏。禁无理由旋转、环绕、航拍、快推等炫技。
- **光线写真实光源**（禁「电影感灯光」空词）：窗光/顶灯/路灯/屏幕光/火光/黄昏侧逆光等，按场景定主光方向、阴影方向、轮廓光、反差、人物与背景分离。
- **色彩服务剧情**：平静=自然柔和低对比；压迫=低饱和深阴影高反差；温暖=暖环境光自然肤色；孤独=冷环境肤色轻分离；高潮=强化局部色彩或对比。

## 三、表演层

**先心理，后动作。**人物要素：目标 + 当前情绪 + 情绪变化 + 身体状态 + 视线 + 注意力对象 + 动作 + 微表情 + 呼吸 + 停顿 + 与他人的空间关系。

禁：始终盯镜头、站定不动、每句夸张手势、全程表情不变（「会移动的立绘」）。自然微动作白名单：呼吸、停顿、犹豫、移开视线、吞咽、轻微转身、手部动作、重心变化、眼神变化。

## 四、剪辑层

镜头是叙事链不是拼接。相邻镜匹配关系（至少其一）：动作匹配、视线匹配、方向匹配、轴线关系、空间连续、时间连续、情绪连续、声音先行、声音延续、信息递进、视觉匹配、反应镜头、平行剪辑、对比剪辑、动作切、情绪切、信息揭示切。

- **节奏**：平静=镜头完整稳定；信息出现=适当缩短；冲突升级=提高切换频率；关键情绪=减剪辑给反应时间；高潮≠疯狂快切（选有价值的镜头变化）；高潮后=延长镜头让情绪落地。
- **切点来源**：动作开始/结束、台词关键词、表情变化、眼神、音效、音乐重拍、环境变化、信息揭示、情绪转折、视觉匹配。**禁机械平均切**。
- **台词与反应镜头**：禁一句台词固定一镜。按对白重要程度设计说话者/对方反应/关键字特写/插入镜头/停顿/留白；高情绪对白可用「说话→对方反应→回到说话者」；关键台词用降环境声+减运动+缓推+延长停顿强化。

## 五、连续性与空间逻辑

全片恒保：人物身份、面容、发型、服装、配饰、道具、左右位置、动作状态、视线、光线方向、时间顺序、空间结构。

- **动作接力**：上一镜抬手，下一镜不能突然放下；上一镜向右走，下一镜保持合理方向（剧情明确改变除外）。
- **180° 轴线**：默认不跨轴；对话双方左右位置稳定；对话默认 A 看画面右侧、B 看画面左侧；视线方向合理；空间始终可理解。

## 六、声音层

声音参与叙事不是附属。层级：**对白 → 关键动作音 → 环境音 → 空间声音 → 声音过渡 → 非叙事音乐**。真实声学：远处声更弱混响多、近处更清晰、室内自然反射、户外开放、封闭空间更集中。

三字段分工（对接 h3-prompt-writing 同名字段）：`overall_soundscape`=贯穿全片的环境底噪/空间声/远近层次；`detailed_description` 内嵌=单镜瞬时音效/动作音；`non_diegetic_music`=仅观众听见的 BGM（类型/情绪/速度/进入/递进/高潮/结束；无音乐写「无」）。本地产线附加：旁白走外部 TTS 轨不进 H3 提示词（见 h3-prompt-writing「Manying Pipeline Audio Policy」）。

## 七、AI 生成稳定性

专业≠堆词。避免互相冲突的指令：高速运动+极度稳定 / 浅景深+全部清晰 / 柔光+强硬顶光 / 静止+高速奔跑。优先保证：**主体明确 + 动作明确 + 空间明确 + 摄影明确 + 情绪明确**。禁用「电影感/震撼/唯美/高级/真实」空词代替具体摄影与表演指令。

## 八、镜头设计操作层

- **首镜**：承担开场功能（谁/在哪/发生什么/氛围），不强制大全景——悬疑可藏信息，强冲突可直接进关键动作。
- **后续镜**：连续时间戳不倒退不跳跃；时长符合动作与对白（动作复杂→更长；对白长→更长；关键信息→给理解时间；高潮≠必快切）。
- **结尾镜**：必担至少一项——情绪收束/剧情落点/信息完成/悬念保留。禁随意结束。
- **镜头公式**（按需组织非堆满）：时间位置+景别+机位+焦段感+构图+主体位置+动作+微表情+视线+环境变化+光线+景深+运镜+对焦变化+台词+瞬时音效+剪辑意图+情绪目的。
- **主体首现**写位置+状态+动作+与场景关系；**后续出现**复用 Subject 标签但状态变化时重写当前位置/动作/情绪/道具状态。
- **镜头因果**：相邻镜至少一种明确关系——动作/视线/空间/声音/情绪/信息延续、视觉匹配、反应关系、时间推进。禁无理由空间或动作跳变。

## 九、本地产线嫁接（分镜表落地口径）

- **单镜时长 5-15s**（H3 训练区），帧数恒落 **17k+5 网格**（124/158/192/294/362…，见 docs/comfyui-kb/参数速查.md 与产线 §二）——分镜表每镜标秒数，工程侧自动吸附网格。
- **跨场/动作衔接镜**：产线用上一镜视频末帧做下一镜首帧（末帧交接，成片抽帧不用 K2 图）——分镜表设计时衔接镜首帧状态要与上场末镜呼应。
- **一镜内多 Shot vs 多镜**：H3 提示词原生支持一段多镜（[Shot 1]…[Shot 2]）；AutoContext 多段拼接=一镜内延长。分镜表「镜」=一次生成任务，「Shot」=镜内切——两层勿混。
- 分镜表产出后：单镜提示词按 h3-prompt-writing（2611.3 双模式）展开；App 分镜表字段（情绪/台词/时长等）由产线组装器消费。
- 视频生成分辨率/多采升档按现役产线口径（Windows 线，见 docs/comfyui-kb/分镜H3视频产线.md §三）。

## 十、输出前自检

1. 每镜有戏剧功能？2. 情绪成曲线？3. 抽象情绪全转成可拍行为？4. 相邻镜有因果/匹配关系？5. 180° 轴线与左右关系稳？6. 动作接力无断裂？7. 时间戳连续不倒退？8. 结尾镜有收束？9. 无炫技空镜头？10. 无空词（电影感/震撼类）？11. 无冲突指令？12. 单镜时长在 5-15s 训练区？13. 台词镜有反应设计？14. 声音三层各归其位？
