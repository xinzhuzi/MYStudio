## 2026-11-08 三套工作流原件定谳（夸克盘取件，解析原件 JSON）

三套工作流已存档 `workflows/`（原件+README）。**由 JSON 本体推翻/补正此前全部帧证据推断**：

- **D2 终裁**：发布包真 LoRA = `dmad_minimax_h3_8step_full_critic_comfyui` @1.0（8 步 DMD 蒸馏）。
  frame_0013 的 `fi2v_lightx2v_turbo_4step_v0.1_comfy` 是录屏旧变体，帧证据就此作废；
  「fi2v=镜像改名」的中间假设同样作废（压根不是 lightx2v 件）。
- **D6 关闭**：低显存版切块节点真名 = `MiniMaxLowVRAMAttention`（参数=切分数，1=不切）+
  `MiniMaxChunkFeedForward`（切分数+4096）；同栈带 `MiniMaxH3MemoryEfficientSageAttentionPatch`
  （Sage 真身）——视频把 sage 安到 ModelAttentionBackend 头上的口误由原件三重坐实。
- **BlockSparseAttention 实参**：sol-attn / tau 1.3 / start 0.2 / end 1.0 / min_tokens 12288 /
  exact_kv_and_rows；ModelAttentionBackend=comfy kitchen attention（INT8）。
- **默认 UNet = hybrid 班长拼接件**（`minimax_h3_hybrid_fl2va_ref2va_b25-49-int8`，本仓 1104 已知档案），
  非 ref2va_pruned_int8。
- **缺口件**：latent 放大器引用 `3d_fp16_V2`，盘内只有 v1_bf16/lms_v0.1——V2 须另行获取。
- 「7+1=8 与口播吻合」的推断由 widgets 证实（1st=7 + SigmaRefiner extra 1；8 步 DMD LoRA 同船）。
